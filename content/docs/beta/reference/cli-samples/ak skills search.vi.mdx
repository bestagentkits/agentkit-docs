Dùng `ak skills search` khi bạn biết keyword của capability nhưng chưa biết
reference `<kit>/<skill>` chính xác.

## Cách dùng

```bash
ak skills search <query>
```

Một hoặc nhiều query token được nối bằng dấu cách. Lệnh không có cờ riêng.

## Matching và ranking

Search chạy trên cùng tập installed-plus-available đã deduplicate như
`ak skills list`. Matching dùng substring không phân biệt hoa thường:

| Field | Điểm cho mỗi token khớp |
| --- | --- |
| Tên skill | `3` |
| Mỗi tag | `2` |
| Description | `1` |

Điểm được cộng lại. Kết quả sort theo điểm giảm dần, rồi canonical reference
tăng dần. Installed metadata thắng khi cùng reference cũng tồn tại trong local
kits source.

Lệnh đọc `AGENTKIT_PLUGIN_DIR` hoặc `~/.claude/plugins` và
`AGENTKIT_KITS_DIR` hoặc `./kits`. Nó không tìm remote registry và không gửi
request auth hay entitlement.

## Đầu ra

Human stdout dùng cùng table với list. JSON thành công dùng `kind=assets.list`,
không phải search kind riêng, với kết quả dưới `data.skills[]`. Mỗi record có
`kit`, `name`, `version`, `description`, `tags`, `runtime` và `installed`.

Không có kết quả khớp vẫn là thành công với list rỗng.

## Tác động và mã thoát

Lệnh chỉ đọc và không tương tác. Không có cache mutation, preview, backup hay
force behavior.

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Search hoàn tất, kể cả không có kết quả. |
| `1` | Không đọc được local source. Bỏ hẳn query bị Cobra từ chối và hiện cũng thoát `1`. |
| `2` | Query được cung cấp chỉ còn whitespace sau khi nối, hoặc cờ không hợp lệ. |

Với đường query chỉ có whitespace, JSON error envelope hiện có thể ghi
`exit_code: 1` trong khi process thoát `2`.
