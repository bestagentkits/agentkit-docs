Dry-run credential redaction for Claude Code session JSONL files. Detection is best-effort and intentionally pattern-based.

**When to use it:** Run before attaching Claude Code transcripts to issues, PRs, or support reports. Default mode is dry-run; apply requires both `--apply` and `--yes`.

Dry-run is read-only. Apply snapshots each affected session root, then rewrites changed JSONL files via temp-file and rename.

### Usage

```bash
ak sessions redact [flags]
```

### Examples

```bash
ak sessions redact --json
ak sessions redact --project myapp --session 550e8400 --json
ak sessions redact --project myapp --apply --yes --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--apply` | Rewrite changed session files after taking a session-root backup |
| `--project stringArray` | Project name to scan; repeatable |
| `--redact-emails` | Also redact email addresses |
| `--session stringArray` | Session ID to scan; repeatable |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | scan or rewrite failed |
| `2` | invalid flags or --apply without --yes |
