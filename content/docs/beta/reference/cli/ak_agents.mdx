Manage individual agents from any kit—list, install, remove, show, and search per-role markdown personas that install into the underlying agent runtime.

**When to use it:** Use as the entry point for any per-agent operation; subcommands handle the action. Run `ak agents list` to see what's installed and available, or `ak agents search` to find agents by keyword.

This group is read-only at the top level; each subcommand documents its own disk effects.

### Examples

```bash
ak agents list                         # show what's installed + available
ak agents search code                  # find agents matching a keyword
ak agents install engineer/researcher  # install one agent
ak agents show engineer/researcher     # inspect metadata
ak agents remove engineer/researcher   # uninstall
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
