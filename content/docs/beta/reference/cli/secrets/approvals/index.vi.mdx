Trả lời các yêu cầu secret gửi từ một máy đồng bộ khác.

Dùng `ak secrets approvals` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Answer secret requests sent from another synced machine

### Synopsis

When an agent on one of your synced devices asks for a secret no grant covers, that device sends a sealed, signed request to your other devices. List them here and answer one with approve or deny; the requesting device checks the signed answer before it grants anything, and an answer given there first withdraws the request. Only a human owner or editor device can answer. Requests asked on this device are answered with `ak secrets approve`.

### Examples

```
  ak secrets approvals list
  ak secrets approvals approve 3f2a --ttl 2h
  ak secrets approvals deny 3f2a --json
```

### Options

```
  -h, --help             help for approvals
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
