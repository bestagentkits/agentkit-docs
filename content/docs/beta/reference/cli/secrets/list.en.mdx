Use `ak secrets list` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

List stored secret refs and metadata

### Synopsis

List every stored ref with its metadata (creator, created/rotated timestamps) and a footer naming any ref past its rotation window. Never prints a value: this reads only the on-disk index, not the backend, so it works even when the backend cannot enumerate or would prompt for consent per item. Use it to check what is stored before a set/rotate, or to build a provisioning report.

Effects:
  Read-only: reads the on-disk index.

Exit status:
  0   success
  2   invalid flags or arguments
  5   backend or index failure

```
ak secrets list [flags]
```

### Examples

```
  ak secrets list         # human-readable ref list
  ak secrets list --json  # machine-readable metadata array
```

### Options

```
      --backend string         Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway)
  -h, --help                   help for list
      --json                   Emit machine-readable JSON (implies --no-interactive)
      --no-interactive         Disable interactive prompts (CI-safe)
  -q, --quiet                  Suppress non-error output on stderr
      --unlock-with-recovery   Open the file backend's vault with a recovery private key and set a new passphrase
  -V, --verbose                Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                    Assume yes for all prompts
```
