Use `ak secrets recovery` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Manage the file backend's vault and its recovery keys

### Synopsis

The file backend keeps every secret in one age-encrypted vault opened with a passphrase. A recovery key is a second way in: an age keypair whose public half the vault is encrypted to, and whose private half you keep somewhere the host cannot reach. Without one, a forgotten passphrase means the vault is gone — there is no reset. These commands create the vault, add and remove recovery keys, and accept a vault that has moved backwards in time.

### Examples

```
  ak secrets recovery init --label laptop-card   # create the vault and its first key
  ak secrets recovery list                       # labels and fingerprints, never keys
  ak secrets recovery add age1... --label backup-card
  ak secrets recovery remove <fingerprint>       # cut a lost key out of future writes
```

### Options
