Quản lý các giá trị bí mật trong kho của AgentKit.

Chọn backend bằng `--backend`, sau đó đến biến môi trường `AGENTKIT_SECRETS_BACKEND`, rồi đến mục `secrets` trong `config.yaml` cấp người dùng ở thư mục home của AgentKit, theo đúng thứ tự đó. Nếu không đặt gì, AgentKit dùng keychain của hệ điều hành. Config của project không bao giờ được đọc cho lựa chọn này. Biến môi trường và `config.yaml` chỉ chấp nhận `keychain` hoặc `file`; backend `memory` (dữ liệu dùng xong bỏ) phải được yêu cầu bằng `--backend memory` trên dòng lệnh.

Backend `file` chỉ đọc passphrase của vault từ một terminal tương tác. Không có flag hay biến môi trường nào cung cấp passphrase, nên một lần chạy không có người trực tiếp dùng backend file sẽ không mở được vault, và một lần resolve bí mật do hook của agent kích hoạt sẽ thoát với mã 7. Hãy dùng backend keychain cho các lần chạy bằng script.

Dùng `ak secrets` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Manage named secret values (API keys, tokens)

### Synopsis

Store, read, list, delete, and rotate small named secret values behind the OS keychain, an age-encrypted vault (--backend=file, for a host with no usable keychain; see `ak secrets recovery`), or an in-memory --backend=memory dev backend. Values are written only to the active backend; ~/.agentkit/secrets/index.json holds metadata (ref, creator, timestamps, a short value hint, and an optional searchable profile) and never a value. Use it for an API key, token, or certificate AgentKit or an adapter needs at runtime, instead of an unmanaged .env file or shell export.

### Examples

```
  ak secrets set ${REF}                                  # interactive prompt
  ak secrets list --json                                 # machine-readable metadata
  ak secrets search stripe --environment production --json  # find a ref by metadata
  ak secrets describe ${REF} --json                      # one ref's full profile, never its value
```

### Options

```
  -h, --help             help for secrets
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
