Quản lý các giá trị bí mật trong kho của AgentKit.

Dùng `ak secrets` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Manage named secret values (API keys, tokens)

### Synopsis

Store, read, list, delete, and rotate small named secret values behind the OS keychain (or an in-memory --backend=memory dev backend). Values are written only to the active backend; ~/.agentkit/secrets/index.json holds metadata (ref, creator, timestamps) and never a value. Use it for an API key, token, or certificate AgentKit or an adapter needs at runtime, instead of an unmanaged .env file or shell export.

### Examples

```
  ak secrets set ${REF}                                  # interactive prompt
  echo -n "${VALUE}" | ak secrets set ${REF} --value=-  # pipe from stdin
  ak secrets get ${REF}                                  # prints [redacted]
  ak secrets list --json                                 # machine-readable metadata
```

### Options

```
  -h, --help             help for secrets
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
