---
title: ak secrets alias unset
description: Remove an alias; the secret it pointed at is untouched.
---

Use `ak secrets alias unset` to drop an alias name. Only the mapping goes
away: the stored secret it pointed at keeps its value and its grants.

## Usage

```bash
ak secrets alias unset <NAME>
```

Exactly one argument is required. The command has no flags of its own. It
writes `~/.agentkit/secrets/aliases.json` and never touches a value.

## Output

Human stdout prints `removed NAME (was REF)`.

JSON success uses:

```text
schema_version: 1
kind: secrets.alias
data.action: unset
data.aliases[]: name, ref, updatedAt
```

`data.aliases` holds the one removed alias with the ref it pointed at.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success. |
| `2` | Invalid flags or arguments, or an invalid row in the aliases file. |
| `3` | No such alias. |
| `5` | The aliases file could not be read or written. |
