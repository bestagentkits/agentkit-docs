---
title: ak secrets alias list
description: List every alias on this device and the ref each one points at.
---

Use `ak secrets alias list` to see which stored secret each alias name
currently follows. It prints names only, never a value.

## Usage

```bash
ak secrets alias list
```

The command takes no positional arguments and has no flags of its own. It is
read-only: it reads `~/.agentkit/secrets/aliases.json` and never opens the
backend.

## Output

Human stdout prints one `NAME -> REF` line per alias, sorted by name. With no
aliases it prints `(no aliases; set one with ak secrets alias set NAME REF)`.

JSON success uses:

```text
schema_version: 1
kind: secrets.alias
data.action: list
data.aliases[]: name, ref, updatedAt
```

`data.aliases` is an empty array when nothing is stored.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success, including an empty list. |
| `2` | Invalid flags or arguments, or an invalid row in the aliases file. |
| `5` | The aliases file could not be read. |
