Dùng `ak secrets alias list` để xem mỗi tên alias hiện đang theo secret đã lưu
nào. Lệnh chỉ in tên, không bao giờ in giá trị.

## Cách dùng

```bash
ak secrets alias list
```

Lệnh không nhận argument và không có cờ riêng. Lệnh chỉ đọc: đọc
`~/.agentkit/secrets/aliases.json` và không bao giờ mở backend.

## Đầu ra

Stdout cho người dùng in một dòng `NAME -> REF` cho mỗi alias, sắp xếp theo
tên. Khi không có alias nào, lệnh in
`(no aliases; set one with ak secrets alias set NAME REF)`.

JSON thành công dùng:

```text
schema_version: 1
kind: secrets.alias
data.action: list
data.aliases[]: name, ref, updatedAt
```

`data.aliases` là mảng rỗng khi chưa lưu alias nào.

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Thành công, kể cả khi danh sách rỗng. |
| `2` | Cờ hoặc argument không hợp lệ, hoặc một dòng không hợp lệ trong file alias. |
| `5` | Không đọc được file alias. |
