Lưu giá trị bí mật theo tên.

Dùng `ak secrets set` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Store a secret value

### Synopsis

Store a value under &lt;ref&gt; in the active secrets backend. The value is read from --value=- (stdin), --value-file=&lt;path&gt;, or an interactive, non-echoing prompt — never from --value=&lt;literal&gt; on the command line, which would leak the value into shell history and process listings (ps, /proc). The active backend allows up to no limit per value. Use it before the first run that needs $&#123;REF&#125;, or with --force to overwrite an existing value.

Effects:
  Writes the value to the active backend and creates or updates the ref's metadata (never a value) in ~/.agentkit/secrets/index.json.

Exit status:
  0   success
  2   invalid flags or arguments
  4   ref already exists and --force was not passed
  5   backend or index failure

```
ak secrets set <ref> [flags]
```

### Examples

```
  ak secrets set ${REF}                                  # interactive, non-echoing prompt
  echo -n "${VALUE}" | ak secrets set ${REF} --value=-  # pipe from stdin
  ak secrets set ${REF} --value-file ${PATH}             # read from a file
  ak secrets set ${REF} --force                          # overwrite an existing value
```

### Options

```
      --backend string      Storage backend: keychain (default) or memory (dev/test; values and its index are throwaway)
      --force               Overwrite an existing value instead of failing
  -h, --help                help for set
      --json                Emit machine-readable JSON (implies --no-interactive)
      --no-interactive      Disable interactive prompts (CI-safe)
  -q, --quiet               Suppress non-error output on stderr
      --value string        Secret value source: '-' reads from stdin. A literal value is rejected — use --value=- or --value-file
      --value-file string   Path to a file containing the secret value
  -V, --verbose             Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                 Assume yes for all prompts
```
