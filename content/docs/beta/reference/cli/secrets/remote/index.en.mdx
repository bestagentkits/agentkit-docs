Use `ak secrets remote` on a machine that must not hold secrets, such as a
cloud coding-agent sandbox. It asks the vault's remote MCP endpoint to run a
program on one of your own online relay devices, under that device's exec
grants, and prints the output with every released value redacted. The values
never reach the calling machine. Running the group command itself prints help.

<Callout type="warning" title="Preview">
  `ak secrets remote` is a preview. The remote vault endpoint it uses is
  pre-release and may not be available for every account yet. If the sign-in
  server does not offer device sign-in, `ak secrets remote login` fails with
  exit `5`.
</Callout>

## Usage

```bash
ak secrets remote <command>
```

```bash
ak secrets remote login
ak secrets remote run --env STRIPE_API_KEY=STRIPE_API_KEY -- stripe customers list
```

The group accepts no positional arguments and has no flags of its own.

## Workflow

1. On a device that holds the vault, keep a relay connection open:

   ```bash
   ak secrets sync now --watch --relay
   ```

   See [Keep a device online](../../guides/secrets-vault-remote-mcp#keep-a-device-online).
2. On the machine that must not hold secrets, sign in with
   [`ak secrets remote login`](../cli/ak_secrets_remote_login). For a sandbox
   that does not keep its AgentKit home, use `--export` on a trusted machine
   and set the printed token as `AK_VAULT_MCP_REFRESH_TOKEN` in the sandbox's
   secret store.
3. Run the program with
   [`ak secrets remote run`](../cli/ak_secrets_remote_run). If no exec grant on
   the relay device covers the run, the command exits `8` and a request waits
   on that device. Approve it there with `ak secrets approve`, then run the
   command again. Approve every scope a task needs before the task starts.

## What passes through where

- The secret values reach the relay device and the program it runs, never the
  calling machine.
- The vault server sees the command, the variable and secret names, and the
  redacted output in memory while it passes them on.
- Redaction removes exact values only. A program that prints a value encoded,
  split, or in part is not caught.

## Subcommands

| Command | Outcome | Disk effect |
| --- | --- | --- |
| [`ak secrets remote login`](../cli/ak_secrets_remote_login) | Sign in with a device code, or export a refresh token for a sandbox. | Writes `AGENTKIT_HOME/state/vault-remote.json` (0600), unless `--export`. |
| [`ak secrets remote run`](../cli/ak_secrets_remote_run) | Run a program on a relay device and print its redacted output. | Renews the sign-in in the same file when needed. Runs nothing locally. |

No subcommand reads the local vault.

## Exit behavior

| Exit | Meaning |

| `0` | Success. |
| `1` | Command failure. |
| `2` | Invalid flags or arguments. |
