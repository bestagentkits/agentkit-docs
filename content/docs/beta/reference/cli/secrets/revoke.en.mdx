Use `ak secrets revoke` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Remove an agent's grants on a secret, or all of them

### Synopsis

Delete the grants an agent binary holds. Without --all this removes every decision — allow and block alike — on one exact scope, which is also how a block is cleared. --all is the panic button: it removes every grant that fingerprint holds, across all secrets, projects, and purposes.

An exec grant is revoked by naming it the way it was granted, with --exec and --env; any program hash matches, so a grant to a program that has since changed or been removed can still be cleared; pass the program by the path `ak secrets grants` prints if it is gone. An ordinary revoke leaves exec grants on the same secret in place and says how many remain. --all removes exec grants too.

This revokes grants, not secrets. The stored values are untouched and any copy the agent already read is still out there, so treat a panic revoke as the first step and `ak secrets rotate <ref>` as the second.

Effects:
  Removes matching rows from the grants file under AGENTKIT_HOME. The stored secret values are untouched, and so is any copy an agent already read.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak secrets revoke [<ref>] [flags]
```

### Examples

```
  ak secrets revoke ${REF} --agent sha256:${HASH}          # one scope
  ak secrets revoke --agent sha256:${HASH} --all           # panic button
```

### Options

```
      --agent string     Agent binary fingerprint, sha256:<64 hex> (required)
      --all              Revoke every grant this agent holds, across all secrets
      --env string       Environment variable the program receives the secret in (needs --exec)
      --exec string      Program the secret is revoked for, by name on PATH or by path; makes this an exec scope (needs --env)
  -h, --help             help for revoke
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   Project slot; defaults to the AK project containing the current directory
      --purpose string   Purpose label of the grant to remove; matched literally
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
