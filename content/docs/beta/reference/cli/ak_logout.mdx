Clear local AgentKit credentials. Removes the CLI registry credential but preserves paid App device sessions.

**When to use it:** Before handing off a machine, or to force a fresh login. A missing session exits 0—idempotent.

Removes the CLI registry credential from the auth session store.

### Usage

```bash
ak logout [flags]
```
