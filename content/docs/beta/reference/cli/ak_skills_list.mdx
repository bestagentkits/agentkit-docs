## ak skills list

List installed skills

### Synopsis

What it does:
  Enumerate the skills installed on this machine, optionally filtered by kit or tag.

Who it's for:
  Both: power devs scripting installs (--json) and users browsing what's available.

When to use it:
  Run before `ak skills install` / `remove` to confirm what is and isn't already on disk.

Examples:
  ak skills list
  ak skills list --kit engineer
  ak skills list --json | jq .skills

What changes on disk:
  Read-only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak skills list [flags]
```

### Options

```
  -h, --help             help for list
      --json             Emit machine-readable JSON (implies --no-interactive)
      --kit string       Filter by kit name
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --tag strings      Filter by tag (repeatable)
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
