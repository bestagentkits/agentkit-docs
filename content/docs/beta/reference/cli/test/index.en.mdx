Use `ak test` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Plan and execute repository test-impact checks

### Synopsis

Use repository-owned manifests to select checks conservatively. Mandatory policy checks always apply. Semantic observations require explicit consumer consent; default planning stays offline.

### Examples

```
  ak test optimize --base origin/dev --json
  ak test benchmark corpus.json --json
```

### Options

```
  -h, --help             help for test
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
