Đánh giá hiệu quả thực thi dựa trên bộ dữ liệu và bằng chứng được chỉ định.

Dùng `ak eval` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Run controlled skill and agent evaluations

### Synopsis

Run trusted local suites in isolated workspaces and runtime homes. Graders check output independently; model calls may incur provider charges.

### Examples

```
  ak eval run suite.json --json
  ak eval run holdout-suite.json
```

### Options

```
  -h, --help             help for eval
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
