Print the resolved OS install path for a kit without performing an install.

**When to use it:** Confirm the destination before `ak kit init`, or when scripts need the path without triggering an install.

Read-only. Respects the `AGENTKIT_PLUGIN_DIR` override.

### Usage

```bash
ak kit install-path <kit-name> [flags]
```

### Examples

```bash
ak kit install-path engineer            # prints ~/.claude/plugins/ak-engineer
ak kit install-path engineer --json     # {"kit":"engineer","path":"..."}
```
