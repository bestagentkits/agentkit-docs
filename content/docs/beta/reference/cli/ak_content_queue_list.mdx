Display all entries in the scheduled-post queue, with their status, scheduled time, and attempt count.

**Who it's for:** Both: power devs (--json) and non-technical users.

**When to use it:** After scheduling posts via `ak content publish --at`, to see what is queued.

**What changes on disk:** Read-only (reads ~/.agentkit/content/queue.json).

### Usage

```bash
ak content queue list [flags]
```

### Examples

```bash
ak content queue list
ak content queue list --json | jq '.entries'
```

### Flags

| Flag | Description |
| --- | --- |
| `-h, --help` | help for list |

| `--no-interactive` | Disable interactive prompts (CI-safe) |
| `-q, --quiet` | Suppress non-error output on stderr |
| `-V, --verbose` | Extra diagnostic output on stderr (loses to --quiet) |
