Search available skills by name, description, and tags. Results are ranked deterministically; ties are broken by `<kit>/<skill>` alphabetical order.

**When to use it:** To find a skill by keyword when you don't know the exact `<kit>/<skill>` ref. Follow up with `ak skills show` before installing.

Read-only.

### Usage

```bash
ak skills search <query> [flags]
```

### Examples

```bash
ak skills search browser
ak skills search 'code review' --json
```
