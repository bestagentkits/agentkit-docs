Browse and install kit skills—the primary unit of value users discover and install. For per-skill runtime env management (verify, repair, upgrade), see `ak skill`.

**When to use it:** Use as the entry point for any per-skill catalog operation; subcommands handle the action.

Read-only at the group level; subcommands document their own disk effects.

### Examples

```bash
ak skills list                            # show what's installed + available
ak skills search browser                  # find skills matching a keyword
ak skills install engineer/agent-browser  # install one skill
ak skills show engineer/agent-browser     # inspect metadata
ak skills remove engineer/agent-browser   # uninstall
```
