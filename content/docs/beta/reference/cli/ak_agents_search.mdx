Search available agents by name, description, and tags. Results are ranked deterministically; ties broken by &lt;kit>/&lt;agent> alphabetical order.

**Who it's for:** Power devs scripting (--json) and users discovering what's available.

**When to use it:** To find a agent by keyword without knowing the exact name.

**What changes on disk:** Read-only.

### Usage

```bash
ak agents search <query> [flags]
```

### Examples

```bash

ak agents search 'code review' --json
```
