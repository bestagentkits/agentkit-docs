Parse a plan directory and print a structured summary of phases, task counts, and progress.

**When to use it:** Inspecting plan structure, dumping a parsed view for tooling, or feeding into a script via `--json`.

Read-only.

### Usage

```bash
ak plan parse <path> [flags]
```

### Examples

```bash
ak plan parse ./plans/my-plan
ak plan parse ./plans/my-plan --json
```

### Flags

| Flag | Description |
| --- | --- |
| `-h, --help` | help for parse |
| `--json` | Emit machine-readable JSON (implies --no-interactive) |
| `--no-interactive` | Disable interactive prompts (CI-safe) |
| `-q, --quiet` | Suppress non-error output on stderr |
| `-V, --verbose` | Extra diagnostic output on stderr (loses to --quiet) |
| `-y, --yes` | Assume yes for all prompts |

### Output modes
