Reads the same local activity event log used by the dashboard and desktop app. Use list for a finite snapshot, tail for a live stream, and stats for local skill usage aggregates.

**Who it's for:** Power devs, AI agents, CI jobs, and reviewers who need the desktop activity feed from the CLI.

**When to use it:** Use when debugging recent ak run activity or when a headless workflow needs activity evidence.

**What changes on disk:** Read-only. Reads ~/.agentkit/activity/events.ndjson; AGENTKIT_HOME overrides the base dir.

### Examples

```bash
ak activity list --json
ak activity list --limit 20 --since 00000000000000000000-000000
ak activity stats --window 7d --json
ak activity tail --json
```
