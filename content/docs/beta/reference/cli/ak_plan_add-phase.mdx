Append a new `phase-NN-<slug>.md` file to an existing plan directory with a template header and empty todo checkboxes. The next sequential phase number is assigned automatically.

**When to use it:** When a plan needs a new phase after the initial bootstrap.

Creates `phase-NN-<slug>.md` in the plan directory.

### Usage

```bash
ak plan add-phase <plan-dir> <name> [flags]
```

### Examples

```bash
ak plan add-phase ./plans/my-plan "Deploy"
ak plan add-phase ./plans/my-plan "Integration Tests" --json
```
