Display a kanban board of plan phases with Todo, In Progress, and Done columns. Uses a Bubble Tea TUI on a real terminal; falls back to plain text when stdout is not a TTY.

**When to use it:** To visualize plan progress at a glance. Use `--json` for structured output in scripts.

Read-only.

### Usage

```bash
ak plan kanban [path] [flags]
```

### Examples

```bash
ak plan kanban
ak plan kanban ./plans/my-plan
ak plan kanban ./plans/my-plan --json
```

### Flags

| Flag | Description |
| --- | --- |
| `-h, --help` | help for kanban |
| `--json` | Emit machine-readable JSON (implies --no-interactive) |
| `--no-interactive` | Disable interactive prompts (CI-safe) |
| `-q, --quiet` | Suppress non-error output on stderr |
| `-V, --verbose` | Extra diagnostic output on stderr (loses to --quiet) |
| `-y, --yes` | Assume yes for all prompts |

### Output modes

| Mode | Behavior |

| `plain` | auto when stdout piped or --no-interactive |
