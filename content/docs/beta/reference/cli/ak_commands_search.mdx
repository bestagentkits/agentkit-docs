Search available slash commands by name, description, and tags. Results are ranked deterministically; ties are broken by `<kit>/<command>` alphabetical order.

**When to use it:** To find a command by keyword when you don't know the exact `<kit>/<command>` ref. Follow up with `ak commands show` before installing.

This command is read-only.

### Usage

```bash
ak commands search <query> [flags]
```

### Examples

```bash
ak commands search browser
ak commands search 'code review' --json
```
