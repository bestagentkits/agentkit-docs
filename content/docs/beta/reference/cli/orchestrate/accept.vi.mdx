Ghi nhận chấp nhận kết quả theo contract orchestration.

Đây là thao tác ghi run state và chạy declared verification command. CLI dispatch
chỉ có trên Darwin; không dùng kết quả từ harness nội bộ để suy ra host hỗ trợ.

Dùng `ak orchestrate accept` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Verify and accept one settled attempt's artifact receipt

### Synopsis

Verify and accept one settled attempt's artifact receipt. CLI dispatch requires Darwin; internal dispatch belongs to the active harness.

Effects:
  Writes private jobs.yaml, state.json and metrics.jsonl in the run directory. Acceptance runs declared verification commands; advance may copy declared artifacts and spawn CLI jobs.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate accept <run-dir> <job-id> --attempt <id> --result <receipt.json> [flags]
```

### Examples

```
  ak orchestrate accept ./run build --attempt build-1 --result receipt.json
  ak orchestrate accept ./run build --attempt build-1 --result receipt.json --json
```

### Options

```
      --attempt string   Current attempt ID returned by advance
  -h, --help             help for accept
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --result string    JSON receipt with settled outcome and artifact hashes
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
