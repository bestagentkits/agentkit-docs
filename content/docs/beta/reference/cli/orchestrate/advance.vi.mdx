Chuyển tiến trình kế hoạch sang bước tiếp theo theo trạng thái đã xác minh.

Lệnh ghi run state và có thể copy artifact đã khai báo rồi spawn job CLI. CLI
dispatch chỉ có trên Darwin; internal harness là đường riêng.

Dùng `ak orchestrate advance` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Reconcile attempts and dispatch dependency-ready jobs

### Synopsis

Reconcile attempts and dispatch dependency-ready jobs. CLI dispatch requires Darwin; internal dispatch belongs to the active harness.

Effects:
  Writes private jobs.yaml, state.json and metrics.jsonl in the run directory. Acceptance runs declared verification commands; advance may copy declared artifacts and spawn CLI jobs.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate advance <run-dir> [flags]
```

### Examples

```
  ak orchestrate advance ./run
  ak orchestrate advance ./run --json
```

### Options

```
  -h, --help             help for advance
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
