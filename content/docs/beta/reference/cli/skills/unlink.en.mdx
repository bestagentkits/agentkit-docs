Use `ak skills unlink` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Remove the SkillX link to your agentkit.best account

### Synopsis

Deletes the linked credential and record and revokes the grant at agentkit.best. Afterwards SkillX requests use SKILLX_TOKEN again when it is set. Running it with no link does nothing.

Effects:
  Removes SKILLX_LINK from the ak secrets store and AGENTKIT_HOME/state/skillx-link.json, then revokes the refresh token at agentkit.best best effort. Leaves SKILLX_TOKEN untouched. Never prompts.

Exit status:
  0   unlinked, or nothing was linked
  1   the secrets store or the link record could not be changed
  2   invalid flags

```
ak skills unlink [flags]
```

### Examples

```
  ak skills unlink
  ak skills unlink --json
```

```

  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
