---
title: ak skills publish
description: Upload one skill directory to SkillX as a release of @<handle>/<slug>. A new package is private by default.
---

Use `ak skills publish` to upload a single skill to SkillX. It publishes one
skill directory as a release of `@<handle>/<slug>`. A package that does not exist
yet is created **private**, so nothing becomes public until you change its
[visibility](./visibility).

## Usage

```bash
ak skills publish <dir> --name @<handle>/<slug> --version <semver> [--visibility <level>] [--channel <channel>] [--json]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--name @<handle>/<slug>` | Required | SkillX package name to publish to. |
| `--version <semver>` | Required | Semantic version of the release. |
| `--visibility <level>` | Private for a new package | Visibility to set on a new package: `public`, `unlisted` or `private`. |
| `--channel <channel>` | SkillX default | Release channel of this version. |
| `--json` | Off | Write one JSON envelope instead of human output. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

SkillX must be on, after `ak update --ssot` or with `AGENTKIT_SKILLX=1`. The
command uses your linked agentkit.best account first (see
[`ak skills link`](./link/index)) and falls back to `SKILLX_TOKEN` when no link
exists.

## Visibility

A new package is private unless you pass `--visibility`. Asking for a wider
level than SkillX allows without approval does not publish publicly: widening
needs approval on the SkillX dashboard and the command exits `7`. See
[`ak skills visibility`](./visibility) for the rules.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Published. |
| `1` | Command failure: SkillX offline, or the linked account or `SKILLX_TOKEN` missing, revoked or expired. |
| `2` | SkillX disabled, or invalid flags, name, version or skill directory. |
| `5` | The package or publisher was not found. |
| `6` | The release conflicts with the current state of the package on SkillX. |
| `7` | The change needs approval on the SkillX dashboard. |
