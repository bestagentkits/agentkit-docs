Dùng `ak skills unpublish` để gỡ một Skill khỏi SkillX. Không có `--version`, lệnh
xoá mềm cả package: SkillX ẩn nó và giữ có thể khôi phục trong 30 ngày bằng
[`ak skills restore`](./restore). Với `--version`, lệnh yank đúng release đó và
giữ nguyên phần còn lại của package.

## Cách dùng

```bash
ak skills unpublish @<handle>/<slug> [--version <version>] [--json]
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--version <version>` | Cả package | Chỉ yank release này. |
| `--json` | Tắt | Ghi một JSON envelope thay vì đầu ra cho người đọc. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Điều kiện

SkillX phải bật, sau `ak update --ssot` hoặc với `AGENTKIT_SKILLX=1`. Lệnh dùng
tài khoản agentkit.best đã liên kết trước và quay về `SKILLX_TOKEN`. Lệnh này
tách biệt với `ak skills kit unpublish`, vốn gỡ một Kit cá
nhân.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Đã unpublish hoặc yank. |
| `1` | Lệnh thất bại: SkillX offline, hoặc tài khoản đã liên kết hay `SKILLX_TOKEN` thiếu, bị thu hồi hoặc hết hạn. |
| `2` | SkillX bị tắt, hoặc cờ hay tên không hợp lệ. |
| `5` | Không tìm thấy package hoặc phiên bản. |
| `6` | Thay đổi xung đột với trạng thái hiện tại của package trên SkillX. |
| `7` | SkillX từ chối thay đổi với thông tin xác thực hiện tại. |
