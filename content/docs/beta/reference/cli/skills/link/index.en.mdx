Use `ak skills link` for the operation described below. The command help records its arguments, effects, and options.

Owner management is the exception to the link-first rule below. [`ak skills visibility`](../visibility), [`ak skills unpublish`](../unpublish), [`ak skills restore`](../restore), [`ak skills kit unpublish`](../kit/unpublish), and [`ak skills kit restore`](../kit/restore) send the stored `SKILLX_TOKEN` even while a link exists, because SkillX refuses the linked credential on those routes. Keep an unscoped `SKILLX_TOKEN` in the secrets store if you manage packages or kits you published.

## Command contract

Link SkillX to your agentkit.best account

### Synopsis

Signs in to agentkit.best with OAuth (authorization code with PKCE) and stores a SkillX credential scoped to https://skillx.sh/api. While a link exists every SkillX request to skillx.sh uses it and refreshes it; SKILLX_TOKEN is used only when no link exists. A revoked link fails with a re-link message instead of falling back. SkillX must also be linked to the same agentkit.best account (skillx.sh: Link with AgentKit). AGENTKIT_OAUTH_ISSUER selects another agentkit.best deployment.

Effects:
  Opens the agentkit.best sign-in page in the default browser (the URL is also printed on stderr) and waits on a 127.0.0.1 loopback port for the approval. Stores the linked credential as SKILLX_LINK in the ak secrets store and the non-secret record AGENTKIT_HOME/state/skillx-link.json. Replaces an existing or revoked link and revokes the replaced one. SKILLX_TOKEN is kept and used again after `ak skills unlink`. Never prompts beyond the browser approval.

Exit status:
  0   linked
  1   command failure: approval declined or timed out, agentkit.best unreachable or refused, or the secrets store unavailable
  2   invalid flags or AGENTKIT_OAUTH_ISSUER

```
ak skills link [--no-browser] [--timeout <duration>] [flags]
```

### Examples

```
  ak skills link
  ak skills link --no-browser
  ak skills link status --json
  ak skills unlink
```

### Options

```
  -h, --help               help for link
      --json               Emit machine-readable JSON (implies --no-interactive)
      --no-browser         print the sign-in URL without opening a browser
      --no-interactive     Disable interactive prompts (CI-safe)
  -q, --quiet              Suppress non-error output on stderr
      --timeout duration   how long to wait for the approval (default 5m0s)
  -V, --verbose            Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                Assume yes for all prompts
```
