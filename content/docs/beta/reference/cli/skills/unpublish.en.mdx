---
title: ak skills unpublish
description: Soft-delete a skill package on SkillX, restorable for 30 days, or yank a single release with --version.
---

Use `ak skills unpublish` to take a skill off SkillX. Without `--version` it
soft-deletes the whole package: SkillX hides it and keeps it restorable for 30
days with [`ak skills restore`](./restore). With `--version` it yanks that one
release and leaves the rest of the package in place.

## Usage

```bash
ak skills unpublish @<handle>/<slug> [--version <version>] [--json]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--version <version>` | Whole package | Yank only this release. |
| `--json` | Off | Write one JSON envelope instead of human output. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

SkillX must be on, after `ak update --ssot` or with `AGENTKIT_SKILLX=1`. The
command uses your linked agentkit.best account first and falls back to
`SKILLX_TOKEN`. This is separate from
`ak skills kit unpublish`, which removes a personal kit.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Unpublished or yanked. |
| `1` | Command failure: SkillX offline, or the linked account or `SKILLX_TOKEN` missing, revoked or expired. |
| `2` | SkillX disabled, or invalid flags or name. |
| `5` | The package or version was not found. |
| `6` | The change conflicts with the current state of the package on SkillX. |
| `7` | SkillX refused the change for the current credential. |
