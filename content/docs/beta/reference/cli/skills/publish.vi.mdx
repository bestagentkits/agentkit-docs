Dùng `ak skills publish` để upload một Skill lên SkillX. Lệnh publish một thư mục
Skill thành một release của `@<handle>/<slug>`. Package chưa tồn tại sẽ được tạo
ở chế độ **private**, nên không có gì thành public cho tới khi bạn đổi
[visibility](./visibility).

## Cách dùng

```bash
ak skills publish <dir> --name @<handle>/<slug> --version <semver> [--visibility <level>] [--channel <channel>] [--json]
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--name @<handle>/<slug>` | Bắt buộc | Tên package SkillX để publish. |
| `--version <semver>` | Bắt buộc | Phiên bản semantic của release. |
| `--visibility <level>` | Private với package mới | Visibility đặt cho package mới: `public`, `unlisted` hoặc `private`. |
| `--channel <channel>` | Mặc định của SkillX | Channel phát hành của phiên bản này. |
| `--json` | Tắt | Ghi một JSON envelope thay vì đầu ra cho người đọc. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Điều kiện

SkillX phải bật, sau `ak update --ssot` hoặc với `AGENTKIT_SKILLX=1`. Lệnh dùng
tài khoản agentkit.best đã liên kết trước (xem [`ak skills link`](./link/index))
và quay về `SKILLX_TOKEN` khi chưa có liên kết.

## Visibility

Package mới là private trừ khi bạn truyền `--visibility`. Nếu yêu cầu mức rộng
hơn mức SkillX cho phép mà chưa được duyệt thì lệnh không publish công khai: mở
rộng cần được duyệt trên dashboard SkillX và lệnh thoát với mã `7`. Xem
[`ak skills visibility`](./visibility) để biết quy tắc.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Đã publish. |
| `1` | Lệnh thất bại: SkillX offline, hoặc tài khoản đã liên kết hay `SKILLX_TOKEN` thiếu, bị thu hồi hoặc hết hạn. |
| `2` | SkillX bị tắt, hoặc tên, phiên bản, cờ hay thư mục Skill không hợp lệ. |
| `5` | Không tìm thấy package hoặc publisher. |
| `6` | Release xung đột với trạng thái hiện tại của package trên SkillX. |
| `7` | Thay đổi cần được duyệt trên dashboard SkillX. |
