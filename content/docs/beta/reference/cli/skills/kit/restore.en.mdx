---
title: ak skills kit restore
description: Restore a personal kit unpublished from SkillX within the last 30 days, with its visibility and revisions.
---

Use `ak skills kit restore` to bring back a SkillX kit that
[`ak skills kit unpublish`](./unpublish) or the SkillX dashboard soft-deleted
in the last 30 days. It returns with the visibility and revisions it had.
Restoring is reversible, so the command never prompts.

## Usage

```bash
ak skills kit restore <name> [--kit @<handle>/<name>] [flags]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--kit @<handle>/<name>` | The linked one | SkillX personal kit to restore. Required when the personal kit has no SkillX link. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

SkillX must be on, after `ak update --ssot` or with `AGENTKIT_SKILLX=1`. Like
an unpublish, SkillX accepts a restore only from an unscoped SkillX API key
(`ak secrets set SKILLX_TOKEN`) or a session on the
[SkillX dashboard](https://skillx.sh/dashboard), never from the agentkit.best
link token. A kit the SkillX admin unpublished can be restored only by the
admin.

## What it changes

Only the SkillX kit. SkillX moves the kit generation by one; with the skill
store on, the link record follows when it held the generation from before the
restore. Running the command again reports `unchanged`.

## Output

JSON uses `kind=skills.kit.restore` with these fields under `data`:

```text
personalKit, kit, host, status, restoredAt, generation, linkUpdated, warnings
```

`status` is `restored`, or `unchanged` when the kit was not unpublished.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Restored, or not unpublished (`status: unchanged`). |
| `1` | Command failure: SkillX offline, or the credential refused (a scoped key or the link token). |
| `2` | SkillX or the overlay flag disabled, invalid flags, or no linked kit and no `--kit`. |
| `5` | The SkillX kit was not found for this credential, or its 30-day restore window has passed. |
| `6` | The kit changed while the command ran. |
| `7` | A publisher the credential does not own, or a kit the SkillX admin unpublished. |
| `10` | Personal kits are not enabled for your account yet (SkillX answered `kit.api_disabled`). |
