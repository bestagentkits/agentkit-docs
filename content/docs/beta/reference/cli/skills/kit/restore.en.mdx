---
title: ak skills kit restore
description: Restore a personal kit that was unpublished from SkillX, within its 30-day window.
---

Use `ak skills kit restore` to bring back a personal kit that
[unpublish](./unpublish) removed from SkillX. SkillX keeps an unpublished kit
for 30 days. The command restores the kit and its revisions on SkillX; local
files are not touched.

## Usage

```bash
ak skills kit restore <name> [--kit @<handle>/<name>] [--json]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--kit @<handle>/<name>` | The linked one | SkillX personal kit to restore. Required when the personal kit has no SkillX link. |
| `--json` | Off | Write one JSON envelope instead of human output. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

Restore needs the same key as [unpublish](./unpublish): an unscoped SkillX API
key in `ak secrets` (`SKILLX_TOKEN`), used even while SkillX is linked through
agentkit.best. SkillX refuses the agentkit.best link and scoped keys, and the
command exits `1` with an error that names the key. Restoring is additive and
reversible, so it never asks for confirmation.

## When restore is refused

- **Past 30 days:** the window has closed and the command exits `5`.
- **Deleted by an administrator:** SkillX does not let the owner restore it and
  the command exits `7`.

## Output

JSON uses `kind=skills.kit.restore`.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Restored. |
| `1` | Command failure: SkillX offline, or the API key missing, scoped or expired, or the call came from the agentkit.best link. |
| `2` | SkillX or the overlay flag disabled, invalid flags, or no linked kit and no `--kit`. |
| `5` | The kit was not found, or its 30-day restore window has passed. |
| `7` | An administrator deleted the kit, so the owner cannot restore it. |
| `10` | Personal kits are not enabled for your account yet (SkillX answered `kit.api_disabled`). |
