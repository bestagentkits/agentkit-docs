Dùng `ak skills kit restore` để đưa trở lại một Kit SkillX mà
[`ak skills kit unpublish`](./unpublish) hoặc SkillX dashboard đã xoá mềm trong
30 ngày qua. Kit trở lại với visibility và các revision nó từng có. Khôi phục là
thao tác đảo ngược được, nên lệnh không bao giờ hỏi xác nhận.

## Cách dùng

```bash
ak skills kit restore <name> [--kit @<handle>/<name>] [flags]
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--kit @<handle>/<name>` | Kit đã liên kết | Kit cá nhân trên SkillX cần khôi phục. Bắt buộc khi Kit cá nhân chưa có link SkillX. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Điều kiện

SkillX phải bật, sau `ak update --ssot` hoặc với `AGENTKIT_SKILLX=1`. Giống lệnh
gỡ, SkillX chỉ chấp nhận khôi phục từ SkillX API key không scope
(`ak secrets set SKILLX_TOKEN`) hoặc phiên trên
[SkillX dashboard](https://skillx.sh/dashboard), không bao giờ từ link token
agentkit.best. Kit do admin SkillX gỡ thì chỉ admin mới khôi phục được.

## Lệnh thay đổi gì

Chỉ Kit trên SkillX. SkillX tăng generation của Kit thêm một; khi skill store
bật, link record cũng được cập nhật nếu nó đang giữ generation trước lúc khôi
phục. Chạy lại lệnh sẽ báo `unchanged`.

## Đầu ra

JSON dùng `kind=skills.kit.restore` với các trường sau trong `data`:

```text
personalKit, kit, host, status, restoredAt, generation, linkUpdated, warnings
```

`status` là `restored`, hoặc `unchanged` khi Kit chưa bị gỡ.

## Mã thoát

| Exit | Ý nghĩa |
| --- | --- |
| `0` | Đã khôi phục, hoặc Kit chưa bị gỡ (`status: unchanged`). |
| `1` | Lệnh thất bại: SkillX offline, hoặc credential bị từ chối (key có scope hoặc link token). |
| `2` | SkillX hoặc cờ overlay đang tắt, cờ không hợp lệ, hoặc không có Kit liên kết và không có `--kit`. |
| `5` | Không tìm thấy Kit SkillX với credential này, hoặc đã quá thời hạn khôi phục 30 ngày. |
| `6` | Kit thay đổi trong lúc lệnh chạy. |
| `7` | Publisher mà credential không sở hữu, hoặc Kit do admin SkillX gỡ. |
| `10` | Tài khoản của bạn chưa được bật Kit cá nhân (SkillX trả về `kit.api_disabled`). |
