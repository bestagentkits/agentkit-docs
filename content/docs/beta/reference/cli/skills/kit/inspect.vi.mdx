title: ak skills kit inspect

---

Dùng `ak skills kit inspect` để xem một Kit cá nhân compose những gì: các
foundation và mọi Skill cùng kind (foundation, overlay hoặc fork), digest của
base, overlay và composition, exposure, trust và script. Projection theo runtime
không được xem trước; plan hiển thị composition, không phải các file mà runtime
adapter sẽ ghi.

## Cách dùng

```bash
ak skills kit inspect <name> [flags]
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--kits-dir <dir>` | `$AGENTKIT_KITS_DIR` hoặc `./kits` | Thư mục foundation Kit. |
| `--runtime <runtime>` | Trống | Runtime cần xem plan. Runtime không có trong manifest là lỗi cách dùng. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions). Lệnh chạy offline
cho mọi người dùng: không cần skill store lẫn SkillX.

## Lệnh đọc gì

Lệnh chỉ đọc. Nó đọc Kit cá nhân dưới `AGENTKIT_HOME/kits/personal/<name>` và
thư mục foundation Kit, không bao giờ ghi, cài, apply plan, hay gọi mạng hoặc
model. Các override của người dùng AgentKit được báo, không bao giờ được áp
dụng.

## Đầu ra

Đầu ra text mở đầu bằng Kit và owner của nó, rồi một dòng `foundation` cho mỗi
foundation (kit, phiên bản, tier, trust), một khối cho mỗi Skill (kind,
identity, alias, `from` với fork, exposure và nguồn của nó, composition digest,
script đã khai báo), inputs digest, cảnh báo của resolver, và ghi chú
`projection_preview_unavailable`.

JSON dùng `kind=skills.kit.inspect` với các trường sau dưới `data`:

```text
plan: schema, personalKit, name, owner, manifestDigest,
      foundations[]: kit, version, tier, origin, trust
      packages[]: identity, alias, kind, from, foundation, ownerKit, providers[],
                  baseTreeDigest, overlayDigest, compositionDigest, owner,
                  exposure, exposureSource, trust, origin, scripts[], overlayDir,
                  resolutionDigest, pinnedBy
      runtimes[], warnings[], inputsDigest
runtime
warnings[]
```

Resolve cùng một bộ input cho ra JSON plan giống hệt từng byte.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Thành công. |
| `1` | Lệnh thất bại, hoặc overlay conflict, shared alias, alias collision hay proposal cũ (JSON `error_code` `conflict`). |
| `2` | Cờ hoặc argument không hợp lệ, hoặc manifest, overlay hay proposal sai định dạng. |
| `5` | Không tìm thấy Kit cá nhân, foundation Kit, phiên bản hoặc Skill. |
| `7` | Foundation bị revoke. |
