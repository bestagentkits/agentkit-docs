Dùng `ak skills restore` để đưa trở lại một package Skill mà
[`ak skills unpublish`](./unpublish) đã xoá mềm. SkillX giữ package đã xoá trong
30 ngày.

## Cách dùng

```bash
ak skills restore @<handle>/<slug> [--json]
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--json` | Tắt | Ghi một JSON envelope thay vì đầu ra cho người đọc. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Điều kiện

SkillX phải bật, sau `ak update --ssot` hoặc với `AGENTKIT_SKILLX=1`. Lệnh dùng
tài khoản agentkit.best đã liên kết trước và quay về `SKILLX_TOKEN`. Để khôi phục
một Kit cá nhân, dùng `ak skills kit restore`.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Đã khôi phục. |
| `1` | Lệnh thất bại: SkillX offline, hoặc tài khoản đã liên kết hay `SKILLX_TOKEN` thiếu, bị thu hồi hoặc hết hạn. |
| `2` | SkillX bị tắt, hoặc cờ hay tên không hợp lệ. |
| `5` | Không tìm thấy package, hoặc đã quá cửa sổ khôi phục 30 ngày. |
| `6` | Việc khôi phục xung đột với trạng thái hiện tại của package trên SkillX. |
| `7` | SkillX từ chối khôi phục với thông tin xác thực hiện tại. |
