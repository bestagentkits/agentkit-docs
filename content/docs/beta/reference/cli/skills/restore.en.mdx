---
title: ak skills restore
description: Restore a skill package that was unpublished from SkillX, within its 30-day window.
---

Use `ak skills restore` to bring back a skill package that
[`ak skills unpublish`](./unpublish) soft-deleted. SkillX keeps a deleted
package for 30 days.

## Usage

```bash
ak skills restore @<handle>/<slug> [--json]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--json` | Off | Write one JSON envelope instead of human output. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

SkillX must be on, after `ak update --ssot` or with `AGENTKIT_SKILLX=1`. The
command uses your linked agentkit.best account first and falls back to
`SKILLX_TOKEN`. To restore a personal kit instead, use
`ak skills kit restore`.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Restored. |
| `1` | Command failure: SkillX offline, or the linked account or `SKILLX_TOKEN` missing, revoked or expired. |
| `2` | SkillX disabled, or invalid flags or name. |
| `5` | The package was not found, or its 30-day restore window has passed. |
| `6` | The restore conflicts with the current state of the package on SkillX. |
| `7` | SkillX refused the restore for the current credential. |
