---
title: ak skills self-improve review
description: Review the screened skills with their improvement candidates and record an explicit approve, reject, or defer decision.
---

Use `ak skills self-improve review` to decide what to do about the skills that
[`ak skills self-improve status`](../cli/ak_skills_self-improve_status)
screened. It joins each screened skill with the candidates
[`ak skills improve`](../cli/ak_skills_improve) recorded for it and their
evaluation outcome. Running the group command itself prints help.

## Usage

```bash
ak skills self-improve review <command>
```

```bash
ak skills self-improve review list --json
ak skills self-improve review inspect ak-fix
ak skills self-improve review approve 3f2a91c0 --yes
ak skills self-improve review defer ak-fix --days 14
```

## Decisions

`list` and `inspect` only read. `approve`, `reject`, and `defer` record one
decision per skill in `AGENTKIT_HOME/state/self-improve/review.json`, and a
later decision replaces the earlier one. A decision also silences the
session-start line for that skill.

Approval is always explicit: `approve` only previews without `--yes`. Only a
skill of your own personal kit (`@local/`) is applied, through the same plan,
`--plan` token, and rollback record as
[`ak skills evolution apply`](../cli/ak_skills_evolution_apply). An AgentKit
skill is proposal-only: `approve` records the proposal and writes no kit file.

An evaluation outcome of `not_run` or `inconclusive` is normal.

Review reads the screened skills whatever the current consent, so you can
still decide after you turn recording off.

## Skill references

`inspect`, `reject`, and `defer` take a screened skill. The reference is
matched case-insensitively, with `:` read as `-` and any publisher or kit
prefix dropped, so `ak:fix` finds `ak-fix`. `approve` takes a candidate ID
instead.

## Subcommands

| Command | Outcome | Disk effect |
| --- | --- | --- |
| [`ak skills self-improve review list`](./list) | List screened skills with their decision and candidates. | Read-only. |
| [`ak skills self-improve review inspect <skill>`](./inspect) | Show one screened skill's reasons, evidence ids, candidates, and next steps. | Read-only. |
| [`ak skills self-improve review approve <candidateId>`](./approve) | Preview, then apply or propose a candidate. | With `--yes`, writes `review.json`, and applies a personal kit candidate. |
| [`ak skills self-improve review reject <skill>`](./reject) | Reject the improvement at the skill's current digest. | Writes `review.json`. |
| [`ak skills self-improve review defer <skill>`](./defer) | Silence the skill for some days. | Writes `review.json`. |

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success, including a disabled feature or an empty store. |
| `1` | The AgentKit home could not be resolved (`self_improve.home_unresolved`), or the event store could not be read or written (`self_improve.store_failed`). |
| `2` | Invalid flags or arguments (`self_improve.invalid_input`). |
| `4` | Another writer held the event store lock (`self_improve.store_busy`). |
| `5` | No screened skill or recorded candidate matches the reference (`self_improve.not_found`). |

[`approve`](./approve) uses the exit codes of `ak skills evolution apply`.
