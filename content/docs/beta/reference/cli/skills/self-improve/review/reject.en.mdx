---
title: ak skills self-improve review reject
description: Reject the improvement of a screened skill at its current digest, silencing it until the skill changes.
---

Use `ak skills self-improve review reject` when a screened skill does not need
improving. The rejection holds for the skill's current digest. The command
never prompts.

## Usage

```bash
ak skills self-improve review reject <skill> [flags]
```

```bash
ak skills self-improve review reject ak-fix
ak skills self-improve review reject ak-fix --json
```

Exactly one skill reference is required. It is matched case-insensitively,
with `:` read as `-` and any publisher or kit prefix dropped. The command has
no flags of its own. Shared flags are described in
[CLI conventions](../cli-conventions).

## What it does

The command records a `rejected` decision for the skill's current digest in
`AGENTKIT_HOME/state/self-improve/review.json`, under the store lock. A later
decision replaces it.

Until the skill's digest changes, the session-start line stays silent for it,
and [`review list`](./list) shows the rejection. The command changes no skill,
candidate, or kit, and runs no model, script, or network call.

## Output

The text output says `recorded rejected` for the skill. JSON uses
`kind=skills.self_improve.review.rejected` with these fields under `data`:

```text
skill, decision, recorded
decision: decision, digest, decided_at
```

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | The AgentKit home could not be resolved (`self_improve.home_unresolved`), or the event store could not be read or written (`self_improve.store_failed`). |
| `2` | Invalid flags or arguments (`self_improve.invalid_input`). |
| `4` | Another writer held the event store lock (`self_improve.store_busy`). |
| `5` | The skill has no screened events (`self_improve.not_found`). |
