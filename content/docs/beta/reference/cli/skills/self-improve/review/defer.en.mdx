---
title: ak skills self-improve review defer
description: Defer the review of a screened skill, silencing its session-start line for 7 days by default and at most 30.
---

Use `ak skills self-improve review defer` to put off a screened skill's review
for a while. The command never prompts.

## Usage

```bash
ak skills self-improve review defer <skill> [--days <n>] [flags]
```

```bash
ak skills self-improve review defer ak-fix
ak skills self-improve review defer ak-fix --days 14 --json
```

Exactly one skill reference is required. It is matched case-insensitively,
with `:` read as `-` and any publisher or kit prefix dropped.

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--days <n>` | `7` | Days to silence the skill, from 1 to 30. |

Shared flags are described in [CLI conventions](../cli-conventions).

## What it does

The command records a `deferred` decision with an end time in
`AGENTKIT_HOME/state/self-improve/review.json`, under the store lock. A later
decision replaces it. Until the end time, the session-start line stays silent
for the skill.

The command changes no skill, candidate, or kit, and runs no model, script, or
network call.

## Output

The text output says `recorded deferred` for the skill and the end time. JSON
uses `kind=skills.self_improve.review.deferred` with these fields under
`data`:

```text
skill, decision, recorded
decision: decision, digest, decided_at, until
```

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | The AgentKit home could not be resolved (`self_improve.home_unresolved`), or the event store could not be read or written (`self_improve.store_failed`). |
| `2` | Invalid flags or arguments, such as `--days` out of range (`self_improve.invalid_input`). |
| `4` | Another writer held the event store lock (`self_improve.store_busy`). |
| `5` | The skill has no screened events (`self_improve.not_found`). |
