Dùng `ak skills self-improve review inspect` để xem chi tiết một Skill đã sàng
lọc trước khi quyết định. Lệnh chỉ đọc.

## Cách dùng

```bash
ak skills self-improve review inspect <skill> [flags]
```

```bash
ak skills self-improve review inspect ak-fix
ak skills self-improve review inspect ak:fix --json
```

Cần đúng một tham chiếu Skill. Tham chiếu được so khớp không phân biệt hoa
thường, với `:` được đọc là `-` và bỏ mọi tiền tố publisher hoặc Kit. Lệnh không
có cờ riêng. Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Lệnh làm gì

Lệnh hiện cùng mục như [`review list`](./list), thêm từng lý do đạt ngưỡng và
các evidence event id để truyền cho `/ak-dogfood --evidence`. Dùng
[`ak skills evolution show <id>`](../cli/ak_skills_evolution_show) để xem diff
của một candidate.

Lệnh đọc cùng các file như `review list`, không ghi gì, và không chạy model,
script hay network call.

## Đầu ra

Đầu ra text thêm một dòng `reason` cho mỗi vấn đề đạt ngưỡng, kèm fingerprint,
loại tín hiệu, error class, độ mạnh và số session, và một dòng `evidence` với
các event id.

JSON dùng `kind=skills.self_improve.review.inspect`. `data` là một mục với các
trường mà [`review list`](./list) mô tả.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Thành công. |
| `1` | Không xác định được thư mục home của AgentKit (`self_improve.home_unresolved`), hoặc không đọc được event store (`self_improve.store_failed`). |
| `2` | Cờ hoặc argument không hợp lệ (`self_improve.invalid_input`). |
| `4` | Một tiến trình ghi khác đang giữ khoá của event store (`self_improve.store_busy`). |
| `5` | Skill không có event nào đã sàng lọc (`self_improve.not_found`). |
