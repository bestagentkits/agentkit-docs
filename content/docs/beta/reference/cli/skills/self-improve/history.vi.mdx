Dùng `ak skills self-improve history` để xem Hook session-end đã ghi những gì.
Lệnh liệt kê các event đã lưu bất kể sự đồng ý hiện tại, nên vẫn dùng được sau
khi bạn tắt việc ghi. Lệnh chỉ đọc.

## Cách dùng

```bash
ak skills self-improve history [--skill <id>] [--limit <n>] [flags]
```

```bash
ak skills self-improve history
ak skills self-improve history --skill ak-cook --limit 10 --json
```

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--skill <id>` | Mọi Skill | Chỉ lấy event của skill id này. |
| `--limit <n>` | `50` | Số event tối đa cần liệt kê, từ 1 đến 5000. |

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).

## Lệnh làm gì

Lệnh đọc `AGENTKIT_HOME/state/self-improve/events.jsonl` và liệt kê các event
mới nhất trước, gồm cả các quan sát không có vấn đề. Lệnh không ghi gì, không
chạy model, script hay network call, và bỏ qua bước kiểm tra cập nhật chạy nền.

## Đầu ra

Mỗi dòng text hiện thời điểm, event id, runtime, skill id, cùng loại tín hiệu,
error class và độ mạnh.

JSON dùng `kind=skills.self_improve.history` với các trường sau dưới `data`:

```text
events[], total
events[]: schema_version, event_id, recorded_at, runtime, hook_event,
          session_ref, project_ref, skill, signal, fingerprint, evidence_refs[]
skill: id, digest
signal: type, strength, error_class
evidence_refs[]: kind, line, tool
```

`total` đếm mọi event khớp trước khi áp dụng `--limit`.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Thành công, kể cả khi store trống. |
| `1` | Không xác định được thư mục home của AgentKit (`self_improve.home_unresolved`), hoặc không đọc được event store (`self_improve.store_failed`). |
| `2` | Cờ hoặc argument không hợp lệ, ví dụ `--limit` ngoài khoảng cho phép (`self_improve.invalid_input`). |
| `4` | Một tiến trình ghi khác đang giữ khoá của event store (`self_improve.store_busy`). |
