title: ak skills self-improve enable
description: Turn skill self-improve event recording on in the user config, starting at the next Claude Code or Codex session end.

Use `ak skills self-improve enable` to opt in to skill self-improve recording.
The Claude Code and Codex session-end Hooks start recording at the next session
end. The command never prompts.

## Usage

```bash
ak skills self-improve enable [flags]
```

```bash
ak skills self-improve enable
ak skills self-improve enable --json
```

The command takes no arguments and has no flags of its own. Shared flags are
described in [CLI conventions](../cli-conventions).

## What it does

The command backs up `config.yaml` in your AgentKit home, then writes
`skill_self_improve.enabled: true` to it. It touches no event, skill, or
project file. Undo it with [`ak skills self-improve disable`](./disable).

A project whose `.agentkit/config.yaml` turns recording off with
`skill_self_improve.enabled: false` stays off. Check the effective consent for
a directory with [`ak skills self-improve status`](./status).

## Output

The text output says that self-improve is on in the user config. JSON uses
`kind=skills.self_improve.enable` with these fields under `data`:

```text
enabled, config_path, changed
```

`changed` is `false` when the user config already had recording on.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | The AgentKit home could not be resolved (`self_improve.home_unresolved`), or the config could not be written (`self_improve.config_write_failed`). |
| `2` | Invalid flags or arguments (`self_improve.invalid_input`). |
