---

Dùng `ak skills self-improve disable` để dừng việc ghi skill self-improve và
dòng nhắc khi bắt đầu session. Lệnh không bao giờ hỏi.

## Cách dùng

```bash
ak skills self-improve disable [flags]
```

```bash
ak skills self-improve disable
ak skills self-improve disable --json
```

Lệnh không nhận argument và không có cờ riêng. Các cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Lệnh làm gì

Lệnh sao lưu `config.yaml` trong thư mục home của AgentKit, rồi ghi
`skill_self_improve.enabled: false` vào đó. Lệnh không chạm vào event, Skill hay
file nào của project. Bật lại việc ghi bằng
[`ak skills self-improve enable`](./enable).

Các event đã lưu được giữ lại. Khi việc ghi đang tắt, [`status`](./status)
không liệt kê Skill nào, nhưng [`history`](./history) và
[`review list`](./review/list) vẫn đọc các event đã lưu.

## Đầu ra

Đầu ra text cho biết self-improve đang tắt trong config người dùng. JSON dùng
`kind=skills.self_improve.disable` với các trường sau dưới `data`:

```text
enabled, config_path, changed
```

`changed` là `false` khi config người dùng đã tắt việc ghi từ trước.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Thành công. |
| `1` | Không xác định được thư mục home của AgentKit (`self_improve.home_unresolved`), hoặc không ghi được config (`self_improve.config_write_failed`). |
| `2` | Cờ hoặc argument không hợp lệ (`self_improve.invalid_input`). |
