Dùng `ak skills self-improve enable` để chủ động bật việc ghi skill
self-improve. Các Hook session-end của Claude Code và Codex bắt đầu ghi từ lần
kết thúc session kế tiếp. Lệnh không bao giờ hỏi.

## Cách dùng

```bash
ak skills self-improve enable [flags]
```

```bash
ak skills self-improve enable
ak skills self-improve enable --json
```

Lệnh không nhận argument và không có cờ riêng. Các cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Lệnh làm gì

Lệnh sao lưu `config.yaml` trong thư mục home của AgentKit, rồi ghi
`skill_self_improve.enabled: true` vào đó. Lệnh không chạm vào event, Skill hay
file nào của project. Hoàn tác bằng
[`ak skills self-improve disable`](./disable).

Một project có `.agentkit/config.yaml` tắt việc ghi bằng
`skill_self_improve.enabled: false` vẫn tắt. Kiểm tra sự đồng ý đang có hiệu lực
cho một thư mục bằng [`ak skills self-improve status`](./status).

## Đầu ra

Đầu ra text cho biết self-improve đang bật trong config người dùng. JSON dùng
`kind=skills.self_improve.enable` với các trường sau dưới `data`:

```text
enabled, config_path, changed
```

`changed` là `false` khi config người dùng đã bật việc ghi từ trước.

## Kết quả và mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Thành công. |
| `1` | Không xác định được thư mục home của AgentKit (`self_improve.home_unresolved`), hoặc không ghi được config (`self_improve.config_write_failed`). |
| `2` | Cờ hoặc argument không hợp lệ (`self_improve.invalid_input`). |
