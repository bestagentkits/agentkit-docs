---
title: ak skills self-improve disable
description: Turn skill self-improve event recording and the session-start line off in the user config, keeping the stored events.
---

Use `ak skills self-improve disable` to stop skill self-improve recording and
the session-start line. The command never prompts.

## Usage

```bash
ak skills self-improve disable [flags]
```

```bash
ak skills self-improve disable
ak skills self-improve disable --json
```

The command takes no arguments and has no flags of its own. Shared flags are
described in [CLI conventions](../cli-conventions).

## What it does

The command backs up `config.yaml` in your AgentKit home, then writes
`skill_self_improve.enabled: false` to it. It touches no event, skill, or
project file. Turn recording back on with
[`ak skills self-improve enable`](./enable).

Stored events are kept. While recording is off,
[`status`](./status) lists no skill, but
[`history`](./history) and [`review list`](./review/list) still read the
stored events.

## Output

The text output says that self-improve is off in the user config. JSON uses
`kind=skills.self_improve.disable` with these fields under `data`:

```text
enabled, config_path, changed
```

`changed` is `false` when the user config already had recording off.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | The AgentKit home could not be resolved (`self_improve.home_unresolved`), or the config could not be written (`self_improve.config_write_failed`). |
| `2` | Invalid flags or arguments (`self_improve.invalid_input`). |
