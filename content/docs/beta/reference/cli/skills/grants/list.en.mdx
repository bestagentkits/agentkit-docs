---
title: ak skills grants list
description: List the exec grants recorded in the grants file without changing anything.
---

Use `ak skills grants list` to see which skill entrypoints may run through
[`ak skills exec`](../exec).

## Usage

```bash
ak skills grants list
```

The command accepts no positional arguments and no flags of its own. It needs
`AGENTKIT_SKILL_EXEC_BROKER=1`. Shared flags are described in
[CLI conventions](../../cli-conventions).

## Output

Each text line shows the grant id, `identity@digest`, entrypoint, scope,
creation time, and label. A missing grants file is an empty list and prints
`No exec grants.`

JSON uses `kind=skills.grants.list` with these fields under `data`:

```text
path, grants[]
```

## Effects and exits

The command is read-only. It reads `AGENTKIT_HOME/state/exec/grants.json`.

| Exit | Meaning |
| --- | --- |
| `0` | The list was produced, including an empty list. |
| `1` | Command failure, such as a busy grants store. |
| `2` | The broker is disabled or flags are invalid. |
| `7` | The grants file is invalid. |
