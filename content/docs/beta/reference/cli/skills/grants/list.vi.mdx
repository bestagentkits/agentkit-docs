Dùng `ak skills grants list` để xem entrypoint Skill nào được phép chạy qua
[`ak skills exec`](../exec).

## Cách dùng

```bash
ak skills grants list
```

Lệnh không nhận argument theo vị trí và không có cờ riêng. Cần
`AGENTKIT_SKILL_EXEC_BROKER=1`. Các cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Đầu ra

Mỗi dòng text hiển thị grant id, `identity@digest`, entrypoint, scope, thời điểm
tạo và label. File grants không tồn tại là danh sách rỗng và in
`No exec grants.`

JSON dùng `kind=skills.grants.list` với các trường sau dưới `data`:

```text
path, grants[]
```

## Tác động và mã thoát

Lệnh chỉ đọc. Nó đọc `AGENTKIT_HOME/state/exec/grants.json`.

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Đã tạo danh sách, kể cả danh sách rỗng. |
| `1` | Lệnh thất bại, ví dụ grants store đang bận. |
| `2` | Broker bị tắt hoặc cờ không hợp lệ. |
| `7` | File grants không hợp lệ. |
