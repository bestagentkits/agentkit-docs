---

Dùng `ak skills grants revoke` để rút quyền khỏi
[`ak skills exec`](../exec). Entrypoint bị thu hồi lỗi `exec.not_granted` cho đến
khi được grant lại.

## Cách dùng

```bash
ak skills grants revoke <grant-id>
ak skills grants revoke --all
```

Chỉ đưa đúng một trong grant id hoặc `--all`; nếu không lệnh thoát `2`.

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--all` | `false` | Thu hồi mọi grant đã ghi. |

Tìm id bằng [`ak skills grants list`](./list). Id có dạng `eg-<16 hex>`. Cần
`AGENTKIT_SKILL_EXEC_BROKER=1`. Các cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Đầu ra

JSON dùng `kind=skills.grants.revoke` với các trường sau dưới `data`:

```text
revoked[]
```

`revoked[]` chứa các id đã được gỡ.

## Tác động và mã thoát

Lệnh ghi lại `AGENTKIT_HOME/state/exec/grants.json` một cách atomic.

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Các grant đã được thu hồi. |
| `1` | Lệnh thất bại, ví dụ grants store đang bận. |
| `2` | Broker bị tắt, hoặc không đưa id lẫn `--all`, hoặc đưa cả hai. |
| `5` | Grant id không tồn tại (`exec.grant_not_found`). |
| `7` | File grants không hợp lệ. |
