Dùng `ak skills mcp` để đưa các lệnh skill thành tool của một MCP server cục bộ.
Đây không phải [`ak mcp`](../cli/ak_mcp), lệnh quản lý cấu hình MCP của runtime.
Chạy riêng lệnh nhóm sẽ in help và thoát `0`; lệnh chỉ đọc.

## Cách dùng

```bash
ak skills mcp <command>
```

Nhóm lệnh không nhận argument theo vị trí và không có cờ riêng.

## Lệnh con

| Lệnh | Kết quả |
| --- | --- |
| `ak skills mcp serve` | Chạy MCP server `ak-skills` qua stdio. |

Mặc định server chỉ cung cấp các tool chỉ đọc. Nếu không có `--allow-exec`, không
tool nào chạy Skill hay script. Các cờ opt-in được mô tả tại
[`ak skills mcp serve`](./serve).

Các cờ dùng chung nằm trong [quy ước CLI](../cli-conventions).
