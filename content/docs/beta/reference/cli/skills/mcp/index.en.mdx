---
title: ak skills mcp
description: Serve the skill commands to an MCP client as tools over stdio, read-only by default.
---

Use `ak skills mcp` to expose skill commands as tools of a local MCP server.
This is not [`ak mcp`](../cli/ak_mcp), which manages runtime MCP configuration.
Running the group command prints help and exits `0`; it is read-only.

## Usage

```bash
ak skills mcp <command>
```

The group accepts no positional arguments and has no flags of its own.

## Subcommands

| Command | Outcome |
| --- | --- |
| `ak skills mcp serve` | Run the `ak-skills` MCP server over stdio. |

By default the server offers only read-only tools. Without `--allow-exec`, no
tool executes a skill or script. The opt-in flags are described on
[`ak skills mcp serve`](./serve).

Shared flags are described in [CLI conventions](../cli-conventions).
