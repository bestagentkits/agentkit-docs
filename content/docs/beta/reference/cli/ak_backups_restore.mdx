Restore AgentKit state from a snapshot by replaying every file in the manifest back to its original on-host path. Replace-only: files added under the snapshotted scope after the snapshot are not deleted. The manifest is verified end-to-end before any live file is touched.

**When to use it:** After a failed update or migration, or to recover a known-good prior state. Run `ak backups verify` first; use `--latest` to restore the newest snapshot.

Overwrites files under `~/.claude/plugins/` and `~/.agentkit/skills/` to match the snapshot.

### Usage

```bash
ak backups restore [id] [flags]
```

### Examples

```bash
ak backups restore 20260426T123005Z-deadbeef           # asks confirmation on TTY
ak backups restore 20260426T123005Z-deadbeef --yes     # CI-friendly
ak backups restore 20260426T123005Z-deadbeef --json    # machine envelope
ak backups restore --latest                             # restore the newest snapshot
ak backups restore --latest --yes                       # CI-friendly latest restore
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | Print the restore plan without modifying live files |
| `--latest` | Restore the most recently created snapshot (mutually exclusive with positional &lt;id>) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `3` | user declined the confirmation prompt |
| `4` | another ak backups operation already holds the lock |
| `5` | snapshot id not found or no snapshots exist |
