---
title: ak agents model get
description: Show one Agent's model layer by layer for each installed file in a runtime.
---

Use `ak agents model get` to see the kit default, adapter default, user and
project overrides, AgentKit's recorded choice, and the model the runtime file
carries for one Agent.

## Usage

```bash
ak agents model get <agent> --runtime <runtime> [--project <dir>]
```

Exactly one Agent name is required. The command is read-only, never prompts,
and performs no network work.

| Flag | Default | Description |
| --- | --- | --- |
| `--runtime <runtime>` | required | One of `claude-code`, `codex`, `cursor`, `omp`, `pi`. |
| `--project <dir>` | nearest project config, else the current directory | Project whose installs and `.agentkit/config.yaml` apply. |

An Agent installed both globally and in the project yields one row per file.

## Output

Human stdout uses the same table as [`list`](./list), filtered to the Agent.

JSON success uses:

```text
schema_version: 1
kind: agents.model.get
data.agents[]
data.warnings?
```

The `agents[]` entries have the same fields as `list`: layers
(`kit_default`, `adapter_default`, `user_override`, `project_override`),
`desired` with `desired_source`, `recorded`, `materialized`, `effective`, and
`status`.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | At least one installed file of the Agent was found. |
| `1` | A local runtime error occurred. |
| `2` | Wrong argument count, invalid flags, an unsupported runtime, or a missing `--project` directory. |
| `5` | The Agent is not installed in the runtime. The error points to `ak agents model list --runtime <runtime>`. |
