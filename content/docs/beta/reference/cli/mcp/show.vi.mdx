Dùng `ak mcp show` để xem command, argument, nguồn và tên environment key đã
resolve cho một MCP server. Thao tác chỉ đọc.

## Cách dùng

```bash
ak mcp show <name>
```

Truyền đúng một tên server. Lệnh kế thừa `--claude-home <dir>` và `--cwd <dir>`;
`CODEX_HOME` thay discovery Codex. Cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Cách chọn entry

Cấu hình Claude được merge với project precedence trước lookup. Codex nằm ở
inventory harness riêng. Nếu hai harness có cùng tên, lookup hiện trả entry
Claude trước; `show` không có `--source` hay harness selector. Dùng tên riêng
nếu sự mơ hồ này quan trọng.

Tệp nguồn thiếu được bỏ qua. Một nguồn hiện có sai định dạng hoặc không đọc
được làm lệnh thất bại ngay cả khi nguồn khác có tên cần tìm.

## Output và riêng tư

Human output trên stdout gồm tên, command, args, environment key names và nguồn.
JSON success là một envelope với `kind=mcp.show` và server tại
`data.server`.

Giá trị môi trường không bao giờ được trả về, gồm cả bearer-token value của
Codex. Server argument, environment key name và absolute source path không được
redaction; hãy xem lại trước khi chia sẻ. Flag-parse error có thể vẫn là plain
text.

## Hiệu ứng và mã thoát

Không prompt, đọc stdin, request network, chạy subprocess hay thay disk.

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Tìm thấy và hiển thị server. |
| `1` | Discovery hoặc rendering thất bại. |
| `2` | Argument hoặc cờ không hợp lệ. |
| `5` | Không có server đã khám phá mang tên đó. |
