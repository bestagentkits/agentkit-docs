Manage individual slash commands from any kit—list, install, remove, show, and search markdown prompt templates that Claude Code surfaces as `/<namespace>:<name>`.

**When to use it:** Use as the entry point for any per-slash-command operation; subcommands handle the action. Run `ak commands list` to see what's installed and available, or `ak commands search` to find commands by keyword.

This group is read-only at the top level; each subcommand documents its own disk effects.

### Examples

```bash
ak commands list                              # show what's installed + available
ak commands search email                      # find slash commands matching a keyword
ak commands install marketing/ckm-email       # install one command
ak commands show marketing/ckm-email          # inspect metadata
ak commands remove marketing/ckm-email        # uninstall
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
