Check plan directory format against the CK convention: `plan.md` with front-matter title plus at least one `phase-NN-*.md`. Exits 0 when valid, 3 when invalid.

**When to use it:** Before committing plan changes or in CI to catch format errors.

Read-only.

### Usage

```bash
ak plan validate <path> [flags]
```

### Examples

```bash
ak plan validate ./plans/my-plan
ak plan validate ./plans/my-plan --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | plan is valid |
| `3` | plan failed validation |
