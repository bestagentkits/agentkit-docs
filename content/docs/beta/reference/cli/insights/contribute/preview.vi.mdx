Xem trước payload đóng góp đã lọc thông tin riêng tư trước khi gửi.

Dùng `ak insights contribute preview` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Inspect the exact voluntary aggregate payload

### Synopsis

Inspect the exact voluntary aggregate payload. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Freezes one closed-month aggregate locally; sends nothing.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights contribute preview [flags]
```

### Examples

```
  ak insights contribute preview --month 2026-08 --json
  ak insights contribute preview --help
```

### Options

```
  -h, --help             help for preview
      --json             Emit machine-readable JSON (implies --no-interactive)
      --month string     Closed UTC month, YYYY-MM
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
