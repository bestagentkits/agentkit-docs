Use `ak insights evaluate` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Record an outcome assessment with evidence

### Synopsis

Record an outcome assessment with evidence. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Appends a local evaluator verdict; never overwrites earlier evidence.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights evaluate [flags]
```

### Examples

```
  ak insights evaluate --file evaluation.json --json
  ak insights evaluate --help
```

### Options

```
      --file string      Evaluation JSON file
  -h, --help             help for evaluate
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
