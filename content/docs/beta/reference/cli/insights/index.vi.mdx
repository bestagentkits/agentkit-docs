Đọc và quản lý bằng chứng hiệu quả của Skill và Agent.

Dùng `ak insights` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Measure skill and agent effectiveness

### Synopsis

Inspect local quality, cost and time with evidence, revisions and runtime coverage. Collection and aggregate sharing are separate opt-ins.

### Examples

```
  ak insights skills
  ak insights agents --json
  ak insights consent --collection=true
```

### Options

```
  -h, --help             help for insights
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
