Use `ak insights evidence` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Inspect an execution and its evaluation evidence

### Synopsis

Inspect an execution and its evaluation evidence. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Read-only local evidence; no transcript content.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights evidence <execution-id> [flags]
```

### Examples

```
  ak insights evidence execution-id --json
  ak insights evidence --help
```

### Options

```
  -h, --help             help for evidence
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
