Run the content scheduler daemon. The daemon polls the queue every minute and publishes any posts whose scheduled time has arrived.

**Who it's for:** Power devs running persistent content pipelines.

**When to use it:** Use `ak content schedule daemon` to start a long-running scheduler process.

**What changes on disk:** Reads and writes ~/.agentkit/content/queue.json atomically on each poll tick.

### Examples

```bash
ak content schedule daemon
ak content schedule daemon --poll-interval 30
```
