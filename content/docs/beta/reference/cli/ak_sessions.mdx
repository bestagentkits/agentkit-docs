Inspect and maintain local coding-agent session transcripts. Subcommands cover listing, showing, tailing, redacting, and aggregating session analytics.

**When to use it:** Use redaction before sharing local Claude Code session transcripts. Inspects local session JSONL files used by supported coding agents.

Read-only at the group level; subcommands document their own disk effects.

### Examples

```bash
ak sessions list --json
ak sessions show myapp session-abc --json
ak sessions tail myapp session-abc --json
ak sessions redact --json
ak sessions redact --project myapp --json
ak sessions redact --project myapp --apply --yes
```
