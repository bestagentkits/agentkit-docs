Deregister a project from the global AgentKit registry without touching the project directory or its files.

**When to use it:** Cleaning up stale registry entries for moved or deleted projects. Called automatically by `ak uninstall` unless `--keep-registry`. Idempotent—exit 0 even if the entry is already absent.

Writes `~/.agentkit/projects.json` atomically.

### Usage

```bash
ak projects remove <name|path> [flags]
```

### Examples

```bash
ak projects remove myproj              # remove by name
ak projects remove $HOME/projects/myproj    # remove by absolute path
ak projects remove ./myproj --json     # machine-readable output
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, or entry was already absent (idempotent) |
| `2` | invalid arguments |
| `1` | registry read/write error |
