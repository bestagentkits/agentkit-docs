Remove an MCP server entry from the selected MCP JSON file. Defaults to project `.mcp.json`; use `--source` to override the config path.

**When to use it:** After previewing the inventory with `ak mcp list`.

Writes the selected MCP JSON file.

### Usage

```bash
ak mcp remove <name> [flags]
```

### Examples

```bash
ak mcp remove memory
ak mcp remove db --source .mcp.json --json
```
