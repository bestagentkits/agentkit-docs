---

Dùng `ak commands show` để xem template command trước khi sao chép hoặc xác nhận
metadata mà tệp installed hiện cung cấp.

## Cách dùng

```bash
ak commands show <kit>/<command>
```

Command component là asset name đã làm phẳng. Ví dụ, source
`ckm/write/good.md` được gọi bằng `<kit>/ckm-write-good`, không phải
`<kit>/ckm:write/good`. Phải có đúng một ref. Prefix rút gọn `ak:`, `ake:` và
`akm:` được chấp nhận cho `core`, `engineer` và `marketing`.

Không có cờ riêng cho lệnh. Lệnh chỉ đọc và không prompt.

## Lookup và metadata

Tệp installed dạng phẳng dưới
`~/.claude/plugins/<kit>/commands/<command>.md` được kiểm tra trước. Nếu vắng,
lệnh discover đệ quy source đã làm phẳng tương ứng dưới
`./kits/<kit>/commands/`. Environment override có thể thay cả hai root.

Khi có cả hai, metadata installed thắng; không có drift comparison. YAML
frontmatter ở đầu tệp có thể cung cấp `description`, `keywords` làm tag và
`argument-hint`. Record available giữ source `rel_path` và tạo Claude slash
name từ path. Record installed báo `<command>.md` làm `rel_path` và flat command
name làm `slash_name`, vì cấu trúc source không được giữ ở destination.

Lệnh không in Markdown body hoặc thực thi template. Nó không liên hệ registry,
authenticate, kiểm tra entitlement hoặc yêu cầu runtime xác minh discovery.

## Đầu ra

Stdout cho người dùng có thể gồm:

```text
ref, name, slash_name, kit, rel_path, description
argument_hint, tags
state: installed | available
```

JSON thành công dùng `schema_version: 1`, `kind: assets.show` và các trường tương
ứng dưới `data`; `argument_hint` bị bỏ qua khi rỗng.

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Tìm thấy record installed hoặc available. |
| `1` | Sai số lượng argument theo vị trí hoặc discovery thất bại. |
| `2` | Ref sai dạng hoặc không phân tích được cờ. |
| `5` | Không có record installed hoặc available khớp ref. |

Lỗi được ghi vào stderr. Lỗi thực thi JSON dùng shared error envelope; lỗi phân
tích cờ có thể vẫn là plain text.
