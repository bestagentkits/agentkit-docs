Lists merged MCP servers from Claude user settings, Claude user .mcp.json, and project .mcp.json.

**Who it's for:** Scripts and reviewers that need a headless MCP inventory.

**When to use it:** Use before MCP edits or to compare with desktop/dashboard MCP views.

**What changes on disk:** Read-only.

### Usage
