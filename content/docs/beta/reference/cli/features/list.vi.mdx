Liệt kê các cờ tính năng preview cùng nguồn và trạng thái của từng cờ.

Dùng `ak features list` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

List preview feature flags with their source and state

### Synopsis

List every preview feature flag: its env var, its `ak config prefs` key, whether it is on, and whether that came from the env var, the user preference, or the default. Precedence is env, then pref, then default. Store-backed defaults follow the mode `ak update --ssot` committed for the working directory's scope. A v3-to-v2 rollback hold overrides a preference that turns the skill store or SkillX on (source hold) until `ak update --ssot` releases it.

Effects:
  Read-only. Reads the environment, the user config.yaml and the committed skill store mode.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak features list [flags]
```

### Examples

```
  ak features list
  ak features list --json
  ak config prefs set features.skill_exec_broker true
```

### Options

```
  -h, --help             help for list

  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
