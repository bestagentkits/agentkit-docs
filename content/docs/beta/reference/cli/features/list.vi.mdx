Liệt kê các cờ tính năng preview cùng nguồn và trạng thái của từng cờ.

Khi phạm vi toàn cục khác phạm vi dự án, dòng `skill_store` hiển thị thêm phạm vi toàn cục (ví dụ `off (global on)`); đây là phạm vi mà `ak skills kit` và cập nhật toàn cục áp dụng. Với `--json`, mục `skill_store` có thêm `scopes` gồm hai giá trị boolean `global` và `project`.

Dùng `ak features list` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

List preview feature flags with their source and state

### Synopsis

List every preview feature flag: its env var, its `ak config prefs` key, whether it is on, and whether that came from the env var, the user preference, or the default. Precedence is env, then pref, then default. Store-backed defaults follow the mode `ak update --ssot` committed for the working directory's scope; skill_store also shows the global scope when it differs (`off (global on)`), the scope `ak skills kit` and global updates act on. A v3-to-v2 rollback hold overrides a preference that turns the skill store or SkillX on (source hold) until `ak update --ssot` releases it.

Effects:
  Read-only. Reads the environment, the user config.yaml and the committed skill store mode.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak features list [flags]
```

### Examples

```
  ak features list
  ak features list --json
  ak config prefs set features.skill_exec_broker true
```
