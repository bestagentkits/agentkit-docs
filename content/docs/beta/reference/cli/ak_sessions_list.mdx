## ak sessions list

List Claude Code sessions for registered projects

### Synopsis

What it does:
  Returns a finite snapshot of Claude Code session JSONL files for registered AgentKit projects.

Who it's for:
  Reviewers, scripts, and AI agents that need desktop Sessions evidence without opening the UI.

When to use it:
  Use before sharing, redacting, or inspecting local Claude Code session transcripts.

Examples:
  ak sessions list --json
  ak sessions list --project myapp --json

What changes on disk:
  Read-only. Reads ~/.agentkit/projects.json and ~/.claude/projects/*/*.jsonl; AGENTKIT_HOME and AGENTKIT_CLAUDE_HOME override those roots.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak sessions list [flags]
```

### Options

```
  -h, --help                  help for list

  -q, --quiet                 Suppress non-error output on stderr
```
