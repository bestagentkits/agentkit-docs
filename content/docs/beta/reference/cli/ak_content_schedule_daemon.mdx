Poll the scheduled-post queue every --poll-interval seconds and publish any due posts via their channel adapter. Runs until SIGINT/SIGTERM. An advisory lockfile prevents two daemons from double-publishing the same post.

**Who it's for:** Power devs automating timed content delivery.

**When to use it:** Start once as a background service or systemd unit.

**What changes on disk:** Reads/writes ~/.agentkit/content/queue.json on each tick. Holds a transient lock file during each publish window.

### Usage

```bash
ak content schedule daemon [flags]
```

### Examples

```bash
ak content schedule daemon
ak content schedule daemon --poll-interval 30
```

### Flags

| Flag | Description |
| --- | --- |

| `--poll-interval int` | Seconds between queue polls (default 60) |
| `-q, --quiet` | Suppress non-error output on stderr |
| `-V, --verbose` | Extra diagnostic output on stderr (loses to --quiet) |
