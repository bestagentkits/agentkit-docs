Export redacted support diagnostics for filing install, update, adapter, or runtime feedback. Subcommands redact secrets, emails, and local path prefixes.

**When to use it:** When you need local health evidence to attach to a support report or bug filing. Use `ak diagnostics export` to produce the bundle.

This group is read-only at the top level; export writes to stdout unless your shell redirects it.

### Examples

```bash
ak diagnostics export --json > agentkit-diagnostics.json
ak diagnostics export --offline --json
```
