List available content kits by walking the kits directory and loading each `kit.yaml`.

**When to use it:** Before `ak kit init` or `ak kit validate` to confirm the target kit exists.

Read-only. Default kits directory is `./kits`.

### Usage

```bash
ak kit list-kits [flags]
```

### Examples

```bash
ak kit list-kits                       # default: ./kits
ak kit list-kits --kits-dir /path      # custom directory
ak kit list-kits --json | jq .kits     # scripted consumption
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--kits-dir string` | Kits directory override (default: embedded kits; overrides: --kits-dir or $AGENTKIT_KITS_DIR) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `5` | kits directory not found |
