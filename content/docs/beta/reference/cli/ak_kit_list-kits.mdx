Walk the kits directory, load each kit.yaml, and print a summary table of name, version, extends, and per-category export counts.

**Who it's for:** Power devs scripting kit selection; users browsing what is available.

**When to use it:** Run before `ak kit init` or `ak kit validate` to confirm the target kit exists.

**What changes on disk:** Read-only.

### Usage

```bash
ak kit list-kits [flags]
```

### Examples

```bash
ak kit list-kits                       # default: ./kits
ak kit list-kits --kits-dir /path      # custom directory
ak kit list-kits --json | jq .kits     # scripted consumption
```

| `--json` | Emit machine-readable JSON (implies --no-interactive) |

| `--no-interactive` | Disable interactive prompts (CI-safe) |
| `-q, --quiet` | Suppress non-error output on stderr |
| `-V, --verbose` | Extra diagnostic output on stderr (loses to --quiet) |
