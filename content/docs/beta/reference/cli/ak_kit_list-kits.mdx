## ak kit list-kits

List available content kits

### Synopsis

What it does:
  Walk the kits directory, load each kit.yaml, and print a summary table of name, version, extends, and per-category export counts.

Who it's for:
  Power devs scripting kit selection; users browsing what is available.

When to use it:
  Run before `ak kit init` or `ak kit validate` to confirm the target kit exists.

Examples:
  ak kit list-kits                       # default: ./kits
  ak kit list-kits --kits-dir /path      # custom directory
  ak kit list-kits --json | jq .kits     # scripted consumption

What changes on disk:
  Read-only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  5  kits directory not found

```
ak kit list-kits [flags]
```

  -h, --help              help for list-kits

      --no-interactive    Disable interactive prompts (CI-safe)
