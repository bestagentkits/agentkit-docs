Toggle every '- [x]' checkbox in the named phase-NN-*.md file back to '- [ ]'. Already-unchecked boxes are left unchanged (idempotent).

**Who it's for:** Both: rollback a phase or reset a plan for re-use.

**When to use it:** (unspecified)

**What changes on disk:** Mutates the phase file in-place (atomic write).

### Usage

```bash
ak plan uncheck <phase-file> [flags]
```

### Examples

```bash
ak plan uncheck ./plans/my-plan/phase-01-setup.md
ak plan uncheck ./plans/my-plan/phase-01-setup.md --json
```
