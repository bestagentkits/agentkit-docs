Use `ak usage` for the operation described below. The command help records its arguments, effects, and options.

Use [`ak usage summary`](./summary) for the token totals of the current UTC day, week, or month, and [`ak usage limits`](./limits) for rolling-window limits per provider.

## Command contract

Inspect local token usage and per-provider usage limits

### Synopsis

Reports rolling-window token usage per coding-agent provider from the local analytics fact store, overlaid with the provider's own quota percentages. Provider polling is on by default and reuses the sign-in each official CLI already stored. To stay local-only, turn it off in the dashboard settings, or set usage_limits.advanced.enabled: false together with usage_limits.opted_out_at (an RFC 3339 time) when editing the config by hand, or set AGENTKIT_USAGE_LIMITS_LOCAL_ONLY=1 for one process. Use limits to inspect trailing 5-hour and week windows per provider (claude, codex, cursor, grok); both windows are always returned in one call.

### Examples

```
  ak usage limits
  ak usage limits --provider claude --json
  ak usage limits --window week --provider codex
```

### Options

```
  -h, --help             help for usage
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
