Bootstrap a new plan directory from template, creating `<basedir>/<timestamp>-<slug>/` with `plan.md` and `phase-01-start.md`.

**When to use it:** When starting a new structured plan. Default `--basedir` is `./plans/`.

Creates the plan directory and initial phase files.

### Usage

```bash
ak plan create <name> [flags]
```

### Examples

```bash
ak plan create "My Feature"
ak plan create "Deploy Pipeline" --basedir ./work
ak plan create "Auth" --json
```
