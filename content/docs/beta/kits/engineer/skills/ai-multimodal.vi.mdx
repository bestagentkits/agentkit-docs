Dùng `ak:ai-multimodal` để phân tích image, transcribe audio hoặc video, trích
xuất structured data, convert document và tạo asset image, video, speech hoặc
music. Skill điều phối CLI theo bản npm mới nhất `@mrgoonie/multix`; catalog
provider vẫn là authority cho model, limit, retention, feature và pricing hiện tại.

## Chọn công việc multimodal dựa trên provider

### Dùng ak:ai-multimodal khi

- Bạn cần OCR, visual evidence, hiểu layout hoặc so sánh nhiều image.
- Bạn cần transcript có timestamp, scene map, summary hoặc structured extraction
  từ audio hay video.
- Bạn cần convert document được hỗ trợ sang Markdown.
- Bạn cần image, video, speech hoặc music do provider tạo với model rõ ràng và
  bước review.
- Bạn cần optimize hay split media trước giới hạn upload provider đã xác minh.

### Chọn workflow khác khi

- Bạn muốn tìm prompt tuyển chọn cho visual concept mới. Dùng
  [`ak:ai-artist`](./ai-artist).
- Công việc là resize, encode, composite, metadata hoặc xóa background local,
  xác định được. Dùng [`ak:media-processing`](./media-processing).
- Bạn không thể upload source media hay prompt cho bên thứ ba.
- Kết luận OCR, identity, measurement, legal, medical hoặc safety quan trọng
  không thể được kiểm tra độc lập với bản gốc.

## Chuẩn bị input, tool và provider access

Trước khi bắt đầu:

- Hoàn thành [Làm quen](../../../getting-started/onboarding) và xác nhận
  Engineer Kit đã được cài cho runtime cùng scope hiện tại.
- Dùng Node.js 20+ và cách gọi theo bản npm mới nhất
  `npx --yes --prefer-online --package=@mrgoonie/multix@latest -- multix`; không thay bằng bản global
  `multix` trôi nổi.
- Chạy `multix --version` qua cách gọi đó, rồi `multix check --verbose`. Lần đầu
  có thể tải npm package và những lần sau dùng npm cache.
- Chỉ cấu hình provider cần thiết: `GEMINI_API_KEY`, tùy chọn
  `OPENROUTER_API_KEY` hoặc tùy chọn `MINIMAX_API_KEY`. CLI theo bản npm mới nhất có thể tìm
  key trong process environment, project `.env` hoặc `~/.multix/.env`.
- Kiểm tra subcommand hiện tại bằng `--help`, rồi xác minh model provider hiện
  tại, input và control được hỗ trợ, retention, quota cùng pricing.
- Nêu mọi input, output dự kiến, upload được phép, nhu cầu redaction và cleanup.
  Chỉ cài hoặc duyệt FFmpeg khi operation đã chọn cần nó.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:ai-multimodal ...` | Skill có thể đọc input local và chạy CLI theo bản npm mới nhất khi quyền file, process, credential, network và write được duyệt. |
| Cursor | `/ak:ai-multimodal ...` | Cách gọi bằng slash đã được người dùng xác minh; provider credential, local media access và subprocess behavior phụ thuộc Cursor. |
| Codex | `$ak:ai-multimodal ...` | Native discovery được hỗ trợ; `skill.yaml` không thay thế command `npx` theo bản npm mới nhất hay bảo đảm network và provider access. |

### Khớp operation với bằng chứng

| Nhu cầu | Họ command | Bằng chứng dự kiến |
| --- | --- | --- |
| Phân tích image hoặc video | `multix gemini analyze` | Quan sát thấy được, timestamp hay region, uncertainty và inference tách riêng |
| Transcript audio hoặc video | `multix gemini transcribe` | Metadata, chunk status và dòng timestamp như `[HH:MM:SS -> HH:MM:SS]` |
| Structured extraction | `multix gemini extract` | JSON theo schema cùng field chưa giải quyết hoặc không đọc được |
| Document conversion | `multix doc convert` | Tệp Markdown và conversion warning |
| Image generation | `multix gemini generate` hoặc `multix openrouter generate` | Prompt, model đã xác minh rõ ràng, setting và image path |
| Video generation | `multix gemini generate-video` hoặc MiniMax operation đã xác minh | Shot brief, model cùng control rõ ràng, output path và review note |
| Speech hoặc music generation | `multix minimax generate-speech` hay `generate-music` đã xác minh | Text hoặc lyrics, voice hay model ID, output path, review quyền và chất lượng |
| Optimize trước upload | `multix media optimize` | Source cùng output path, target size, actual size và quality trade-off |

Không thay `<verified-model-id>` bằng giá trị copy từ trang này. Model ID cùng
control phải được resolve với provider live trước generation.

## Quan sát các giai đoạn xử lý

1. **Skill định nghĩa contract bằng chứng.** Skill xác định source file, mục tiêu
   analysis hay generation, output format, uncertainty và privacy boundary.
2. **Skill kiểm tra backend theo bản npm mới nhất.** Node, npm cache, provider key, FFmpeg khi
   phù hợp và Multix command liên quan được xác minh.
3. **Skill resolve provider fact live.** Model, modality được hỗ trợ, input
   method, size hay duration limit, control, retention, quota và price được kiểm
   tra trước request.
4. **Skill chỉ chuẩn bị media khi cần.** Input quá lớn được compress hoặc split
   sau khi biết boundary; source detail cần cho OCR hay fine visual inspection
   được giữ.
5. **Skill xử lý hoặc tạo.** CLI theo bản npm mới nhất upload input đã duyệt và ghi local
   artifact yêu cầu.
6. **Skill xác minh với source hoặc brief.** Name, number, timestamp, visible
   evidence, prompt adherence, continuity, pronunciation và artifact được kiểm tra.
7. **Skill báo cáo và cleanup.** Provider, model, command, file, segment status,
   limitation và yêu cầu xóa input provider-hosted được ghi nhận.

## Kiểm soát upload, quyền riêng tư, quyền sử dụng và chi phí

<Callout type="warn" title="Media input có thể tiết lộ nhiều hơn chi tiết được hỏi">
  Image, recording, video frame, document, voice, face, screen, metadata và nội
  dung nền có thể được upload tới provider. Kiểm tra và giảm thiểu từng input
  trước khi gửi, đồng thời xác minh retention cùng deletion term hiện tại.
</Callout>

- Không đặt provider key thật trong prompt, `.env` được commit, log hay report
  tạo ra. Giữ provider error nhưng redact credential.
- Phải có consent cùng quyền phù hợp cho voice, likeness, recording, music,
  document, reference image và generated output trước khi dùng hoặc publish.
- Generation và analysis có thể dùng token, media second, storage hay provider
  job tính phí. Tạo review sample ngắn trước và duyệt retry tốn kém.
- `npx` có thể tải code và dùng npm cache. FFmpeg optimization tạo tệp mới, dùng
  CPU, memory, disk và process time local.
- Split media có thể mất context giữa segment. Ghi chunk boundary và không bịa
  continuity của transcript hay narrative khi merge.
- Skill ghi artifact local nhưng không publish, commit, deploy hay xóa bản gốc
  nếu chưa có quyền riêng.

## Xác minh kết quả

Kết quả hoàn tất nên gồm:

- Phiên bản Multix hiện tại, command family chính xác, provider, model rõ ràng
  khi phù hợp và live capability check.
- Input path, file thực sự upload, compression hay segmentation và provider
  cleanup status.
- Output path cùng format, cộng timestamp, schema, prompt hay setting cần để
  diễn giải từng artifact.
- Source-grounded validation cho name, number, text, timing, visual evidence,
  motion, sound, pronunciation hay prompt adherence tùy task.
- Provider error, region không chắc chắn, chunk lỗi, review quyền hoặc privacy
  và current limit đã giới hạn kết quả.

Stable và beta đóng package cùng content `ak:ai-multimodal` qua cách gọi Multix theo bản npm mới nhất.
Provider catalog là external state live; release không chứng minh model
availability, pricing, retention hiện tại hay cross-runtime parity.

## Xử lý sự cố và hiểu giới hạn

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| Lần đầu lỗi khi offline | Pre-warm cách gọi `npx` theo bản npm mới nhất trong môi trường có network được duyệt hoặc báo offline execution không khả dụng. |
| Node cũ hơn 20 | Dùng môi trường Node.js 20+ đã duyệt; không diễn giải lỗi thành AgentKit install failure. |
| Thiếu provider key | Cấu hình environment cần thiết an toàn và chạy lại `multix check --verbose`; không expose key trong output. |
| Model hoặc flag bị từ chối | Kiểm tra lại help của subcommand hiện tại cùng provider catalog hiện tại; không đoán replacement hay model “latest”. |
| Input vượt giới hạn đã xác minh | Split hoặc optimize bằng FFmpeg hay current media command, giữ chunk metadata và xin duyệt quality loss. |
| OCR, transcript hoặc extraction không chắc chắn | Đánh dấu uncertainty, so với bản gốc và yêu cầu human verification cho field quan trọng. |
| Generation job lỗi sau submission | Giữ provider error và kiểm tra billing hay job state trước khi retry. |
| CLI theo bản npm mới nhất thiếu operation | Báo observed gap và dùng upstream path; không khôi phục backend song song chưa được duyệt. |
| Runtime không nhận diện Skill | Xác nhận target cùng scope, mở lại runtime session, rồi làm theo [Runtime không tìm thấy Skill hoặc Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |
