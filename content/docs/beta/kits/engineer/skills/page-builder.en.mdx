---
title: ak:page-builder
description: Build and operate a project-specific page builder.
---

Use `ak:page-builder` to build or extend a reusable page composition system with the project's existing stack and components. For routine page changes, use the project's operator Skill when one exists. A one-off page design does not require a new builder.

## Start with the intended mode

```text
/ak:page-builder setup ./apps/storefront
/ak:page-builder update Add the existing ProductGrid block with category bindings
/ak:page-builder operate Create a pricing draft and share its preview
```

These are Skill arguments, not `ak` CLI subcommands. Supply the project, desired behavior, acceptance criteria and publishing scope. Setup discovers existing components and storage, defines the block/page contract, then integrates the editor, previews and agent interfaces. Update and operate remain bounded to the requested change.

## Check the result

Verify a representative real block, responsive and touch editing, draft/preview/publication boundaries and the requested agent interfaces. The workflow produces project code, documentation and a project-specific operator Skill through `ak:skill-creator`. Publishing authority remains scoped to the user's request. Read the installed Skill's references for the exact interface and verification contract.
