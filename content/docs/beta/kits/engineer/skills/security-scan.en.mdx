<Callout type="info" title="Retired invocation">
  `ak:security-scan` is no longer packaged as a separate Skill. Continue with
  [`ak:security`](./security). Default `ak:security` is the comprehensive
  replacement. `--secrets-only` and `--deps-only` skip code patterns and threat
  modeling; they are not the old combined secrets, dependency, and code scan.
</Callout>

Do not invoke `ak:security-scan`. This route preserves existing bookmarks. It
does not describe a packaged identity or a runnable command.
