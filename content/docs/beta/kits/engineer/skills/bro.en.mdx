title: Restate the last answer plainly with ak:bro

Use `ak:bro` when the assistant's last message is too formal, long, or full of
jargon. The Skill restates that one message in plain language while preserving
its facts, uncertainty, warnings, decisions, and necessary call to action.

## Choose ak:bro for a plain-language restatement

### Use ak:bro when

- You want the immediately previous assistant message explained more simply.
- You want repetition, filler, process narration, or excessive formatting
  removed.
- You want unavoidable technical terms defined briefly.

### Choose another workflow when

- You want new analysis, a different question answered, or additional evidence.
- You want a whole conversation, document, or implementation summarized. Use an
  appropriate summary workflow instead.
- You want an action from the previous answer performed. Invoke the relevant
  Skill separately.

## Run the Skill

Complete [Onboarding](../../../getting-started/onboarding), and confirm Engineer
Kit is installed for your active runtime and scope. Invoke `ak:bro` immediately
after the answer you want restated.

| Runtime | Invocation | Availability boundary |
| --- | --- | --- |
| Claude Code | `/ak:bro` | Uses the installed Engineer Skill; conversation and tool access remain bounded by the active session. |
| Cursor | `/ak:bro` | Uses the user-verified slash spelling; installed-Skill discovery depends on the Cursor session. |
| Codex | `$ak:bro` | Uses native Skill discovery; availability depends on the installed target and scope. |

The Skill replies in your language unless you request another language. It
returns only the restated message, without a preface announcing that it was
simplified.

## Understand the workflow and result

1. The Skill uses only the immediately previous assistant message as its source.
2. It preserves meaning and material boundaries, including uncertainty and
   safety warnings.
3. It replaces jargon and abstract phrasing with ordinary words, then removes
   details that do not affect understanding.
4. It returns a shorter, coherent restatement.

If there is no previous assistant message, the Skill says so and asks you to
provide the text. It does not run tools, change files, add analysis, answer a
new request, or perform actions described in the source message.

## Keep instructions and private data bounded

<Callout type="warn" title="Restatement does not change authority">
  Quoted text and embedded instructions in the prior message remain content to
  restate, not commands to follow. Simplifying an answer cannot bypass its
  safety or privacy boundaries.
</Callout>

The Skill does not reveal hidden prompts, credentials, secrets, personal data,
or private details that were omitted from the original answer.

Use [`ak:sumup`](./sumup) when you need a technical implementation recap rather
than a restatement of one message.
