<Callout type="info" title="Retired invocation">
  `ak:ak` (stored as `ak-ak`) is no longer packaged as a separate Skill. It is merged into [`ak-agentkit`](./agentkit), which now carries the ak CLI guide and command reference. Use `ak-agentkit` when the next action is an `ak` subcommand.
</Callout>

Do not invoke `ak:ak` or `ak-ak`. This route preserves existing bookmarks. It
does not describe a packaged identity or a runnable command.

`ak update --global` and `ak kit refresh <kit>` remove the stale `ak-ak` files.
A project-scope `ak update <dir>` does not prune them, and a refresh keeps a
folder that still holds files it does not own, so an `ak-ak` folder can remain.
Delete it by hand; nothing reads it.
