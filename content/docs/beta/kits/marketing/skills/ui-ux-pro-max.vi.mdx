Dùng `ak:ui-ux-pro-max` cho cấu trúc UI, visual direction, interaction pattern,
responsive behavior, accessibility guidance và review chất lượng interface.
Skill tìm kiếm trong dataset đi kèm và có thể tổng hợp design-system
recommendation; implementation vẫn là quyết định riêng.

## Chọn ak:ui-ux-pro-max cho guidance và review

### Dùng ak:ui-ux-pro-max khi

- Bạn cần guidance về product, style, color, typography, landing, chart, UX,
  icon, web hoặc React từ knowledge đi kèm.
- Bạn muốn design-system recommendation trước khi viết code.
- Bạn đang review accessibility, interaction, responsive behavior, form,
  navigation, chart hoặc theme consistency.
- Bạn muốn persist recommendation đã duyệt cho công việc page sau này.

### Chọn workflow khác khi

- Bạn cần interface code hoạt động. Dùng
  [`ak:frontend-design`](./frontend-design).
- Bạn cần audit theo upstream rule hiện tại với finding `file:line`. Dùng
  [`ak:web-design-guidelines`](./web-design-guidelines).
- Bạn cần token file và component spec chính thức. Dùng
  [`ak:design-system`](./design-system).
- Bạn cần campaign hoặc brand visual. Dùng [`ak:design`](./design).

## Chuẩn bị decision context và runtime

Cung cấp product type, audience, usage context, platform, stack, brand source,
screen hoặc flow đích, vấn đề hiện tại, theme cùng viewport được hỗ trợ và lần
chạy có được ghi recommendation file không. Cung cấp user evidence thật khi có;
recommendation đi kèm không thay thế bằng chứng đó.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:ui-ux-pro-max ...` | Phân phối native là mặc định; plugin là lựa chọn rõ ràng. Local search và persistence tùy chọn phụ thuộc Python support đi kèm cùng quyền project. |
| Cursor | `/ak:ui-ux-pro-max ...` | Cách gọi bằng slash đã được người dùng xác minh; parity tool và automation rộng hơn chưa được thiết lập. |
| Codex | `$ak:ui-ux-pro-max ...` | Có hỗ trợ native discovery; Agent và Hook liên quan vẫn phụ thuộc từng capability. |

Hoàn thành [Làm quen](../../../getting-started/onboarding) và xem
[Runtime adapter](../../../concepts/runtime-adapters).

Search helper đi kèm hỗ trợ `--design-system`, `--domain`, `--stack`,
`--max-results` hoặc `-n` và `--json`. Output design-system dùng `--format` hoặc
`-f` với `ascii` hoặc `markdown`. Đây là helper option, không phải Skill flag.

Persistence là opt-in qua `--persist`. `--project-name` hoặc `-p` xác định
project slug; `--page` thêm page override, còn `--output-dir` hoặc `-o` đổi base
directory. Output thực tế là `design-system/<project-slug>/MASTER.md` và, khi
được yêu cầu, `design-system/<project-slug>/pages/<page-slug>.md`.

## Hiểu các giai đoạn

1. **Đóng khung quyết định.** Workflow ghi product, audience, platform, brand,
   screen, constraint, evidence và bạn cần advice hay review.
2. **Tìm trong local knowledge.** BM25 search chọn row từ domain đi kèm. Lần
   chạy design-system kết hợp match product, style, color, landing và typography
   với reasoning rule đi kèm.
3. **Tổng hợp recommendation.** Output có thể gồm pattern, section order, CTA
   placement, style, color, typography, effect, anti-pattern và pre-delivery
   checklist.
4. **Thêm guidance tập trung.** Domain search có thể đào sâu accessibility,
   form, chart, interaction, responsive behavior, icon hoặc React.
5. **Review theo thực tế.** Bạn so sánh từng recommendation với brand asset,
   user evidence, platform convention, content và code hiện tại.
6. **Chỉ persist khi được duyệt.** Helper ghi Master file cùng page override tùy
   chọn; nó không implement UI.

## Tách guidance khỏi mutation

<Callout type="warn" title="Recommendation đi kèm không phải user evidence hiện tại">
  Local search không validate live product, platform guidance hiện tại, font
  availability, browser behavior hay accessibility. Hãy coi kết quả là đề xuất
  cần test. `--persist` ghi tệp và có thể thay Master hoặc page override hiện có
  tại cùng đường dẫn, vì vậy hãy review destination trước.
</Callout>

Skill không cấp quyền implementation, package installation, tải font hoặc asset,
external research, analytics access, account change, publication, Git operation
hay deployment. Hãy duyệt riêng các thao tác đó.

## Xác minh output và bằng chứng

Kết quả hữu ích nên nêu query, source domain đã match, recommendation,
reasoning, accessibility cùng responsive check, uncertainty đã biết và mọi tệp
được ghi. Xác minh contrast bằng color thực, typography với ngôn ngữ cần dùng,
layout bằng content cùng viewport size thật, mọi interaction state, keyboard và
screen-reader behavior, touch target cùng reduced motion.

Đừng coi checklist line hoặc CSV field có nhãn performance hay accessibility là
bằng chứng đã đo.

## Xử lý sự cố hoặc tiếp tục

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| Runtime không nhận diện `ak:ui-ux-pro-max` | Xác nhận target cùng scope, mở lại runtime, rồi dùng [Runtime không tìm thấy Skill hoặc Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |
| Recommendation quá chung | Thêm product, audience, industry, platform, tone, density và user constraint cụ thể. |
| Domain không trả kết quả | Thử synonym chính xác hoặc domain rộng hơn; không tự tạo match. |
| `--stack` từ chối stack yêu cầu | Dùng generic domain hoặc cung cấp guidance riêng project. Stack lookup đi kèm hiện chỉ expose `react-native`. |
| Persisted file không ở nơi dự kiến | Kiểm tra `--output-dir`, project slug và hierarchy `design-system/<project-slug>/` thực tế. |
| Guidance xung đột với brand hoặc user research | Giữ evidence đã duyệt, ghi conflict và từ chối hoặc sửa recommendation đi kèm. |

## Biết các giới hạn hiện tại

- Stable và beta chứa nội dung `ak:ui-ux-pro-max` byte-identical trong các
  release đã kiểm tra.
- Source description nêu nhiều technology stack, nhưng stack-specific lookup
  thực thi trong các release này chỉ expose `react-native`. Generic domain vẫn
  gồm record hướng web và React.
- Dataset count và wording rule mô tả nội dung release đi kèm, không chứng minh
  completeness, freshness, quality hay standards compliance.
- Generator có thể fallback sang pattern và value chung khi local search không
  tìm được match. Recommendation có format đẹp không phải bằng chứng relevance.
- Markdown được persist có generated guidance cùng timestamp. Hãy review trước
  khi coi nó là project source of truth.
