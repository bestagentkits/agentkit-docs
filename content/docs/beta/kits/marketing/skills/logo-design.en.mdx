Use `ak:logo-design` to research logo styles, colors, and industry patterns,
turn an approved brand brief into image-generation prompts, and produce one or
more PNG concepts through Gemini. The Skill supports exploration and review; it
does not clear trademarks, create a complete identity system, deliver a
production vector master, register a mark, or launch the new logo.

## Choose ak:logo-design for concept development

### Use ak:logo-design when

- You need logo concepts, style recommendations, a color direction, or an
  industry-aware design brief.
- You know the brand name, audience, positioning, desired attributes, and
  important constraints.
- You want to search the packaged style, color, and industry catalogs before
  generating raster variants.
- You can review distinctiveness, text accuracy, scalability, accessibility,
  source rights, and brand fit with human stakeholders.

### Choose another workflow when

- You need a full brand system, naming decision, or positioning work before
  visual exploration. Start with the relevant Marketing brand workflow.
- You need a campaign banner rather than a reusable identity mark. Use
  `ak:banner-design`.
- You need trademark clearance, legal advice, registration, vector cleanup,
  print preflight, or production files. Hand the selected concept to the
  appropriate legal and design-production owners.
- You intend to imitate an existing mark, protected character, or living
  artist's recognizable work without authority.

## Prepare the brand brief and provider

Before you start:

- Complete [Onboarding](../../../getting-started/onboarding), and confirm
  Marketing Kit is installed for the current runtime and scope.
- Provide the approved brand name, positioning, audience, industry, desired
  personality, symbols to include or avoid, color constraints, and competitors
  or marks that must not be confused with the result.
- Decide whether you need research and a brief only, one PNG, or a bounded
  batch of variants.
- Make `GEMINI_API_KEY` available, install `google-genai`, and allow provider
  network access only when image generation is approved.
- Choose an output directory you control and state whether existing files may
  be replaced.
- Plan a separate trademark and similarity review before public adoption. A
  local catalog search is not a clearance search.

| Runtime | Invocation | Availability boundary |
| --- | --- | --- |
| Claude Code | `/ak:logo-design ...` | Native delivery is the default; explicit plugin delivery is also supported. Generation still depends on the local Gemini credential and provider availability. |
| Cursor | `/ak:logo-design ...` | Slash invocation is user-verified. Image display and optional HTML-preview tooling can vary by setup. |
| Codex | `$ak:logo-design ...` | The Skill uses native Codex discovery. Partial Hook projection does not provide legal clearance or provider access. |

See [Runtime adapters](../../../concepts/runtime-adapters) for component-level

### Use the packaged research and generator controls

The local search helper accepts a query and can narrow `--domain` to `style`,
`color`, or `industry`. It also supports `--max-results`, `--json`,
`--design-brief`, and `--brand-name`/`-p`.

When generation is approved, the bundled Python generator exposes:

| Control | Purpose |
| --- | --- |
| `--prompt`, `-p` | Logo description |
| `--brand`, `-b` | Brand name |
| `--style`, `-s` | One generator-supported style |
| `--industry`, `-i` | One generator-supported industry |
| `--output`, `-o` | Output path for one PNG |
| `--batch` and `--output-dir` | Variant count and batch destination |
| `--brand-context` | Additional prompt context in batch mode |
| `--pro` | Request the packaged Pro image model instead of the default Flash-family model |
| `--aspect-ratio`, `-r` | `1:1`, `16:9`, `9:16`, `4:3`, or `3:4`; default is `1:1` |
| `--list-styles`, `--list-industries` | Print the generator's accepted choices without generating |

If no `--output` is given, a single image uses a name such as
`{brand_slug}_{timestamp}.png` in the working directory. Batch mode defaults to
`./{brand_name}_logos` and writes names such as
`{brand_name}_minimalist_01.png`.

## Follow the concept stages

1. **Confirm the brief.** The Skill records brand, audience, positioning,
   industry, personality, desired and forbidden motifs, color, wordmark needs,
   quantities, rights, and authority.
2. **Search packaged guidance.** It can query local CSV catalogs for relevant
   style, color, and industry rows and turn the findings into a design brief.
3. **Select directions.** Review the proposed concepts and prompts before
   spending provider quota. Reject confusing, derivative, culturally unsafe,
   or off-brand directions.
4. **Generate approved variants.** Gemini receives the prompt and writes raster
   PNG output. The packaged instruction requests a white background.
5. **Review at multiple sizes.** Check silhouette, text and spelling, contrast,
   color, grayscale behavior, small-size recognition, unintended symbols, and
   similarity to known marks.
6. **Stop before adoption.** HTML preview is optional and should be created only
   after you approve that extra local artifact. Replacement, registration,
   launch, publication, and production conversion remain separate work.

## Keep legal, provider, and launch decisions separate

<Callout type="warn" title="Generation is not trademark clearance">
  A visually distinct-looking output may still conflict with an existing mark
  or contain protected material. Perform qualified similarity, trademark,
  cultural, and jurisdictional review before adoption or registration.
</Callout>

| Work category | Normal boundary |
| --- | --- |
| Guidance and drafting | Catalog search, design briefs, prompt writing, and review criteria can be completed without a generation request. |
| Local mutations | Generation creates PNG files; an approved optional preview can add an HTML gallery. Confirm paths before writing or replacing files. |
| Provider and cost effects | Each variant and retry sends a prompt to Gemini, consumes quota, and may incur charges or be blocked by provider safety policy. |
| Brand and legal effects | The Skill does not authorize trademark filing, legal clearance, assignment of rights, or adoption as the official identity. |
| Publishing and account effects | It does not replace a current logo, update profiles or products, publish assets, order print materials, or notify stakeholders. |

Use only names, source images, fonts, symbols, and references you are entitled
to use. Avoid deceptive similarity, false certification marks, harmful
stereotypes, and claims that the concept is unique or legally available without
evidence.

## Review outputs and evidence

For each concept, preserve:

- The approved brief, search query, catalog rows used, prompt, style, industry,
  aspect ratio, model request, and output path.
- Provider success or failure and the exact PNG files actually created.
- Visual review at full, small, monochrome, and high-contrast sizes.
- Text and spelling checks, source rights, potential similarity, cultural
  review, and open legal questions.
- The selected shortlist and every vector-production, trademark, replacement,
  launch, and publishing action still pending.

Raster output should be treated as concept evidence. A production handoff may
need redrawing, typography licensing, spacing rules, color definitions, vector
masters, monochrome variants, responsive marks, and a usage guide.

## Troubleshoot safely

| Symptom | Safe next step |
| --- | --- |
| Runtime cannot find `ak:logo-design` | Confirm target and scope, start a fresh session, then follow [Runtime cannot find a Skill or Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |
| Local search returns no rows | Broaden the query or choose `style`, `color`, or `industry` explicitly; do not invent catalog evidence. |
| `google-genai package not installed` appears | Install it in the approved Python environment, then rerun only the intended generation. |
| `GEMINI_API_KEY not set` appears | Configure the key through the approved secret mechanism; never paste or commit it. |
| No image is generated | Preserve the brief and provider error, then revise the prompt or defer generation without claiming a file exists. |
| Brand text is misspelled or distorted | Reject the image. Do not use a raster correction as evidence of a finished wordmark without review. |
| A concept resembles another mark | Remove it from the shortlist and escalate to qualified brand and legal review. |
| Batch output is smaller than requested | Review the generator's bounded style list and each failed request before retrying or changing quantity. |

Continue with the [Marketing Kit overview](../../marketing) or
[Projects, artifacts, and checkpoints](../../../concepts/projects-artifacts-checkpoints).

## Know the current limits

- The packaged knowledge catalogs are broader than the generator flags. The
  current generator exposes 18 style choices and 10 industry choices; a catalog
  recommendation is not automatically an accepted `--style` or `--industry`.
- Batch generation is bounded by a fixed list of nine styles and currently
  passes `industry="tech"` internally. Do not use its batch output as evidence
  of industry-specific prompting for a non-tech brief; prefer deliberate single
  generations or correct the workflow before use.
- The generator produces raster PNG concepts, not SVG, EPS, PDF, font files,
  trademark evidence, or a complete brand guideline.
- The prompt requests white or transparent background behavior, while the
  Skill instruction calls for white. Inspect the actual pixels; do not assume
  background transparency or production-ready isolation.
- Model IDs, safety filters, quotas, prices, resolution, text rendering, and
  provider availability can change outside AgentKit.
- Generated concepts do not guarantee originality, registrability, legal
  clearance, brand recognition, conversion, revenue, or stakeholder approval.
