Dùng `ak:slides` để tạo strategic HTML presentation từ topic, audience và
evidence set đã duyệt. Skill kết hợp slide strategy, layout pattern, design
token, copywriting formula, responsive HTML và data visualization bằng Chart.js
khi cần. Artifact là HTML deck, không phải file PowerPoint native.

## Chọn ak:slides cho HTML presentation có thể review

### Dùng ak:slides khi

- Marketing presentation hoặc pitch cần narrative có cấu trúc và deck chạy
  trong browser.
- Metric đã duyệt cần xuất hiện dưới dạng chart hoặc slide kiểu dashboard.
- Product demo, sales pitch, case study, internal update, webinar hoặc workshop
  cần slide flow nhất quán.
- Bạn muốn artifact responsive với HTML, CSS và JavaScript có thể review.

### Chọn workflow khác khi

- Bạn chỉ cần một image architecture hoặc process. Dùng `ak:tech-graph` hay
  `ak:mermaidjs-v11`.
- Narrative hoặc bằng chứng chưa được duyệt. Hãy research và review trước khi
  sản xuất deck.
- Bạn cần `.pptx`, Keynote, Google Slides, PDF hoặc presentation đã host. Các
  format cùng bước publish đó nằm ngoài output được nêu của Skill.

## Chuẩn bị brief và asset policy

Cung cấp audience, mục tiêu presentation, topic, slide count mong muốn, brand
token đã duyệt, source material, claim, metric, CTA và output path. Đánh dấu số
liệu cùng testimonial thiếu hỗ trợ để loại bỏ thay vì tự nghĩ ra.

HTML pattern đóng package có thể tham chiếu Chart.js từ CDN và dùng background
image remote. Đó là network dependency bên ngoài tùy chọn. Nêu deck có phải
hoạt động offline, third-party asset có được duyệt và có được ghi file local.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:slides ...` | Phân phối native là mặc định; plugin rõ ràng cũng được hỗ trợ. |
| Cursor | `/ak:slides ...` | Cách gọi bằng slash đã được người dùng xác minh; preview behavior phụ thuộc local tool có sẵn. |
| Codex | `$ak:slides ...` | Native Skill discovery được hỗ trợ; statusline Marketing và một phần Hook coverage không khả dụng. |

## Theo các giai đoạn presentation

1. **Xác nhận brief.** Thiết lập audience, decision, narrative, bằng chứng, slide
   count, CTA, brand constraint và output path.
2. **Chọn strategy.** Khớp context với structure có sẵn như product demo, sales
   pitch, case study, internal update hoặc workshop.
3. **Xây narrative.** Giao một nhiệm vụ cho mỗi slide và chỉ dùng copy formula
   để framing, không dùng làm quyền nghĩ ra urgency hay proof.
4. **Chọn layout.** Map content vào pattern title, problem, solution, feature,
   comparison, timeline, metric, screenshot hoặc closing.
5. **Tạo responsive HTML.** Dùng design token, deck container desktop 16:9,
   mobile breakpoint, navigation, progress và animation có giới hạn.
6. **Thêm data visual có chủ đích.** Chỉ dùng Chart.js cho data đã duyệt và khi
   dependency policy chấp nhận được.
7. **Review artifact.** Mở HTML trong local preview đã duyệt, kiểm tra từng slide
   cùng viewport rồi báo output path và rủi ro còn lại.

## Tách riêng claim, network access và publishing

<Callout type="warn" title="Layout thuyết phục không phải là bằng chứng">
  Đừng nghĩ ra customer quote, logo, revenue, conversion, market size, pricing,
  ROI hoặc performance. Copywriting formula có thể sắp xếp bằng chứng đã duyệt;
  nó không thể làm claim thành đúng. Giữ hosting, sharing, sending và presenting
  deck thành phê duyệt riêng.
</Callout>

Hãy hỏi trước khi cài dependency, tải CDN script, fetch remote image hoặc gửi
source material tới provider bên ngoài. Giữ credential và dữ liệu khách hàng
riêng tư khỏi deck. HTML file local không cấp quyền thay campaign, chi ngân sách
hay liên hệ audience.

## Xác minh HTML artifact và bằng chứng

Một lần chạy hoàn tất nên cung cấp:

- exact output path `.html`;
- slide count, audience, narrative và CTA đã dùng;
- mapping từ mỗi claim, quote, chart cùng image tới source material đã duyệt;
- bằng chứng đã kiểm tra desktop và responsive layout;
- disclosure dependency remote hoặc xác nhận không dùng; và
- bước publication, hosting hay distribution vẫn chờ phê duyệt.

Kiểm tra keyboard navigation, slide counter, progress, content overflow, chart
label, color contrast và mobile layout. Nếu deck chưa được mở trong browser,
hãy ghi visual verification chưa đầy đủ.

## Khắc phục và hiểu giới hạn

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| Runtime không nhận diện `ak:slides` | Xác nhận target cùng scope, mở lại runtime, rồi làm theo [Runtime không tìm thấy Skill hoặc Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |
| Skill không route request | Đặt `create` đầu tiên, rồi cung cấp topic cùng slide count. |
| Chart trống khi offline | Bỏ CDN dependency hoặc dùng Chart.js asset local đã duyệt; không âm thầm bật network access. |
| Slide bị overflow | Rút ngắn copy, đổi layout hoặc tách slide; kiểm tra lại desktop cùng mobile. |
| Số liệu hay quote không có nguồn | Xóa hoặc đánh dấu thành placeholder chưa giải quyết bên ngoài presentation. |
| Cần native deck hay PDF | Coi conversion là workflow riêng và xác minh artifact đã convert độc lập. |

Skill không bảo đảm persuasion, funding, sales, conversion, platform
compatibility hay native slide format. Tiếp tục với `ak:tech-graph` cho technical
visual để publish hoặc `ak:docs` cho context project lâu dài.
