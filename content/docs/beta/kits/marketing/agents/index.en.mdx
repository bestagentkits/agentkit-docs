Marketing Kit packages 32 resolved Agents: 10 shared Agents inherited from the
Kit foundation and 22 Marketing-specific Agents. Together they cover research,
planning, content, campaigns, optimization, implementation, and verification.

## How Agents support Skills

Skills define repeatable workflows for an outcome. Agents provide specialized
roles that a workflow can use for bounded research, creation, coordination, or
review steps. Their results return to the surrounding workflow, where they can
be checked and combined with other work.

This roster describes roles included in the resolved package. It does not
guarantee a standalone invocation path, a particular provider, tool, model, or
identical behavior on every runtime. See [Kits, Skills, Agents, and
Hooks](../../../concepts/building-blocks) for the component boundaries.

## Research and understand context

| Agent | Bounded purpose |
| --- | --- |
| `Explore` | Scans a codebase quickly and returns relevant files, symbols, and relationships. |
| `researcher` | Synthesizes software technology and documentation research into a sourced report. |
| `scout` | Locates files and implementation context across a large codebase. |
| `scout-external` | Performs read-only codebase discovery, preferring native search tools. |
| `analytics-analyst` | Turns marketing performance data into metrics, trends, and recommendations. |
| `kongming` | Provides strategic options, trade-offs, and advice for a difficult decision. |

## Codex projection note

For the package version documented here, when the shared `researcher` Agent's
Codex model resolves, its emitted configuration includes
`model_reasoning_effort = "medium"`. If no model resolves, the setting is
omitted. This changes emitted Codex configuration only; the Agent roster and
Skill workflows are unchanged.
