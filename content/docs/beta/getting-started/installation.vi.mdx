Sau trang này, lệnh `ak` sẽ hoạt động trong terminal và sẵn sàng cho bước thiết
lập đầu tiên.

## Môi trường được hỗ trợ

AgentKit phát hành bản 64-bit cho:

| Hệ điều hành | Kiến trúc | Yêu cầu của trình cài đặt |
| --- | --- | --- |
| macOS | Intel (`amd64`) và Apple silicon (`arm64`) | POSIX shell, `curl` hoặc `wget`, và `tar` |
| Linux | x64 (`amd64`) và ARM64 (`arm64`) | POSIX shell, `curl` hoặc `wget`, và `tar` |
| Windows | x64 (`amd64`) và ARM64 (`arm64`) | Windows PowerShell 5.1 trở lên |

Bạn cũng cần cài và đăng nhập Claude Code hoặc Codex trước khi có thể chạy skill
của kit trong trợ lý đó. Xác thực tài khoản AgentKit là một bước riêng.

## Cài CLI

<Tabs items={['macOS / Linux', 'Windows']}>
  <Tab value="macOS / Linux">

```bash
curl -fsSL https://agentkit.best/install.sh | sh
```

Đích mặc định là `~/.local/bin/ak`. Trình cài đặt sẽ cảnh báo nếu thư mục này
chưa có trong `PATH` và in lệnh cấu hình shell bạn có thể dùng.

  </Tab>
  <Tab value="Windows">

```powershell
irm https://agentkit.best/install.ps1 | iex
```

Đích mặc định là `%USERPROFILE%\bin\ak.exe`. Khi cần, trình cài đặt thêm thư mục
vào `PATH` của người dùng; hãy mở terminal mới sau đó.

  </Tab>
</Tabs>

Cả hai lệnh đều cài từ kênh `stable` trừ khi bạn đặt `AK_CHANNEL`.
Từ Windows `cmd.exe`, gọi cùng trình cài đặt PowerShell bằng:

```bat
powershell -NoProfile -Command "irm https://agentkit.best/install.ps1 | iex"
```

## Trình cài đặt xác minh bản phát hành như thế nào

Trình cài đặt chính thức từ chối tải xuống chưa được xác minh. Với kênh đã được
ghim trong trình cài đặt, nó đối chiếu kích thước byte và SHA-256 của archive với
giá trị bất biến đi kèm trình cài đặt. Với một phiên bản cụ thể, release base tùy
chỉnh hoặc lựa chọn chưa được ghim khác, nó dùng verifier đã ghim hash để xác
thực metadata kênh và bản phát hành đã ký, rồi kiểm tra archive đã chọn trước khi
trả về dữ liệu.

<Callout type="warn">
  Hãy giữ xác minh checksum và chữ ký ở trạng thái bật. Nếu endpoint protection
  hoặc proxy công ty chặn tải xuống, đừng tạo ngoại lệ bảo mật chỉ để hoàn tất
  cài đặt.
</Callout>

Nếu chỉ domain chính bị lọc, hãy thử lại entry point chính thức có nội dung giống
hệt mà không thay đổi chuỗi xác minh:

<Tabs items={['macOS / Linux', 'Windows']}>
  <Tab value="macOS / Linux">

```bash
curl -fsSL https://releases.agentkit.best/install.sh | sh
```

  </Tab>
  <Tab value="Windows">

```powershell
irm https://releases.agentkit.best/install.ps1 | iex
```

  </Tab>
</Tabs>

Nếu cùng object vẫn bị chặn, hãy giữ endpoint protection hoạt động và nhờ quản
trị viên xem xét việc từ chối.

## Xác minh cài đặt

Mở terminal mới nếu trình cài đặt đã đổi `PATH`, rồi chạy:

```bash
ak --version
ak doctor --json
```

Bạn sẽ thấy phiên bản đã cài. Trong kết quả doctor, hãy kiểm tra `data.healthy`;
một lần chạy hoàn tất của `ak doctor --json` thường trả exit code `0` ngay cả
khi một health check thất bại. Dùng `ak doctor --exit-on-fail` khi exit code của
process phải làm gate cho script. Nếu không tìm thấy `ak`, hãy thêm thư mục cài
đặt được báo vào `PATH` và khởi động lại terminal.

## Chọn kênh phát hành khác

Kênh mặc định là `stable`. Để chọn bản `beta` mới nhất qua cùng quy trình cài đặt
được xác minh:

<Tabs items={['macOS / Linux', 'Windows']}>
  <Tab value="macOS / Linux">

```bash
curl -fsSL https://agentkit.best/install.sh | AK_CHANNEL=beta sh
```

  </Tab>
  <Tab value="Windows">

```powershell
$env:AK_CHANNEL = 'beta'; irm https://agentkit.best/install.ps1 | iex
```

  </Tab>
</Tabs>

`AK_VERSION` ghim một phiên bản semantic, còn `AK_INSTALL_DIR` đổi thư mục đích.
Hãy để cả hai chưa đặt nếu bạn không cần quyền kiểm soát này.

## Chạy thiết lập lần đầu

```bash
ak setup
```

Setup phát hiện trạng thái đăng nhập của các runtime hiện có và cập nhật
`~/.agentkit/config.yaml` theo cách nguyên tử. Thiết lập cơ bản cấu hình adapter
đang bật, kit mặc định và telemetry mà không sao chép credential của runtime.
Lệnh này không đăng nhập tài khoản AgentKit và không cài nội dung kit. Tiếp tục với
[Làm quen](./onboarding) để xác thực, kiểm tra quyền sử dụng và cài kit đầu tiên.

## Cập nhật hoặc gỡ AgentKit an toàn

Dùng `ak self-update --check` để kiểm tra CLI mới hơn mà chưa áp dụng. Xem
[Cập nhật ak](../guides/updating) trước khi đổi kênh hoặc cập nhật bản cài hiện có.

Trước khi gỡ bất cứ thứ gì, hãy xem trước thao tác dọn dẹp được quản lý tương ứng
với nội dung bạn đã cài:

```bash
ak kit uninstall engineer --dry-run
ak uninstall --dry-run
```

Lệnh đầu xem trước việc gỡ Engineer Kit. Lệnh thứ hai xem trước việc gỡ project
được AgentKit quản lý ở thư mục hiện tại; đây không phải lệnh gỡ CLI. Chỉ chạy
lại lệnh phù hợp với `--yes` sau khi đã xem kế hoạch. Mặc định, cả hai đều giữ
tệp không rõ nguồn gốc hoặc đã sửa và tạo snapshot cho các thay đổi được hỗ trợ
trước khi xóa. Một lần xem trước hoàn tất sẽ trả exit code `3` theo thiết kế;
thao tác gỡ được áp dụng thành công trả exit code `0`.

Cuối cùng, chạy `ak logout` để xóa phiên CLI cục bộ trước. Thu hồi từ xa cho một
phiên email có thể làm mới là best-effort, nên registry ngừng hoạt động không
thể khiến máy vẫn đăng nhập cục bộ. Sau đó, chỉ xóa binary đã cài
(`~/.local/bin/ak` hoặc `%USERPROFILE%\bin\ak.exe`). Đừng xóa toàn bộ
`~/.agentkit` hoặc `%USERPROFILE%\.agentkit` trừ khi bạn đã kiểm tra và không còn
cần registry project, phiên thiết bị của ứng dụng, cache hay snapshot khôi phục bên trong.
