This walks you from a fresh install to invoking a kit skill. It assumes `ak` is
already on your `PATH` — if not, start with [Installation](./installation).

<Steps>
  <Step>
    ### Sign in

    Authenticate with your account. The token is stored in your system keychain,
    not in a plaintext file.

    ```bash
    ak login
    ```

    Check who you are and what you can install:

    ```bash
    ak whoami
    ak licenses
    ```
  </Step>
  <Step>
    ### Install a kit

    A **kit** is a bundle of skills for a coding assistant. Install one and pick
    the target runtime — here, Claude Code, installed globally:

    ```bash
    ak kit init engineer --target claude-code --global
    ```

    To install only part of a kit, select or exclude skills:

    ```bash
    ak kit install engineer --target codex --global --skills ak-cook,ak-plan
    ```
  </Step>
  <Step>
    ### Invoke a skill

    Kit skills are invoked by their slash command inside your assistant,
    regardless of which kit they came from:

    ```text
    /ak:cook      # shared core skill, available in every kit
    /ak:agentize  # an engineer-kit skill
    ```

    The kit name you type on the command line stays plain (`ak kit init
    engineer`); only the slash invocation uses the `ak:` prefix.
  </Step>
  <Step>
    ### Keep it current

    Check for updates any time — the CLI verifies the release before applying:

    ```bash
    ak self-update --check
    ```
  </Step>
</Steps>
