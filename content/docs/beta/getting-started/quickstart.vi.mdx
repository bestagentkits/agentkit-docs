Hướng dẫn này đưa bạn từ bản cài mới đến việc gọi một skill của kit. Giả định
`ak` đã có trên `PATH` — nếu chưa, bắt đầu từ [Cài đặt](./installation).

<Steps>
  <Step>
    ### Đăng nhập

    Xác thực bằng tài khoản của bạn. Token phiên được lưu dưới
    `~/.agentkit/auth/` dạng tệp mode `0600` (không nằm trong system keychain).

    ```bash
    ak login
    ```

    Kiểm tra bạn là ai và được cài những gì:

    ```bash
    ak whoami
    ak licenses
    ```
  </Step>
  <Step>
    ### Cài một kit

    Một **kit** là bó skill cho trợ lý lập trình. Cài một kit và chọn runtime —
    ví dụ Claude Code, cài global:

    ```bash
    ak kit init engineer --target claude-code --global
    ```

    Để chỉ cài một phần kit, chọn hoặc loại trừ skill:

    ```bash
    ak kit install engineer --target codex --global --skills ak-cook,ak-plan
    ```
  </Step>
  <Step>
    ### Gọi skill

    Skill của kit được gọi bằng slash command trong trợ lý, bất kể kit nào:

    ```text
    /ak:cook      # skill core dùng chung, có trong mọi kit
    /ak:agentize  # skill của engineer kit
    ```

    Tên kit trên dòng lệnh vẫn viết thường (`ak kit init engineer`); chỉ lời
    gọi slash dùng tiền tố `ak:`.
  </Step>
  <Step>
    ### Giữ bản mới

    Kiểm tra cập nhật trên kênh beta:

    ```bash
    ak self-update --check --channel beta
    ```
  </Step>
</Steps>
