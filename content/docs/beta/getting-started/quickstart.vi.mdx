Hướng dẫn này đưa bạn từ một bản cài mới đến khi gọi được skill của kit. Nó giả
định `ak` đã có trên `PATH` — nếu chưa, hãy bắt đầu từ [Cài đặt](./installation).

<Steps>
  <Step>
    ### Đăng nhập

    Xác thực bằng tài khoản của bạn. Token phiên được lưu trong
    `~/.agentkit/auth/` dưới dạng tệp có quyền `0600` (không nằm trong system
    keychain).

    ```bash
    ak login
    ```

    Kiểm tra bạn là ai và được phép cài những gì:

    ```bash
    ak whoami
    ak licenses
    ```
  </Step>
  <Step>
    ### Cài một kit

    Một **kit** là một bộ skill dành cho trợ lý lập trình. Hãy cài một kit và
    chọn runtime đích — ví dụ Claude Code, cài ở phạm vi global:

    ```bash
    ak kit init engineer --target claude-code --global
    ```

    Để chỉ cài một phần của kit, hãy chọn hoặc loại trừ skill:

    ```bash
    ak kit install engineer --target codex --global --skills ak-cook,ak-plan
    ```
  </Step>
  <Step>
    ### Gọi skill

    Skill của kit được gọi bằng slash command ngay trong trợ lý, bất kể nó thuộc
    kit nào:

    ```text
    /ak:cook      # skill core dùng chung, có trong mọi kit
    /ak:agentize  # skill của engineer kit
    ```

    Tên kit khi gõ trên dòng lệnh vẫn viết thường (`ak kit init engineer`); chỉ
    có lời gọi bằng slash mới dùng tiền tố `ak:`.
  </Step>
  <Step>
    ### Giữ bản mới

    Kiểm tra cập nhật trên kênh beta:

    ```bash
    ak self-update --check --channel beta
    ```
  </Step>
</Steps>
