Quy trình tập trung này cài Engineer Kit vào project hiện tại và bắt đầu một tác
vụ phần mềm trong Claude Code hoặc Codex.

## Trước khi bắt đầu

Hoàn thành [Cài đặt](./installation) và [Làm quen](./onboarding), hoặc xác minh ba
trạng thái bắt buộc ngay bây giờ:

```bash
ak --version
ak whoami
ak licenses
```

`ak whoami` phải hiển thị đúng tài khoản, còn Engineer Kit phải xuất hiện trong
`ak licenses`. Runtime đã chọn cũng phải được cài và đăng nhập. Các phép kiểm tra
này không in secret đã lưu của bạn.

## Cài và chạy

<Steps>
  <Step>
    ### Mở một project

    Chuyển tới project nơi bạn có thể review và hoàn tác thay đổi. Mặc định, kit
    được cài ở scope project.
  </Step>
  <Step>
    ### Cài Engineer Kit

    <Tabs items={['Claude Code', 'Codex']}>
      <Tab value="Claude Code">

    ```bash
    ak kit init engineer --target claude-code
    ```

      </Tab>
      <Tab value="Codex">

    ```bash
    ak kit init engineer --target codex
    ```

      </Tab>
    </Tabs>

    Xem trước kế hoạch và xác nhận. Khi thành công, phần tóm tắt nêu tên kit, vị
    trí đầu ra, install mode, scope và số tệp đã ghi. Nếu CLI in cảnh báo, hãy đọc
    trước khi tiếp tục.
  </Step>
  <Step>
    ### Nạp lại trợ lý

    Mở phiên Claude Code hoặc Codex mới trong cùng project để trợ lý phát hiện
    skill đã cài.
  </Step>
  <Step>
    ### Gọi `ak:cook`

    <Tabs items={['Claude Code', 'Codex']}>
      <Tab value="Claude Code">

    ```text
    /ak:cook Add a health-check endpoint
    ```

      </Tab>
      <Tab value="Codex">

    ```text
    $ak:cook Add a health-check endpoint
    ```

      </Tab>
    </Tabs>

    Claude Code dùng `/ak:...`; Codex dùng `$ak:...`. Tên kit vẫn ở dạng thường
    trong lệnh CLI như `ak kit init engineer`.
  </Step>
</Steps>

## Kết quả mong đợi

Trợ lý nhận diện `ak:cook`, đọc tác vụ cùng context project hiện tại và bắt đầu
workflow của skill. Hãy review scope đề xuất và mọi thay đổi tệp như với công
việc lập trình khác. Quickstart hoàn tất khi skill đã khởi chạy thành công; kết
quả của tác vụ mẫu phụ thuộc vào project của bạn.

## Nếu skill không được nhận diện

1. Xác nhận phần tóm tắt cài đặt ghi `engineer` và đúng target bạn muốn.
2. Mở phiên trợ lý mới trong cùng project.
3. Chạy `ak doctor` và xử lý mọi kiểm tra runtime hoặc kit được báo.
4. Nếu có xung đột quyền sở hữu khi cài, hãy dừng và kiểm tra; đừng lập tức thử
   lại với `--force`.

Nếu thao tác được quản lý đã in backup ID, hãy giữ ID tới khi xác minh xong
project. Khôi phục điểm đó bằng `ak backups restore <backup-id>`.
