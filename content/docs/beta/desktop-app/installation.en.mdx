After this page, you will have opened a checksum-verified AgentKit Desktop
v2.13.0-beta.39 package. Desktop is a manual download in this release; the CLI installer
does not install it.

## Download the matching package

Download the artifact and its `.sha256` sidecar from the official
[AgentKit v2.13.0-beta.39 release](https://github.com/bestagentkits/agentkit/releases/tag/v2.13.0-beta.39).

| Platform | Artifact | Bytes | SHA-256 |
| --- | --- | ---: | --- |
| macOS Intel | `ak-gui_2.13.0-beta.39_darwin_amd64.zip` | 13,425,844 | `7c0a31da89b644e424786e5db347c5c4b74d6cacb59c037b70e3b3d5841de80f` |
| macOS Apple silicon | `ak-gui_2.13.0-beta.39_darwin_arm64.zip` | 12,391,676 | `46a71e625a15c002d23ed5da4e9d7e4362b2b2898ad0f4e4109255cdd449c4e5` |
| Linux x64 | `ak-gui_2.13.0-beta.39_linux_amd64.AppImage` | 90,438,136 | `59791ee26bfd702ce92e9473266a81c02fe71a1775ccafd6cfd0e2885c8e89d2` |
| Windows x64 | `ak-gui_2.13.0-beta.39_windows_amd64.zip` | 13,516,355 | `14354b79f1a6e405c26d04124ef37fd9b98edf462f232bf1b4bf5c6e63129d48` |

There is no Desktop artifact for Linux ARM64 or Windows ARM64 in v2.13.0-beta.39.
Do not substitute the similarly named `ak_2.13.0-beta.39_*` archive: that is the CLI
artifact and contains no Wails window.

## Verify the download

Calculate the digest of the artifact itself and compare all 64 hexadecimal
characters with the table and downloaded sidecar. Stop if the file size or
digest differs.

### macOS

```bash
shasum -a 256 ak-gui_2.13.0-beta.39_darwin_arm64.zip
```

Replace `arm64` with `amd64` for an Intel Mac.

### Linux

```bash
sha256sum ak-gui_2.13.0-beta.39_linux_amd64.AppImage
```

### Windows PowerShell

```powershell
Get-FileHash .\ak-gui_2.13.0-beta.39_windows_amd64.zip -Algorithm SHA256
```

<Callout type="warn">
  The macOS and Linux sidecars include the build runner's original absolute
  path. Compare the digest value itself; do not expect a direct `-c` check of
  those sidecar files to find your download.
</Callout>

## Install and open it

### macOS

1. Expand the matching zip.
2. Move `agentkit.app` to `/Applications`.
3. Open `agentkit.app`.

If Gatekeeper blocks the first launch, confirm the digest first. Then attempt
to open the app once and use **System Settings → Privacy & Security → Open
Anyway** for that exact app. If you deliberately use the command-line fallback
for the verified bundle, run:

```bash
xattr -rd com.apple.quarantine /Applications/agentkit.app
```

SHA-256 verification confirms the downloaded bytes, but it is separate from
Apple notarization. Do not assume this package is notarized. Keep Gatekeeper
on; do not apply a system-wide exception.

### Linux

Keep the AppImage in a user-controlled applications directory, then run:

```bash
chmod +x ak-gui_2.13.0-beta.39_linux_amd64.AppImage
./ak-gui_2.13.0-beta.39_linux_amd64.AppImage
```

If it reports a FUSE error, install your distribution's FUSE compatibility
package and retry the same verified AppImage. Do not run it as root.

### Windows

1. Extract `ak-gui_2.13.0-beta.39_windows_amd64.zip` to a user-controlled applications
   folder.
2. Run `ak-gui.exe` from the extracted folder.

If SmartScreen appears, recheck the SHA-256 first. For the matching official
artifact, choose **More info → Run anyway**. Keep endpoint protection enabled.

## Install the CLI separately when needed

Desktop can manage its interface without an HTTP port, but terminal commands
and Desktop's paired updater need the standard `ak` CLI installed separately.
Follow [CLI installation](../getting-started/installation), then confirm:

```bash
ak --version
```

The CLI and Desktop should report the same release before you enable Desktop
auto-update. Running `ak gui` from the standard CLI does not launch the separate
Desktop installation.

## Remove Desktop

There is no Desktop uninstaller in v2.13.0-beta.39. Quit the app, optionally sign out
from **Profile** to clear the local App session, then remove only the item you
installed:

- `/Applications/agentkit.app` on macOS;
- The exact `ak-gui_2.13.0-beta.39_linux_amd64.AppImage` on Linux; or
- The extracted Desktop folder containing `ak-gui.exe` on Windows.

This does not remove the CLI, installed Kits, runtime files, or AgentKit state.
`ak uninstall` is a managed-project removal command, not a Desktop uninstaller.
Do not delete `~/.agentkit`, `%USERPROFILE%\.agentkit`, `.claude`, or `.codex`
wholesale. Continue with [First launch](./getting-started).
