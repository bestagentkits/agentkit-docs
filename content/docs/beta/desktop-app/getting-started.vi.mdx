Sau trang này, Desktop sẽ được kích hoạt cho thiết bị này và bạn sẽ biết bước
khởi động nào thay đổi trạng thái AgentKit hoặc coding assistant cục bộ.

## Kích hoạt thiết bị này

Mở gói Desktop đã xác minh và nhập license App bắt đầu bằng `ak_live_`. Lần
kích hoạt đầu cần kết nối mạng. Desktop phải xác minh App session trước khi mở
giao diện chính; đăng nhập CLI hoặc coding assistant không mở khoá ứng dụng.

![Hộp thoại kích hoạt license ứng dụng với license key bắt đầu bằng ak_live_](./activate-license.png)

| Session | Phạm vi được mở khoá | Ranh giới đăng xuất |
| --- | --- | --- |
| License App Desktop | Desktop và thao tác với catalog Kit được cấp quyền trên thiết bị này | **Profile → Sign out** chỉ xoá App session cục bộ |
| Đăng nhập AgentKit CLI | Lệnh CLI có xác thực | `ak logout` chỉ xoá CLI session |
| Đăng nhập coding assistant hoặc provider | Runtime hoặc provider tương ứng | Được assistant hoặc provider đó quản lý |

Slot App và CLI được lưu riêng trong `$AGENTKIT_HOME/auth/session.json`.
AgentKit home mặc định là `~/.agentkit` trên macOS và Linux, và
`%USERPROFILE%\.agentkit` trên Windows. Session file được bảo vệ bằng quyền chỉ
cho owner khi hệ điều hành hỗ trợ; điều đó không có nghĩa là có thể chia sẻ tệp
hoặc license key.

Sau khi xác minh online thành công, Desktop cho phép dùng offline tối đa 72 giờ.
Khi grace period hết hạn, hãy kết nối lại và xác minh license. Đăng xuất trong
Desktop xoá credential App cục bộ; thao tác này không revoke license từ xa hay
đăng xuất CLI.

## Hoàn tất onboarding

Desktop quét thiết lập cục bộ để tìm coding agent được hỗ trợ, project đã đăng
ký, Kit đã cài và được cấp quyền, cấu hình, health, license và update. Hãy xem
kết quả trước khi áp dụng thay đổi.

Bước Kit tuỳ chọn chỉ cài các Kit bạn chọn, ở global scope cho coding agent đã
phát hiện, từ Kit catalog mà Desktop v2.11.0 sử dụng. Bạn có thể bỏ qua nếu không
có runtime hoặc entitlement phù hợp. Sau khi cài, hãy khởi động lại coding
assistant hoặc mở runtime session mới trước khi dùng skill mới.

Desktop v2.11.0 không khởi động skill của Kit hay agent run. Hãy khởi chạy skill
đã cài trong coding assistant hoặc dùng quy trình CLI phù hợp.

## Dùng các quy trình chính

| Khu vực | Thao tác được hỗ trợ | Ranh giới quan trọng |
| --- | --- | --- |
| Kit và skill | Duyệt entitlement, kiểm tra skill, cài Kit, xem trước và áp dụng update Kit được hỗ trợ | Gỡ Kit là quy trình CLI; hãy xem trước trước khi xác nhận bằng `--yes` |
| Project | Đăng ký project cục bộ và kiểm tra trạng thái Kit | Xoá project chỉ xoá mục registry AgentKit, không xoá thư mục project |
| Activity | Theo dõi activity AgentKit cục bộ khi cửa sổ đang mở | Nguồn là `$AGENTKIT_HOME/activity/events.ndjson` |
| Session | Kiểm tra bằng chứng session Claude Code và Codex được hỗ trợ | Desktop là công cụ kiểm tra, không phải session launcher |
| MCP | Liệt kê và xác minh server, xem trước thay đổi cấu hình được hỗ trợ trước khi áp dụng | Xem kỹ preview vì cấu hình runtime đích có thể thay đổi |
| Cấu hình và store | Chỉnh thiết lập AgentKit, kiểm tra giá trị hiệu lực và tìm local store | Giá trị secret bị che trong Desktop; đừng sao chép raw config hoặc session file vào báo cáo |

Để xem hướng dẫn từng màn hình của các bề mặt này, xem [Tổng quan giao
diện](./interface-overview), [Quản lý entities](./managing-entities), [Project và
plan](./projects-and-plans), và [Cài đặt và hệ thống](./settings-and-system).

## Hiểu process cục bộ

Desktop nhúng giao diện và gọi Go backend trong cùng process. Ứng dụng không
khởi động browser dashboard, bind HTTP port hay ghi trạng thái dashboard server.
Đóng cửa sổ sẽ dừng Desktop API, Activity stream, session indexing và local
analytics reconciler.

Browser dashboard là bề mặt riêng. `ak config start` phục vụ nó trên loopback
`127.0.0.1:8766` theo mặc định. API server cũng riêng và mặc định là
`127.0.0.1:8765` khi được khởi động bằng `ak api start`.

## Biết dữ liệu nào cục bộ và thao tác nào dùng mạng

Desktop đọc trạng thái AgentKit như `config.yaml`, `projects.json`,
`activity/events.ndjson` và index cục bộ `analytics/analytics.db` dưới AgentKit
home. Index có thể reconcile nguồn session Claude Code và Codex được hỗ trợ khi
cửa sổ đang mở. Tuỳ chọn giao diện và tiến trình onboarding là trạng thái
Desktop cục bộ; xác thực vẫn nằm trong AgentKit session file được bảo vệ.

Truy cập mạng phụ thuộc vào thao tác:

- Kích hoạt App, kiểm tra entitlement và thao tác catalog Kit liên hệ dịch vụ
  AgentKit;
- Kiểm tra update, changelog và announcement liên hệ release service; và
- Feedback chỉ được gửi khi bạn chủ động submit.

Đừng đưa license key, session file, giá trị cấu hình chưa che hay nội dung
session riêng tư vào feedback hoặc chẩn đoán. Tiếp theo, hãy xem [cập nhật
Desktop có chữ ký](./updating) hoặc đến [xử lý sự cố](./troubleshooting).
