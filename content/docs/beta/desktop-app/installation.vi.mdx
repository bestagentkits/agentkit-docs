Sau trang này, bạn sẽ mở một gói AgentKit Desktop vAK_DESKTOP_VERSION đã được xác minh
checksum. Desktop được tải thủ công trong bản phát hành này; trình cài CLI không
cài ứng dụng.

## Tải gói phù hợp

Tải artifact vAK_DESKTOP_VERSION cho nền tảng của bạn từ bảng bên dưới. Cột
SHA-256 là digest đã công bố để bạn đối chiếu.

<DesktopDownloads />

Không có artifact Desktop nào được phát hành cho Linux ARM64 hoặc Windows ARM64
trong vAK_DESKTOP_VERSION. Đừng thay bằng archive có tên gần giống
`ak_AK_DESKTOP_VERSION_*`: đó là artifact CLI và không chứa cửa sổ Wails.

## Xác minh tệp tải xuống

Tính digest của chính artifact rồi so sánh đủ 64 ký tự thập lục phân với cột
SHA-256 trong bảng tải xuống. Dừng lại nếu kích thước tệp hoặc digest khác.

### macOS

```bash
shasum -a 256 AK_DESKTOP_FILE_darwin_arm64
```

Thay `arm64` bằng `amd64` trên máy Mac Intel.

### Linux

```bash
sha256sum AK_DESKTOP_FILE_linux_amd64
```

### Windows PowerShell

```powershell
Get-FileHash .\AK_DESKTOP_FILE_windows_amd64 -Algorithm SHA256
```

## Cài và mở ứng dụng

### macOS

1. Giải nén zip phù hợp.
2. Di chuyển `agentkit.app` vào `/Applications`.
3. Mở `agentkit.app`.

Nếu Gatekeeper chặn lần khởi chạy đầu, hãy xác nhận digest trước. Sau đó thử mở
ứng dụng một lần rồi dùng **System Settings → Privacy & Security → Open Anyway**
cho chính ứng dụng đó. Nếu bạn chủ động dùng phương án command-line cho bundle
đã xác minh, hãy chạy:

```bash
xattr -rd com.apple.quarantine /Applications/agentkit.app
```

Xác minh SHA-256 xác nhận byte đã tải, không xác nhận danh tính ký hay Apple
notarization. Hãy kiểm tra chữ ký của chính bundle thay vì giả định mọi build
đều dùng Developer ID. Ứng dụng đã ký chưa chắc đã được notarize.
Giữ Gatekeeper bật; đừng tạo ngoại lệ cho toàn hệ thống.

### Linux

Giữ AppImage trong thư mục ứng dụng do người dùng kiểm soát, rồi chạy:

```bash
chmod +x AK_DESKTOP_FILE_linux_amd64
./AK_DESKTOP_FILE_linux_amd64
```

Nếu có lỗi FUSE, hãy cài gói tương thích FUSE của distribution rồi thử lại cùng
AppImage đã xác minh. Đừng chạy ứng dụng bằng root.

Cửa sổ Desktop cũng cần runtime WebKitGTK 4.1 từ distribution của bạn; gói này
tự kéo theo GTK 3:

| Distribution | Gói |
| --- | --- |
| Debian và Ubuntu | `libwebkit2gtk-4.1-0` |
| Fedora | `webkit2gtk4.1` |
| Arch | `webkit2gtk-4.1` |

Nếu thiếu runtime này, ứng dụng thoát trước khi mở cửa sổ và nêu tên thư viện bị
thiếu.
CLI không dùng WebKitGTK nên vẫn hoạt động bình thường.

AppImage không đi kèm thư viện GTK, GLib, WebKitGTK, libsoup hay GStreamer; ứng
dụng luôn dùng bản do distribution cung cấp. WebKit khởi động các tiến trình
helper từ một vị trí được build sẵn vào thư viện đang được nạp, nên dùng thư
viện của distribution giúp thư viện và các helper luôn cùng phiên bản và đúng bố
cục của distribution. Vì vậy runtime 4.1 là yêu cầu GUI duy nhất. Cửa sổ
đã được xác minh mở được trên Debian 13, Ubuntu 26.04 và Fedora 45; Arch dự kiến
hoạt động tương tự nhưng chưa được xác minh.

### Windows

1. Giải nén `AK_DESKTOP_FILE_windows_amd64` vào thư mục ứng dụng do người dùng
   kiểm soát.
2. Chạy `ak-gui.exe` trong thư mục đã giải nén.

Nếu SmartScreen xuất hiện, hãy kiểm tra lại SHA-256 trước. Với artifact chính
thức khớp checksum, chọn **More info → Run anyway**. Giữ endpoint protection bật.

## Cài CLI riêng khi cần

Desktop có thể quản lý giao diện mà không cần HTTP port, nhưng lệnh terminal và
paired updater của Desktop cần CLI `ak` tiêu chuẩn được cài riêng. Làm theo
[Cài CLI](../getting-started/installation), rồi xác nhận:

```bash
ak --version
```

CLI và Desktop nên báo cùng bản phát hành trước khi bạn bật auto-update Desktop.
Chạy `ak gui` từ CLI tiêu chuẩn không khởi chạy bản cài Desktop riêng.

## Gỡ Desktop

Không có trình gỡ Desktop trong vAK_DESKTOP_VERSION. Hãy thoát ứng dụng, tuỳ chọn đăng xuất
trong **Profile** để xoá App session cục bộ, rồi chỉ xoá mục bạn đã cài:

- `/Applications/agentkit.app` trên macOS;
- Đúng tệp `AK_DESKTOP_FILE_linux_amd64` trên Linux; hoặc
- Thư mục Desktop đã giải nén chứa `ak-gui.exe` trên Windows.

Thao tác này không gỡ CLI, Kit đã cài, tệp runtime hay trạng thái AgentKit.
`ak uninstall` là lệnh gỡ project được quản lý, không phải trình gỡ Desktop.
Đừng xoá toàn bộ `~/.agentkit`, `%USERPROFILE%\.agentkit`, `.claude` hoặc
`.codex`. Tiếp tục với [Lần khởi chạy đầu tiên](./getting-started).
