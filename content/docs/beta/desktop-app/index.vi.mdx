AgentKit Desktop cung cấp cửa sổ native để kiểm tra và quản lý trạng thái
AgentKit trên máy này. Hãy dùng ứng dụng khi bạn muốn thiết lập lần đầu có hướng
dẫn, điều khiển vòng đời Kit bằng giao diện hoặc xem activity và session cục bộ
mà không phải thực hiện từng thao tác từ terminal.

## Chọn đúng bề mặt

Desktop, CLI và browser dashboard dùng chung dữ liệu AgentKit nhưng là các bề
mặt khởi chạy khác nhau.

| Bề mặt | Phù hợp nhất cho | Cách chạy |
| --- | --- | --- |
| Ứng dụng Desktop | Thiết lập có hướng dẫn và quản lý cục bộ bằng giao diện | Gói Wails riêng có giao diện nhúng và Go API trong cùng process |
| CLI `ak` | Lệnh chính xác, automation, host headless và phạm vi lệnh đầy đủ | Executable terminal được cài riêng trong `PATH` |
| Browser dashboard | Giao diện trong browser, gồm cả dùng từ xa hoặc headless khi được cấu hình an toàn | HTTP server cục bộ do `ak config start` khởi động; mặc định là loopback `127.0.0.1:8766` |

Cài Desktop không cài CLI `ak` tiêu chuẩn vào `PATH`. Artifact CLI thông thường
cũng không chứa Wails: chạy `ak gui` từ artifact đó sẽ in gợi ý tải Desktop thay
vì tìm ứng dụng bạn đã cài ở nơi khác. Đọc [tham chiếu `ak gui` được biên
soạn](../reference/cli-samples/ak%20gui) để biết ranh giới chính xác của lệnh.

## Gói v2.7.0 được hỗ trợ

| Hệ điều hành | Kiến trúc Desktop |
| --- | --- |
| macOS | Intel (`amd64`) và Apple silicon (`arm64`) |
| Linux | Chỉ x64 (`amd64`) |
| Windows | Chỉ x64 (`amd64`) |

Không có gói Desktop v2.7.0 cho Linux ARM64 hoặc Windows ARM64. CLI vẫn khả dụng
trên cả hai. Ma trận phát hành Desktop không bao gồm hệ điều hành, kiến trúc hay
host 32-bit khác.

Tiếp tục đến [Cài đặt](./installation) để xem chính xác tên gói và giá trị
SHA-256.

## Bạn có thể làm gì

Sau khi kích hoạt license App trên thiết bị này, Desktop có thể:

- quét coding agent đã cài, project đã đăng ký, Kit khả dụng, health, cấu hình
  và trạng thái cập nhật;
- duyệt Kit và skill, cài Kit được cấp quyền, xem trước và áp dụng các cập nhật
  Kit được hỗ trợ;
- đăng ký project cục bộ và kiểm tra bản cài Kit ở project scope hoặc global;
- kiểm tra Activity cục bộ và bằng chứng session Claude Code, Codex được hỗ trợ;
- liệt kê, xác minh và xem trước thay đổi cấu hình MCP được hỗ trợ trước khi áp
  dụng; và
- chỉnh cấu hình AgentKit, kiểm tra thiết lập hiệu lực và tìm local data store
  của AgentKit.

Desktop v2.7.0 không khởi chạy skill của Kit hay agent run. Hãy chạy skill đã
cài trong coding assistant của nó hoặc dùng lệnh CLI phù hợp. Sau đó Desktop sẽ
đọc bằng chứng Activity và session cục bộ thu được nếu runtime đó được hỗ trợ.
