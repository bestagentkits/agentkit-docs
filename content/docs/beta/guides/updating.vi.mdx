`ak` tự cập nhật từ kênh phát hành đã ký. Mỗi lần cập nhật xác minh metadata
phát hành và artifact đích trước khi thay binary đang chạy.

## Kiểm tra trước

Giữ kênh beta bằng cờ tường minh:

```bash
ak self-update --check --channel beta           # có bản mới hơn không?
ak changelog --since-current --channel beta     # đổi gì kể từ phiên bản của tôi?
ak self-update --changelog --channel beta       # in thay đổi đã xác minh trực tiếp
```

## Áp dụng

Apply thủ công trên CLI cần `--yes`:

```bash
ak self-update --channel beta --yes
```

## Cài bằng trình quản lý gói

Nếu `ak` chứng minh binary đang chạy thuộc trình quản lý gói (Homebrew,
Scoop), cả check và apply đều báo **managed install** và in lệnh gốc của trình
quản lý thay vì thay tệp:

```bash
brew upgrade ak      # Homebrew
scoop update ak      # Scoop
```

<Callout type="info">
  Chỉ có trình quản lý trên máy là chưa đủ — executable đang resolve phải nằm
  trong prefix của trình quản lý đó thì `ak` mới coi là managed.
</Callout>

## Rollback

Để quay về bản phát hành **binary** trước, cài lại phiên bản đó. Binary
self-update không tạo bản ghi `ak backups`:

```bash
curl -fsSL https://agentkit.best/install.sh | AK_CHANNEL=beta AK_VERSION=<previous-tag> sh
```

`ak backups restore` khôi phục snapshot **state dự án/vòng đời** (ví dụ sau
`ak update` hoặc gỡ kit), không phải binary đã cài:

```bash
ak backups list
ak backups restore --latest
```

Ghi lại `ak --version` và `ak doctor --json` nếu bạn đang báo cáo sự cố cập nhật.
