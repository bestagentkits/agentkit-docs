---
title: Recommended Pi extensions
description: Extend your AgentKit Pi setup with subagents, a statusline, advice, media tools, code feedback, web access, model fallback, and MCP.
---

Pi keeps its core small. AgentKit adds Kit content to your Pi setup; you can
then choose extensions for the capabilities your work needs. The packages below
are optional additions, installed and configured separately through Pi.

If you have not installed your Kit yet, start with
[Installing kits](./installing-kits#use-native-pi).

## Choose your extensions

Each package name links to its maintainer's documentation for current setup
requirements and usage.

| Extension | What it adds | When to use it |
| --- | --- | --- |
| [pi-subagents](https://github.com/nicobailon/pi-subagents) | Delegation to focused child agents, parallel work, background tasks, and saved workflows. | Split research, implementation, and review into separate tasks. |
| [statusline-pi](https://github.com/luongnv89/pi-extensions/tree/main/extensions/statusline-pi) | A compact footer with Git state, context remaining, model, response speed, and estimated session cost. | Keep session and project status visible while working. |
| [advisor-pi](https://github.com/luongnv89/pi-extensions/tree/main/extensions/advisor-pi) | An `advisor` tool that asks another model for strategic guidance using conversation context. The advisor cannot use tools or edit files. | Get a second opinion on a plan, risk, or difficult decision. |
| [pi-multix](https://github.com/bestagentkits/pi-multix) | Image, video, and audio generation, document conversion, and local media processing through multix. | Produce or process media alongside code and content. |
| [pi-lens](https://github.com/apmantza/pi-lens) | Code feedback through language servers, linters, formatters, type checking, and structural analysis. | Give Pi diagnostic feedback as it reads and edits code. |
| [pi-web-access](https://github.com/nicobailon/pi-web-access) | Web search and content extraction from URLs, with additional document and video capabilities. | Research current documentation and bring external sources into a task. |
| [pi-model-fallback](https://github.com/eiei114/pi-model-fallback) | Automatic model switching when provider failures match configured rules. | Continue work through rate limits or provider errors using a chosen fallback. |
| [pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter) | MCP server access with on-demand tool discovery and lazy connections. | Connect Pi to tools and services exposed through MCP. |

For everyday coding, start with the statusline, code feedback, or web access you
need. Add subagents and an advisor for work that benefits from delegation or a
second opinion. Media, fallback, and MCP extensions serve more specific needs;
you do not need to install the entire list.

## Install through Pi

Run only the commands for the extensions you want:

```bash
pi install npm:pi-subagents
pi install npm:statusline-pi
pi install npm:advisor-pi
pi install npm:pi-multix
pi install npm:pi-lens
pi install npm:pi-web-access
pi install npm:pi-model-fallback
pi install npm:pi-mcp-adapter
```

These commands register packages in Pi's user scope. Add `-l` for a
project-local install, for example `pi install -l npm:statusline-pi`.
Restart Pi after installation so the new extensions load.

Use Pi's package manager for their lifecycle. For example:

```bash
pi list
pi update npm:statusline-pi
pi remove npm:statusline-pi
```

## Finish the setup

- **Subagents:** this guide recommends the unscoped `pi-subagents` package by
  nicobailon, which exposes the `subagent` tool. It is a different package from
  `@tintinweb/pi-subagents`; do not assume their tools or settings are interchangeable.
- **Statusline:** use `/statusline-pi` to toggle the footer. The PR indicator
  uses the GitHub CLI (`gh`) and is omitted when it is unavailable.
- **Advisor:** use `/advisor-pi status` to inspect the configuration and
  `/advisor-pi model <provider>/<model>` to choose an authenticated model.
  Consultations send conversation context to that model and use its quota or billing.
- **Media:** pi-multix bundles the multix CLI. Provider-backed generation needs
  a provider API key; local media processing needs `ffmpeg` or ImageMagick.
  Ask Pi to run `multix_check` to see what is available.
- **Code feedback:** follow pi-lens's current Node.js requirements and language
  setup instructions. Available diagnostics depend on the language tools it can use.
- **Web:** pi-web-access documents a keyless search option and additional
  providers with their own authentication. Configure the provider you want to use.
- **Fallback:** configure matching rules and an authenticated destination model
  for your providers. Installing the package does not create a universal fallback
  chain. Use `/model-fallback:status` to inspect its state.
- **MCP:** use `/mcp setup` to configure or adopt servers, then `/mcp` to inspect
  them. Follow the adapter's configuration guide for server credentials and tools.

AgentKit Kit updates and Pi package updates are separate operations. Keep each
extension's configuration with its own package, and use
[Updating](./updating) for AgentKit itself.
