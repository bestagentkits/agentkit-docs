`ak` updates itself from the signed release channel. Every update verifies the
release metadata and the target artifact before replacing the running binary.

## Check first

```bash
ak self-update --check              # is a newer release available?
ak changelog --since-current        # what changed since my version?
ak self-update --changelog          # print the verified changes directly
```

## Apply

Update on your channel. Pass `--yes` to skip the confirmation prompt in scripts:

```bash
ak self-update --channel stable --yes
```

## Package-manager installs

If `ak` proves the running binary belongs to a package manager (Homebrew,
Scoop), both check and apply report a **managed install** and print the
manager-native command instead of replacing files:

```bash
brew upgrade ak      # Homebrew
scoop update ak      # Scoop
```

<Callout type="info">
  A manager installed elsewhere on the machine is not enough — the resolved
  running executable must live inside that manager's prefix for `ak` to treat it
  as managed.
</Callout>

## Roll back

To return to a previous release, reinstall that version and restore the
pre-update snapshot:

```bash
ak backups list
ak backups restore --latest
```

Record the resulting `ak --version` and `ak doctor --json` if you are reporting
an update problem.
