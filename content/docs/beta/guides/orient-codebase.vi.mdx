Repo mới, vùng lạ, hoặc blast radius lớn — định hướng trước để brainstorm /
plan / fix sau này trích path thật.

<Callout type="info">
  Scout là lối vào mặc định. Ghép repomix hoặc công cụ graph khi cần snapshot
  context gói gọn. Cú pháp skill:
  [bảng tra kit Engineer](../kits/engineer).
</Callout>

## Khi nào dùng

- Ngày đầu trên service/module chưa từng chạm.
- Trước plan có thể trải nhiều package.
- Khi debug cần bản đồ caller và config.

## Workflow

<Steps>
<Step>

### Bản đồ nhanh

```text
/ak:scout auth middleware session cookie
```

Tìm symbol, config, test gần đó. Ưu tiên search native; chỉ leo probe ngoài khi
skill ghi rõ và bạn cho phép.

</Step>
<Step>

### Gói context khi cây lớn

```text
/ak:repomix
```

Dùng repomix (hoặc packer kit ship) khi agent cần snapshot file liên quan có
biên. Giữ scope — dump cả monorepo làm loãng tín hiệu.

</Step>
<Step>

### Bàn giao kèm bằng chứng

Tóm tắt: loại project, module liên quan, pattern hiện có, plan đang mở trong
`./plans/`, contract công khai không được phá. Rồi sang
[vòng lặp cốt lõi](./core-loop) hoặc [gỡ lỗi và sửa](./debug-and-fix) với
tóm tắt đó trong prompt.

</Step>
</Steps>

## Prompt mẫu

```text
/ak:scout rate limit redis
/ak:scout "export function createSession" ts
/ak:repomix
```

## Cạm bẫy

- **Định hướng mãi** — dừng khi gọi được path và constraint; plan bắt đầu sau đó.
- **Pack không scope** — context window khổng lồ che file quan trọng.
- **Đoán hành vi từ tên** — mở file; đừng bịa API từ tên thư mục.
