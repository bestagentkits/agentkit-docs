---
title: Cài kit
description: Cài kit vào một hoặc nhiều runtime trợ lý, chọn hoặc loại trừ skill, và refresh an toàn.
---

Một **kit** là một bộ skill dành cho trợ lý lập trình. `ak` phân giải kit từ
registry đã xác thực, xác minh nó, rồi ghi vào runtime mà bạn chọn.

## Target

Dùng `--target` để chọn runtime mà kit sẽ được cài vào. Bạn có thể cài cùng một
kit vào nhiều runtime khác nhau:

```bash
ak kit init engineer --target claude-code --global
ak kit init engineer --target codex --global
```

`--global` cài cho toàn bộ tài khoản người dùng thay vì chỉ một dự án đơn lẻ.

## Chọn skill

Chỉ cài những skill bạn muốn, hoặc cài tất cả trừ một vài skill:

```bash
# chỉ các skill này
ak kit install engineer --target codex --global --skills ak-cook,ak-plan

# mọi thứ trừ các skill này
ak kit install engineer --target claude-code --global --exclude-skills ak-video
```

`--select-skills` sẽ mở một picker tương tác. Các tệp đi kèm mà mỗi skill cần
(references, scripts, assets) sẽ được cài cùng.

## Refresh

Một lần refresh bằng `--force` sau này vẫn giữ nguyên tập skill bạn đã chọn, trừ
khi bạn truyền vào lựa chọn mới. Nghĩa là bạn có thể chạy lại lệnh cài để nhận
bản cập nhật kit mà không mất các skill đã chọn.

## Gọi skill

Sau khi cài xong, gọi skill bằng slash command ngay trong trợ lý:

```text
/ak:cook      # skill core dùng chung (có trong mọi kit)
/ak:agentize  # skill của engineer kit
```

Lời gọi skill luôn dùng chung tiền tố `ak:`, bất kể skill thuộc kit nào. Tên kit
khi gõ trên dòng lệnh vẫn viết thường (`ak kit init engineer`,
`ak kit uninstall engineer`).

## Gỡ kit

Hãy gỡ kit thông qua `ak` để nó hủy đăng ký kit khỏi runtime và chỉ xóa những
tệp do nó quản lý:

```bash
ak kit uninstall engineer --dry-run   # xem trước
ak kit uninstall engineer --yes
```

Quá trình gỡ sẽ tạo snapshot trước khi ghi và giữ nguyên những tệp lạ hoặc tệp
do người dùng chỉnh sửa.
