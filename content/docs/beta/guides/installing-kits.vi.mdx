---
title: Cài kit
description: Cài kit vào một hoặc nhiều runtime trợ lý, chọn hoặc loại trừ skill, và refresh an toàn.
---

Một **kit** là bó skill cho trợ lý lập trình. `ak` phân giải kit từ registry đã
xác thực, xác minh, rồi ghi vào runtime bạn chọn.

## Target

Chọn runtime kit cài vào bằng `--target`. Bạn có thể cài cùng một kit vào nhiều
runtime:

```bash
ak kit init engineer --target claude-code --global
ak kit init engineer --target codex --global
```

`--global` cài cho tài khoản người dùng thay vì một dự án đơn lẻ.

## Chọn skill

Chỉ cài skill bạn muốn, hoặc cài tất cả trừ một vài skill:

```bash
# chỉ các skill này
ak kit install engineer --target codex --global --skills ak-cook,ak-plan

# mọi thứ trừ các skill này
ak kit install engineer --target claude-code --global --exclude-skills ak-video
```

`--select-skills` mở picker tương tác. Các tệp đi kèm mỗi skill cần
(references, scripts, assets) được cài cùng.

## Refresh

Một lần refresh `--force` sau đó giữ subset bạn đã chọn trừ khi bạn truyền lựa
chọn mới. Nghĩa là bạn có thể chạy lại lệnh cài để nhận cập nhật kit mà không
mất lựa chọn skill.

## Gọi skill

Sau khi cài, gọi skill bằng slash command trong trợ lý:

```text
/ak:cook      # skill core dùng chung (có trong mọi kit)
/ak:agentize  # skill của engineer kit
```

Lời gọi skill luôn dùng một tiền tố `ak:` bất kể kit nào. Tên kit trên dòng
lệnh vẫn viết thường (`ak kit init engineer`, `ak kit uninstall engineer`).

## Gỡ kit

Gỡ qua `ak` để nó hủy đăng ký kit khỏi runtime và chỉ xóa tệp nó sở hữu:

```bash
ak kit uninstall engineer --dry-run   # xem trước
ak kit uninstall engineer --yes
```

Uninstall tạo snapshot trước khi ghi và giữ nguyên tệp lạ hoặc tệp người dùng
đã sửa.
