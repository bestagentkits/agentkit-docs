The desktop app opens AgentKit in a **native window**, backed by the same
binary as the CLI. Use it when you prefer point-and-click access to kit
browsing, agent runs, and dashboards. The CLI exposes the same operations for
scripting — see [`ak gui`](./reference/cli/ak_gui).

## Who it is for

Non-technical users and power developers who want a graphical surface for kit
and agent operations without giving up the CLI for automation.

## License and entitlements

Two checks stay separate:

- **App license** unlocks the desktop shell.
- **Kit entitlement** controls which kits you can download and install.

Signing in alone does not unlock the desktop app. The onboarding checklist covers
this in the [Desktop app step](./getting-started/onboarding).

## Platform support

`ak gui` is not packaged on every platform (for example **linux/arm64** and
**windows/arm64**). The CLI works normally on those targets even when the GUI
is unavailable.

When the app is available for your platform:

```bash
ak gui
```

Use `--no-interactive` in CI so the command fails fast instead of blocking on a
window.
