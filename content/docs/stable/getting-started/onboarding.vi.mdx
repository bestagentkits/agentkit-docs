Khi `ak` đã được cài, checklist này đưa bạn đến một setup chạy được và cho biết
dữ liệu nằm ở đâu.

<Steps>
  <Step>
    ### Xác nhận bản cài

    ```bash
    ak --version
    ak doctor --json
    ```

    `ak doctor` báo cáo sức khỏe môi trường và cấu hình. Dùng `--json` khi bạn
    muốn output máy đọc được để gửi kèm yêu cầu hỗ trợ.
  </Step>
  <Step>
    ### Xác thực

    ```bash
    ak login
    ak whoami --json
    ak licenses --json
    ```

    Hai kiểm tra tách biệt: **đăng nhập** nhận diện bạn, còn **quyền kit** kiểm
    soát kit nào bạn tải và cài được. Nếu kit bạn kỳ vọng thiếu trong
    `ak licenses`, tài khoản chưa được cấp — dừng trước khi thử cài.
  </Step>
  <Step>
    ### Cài một kit

    ```bash
    ak kit init engineer --target claude-code --global
    ```

    Bạn có thể cài vào nhiều runtime (ví dụ Claude Code và Codex). Xem
    [Cài kit](../guides/installing-kits) về target và chọn skill.
  </Step>
  <Step>
    ### App desktop (tùy chọn)

    App desktop mở sau cổng license: lần chạy mới hiện kích hoạt và hỗ trợ cho
    đến khi license app hợp lệ mở shell. License app (mở shell desktop) và quyền
    kit (kiểm soát tải kit) độc lập — chỉ đăng nhập bằng API key hoặc email
    không mở khóa app desktop.
  </Step>
</Steps>

## Cập nhật

Kiểm tra rồi mới áp dụng trên kênh stable. Apply thủ công cần `--yes`:

```bash
ak self-update --check --channel stable --json
ak self-update --channel stable --yes
```

Xem thay đổi trước khi cập nhật:

```bash
ak changelog --since-current --channel stable
```

## Backup và rollback

AgentKit giữ nguyên tệp lạ và tệp người dùng đã sửa trong thao tác thường.
Ghi phá hủy được theo dõi cần xác nhận tường minh và tạo snapshot khôi phục
trước. `ak backups restore` khôi phục **state dự án/vòng đời**, không phải
binary đã cài:

```bash
ak backups list --json
ak backups restore --latest     # khôi phục snapshot state trước thay đổi gần nhất
```

Để rollback **binary**, cài lại bản phát hành trước (ví dụ `AK_VERSION=<tag>`
trên trình cài). Xem [Cập nhật ak](../guides/updating).

## Phản hồi

Gửi phản hồi trực tiếp từ CLI:

```bash
ak feedback --type bug --title "Short title" --body "What happened" --yes
ak feedback --type feature --title "Request" --motivation "Why it matters"
```

Ghi OS và kiến trúc, lệnh hoặc màn hình liên quan, và tag phát hành. Chỉ đính
kèm tóm tắt `ak doctor` đã redacted với `--attach-diagnostics` khi hỗ trợ yêu
cầu — diagnostics đầy đủ ở lại máy bạn.

<Callout type="warn">
  Không bao giờ chia sẻ tệp môi trường thô, cấu hình provider, khóa riêng,
  license key, hoặc transcript phiên. Dùng `ak diagnostics export --json` để tạo
  bundle đã redacted trước khi gửi bằng chứng.
</Callout>

## Giới hạn đã biết

- Tạo dự án, thao tác vòng đời phá hủy, và mutation plan chỉ trên CLI; dashboard
  cục bộ (`ak gui` / `ak config`) chỉ đọc với các thao tác đó.
- Bind dashboard ngoài loopback cần auth token.
- Không có telemetry — không SDK analytics và không usage beacon.
