AgentKit chỉ là một binary duy nhất, `ak`. Trình cài đặt tự nhận diện nền tảng,
tải archive đã xác thực theo kênh bạn chọn và cài `ak` vào thư mục đích. Trình
cài đặt có tính idempotent — chạy lại bất cứ lúc nào để nâng cấp tại chỗ.

## Cài nhanh

<Tabs items={['macOS / Linux', 'Windows']}>
  <Tab value="macOS / Linux">

```bash
curl -fsSL https://agentkit.best/install.sh | sh
```

Mặc định cài vào `~/.local/bin` trên kênh **stable**. Trình cài đặt không đụng
đến shell profile — hãy tự thêm `~/.local/bin` vào `PATH` nếu sau khi cài không
tìm thấy `ak`.

  </Tab>
  <Tab value="Windows">

```powershell
irm https://agentkit.best/install.ps1 | iex
```

Cài vào `%USERPROFILE%\bin`, tự thêm vào `PATH` của người dùng và dùng kênh
**stable** mặc định. Hãy mở terminal mới sau khi cài.

  </Tab>
</Tabs>

<Callout type="info">
  Nếu mạng công ty chặn domain chính, host phát hành `releases.agentkit.best`
  phục vụ trình cài đặt giống hệt từng byte với cùng chuỗi xác minh — chỉ cần
  thay vào một trong hai lệnh trên.
</Callout>

## Xác minh và cấu hình

<Steps>
  <Step>
    ### Xác minh binary

    Kiểm tra phiên bản đã cài và xác nhận `ak` đã có trên `PATH`:

    ```bash
    ak --version
    ```

    Nếu gặp `command not found`, hãy đảm bảo thư mục cài (`~/.local/bin`, hoặc
    `%USERPROFILE%\bin` trên Windows) đã nằm trong `PATH`.
  </Step>
  <Step>
    ### Chọn kênh (tùy chọn)

    Mặc định là `stable`. Để cài kênh beta, đặt `AK_CHANNEL` trước khi pipe vào
    trình cài đặt:

    <Tabs items={['macOS / Linux', 'Windows']}>
      <Tab value="macOS / Linux">

    ```bash
    curl -fsSL https://agentkit.best/install.sh | AK_CHANNEL=beta sh
    ```

      </Tab>
      <Tab value="Windows">

    ```powershell
    $env:AK_CHANNEL = "beta"; irm https://agentkit.best/install.ps1 | iex
    ```

      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Xử lý cảnh báo lần chạy đầu

    Metadata phát hành và hash của archive được ký mật mã để chứng minh nguồn
    gốc. Binary của AgentKit chưa được Apple notarize hay Microsoft ký, nên hệ
    điều hành có thể cảnh báo ở lần chạy đầu tiên. Xem ghi chú cho nền tảng của
    bạn bên dưới — đây là thao tác chỉ cần làm một lần cho mỗi lần cài.
  </Step>
</Steps>

## Lần chạy đầu theo nền tảng

<Accordions type="single">
  <Accordion title="macOS">
    Binary tải bằng `curl` không mang cờ quarantine nên CLI chạy được ngay. Nếu
    bạn tải qua trình duyệt, hãy xóa cờ này một lần:

    ```bash
    xattr -d com.apple.quarantine ~/.local/bin/ak
    ```

    Không cần `sudo` — tệp này thuộc về bạn.
  </Accordion>
  <Accordion title="Linux">
    CLI không cần thêm bước nào. Chỉ cần đảm bảo thư mục cài nằm trong `PATH`:

    ```bash
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
    ```
  </Accordion>
  <Accordion title="Windows">
    Lần đầu chạy một binary chưa được nhận diện, SmartScreen có thể hiện
    *"Windows protected your PC."* Bấm **More info → Run anyway**. Windows sẽ ghi
    nhớ chấp thuận cho binary đó trên chính máy đó; những lần chạy sau sẽ không
    hiện lại.
  </Accordion>
</Accordions>

## Biến ghi đè khi cài

Đặt các biến này trước khi pipe vào trình cài đặt để thay đổi hành vi mặc định.

| Biến | Mặc định | Tác dụng |
| --- | --- | --- |
| `AK_CHANNEL` | `stable` | Kênh phát hành để cài (`stable` hoặc `beta`). |
| `AK_VERSION` | mới nhất | Ghim một phiên bản chính xác, ví dụ `AK_VERSION=1.0.0`. |
| `AK_INSTALL_DIR` | `~/.local/bin` (`%USERPROFILE%\bin` trên Windows) | Thư mục cài đích. |

## Cập nhật

`ak` xác minh metadata phát hành đã ký và artifact đích trước khi tự thay thế
chính nó. Trên cây tài liệu stable, luôn truyền `--channel stable` tường minh —
kênh trống mặc định là beta:

```bash
ak self-update --check --channel stable   # chỉ đọc: có bản mới hơn không?
ak self-update --channel stable --yes     # áp dụng (cần --yes)
```

Nếu `ak` được cài bằng trình quản lý gói, `self-update` sẽ báo đây là bản managed
và in ra lệnh gốc của trình quản lý thay vì thay tệp.

## Gỡ cài đặt

Hãy gỡ các kit đã cài trước để AgentKit hủy đăng ký gọn gàng, rồi mới xóa binary
và state:

```bash
ak kit list-kits
ak kit uninstall <kit> --yes        # lặp cho mỗi kit đã cài

rm ~/.local/bin/ak                  # macOS / Linux
rm -rf ~/.agentkit                  # project registry, kit, cache
```

Trên Windows, xóa `ak.exe` khỏi thư mục cài và xóa `%USERPROFILE%\.agentkit`.
