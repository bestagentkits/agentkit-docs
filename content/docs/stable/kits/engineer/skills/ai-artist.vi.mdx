Dùng `ak:ai-artist` để biến visual concept thành prompt Nano Banana đã tinh
chỉnh và một hoặc nhiều asset PNG được tạo. Skill tìm trong bộ 129 prompt
pattern đi kèm, xác minh style, mood cùng hướng màu dự kiến, rồi chuyển rendering
qua backend `ak:ai-multimodal` tới model ảnh Google trực tiếp hoặc qua OpenRouter.

## Chọn image generation dẫn dắt bằng prompt

### Dùng ak:ai-artist khi

- Bạn cần product mockup, campaign visual, social asset, banner, infographic,
  avatar, concept art hoặc khám phá style.
- Một prompt tuyển chọn có thể neo visual direction nhất quán.
- Bạn muốn kết quả gần nhất, remix nhiều pattern hoặc biến đổi style thử nghiệm.
- Bạn muốn kiểm tra prompt đã lắp ghép trước khi provider generation.

### Chọn workflow khác khi

- Bạn cần kiểm tra hoặc biến đổi input image, audio, video hay document có sẵn.
  Dùng [`ak:ai-multimodal`](./ai-multimodal).
- Bạn cần resize, composite, encode hoặc xóa background local, xác định được.
  Dùng [`ak:media-processing`](./media-processing).
- Bạn cần hướng dẫn layout, typography, accessibility và implementation cho
  product interface. Dùng [`ak:frontend-design`](./frontend-design).
- Bạn không thể gửi concept hay reference material tới AI provider bên ngoài.

## Chuẩn bị brief và provider

Trước khi bắt đầu:

- Hoàn thành [Làm quen](../../../getting-started/onboarding) và xác nhận
  Engineer Kit đã được cài cho runtime cùng scope hiện tại.
- Cung cấp subject, audience, use case, style, mood, palette, composition,
  aspect ratio, in-image text chính xác, exclusion và output location.
- Quyết định validation interview có được bỏ qua bằng `--skip` hay không. Nếu
  không có tùy chọn rõ ràng đó, Skill phải tinh chỉnh brief trước generation.
- Bảo đảm Python 3 và `npx` khả dụng. Rendering script tải và chạy package được
  pin `@mrgoonie/multix`.
- Cấu hình `GEMINI_API_KEY` cho Google trực tiếp hoặc `OPENROUTER_API_KEY` cho
  OpenRouter, rồi duyệt provider terms, network use và budget.
- Xác nhận prompt cùng brand information được phép rời máy local.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:ai-artist ...` | Skill có thể chạy Python workflow và provider subprocess khi local tool, credential cùng network được duyệt. |
| Cursor | `/ak:ai-artist ...` | Cách gọi bằng slash đã được người dùng xác minh; subprocess, credential và artifact handling tương đương phụ thuộc Cursor session. |
| Codex | `$ak:ai-artist ...` | Native discovery được hỗ trợ; image tool bên ngoài, provider access và approval behavior không tự động tương đương. |

### Chọn hình dạng generation

| Input hoặc tùy chọn | Behavior | Output quan sát được |
| --- | --- | --- |
| Không chọn mode, hoặc `--mode search` | Dùng prompt tuyển chọn khớp nhất | Một image tại output path yêu cầu |
| `--mode creative` | Remix cấu trúc và style hint từ các prompt khớp hàng đầu | Một interpretation kết hợp |
| `--mode wild` | Áp dụng ngẫu nhiên một artistic transformation thử nghiệm | Một interpretation không xác định |
| `--mode all` | Chạy search, creative và wild | Ba tệp có suffix `-search`, `-creative` và `-wild` |
| `--provider auto` | Tôn trọng `IMAGE_GEN_PROVIDER`; nếu không, chọn từ credential Google hoặc OpenRouter đã cấu hình | Provider đã dùng nên xuất hiện trong verbose evidence |
| `--model flash2|flash|pro` | Chọn alias model Nano Banana đã khai báo; script mặc định `flash2` | Model ID được ghi nhận khi chạy thành công |
| `-ar, --aspect-ratio` | Chọn ratio được hỗ trợ như `1:1`, `16:9` hoặc `9:16` | Image có composition ratio yêu cầu |
| `--size 1K|2K|4K` | Chọn image size phía provider; mặc định `2K` | Output resolution phụ thuộc provider |
| `--dry-run` | Lắp ghép và in prompt mà không gọi image generation | Bằng chứng prompt, không có image file |
| `--skip` trên cách gọi Skill | Bỏ validation interview bắt buộc | Generation script không định nghĩa flag này |

## Quan sát các giai đoạn sáng tạo

1. **Skill xác minh brief.** Trừ khi `--skip` rõ ràng, Skill giải quyết khoảng
   trống quan trọng về subject, style, mood, color, text và output intent.
2. **Skill tìm pattern local.** BM25 xếp hạng các prompt row đi kèm theo concept;
   search mode dùng prompt cơ bản nếu không row nào có score lớn hơn zero.
3. **Skill điều chỉnh prompt.** Placeholder được thay bằng concept và negative
   constraint được thêm nếu source chưa có.
4. **Skill áp dụng mode đã chọn.** Creative kết hợp matched hint; wild chọn
   random transformation; all chuẩn bị ba variant.
5. **Skill resolve provider và model.** Script chọn command Google trực tiếp hay
   OpenRouter dựa trên option, environment và credential.
6. **Skill render tệp.** Subprocess gửi prompt cùng parameter tới provider và
   ghi PNG path yêu cầu, với timeout năm phút trong script.
7. **Skill trả bằng chứng.** Final prompt khi được yêu cầu, provider, model,
   output path, failure và visual review note được báo cáo.

## Kiểm soát quyền riêng tư, quyền sử dụng, chi phí và tính ngẫu nhiên

<Callout type="warn" title="Generation gửi creative material tới provider bên ngoài">
  Prompt, brand detail, exact text và provider metadata rời môi trường local.
  Không đưa secret, dữ liệu khách hàng riêng tư, source asset được bảo vệ hay
  identity reference vào nếu chưa có quyền và quyền sử dụng phù hợp.
</Callout>

- `npx` có thể tải và thực thi rendering package đã pin; generation dùng network,
  provider quota, compute và có thể là request tính phí.
- `--mode all` tạo ba provider call. Request lỗi hoặc timeout vẫn có thể dùng
  provider resource; kiểm tra account trước khi retry.
- Wild mode là random và provider generation không được bảo đảm tái lập. Giữ
  tệp đã chọn cùng prompt thay vì giả định rerun giống nhau.
- Generated text, logo, anatomy, factual diagram và brand element chính xác có
  thể sai. Hãy kiểm tra pixel; prompt thành công không phải asset approval.
- Xác minh usage right, likeness consent, trademark và disclosure cần thiết
  trước publish. Skill không cấp quyền cho source prompt hay output.
- Generation ghi tệp nhưng không publish, upload, commit hay deploy trừ khi một
  workflow riêng đã được cấp quyền thực hiện.

## Xác minh output

Kết quả hoàn tất nên gồm:

- Brief đã xác minh, mode, aspect ratio, size, provider và model đã chọn.
- Final prompt hoặc tóm tắt an toàn, gồm exact text và negative constraint.
- Mọi output path cùng quan hệ giữa từng tệp với mode.
- Visual check cho subject, composition, text, unwanted element, artifact và
  brand constraint.
- Provider error, timeout, credential thiếu, retry nhạy cảm chi phí và review
  quyền hay privacy còn cần.

Stable và beta ship cùng prompt data, script và source `ak:ai-artist`. Không có
release test trực tiếp chứng minh provider availability, output quality,
cross-runtime process parity hay pixel xác định.

## Xử lý sự cố và hiểu giới hạn

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| Concept khớp sai prompt | Dùng subject cùng use case cụ thể hơn, kiểm tra bằng `--dry-run` hoặc chủ động chọn creative mode. |
| `--skip` lỗi khi truyền cho `generate.py` | Giữ `--skip` trên cách gọi `ak:ai-artist`; Python renderer không nhận flag này. |
| Không có provider credential | Cấu hình route đã duyệt hoặc dừng ở `--dry-run`; không paste secret vào prompt hay repository. |
| `npx` hoặc Python không khả dụng | Chỉ cài local prerequisite bị thiếu khi được duyệt và ghi nhận environment gap. |
| Generation timeout hoặc trả lỗi | Giữ provider error, kiểm tra quota cùng network và hỏi trước retry có thể tính phí. |
| Mode `all` tạo nhiều tệp | Review riêng từng suffixed output; không coi số variation là bằng chứng chất lượng. |
| In-image text hoặc layout sai | Tăng exact text cùng placement constraint, rồi chỉ regenerate với cost đã duyệt; edit local nếu sửa xác định phù hợp hơn. |
| Bạn cần sửa asset có sẵn | Chuyển sang [`ak:ai-multimodal`](./ai-multimodal) hoặc workflow [`ak:media-processing`](./media-processing) xác định. |
| Runtime không nhận diện Skill | Xác nhận target cùng scope, mở lại runtime session, rồi làm theo [Runtime không tìm thấy Skill hoặc Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |
