Dùng `ak:seo` để audit page hoặc domain, research và cluster keyword, hoặc thiết
kế programmatic SEO template. Skill còn đóng gói script cho Search Console,
Core Web Vitals, sitemap, schema và bulk page generation. Các script đó có tác
động khác nhau lên network, credential, file và account; chúng không phải một
workflow tự động duy nhất.

## Chọn ak:seo cho evidence và implementation artifact

### Dùng ak:seo khi

- Bạn cần technical hoặc on-page audit cho public URL hay local content.
- Bạn cần keyword idea, intent cluster, difficulty data hoặc competitor gap với
  source và freshness được ghi lại.
- Bạn cần pSEO template, data schema, internal-linking plan và sample page.
- Bạn cần sitemap hoặc JSON-LD artifact đã review trước implementation.

### Chọn workflow khác khi

- Bạn cần content strategy rộng hơn mà không cần search evidence. Dùng
  `ak:content-marketing`.
- Bạn cần final copy từ search brief đã duyệt. Dùng `ak:write` sau khi keyword
  và claim input được chấp nhận.
- Bạn muốn bảo đảm ranking, traffic, rich result, indexing hoặc revenue. Không
  Skill hay provider output nào có thể thiết lập các outcome đó.

## Chuẩn bị data, access và mutation boundary

Xác nhận Marketing Kit đã được cài cho đúng runtime và scope. Cung cấp target
URL, domain, topic, country hoặc market, audience, business relevance, analytics
hiện tại, competitor set và output boundary. Xác định dữ liệu nào có thể được
gửi tới external service.

Keyword và audit data dựa trên ReviewWeb cần `REVIEWWEB_API_KEY`. Core Web
Vitals request dùng Google PageSpeed Insights và có thể dùng
`PAGESPEED_API_KEY`. Google Search Console cần property đã verify, Google Cloud
OAuth client, Search Console API, `googleapis` và
`.claude/secrets/google_client_secret.json` hoặc user-level secret path tương
ứng. OAuth token được lưu cục bộ; hãy bảo vệ như credential.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:seo ...` | Phân phối native là mặc định; network và account operation vẫn cần access cùng approval rõ ràng. |
| Cursor | `/ak:seo ...` | Skill được projection sang Cursor và cách gọi bằng slash đã được người dùng xác minh; provider tooling vẫn có thể khác. |
| Codex | `$ak:seo ...` | Skill dùng native discovery của Codex; capability web, shell, credential và provider có trong session quyết định từng stage. |

## Chạy SEO task được định tuyến

  </Tab>
  <Tab value="Cursor">

```text

```

  </Tab>
  <Tab value="Codex">

```text

```

  </Tab>

Argument hint canonical liệt kê
`[audit|keywords|pseo|optimize|schema] [target]`. Trong bản này, chỉ `audit`,
`keywords` và `pseo` có routed reference workflow. Hãy xem `optimize` và
`schema` là direct route chưa được chứng minh; dùng yêu cầu có scope rõ ràng
hoặc bundled schema tool sau khi kiểm tra tác động.

## Hiểu các giai đoạn

1. **Xác nhận câu hỏi và data source.** Xác định URL, topic, market, timeframe,
   evidence source và task là analysis hay mutation.
2. **Thu thập evidence.** Đọc local content hoặc fetch public page. Khi được
   duyệt, query ReviewWeb, PageSpeed Insights hoặc Search Console và ghi source.
3. **Phân tích evidence.** Audit technical và on-page element, phân loại intent
   cùng cluster, hoặc thiết kế kiến trúc data và template pSEO.
4. **Tạo artifact.** Tạo report, template, schema, sitemap, sample page hoặc
   implementation recommendation trong output boundary đã duyệt.
5. **Validate cục bộ.** Kiểm tra JSON-LD structure, sitemap content, template
   escaping, duplicate, claim, canonical intent và sample quality.
6. **Review trước live action.** Con người duyệt code change, bulk file,
   deployment, indexing control, sitemap submission hoặc deletion, outreach và
   mọi provider account mutation.

## Tách query, file generation và account change

<Callout type="warn" title="SEO analysis không cấp quyền live search change">
  Search Console query action có thể đọc private property data, còn các bundled
  flag riêng có thể submit hoặc delete sitemap. pSEO generator ghi nhiều HTML
  file và checkpoint. Sitemap cùng schema generator ghi output file. Phê duyệt
  rõ từng tác động; không suy ra quyền đó từ yêu cầu audit.
</Callout>

Review URL và customer data trước khi gửi tới ReviewWeb, Google, browser tool
hoặc provider khác. Không đặt API key hay OAuth token trong argument, report
hoặc commit. Link building và outreach vẫn là công việc cần con người duyệt
riêng; tránh spam, placement lừa dối và quan hệ bị bịa.

## Xác minh output và bằng chứng

Top-level Skill summary nêu report path dưới `assets/reports/seo/`, trong khi
routed reference `audit` và `keywords` nêu `assets/seo/audits/` và
`assets/seo/keywords/`. Xác nhận path thực do lần chạy trả về trước khi tạo
automation. Route pSEO ghi dưới `assets/attraction/pseo-templates/`; schema output
được mô tả dưới `assets/seo/schemas/`.

Yêu cầu report xác định URL, query date, country hoặc market, provider và
endpoint, field đo được so với estimate, dữ liệu thiếu, issue theo priority và
next check được khuyến nghị. Với generated file, kiểm tra file list và diff
chính xác. Local schema validation pass không bảo đảm search engine rich result,
còn sitemap được submit không bảo đảm indexing.

## Xử lý sự cố và biết giới hạn

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| ReviewWeb data không khả dụng | Tiếp tục bằng public hoặc local evidence được gắn nhãn rõ, hoặc cấu hình `REVIEWWEB_API_KEY`; không bịa volume, CPC, difficulty, traffic hay backlink. |
| Search Console authentication thất bại | Xác minh property, OAuth client, scope, secret path, local callback, dependency và token status mà không lộ credential. |
| Report path khác overview | Dùng path thực được trả về và ghi nhận source-path inconsistency; không âm thầm move hoặc overwrite file. |
| `optimize` hoặc `schema` không route | Dùng `audit`, `keywords` hoặc `pseo`, hoặc yêu cầu schema artifact có scope rõ rồi kiểm tra bundled generator trực tiếp. |
| Bulk pSEO output chất lượng thấp hoặc trùng lặp | Dừng generation, kiểm tra template cùng dataset, không tự động xóa gì và yêu cầu unique value cùng human sampling trước publication. |
| Runtime discovery thất bại | Làm theo [Runtime không tìm thấy Skill hoặc Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |

Search data, provider API, platform rule và ranking system thay đổi. Skill không
thể bảo đảm data completeness, ranking, indexing, traffic, rich result,
conversion hay revenue. Tiếp tục với [tổng quan Marketing
Kit](../../marketing) và giữ mọi live mutation ở bước duyệt riêng.
