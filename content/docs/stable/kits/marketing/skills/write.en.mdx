Use `ak:write` to create, improve, or audit marketing copy. Its routed workflows
cover quick drafts, planned copy, formula-based variants, blogs, conversion
copy, enhancement, quality review, and a publish-readiness file pass.

## Choose ak:write for a bounded writing deliverable

### Use ak:write when

- You know the audience, offer or topic, format, channel, and desired action.
- You have approved facts, sources, brand voice, prohibited wording, and legal
  constraints for the draft.
- You need variants, a structured article, an audit, or a revision to an
  existing local file.

### Choose another workflow when

- You need a program strategy or editorial calendar. Use
  `ak:content-marketing`.
- You need current keyword, ranking, or technical search evidence. Use `ak:seo`.
- You need actual CMS publication, social posting, or email delivery. A writing
  artifact is an input to those separate workflows, not authorization for them.

## Prepare the brief and workspace

Confirm Marketing Kit is installed for the current runtime and scope. Provide
the outcome, audience, format, source facts, brand guidance, CTA, channel limits,
non-goals, output path, and whether local files may be created or overwritten.
For `blog-youtube`, provide a public video URL and approve transcript, research,
and media access. For `audit`, `enhance`, `cro`, or `publish`, provide the exact
file or bounded workspace location.

| Runtime | Invocation | Availability boundary |
| --- | --- | --- |
| Claude Code | `/ak:write ...` | Native delivery is the default; explicit plugin delivery is also supported. |
| Cursor | `/ak:write ...` | The Skill is projected to Cursor and slash invocation is user-verified; dependent tools can still differ. |
| Codex | `$ak:write ...` | The Skill uses native Codex discovery; external research and media work depend on tools available in the session. |

## Run the appropriate writing route

<Tabs items={['Claude Code', 'Cursor', 'Codex']}>
  <Tab value="Claude Code">

```text
/ak:write good "Draft a 700-word launch article from the attached approved brief. Match docs/brand-guidelines.md, cite every factual claim, and do not publish"
```

  </Tab>
  <Tab value="Cursor">

```text
/ak:write formula AIDA "Create short, medium, and long variants for the approved onboarding offer. Use only supplied proof and avoid artificial urgency"
```

  </Tab>
  <Tab value="Codex">

```text
$ak:write audit assets/articles/launch-guide.md "Score the draft as a heuristic review, list unsupported claims, and make no edits"
```

  </Tab>
</Tabs>

| Route | Intended result | Important effect |
| --- | --- | --- |
| `audit` | Copy, search, platform, and brand review | Reads a file and produces a scored report; scores are internal heuristics. |
| `blog` | Article, metadata, and optional illustrations | Can create an article tree under `assets/articles/` and use research or image workflows. |
| `blog-youtube` | Article derived from a YouTube video | Accesses video metadata, captions, screenshots, research sources, and media tools when available. |
| `cro` | Conversion-focused analysis and revised copy | Can ask a copywriter Agent to edit bounded code or content files. |
| `enhance` | Revised copy from stated issues | Can edit the located copy file after context inspection. |
| `fast` | Direct draft | Uses a copywriter Agent with minimal orchestration. |
| `formula` | AIDA, PAS, BAB, 4Ps, ACCA, or FAB variants | Loads brand context and writes short, medium, and long variants. |
| `good` | Researched and planned draft | May use research, planning, design, and multimodal review before returning work. |
| `publish` | Audited and corrected file version | Can overwrite the same path or create `{path}-published.md`; it does not publish externally. |

## Understand the stages

1. **Route the request.** The first argument selects the reference workflow;
   remaining arguments define the subject or file.
2. **Load context.** Read the brief, source material, brand voice, channel rules,
   and existing file only within the approved boundary.
3. **Research or plan when required.** Blog and `good` routes can use external
   research or specialized Agents; `fast` deliberately does less.
4. **Draft or revise.** Generate the requested format and variants, preserving
   verified facts and prohibited wording.
5. **Audit the artifact.** Check structure, clarity, CTA, channel fit, search
   considerations, brand voice, and unsupported claims.
6. **Return evidence.** Report output paths, sources, major changes, review
   findings, and every unresolved approval.

## Keep publication and claims under human control

<Callout type="warn" title="The publish route does not publish">
  `ak:write publish` is a local quality gate. It may rewrite a supplied file and
  label the result publish-ready, but it does not update a CMS, send an email,
  post to a network, buy media, or prove that the copy is accurate or compliant.
</Callout>

Approve network research, YouTube retrieval, image generation, and provider use
separately. Do not send secrets, private customer data, or licensed material to
an external provider without permission. Review testimonials, statistics,
comparisons, urgency, pricing, guarantees, and regulated claims against their
source and applicable policy.

## Verify outputs and evidence

Output depends on the route. `formula` writes under
`assets/copy/{date}-{formula}-{slug}.md`; `blog` uses
`assets/articles/{date}-{slug}/`; and `blog-youtube` uses `content/blog/` plus
its images directory. Other routes can modify the supplied file or return a
report. Confirm the actual paths before downstream automation.

A complete result identifies the brief and sources used, the brand rules
applied, the created or changed files, material before-and-after edits, audit
findings, missing evidence, and the action still needed to publish. Treat the
numeric quality score and “publish ready” label as workflow signals, not
conversion, ranking, revenue, or compliance guarantees.

## Troubleshoot and know the limits

| Symptom | Safe next step |
| --- | --- |
| The copy invents facts or proof | Remove the claim, supply a source, and rerun the affected section. |
| Brand voice is wrong | Provide the approved guideline path, examples, prohibited terms, and target channel. |
| `publish` changed too much | Stop, inspect the diff, restore the original from your own version control or backup, then rerun with a narrower boundary. |
| A platform rule looks stale | Verify the current platform documentation before approval; bundled limits and templates can age. |
| YouTube or research retrieval fails | Provide a transcript and approved sources, or continue without unsupported enrichment. |
| Runtime discovery fails | Follow [Runtime cannot find a Skill or Agent](../../../troubleshooting/runtime-cannot-find-skill-or-agent). |

The Skill cannot guarantee quality, originality, rights clearance, search
performance, conversion, or publication acceptance. Continue with the
[Marketing Kit overview](../../marketing) or use a channel-specific Skill only
after the copy and authority boundary are approved.
