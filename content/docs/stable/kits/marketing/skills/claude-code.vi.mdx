Dùng `ak:claude-code` cho câu hỏi hoặc change plan có scope rõ về Claude Code.
Marketing Skill định tuyến topic tới reference đi kèm về installation, custom
Skill, slash command, MCP, Hook, plugin, setting, IDE integration, CI/CD,
enterprise control, advanced feature, troubleshooting, API và operational
practice.

Gọi Skill không chứng minh mọi command hoặc setting được tham chiếu còn hiện
hành. Claude Code cùng service surface phát triển độc lập với Kit. Ghi version
đã cài và đối chiếu packaged guidance với contract chính thức hiện tại trước khi
áp dụng thay đổi.

## Chọn ak:claude-code cho product guidance

### Dùng ak:claude-code khi

- Bạn cần hiểu hoặc lập kế hoạch installation cùng authentication Claude Code.
- Bạn đang thiết kế hoặc review Skill, slash command, Hook, plugin, MCP server,
  setting hoặc IDE integration.
- Bạn cần review CI/CD hoặc enterprise deployment với security, access và data
  boundary rõ ràng.
- Bạn đang xử lý symptom authentication, connection, permission, configuration
  hoặc performance đã quan sát.

### Chọn workflow khác khi

- Task nói về AgentKit installation hoặc Kit lifecycle thay vì Claude Code.
- Bạn cần execute MCP tool hiện có; dùng `ak:use-mcp`.
- Bạn cần provider fact hiện tại không có trong installed version cùng
  documentation đã xác minh.
- Bạn muốn mutation installation, account, configuration, CI hoặc enterprise
  nhưng chưa duyệt target cùng effect chính xác.

## Chuẩn bị product context

Trước khi bắt đầu:

- Hoàn thành [Làm quen](../../../getting-started/onboarding) và cài Marketing Kit
  cho runtime cùng scope dùng để gọi Skill.
- Phân biệt **runtime gọi** với **subject**: bạn có thể hỏi Skill từ Claude Code,
  Cursor hoặc Codex, nhưng guidance nói về Claude Code.
- Ghi `claude --version`, operating system, installation method, delivery
  scope, project instruction liên quan và symptom quan sát được.
- Xác định câu trả lời có cần xác minh chính thức hiện tại không. Không dựa vào
  model ID, price, limit, install method, setting hoặc platform feature đi kèm
  khi chưa kiểm tra.
- Che API key, access token, cookie, SSO assertion, connection string, private
  log và customer data.
- Với proposed change, nêu quyền đọc config, sửa file, cài software, kết nối
  service hoặc đổi account đã được cấp chưa.

| Runtime | Cách gọi | Ranh giới khả dụng |
| --- | --- | --- |
| Claude Code | `/ak:claude-code ...` | Delivery native hoặc plugin rõ ràng có thể expose Skill. Guidance chỉ có thể kiểm tra active Claude Code project trong quyền hiện tại. |
| Cursor | `/ak:claude-code ...` | Cách gọi bằng slash đã được người dùng xác minh. Skill vẫn là Claude Code guidance; Cursor không trở thành Claude Code execution environment. |
| Codex | `$ak:claude-code ...` | Native discovery expose Skill dưới dạng guidance. Command, config, Hook và permission riêng Claude không phải capability Codex. |

Xem [Runtime adapter](../../../concepts/runtime-adapters) để phân biệt Skill
projection với runtime parity.

## Theo các giai đoạn guidance

1. **Phân loại topic.** Chọn area nhỏ nhất liên quan: setup, Skill, command, MCP,
   Hook, plugin, setting, IDE, CI/CD, enterprise, API, advanced feature hoặc
   troubleshooting.
2. **Thu bằng chứng theo version.** Ghi installed version, symptom chính xác,
   config đúng scope cùng provider hoặc platform boundary. Chỉ đọc reference đi
   kèm liên quan.
3. **Đối chiếu fact thay đổi.** Kiểm tra behavior chính thức hiện tại trước khi
   khẳng định command, setting, model, API, limit, price hoặc feature khả dụng.
4. **Tách advice khỏi action.** Tạo diagnosis hoặc minimal change plan trước. Nêu
   mọi local, account, network, CI hoặc enterprise mutation.
5. **Chỉ áp dụng scope đã duyệt.** Nếu được cấp quyền, thực hiện thay đổi hẹp
   trong khi giữ unrelated configuration cùng secret handling.
6. **Xác minh và báo cáo.** Dùng diagnostic của installed version hoặc bounded
   reproduction, rồi báo bằng chứng, uncertainty còn lại cùng rollback.

## Giữ configuration và service dưới approval

<Callout type="warn" title="Claude Code extension có thể chạy với quyền thật">
  Hook có thể chạy command, plugin có thể bundle executable behavior, MCP server
  có thể truy cập file cùng service, còn CI hoặc enterprise config có thể ảnh
  hưởng account, repository, network, data và spend. Review source, scope,
  credential cùng rollback trước activation.
</Callout>

Không commit secret hoặc đặt giá trị thật trong example config. Ưu tiên
environment hoặc secret-manager reference đã duyệt với least privilege. Cài
hoặc update Claude Code, thêm plugin, đăng ký MCP server, bật Hook, sửa CI hoặc
đổi SSO cùng access policy là mutation riêng; việc gọi Skill không cấp quyền cho
chúng.

## Xác minh bằng chứng

Response hoàn tất nên cung cấp:

- Claude Code version, environment và topic đã đánh giá.
- Reference đi kèm đã dùng cùng mọi fact cần xác minh hiện tại.
- Config hoặc error evidence đã quan sát và bỏ secret value.
- Recommendation hoặc patch tối thiểu đúng target.
- Command hoặc check thực sự chạy cùng result.
- Mọi local, service, account, CI, data hoặc spend effect.
- Rollback guidance cùng version hay platform uncertainty chưa giải quyết.

## Xử lý sự cố và hiểu giới hạn

| Triệu chứng | Bước tiếp theo an toàn |
| --- | --- |
| Guidance mâu thuẫn behavior đã cài | Tin behavior theo version đã quan sát, xác minh contract chính thức hiện tại và đánh dấu packaged example stale. |
| Authentication thất bại | Báo error mà không in key; phân biệt interactive account auth với API credential trước khi đổi. |
| MCP server hoặc Hook không chạy | Review command, permission, environment reference, log cùng runtime registration trước khi cài lại hoặc mở rộng access. |
| Setting có vẻ bị bỏ qua | Xác minh settings location cùng precedence thực tế của installed version; không copy packaged path mù quáng. |
| CI hoặc enterprise setup cần elevated access | Dừng và yêu cầu quyền cho đúng repository, account, role, secret, network cùng policy change. |
| Skill được gọi từ Cursor hoặc Codex | Coi result là Claude Code guidance; không khẳng định runtime gọi có Claude-only feature. |

Packaged reference là knowledge base tại một thời điểm, không đảm bảo command,
model name, API, pricing hoặc enterprise feature Claude Code hiện tại. Skill
không cài, authenticate, configure hoặc operate Claude Code trừ khi action đó
được duyệt và xác minh rõ.
