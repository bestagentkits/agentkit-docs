import { Callout } from 'fumadocs-ui/components/callout';

<Callout type="info" title="Invocation đã retired">
  `ak:ak` (lưu dưới tên `ak-ak`) không còn được đóng gói như Skill riêng. Skill này đã được gộp vào [`ak-agentkit`](./agentkit), nơi giờ chứa hướng dẫn ak CLI và command reference. Dùng `ak-agentkit` khi hành động tiếp theo là một subcommand của `ak`.
</Callout>

Đừng gọi `ak:ak` hay `ak-ak`. Route này giữ bookmark hiện có. Trang không mô tả
identity trong package hay lệnh có thể chạy.

`ak update --global` và `ak kit refresh <kit>` xóa các file `ak-ak` cũ. Lệnh
`ak update <dir>` ở project scope không dọn chúng, và refresh giữ lại thư mục
vẫn còn file mà nó không sở hữu, nên thư mục `ak-ak` có thể còn sót. Hãy xóa thủ
công; không thành phần nào đọc thư mục đó.
