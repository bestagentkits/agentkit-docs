AgentKit is a command-line tool (`ak`) for installing and running AI agent
**kits** — bundles of skills your coding assistant (Claude Code, Codex) can
invoke. The CLI resolves signed release metadata, verifies each artifact before
use, and manages kits, backups, and updates from one place.

## Where to go next

- [Installation](./getting-started/installation) — install and verify `ak` on
  macOS, Linux, or Windows.
- [Quickstart](./getting-started/quickstart) — authenticate, install a kit, and
  run your first agent.
- [Onboarding](./getting-started/onboarding) — first-run setup: auth, kits,
  updates, backups, and feedback.
- [CLI reference](./reference/cli) — every command and flag, generated from the
  released binary.
