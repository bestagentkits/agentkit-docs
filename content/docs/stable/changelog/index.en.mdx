## AgentKit 2.7.0

Released August 2, 2026.

AgentKit 2.7.0 promotes the final prerelease source without further product-code
changes. Command names, flags, defaults, installers, authentication, updates,
migration, recovery, Kit rosters, and supported runtime targets are unchanged
from 2.6.0.

### Health reports distinguish Notes

`ak doctor` now collapses advisory warnings into a Notes count in its default
human-readable report. Use `ak doctor -V` or select a check explicitly to expand
them. Notes remain warning rows in JSON, where affected checks include
`"advisory": true`; they do not change health or exit-code rules.

### Codex projection is more transparent

Kit installation now reports fully unsupported Hook groups separately from
partially narrowed matchers. Narrowing keeps the supported matcher atoms active
and reports only those removed. Eligible `.cjs` Hooks inside the Codex home can
use managed sibling `.cmd` shims for Windows paths with spaces, while unsafe or
external forms continue to warn. Shared global Hook ownership, cleanup, and
rollback also preserve user and other-Kit registrations more defensively.

The shared `researcher` Agent now emits `gpt-5.4` with medium reasoning effort
for Codex. Engineer's plan reminder emits valid, nonblocking Stop-event JSON
when relevant and stays silent when no active plan is bound.

Release verification also expands Kit tier-depth coverage by trigger cause and
guards the new projection disclosures. These are CI and packaging checks, not
new commands or flags.

### Kit export and context authoring are stricter

Portable builds are export-only: use
`ak kit init <kit> --target portable --out DIR`. Omitting `--out` fails before
preview, prompts, network resolution, lifecycle work, or disk writes. Remote
`agy` installation resolves the signed Claude Code package before projecting it
to its global Gemini/AGY locations.

The shared `ak:docs` Skill adds `agent-context` for repository-root `CLAUDE.md`
and `AGENTS.md` work. Its advice and audit modes keep writes confirmation-based;
`ak:folder-context` remains limited to subfolders.
