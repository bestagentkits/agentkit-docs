Đọc output được lưu của job orchestration.

Dùng `ak orchestrate output` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Read bounded redacted job output by byte offset

### Synopsis

Read captured output without opening private invocation files. Capture is bounded and reports truncation. --limit is a raw-byte target, not a hard cap: a page ends early or runs past it by one released value plus its marker to keep the value whole; follow next_offset for the next page.

Effects:
  Read-only; does not launch or signal processes.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate output <run-id> <job-id> [flags]
```

### Examples

```
  ak orchestrate output <run-id> <job-id> --json
  ak orchestrate output <run-id> <job-id> --offset 16384 --limit 4096
```

### Options

```
  -h, --help             help for output
      --json             Emit machine-readable JSON (implies --no-interactive)
      --limit int        Target bytes in this page (1-65536); a page may end early or run over by one released value to keep it whole, so follow next_offset rather than assume this exact size (default 16384)
      --no-interactive   Disable interactive prompts (CI-safe)
      --offset int       Start at this byte offset
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
