Dùng `ak skills` cho nội dung skill cục bộ và thao tác catalog. Namespace số
nhiều này tách biệt với `ak skill`, nơi quản lý Python và Node runtime record
cho một skill.

## Cách dùng

```bash
ak skills <command>
```

Bản thân group chỉ đọc và in help khi không có lệnh con.

## Chọn lệnh

| Mục tiêu | Lệnh |
| --- | --- |
| Chạy entrypoint của Skill đã được cấp quyền trong môi trường cô lập | `ak skills exec` |
| Xem, đánh giá, áp dụng hoặc hoàn tác một candidate đã ghi | [`ak skills evolution`](../cli/ak_skills_evolution) |
| Quản lý grant cho exec và secret | `ak skills grants` |
| Biến evidence từ session thành candidate overlay đã qua gate | [`ak skills improve`](../cli/ak_skills_improve) |
| Xem một SkillX release mà không cài | `ak skills inspect` |
| Xem trước, áp dụng, rebase hoặc hoàn tác một personal kit | [`ak skills kit`](../cli/ak_skills_kit) |
| Phục vụ các Skill cho MCP client | `ak skills mcp` |
| Tiếp nhận bản cài Skill legacy của Kit vào skill store | [`ak skills migrate`](../cli/ak_skills_migrate) |
| Đọc một file của SkillX release | `ak skills read` |
| Resolve một SkillX reference | `ak skills resolve` |
| Chiếu skill lock vào các Skill đã cài | `ak skills sync --locked` |
| Xem quan hệ workflow | `ak skills graph` |
| Copy một local skill vào user install root | `ak skills install <kit>/<skill>` |
| Liệt kê skill đã cài và có sẵn cục bộ | `ak skills list` |
| Xoá một bản đã cài | `ak skills remove <kit>/<skill>` |
| Chọn skill cục bộ cho một intent, hoặc trả `NONE` | `ak skills route` |
| Tìm metadata cục bộ | `ak skills search <query>` |
| Xem một record đã cài hoặc có sẵn | `ak skills show <kit>/<skill>` |

Hãy dùng reference chuẩn `<kit>/<skill>` trong script. Các lệnh `install`,
`remove` và `show` cũng nhận shorthand đầu vào `ak:<skill>`, `ake:<skill>` và
`akm:<skill>` cho `core`, `engineer` và `marketing`; đây là shorthand reference,
không phải Cobra command alias.

## Source và destination cục bộ

Khi SkillX đang bật (sau `ak update --ssot`, hoặc `AGENTKIT_SKILLX=1`),
`ak skills resolve`, `inspect` và `read` xác minh SkillX skill release mà không
cài, còn `install --source skillx`, `remove @publisher/slug` và `sync` quản lý
chúng trong skill store. Chạy `ak skills --help` để xem các lệnh này và các lệnh
brokered `exec`, `grants` và `mcp`.

Route cục bộ không resolve Kit release từ AgentKit registry từ xa. Nó đọc nội
dung có sẵn từ `AGENTKIT_KITS_DIR` hoặc `./kits`, và nội dung đã cài từ
`AGENTKIT_PLUGIN_DIR` hoặc `~/.claude/plugins`.

`ak skills install` ghi đường dẫn user-level sau bất kể project hoặc runtime
target hiện tại:

```text
~/.claude/plugins/<kit>/skills/<skill>/
```

Hãy dùng `ak kit init` hoặc `ak kit install` khi cần remote resolution có xác
thực, entitlement, project/global scope hoặc chọn target Claude/Codex/Cursor.

## Runtime handoff và an toàn

Cài nội dung có runtime cũng gọi singular runtime manager trừ khi
`AGENTKIT_SKILL_RUNTIME=0`. Xoá nội dung sẽ xoá runtime record tương ứng trước,
nhưng luôn giữ shared package cache.

Không có prompt xác nhận hay recovery snapshot. `--force` xoá content directory
hiện tại trước khi copy; remove xoá trực tiếp. Các thao tác nhiều bước này không
phải rollback transaction.

## Đầu ra tự động hoá

Các lệnh lá số nhiều dùng JSON success envelope có version trên stdout:

```text
schema_version: 1
kind: assets.list | assets.show | assets.install | assets.remove | skills.graph
data: command-specific payload
```

Lỗi dùng stderr. Với reference sai dạng, record không tồn tại và install
conflict, JSON error envelope hiện có thể ghi `exit_code: 1` dù process thoát
`2`, `5` hoặc `6`; hãy gate bằng process status.
