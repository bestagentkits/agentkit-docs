---
title: ak skills kit status
description: List personal kits and show whether each resolves against the exact foundation versions it pins, without writing anything.
---

Use `ak skills kit status` to check the personal kits under
`AGENTKIT_HOME/kits/personal`, or one named kit. A kit that fails to resolve is
listed with its contract error code.

## Usage

```bash
ak skills kit status [name] [flags]
```

Without a name, every directory under the personal kits root that holds a
`personal-kit.yaml` is listed, sorted by name.

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--kits-dir <dir>` | `$AGENTKIT_KITS_DIR` or `./kits` | Foundation kits directory. |

Shared flags are described in [CLI conventions](../cli-conventions). The
command works offline for every user: it needs neither the skill store nor
SkillX.

## What it reads

The command is read-only. It reads the personal kits and the foundation kits
directory, and never writes, installs, applies a plan, or calls a network or
model. AgentKit user overrides (`~/.agentkit/overrides/<kit>/kit.yaml`, or
`$AGENTKIT_OVERRIDES_DIR`) are reported as warnings, never applied.

## Output

Each text line shows the kit, `resolved` with its foundations and the counts of
skills, overlays and forks, or `invalid` with the error code and message.
Warnings follow as indented `warning <code> <identity> <detail>` lines. With no
kits the command prints `No personal kits under AGENTKIT_HOME/kits/personal.`

JSON uses `kind=skills.kit.status` with these fields under `data`:

```text
root
kits[]: name, personalKit, status (resolved | invalid), errorCode, error,
        foundations[], packages, overlays, forks, warnings[]
```

A kit that fails for a reason without a contract code reports
`errorCode=personal_kit.unavailable`.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Success, including a kit listed as `invalid`. |
| `1` | Command failure, or an overlay conflict, shared alias, alias collision or stale proposal (JSON `error_code` `conflict`). |
| `2` | Invalid flags or arguments, or a malformed manifest, overlay or proposal. |
| `5` | Personal kit, foundation kit, version or skill not found. |
| `7` | Revoked foundation. |
