---
title: ak skills kit revisions
description: List the SkillX revisions of a personal kit, newest first, and mark the effective one, without writing anything.
---

Use `ak skills kit revisions` to see every SkillX revision of the kit a
personal kit's link records, or of the one `--kit` names. The listing also
shows the kit's generation and visibility and the revision and generation this
machine last saw, so a publish conflict can be checked before passing
`--expect-generation`, or a revision chosen for `sync --locked`.

## Usage

```bash
ak skills kit revisions <name> [--kit @<handle>/<name>] [flags]
```

## Options

| Flag | Default | Description |
| --- | --- | --- |
| `--kit @<handle>/<name>` | The linked one | SkillX personal kit to list. Required when the personal kit has no SkillX link. |

Shared flags are described in [CLI conventions](../cli-conventions).

## Requirements

SkillX must be on, after `ak update --ssot` or with `AGENTKIT_SKILLX=1`, and
the configured SkillX API key must be valid. The command only touches
`AGENTKIT_HOME` and follows its global scope from any directory.

## What it reads

The command is read-only. It reads the kit and its revision list from SkillX
and the link record `AGENTKIT_HOME/state/personal-kits/<name>/skillx.json`. It
writes nothing, uploads nothing and never prompts.

## Output

The text output starts with the kit, its SkillX name, host, visibility and
generation, then the revision and generation this machine last saw when the
link matches, then one line per revision: number, id, state, digest, origin,
creation time and `[effective]` for the effective one. A kit without revisions
prints `no revisions`.

JSON uses `kind=skills.kit.revisions` with these fields under `data`:

```text
personalKit, kit, host, visibility, generation, effectiveRevisionId,
linkedRevisionId, linkedGeneration
revisions[]: id, number, digest, state, origin, createdAt, activatedAt,
             effective
```

`linkedRevisionId` and `linkedGeneration` are set only when the link record
names the same kit on the same host.

## Exit behavior

| Exit | Meaning |
| --- | --- |
| `0` | Listed. |
| `1` | Command failure: SkillX offline, or the API key missing, scoped or expired. |
| `2` | SkillX or the overlay flag disabled, invalid flags, or no linked kit and no `--kit`. |
| `5` | The SkillX kit was not found. |
