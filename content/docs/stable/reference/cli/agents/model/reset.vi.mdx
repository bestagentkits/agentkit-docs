---
title: ak agents model reset
description: Xóa override model và reasoning effort của một Agent khỏi một config scope để lớp kế tiếp quyết định.
---

Dùng `ak agents model reset` để hoàn tác một lệnh [`set`](./set),
[`inherit`](./inherit) hoặc [`adopt`](./adopt) trong một scope và quay về lớp
kế tiếp.

## Cách dùng

```bash
ak agents model reset <agent> --runtime <runtime> [--scope user|project] [--project <dir>]
```

Phải có đúng một tên Agent.

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--runtime <runtime>` | bắt buộc | Một trong `claude-code`, `codex`, `cursor`, `omp`, `pi`. |
| `--scope user\|project` | `user` | Config cần sửa: AgentKit home, hoặc `.agentkit/config.yaml` trong project. |
| `--project <dir>` | config project gần nhất, nếu không có thì thư mục hiện tại | Project có bản cài và config được áp dụng. |

## Lệnh ghi gì

Lệnh xóa `model` của Agent và, trên `codex` và `omp`, cả `reasoning_effort`
khỏi đúng scope đã chọn. Lớp kế tiếp sẽ quyết định: override Agent ở scope kia,
một ánh xạ tier, hoặc adapter default. Reset ở scope không có override sẽ báo
là không có gì để đổi.

## Tác động phụ

Lệnh lấy kit lifecycle lock, sao lưu rồi ghi lại `config.yaml` của scope khi
tệp tồn tại, sau đó ghi lại mọi tệp đã cài của Agent mà AgentKit vẫn sở hữu
model để chúng mang model vừa được resolve. Tệp drift hoặc tệp chưa chứng minh
được quyền sở hữu được để nguyên kèm cảnh báo. Project scope không tạo sẵn tệp
config vì reset chỉ xóa giá trị.

## Đầu ra

Stdout cho người dùng báo `reset <runtime> agent <agent> in <config path>` (hoặc
config không có gì để đổi), một dòng `updated <path>` cho mỗi tệp được ghi lại,
rồi đến bảng trạng thái.

JSON thành công dùng:

```text
schema_version: 1
kind: agents.model.reset
data.action, data.runtime, data.agent, data.scope
data.config_path, data.config_changed
data.backup_paths?, data.applied?
data.agents[], data.warnings?
```

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Override đã bị xóa hoặc vốn không có. |
| `1` | Lệnh thất bại, ví dụ lỗi ghi config. |
| `2` | Tên Agent, scope hoặc cờ không hợp lệ, runtime không được hỗ trợ, project scope mà không có thư mục project, hoặc thư mục `--project` không tồn tại. |
| `4` | Một thao tác AgentKit khác đang giữ kit lifecycle lock. |
