Dùng `ak agents model list` để xem toàn bộ Agent đã cài và phát hiện các tệp
đang pending hoặc đã drift khỏi config.

## Cách dùng

```bash
ak agents model list [--runtime <runtime>] [--project <dir>]
```

Không nhận argument theo vị trí. Lệnh chỉ đọc, không prompt và không thực hiện
công việc mạng. Lệnh đọc bản ghi agent model của AgentKit, config và các tệp
Agent đã cài.

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--runtime <runtime>` | mọi runtime | Giới hạn ở một trong `claude-code`, `codex`, `cursor`, `omp`, `pi`. |
| `--project <dir>` | config project gần nhất, nếu không có thì thư mục hiện tại | Project có bản cài và `.agentkit/config.yaml` được áp dụng. |

Bản cài global luôn được liệt kê. Bản cài project được liệt kê cho project đã
chọn. Các dòng được sắp theo runtime, rồi theo Agent.

## Đầu ra

Stdout cho người dùng là một bảng:

```text
RUNTIME  AGENT  SCOPE  STATUS  FILE MODEL  DESIRED (FROM)
```

`FILE MODEL` là `-` khi tệp bị thiếu hoặc không đọc được. `DESIRED (FROM)` nêu
tên lớp đã quyết định model. Khi chưa ghi nhận gì, lệnh in
`No agent models recorded yet. Install or refresh a kit to record them.`

JSON thành công dùng:

```text
schema_version: 1
kind: agents.model.list
data.agents[]
data.warnings?
```

Mỗi phần tử `agents[]` có `runtime`, `agent`, `kit`, `install_scope` (`global`
hoặc `project`), `path`, `kit_default?`, `adapter_default`, `user_override?`,
`project_override?`, `desired`, `desired_source`, `recorded`, `materialized?`,
`effective` (`value`, `certainty`, `reason?`) và `status` (`in-sync`,
`pending`, `drift` hoặc `not-materialized`).

Cảnh báo nêu state không đọc được hoặc config đã quay về giá trị mặc định. Ở
chế độ cho người dùng, chúng đi ra stderr dưới dạng dòng `warning: ...`.

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Đã tạo danh sách, kể cả danh sách rỗng. |
| `1` | Có lỗi runtime cục bộ. |
| `2` | Cờ không hợp lệ, runtime không được hỗ trợ, hoặc thư mục `--project` không tồn tại. |
