Use `ak secrets recovery list` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

List the vault's recovery recipients

### Synopsis

Print each recovery recipient's label, fingerprint, and when it was added. Private keys are never stored, so none can be printed; the public key is included in --json output for an operator reconciling a key card against the vault.

Effects:
  Opens the vault, which prompts for the passphrase on a terminal. Reads only.

Exit status:
  0   success
  3   no vault at that path
  5   the vault could not be opened

```
ak secrets recovery list [flags]
```

### Examples

```
  ak secrets recovery list
  ak secrets recovery list --json   # includes each recipient's public key
```

### Options

```
  -h, --help             help for list
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
