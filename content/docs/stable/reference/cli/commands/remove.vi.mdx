title: ak commands remove

---

Dùng `ak commands remove` để xoá một bản sao command dạng phẳng khỏi user plugin
root đã cấu hình. Lệnh không xoá source template, uninstall Kit hay cleanup
runtime artifact khác.

## Cách dùng

```bash
ak commands remove <kit>/<command>
```

Dùng command name đã làm phẳng như `marketing/ckm-email`, không dùng slash name
`ckm:email`. Phải có đúng một ref hợp lệ. Các dạng `ak:<command>`,
`ake:<command>` và `akm:<command>` cũng được chấp nhận.

Không có cờ riêng cho lệnh. Lệnh không prompt và không đọc stdin để xác nhận.

## Tác động chính xác

Với `marketing/ckm-email`, target duy nhất là:

```text
~/.claude/plugins/marketing/commands/ckm-email.md
```

`AGENTKIT_PLUGIN_DIR` thay root. Lệnh giữ nguyên source dưới `./kits`, parent
directory, template cùng cấp, Kit khác, runtime setting, cache và environment.
Target vắng mặt hoặc là directory tại đúng target được báo là not installed và
thoát `0`.

## Giới hạn ownership và recovery

Remover không đọc lifecycle ownership, so sánh hash đã lưu, bảo vệ tệp đã sửa,
tạo snapshot hay yêu cầu xác nhận. Mọi regular file tại destination đã resolve
đều được xem là có thể remove.

Hãy tạo bản sao thủ công trước khi remove nếu đã chỉnh template installed. Lần
chạy `ak commands install` sau chỉ có thể tạo lại tệp từ local source đang được
chọn; nó không thể khôi phục chỉnh sửa đã xoá hoặc slash identity lồng nhau ban
đầu.

## Đầu ra

Stdout cho người dùng báo `removed` hoặc `nothing to remove`. JSON thành công
dùng `schema_version: 1`, `kind: assets.remove` và các trường data:

```text
ref, kit, asset
removed: boolean
not_installed: boolean
```

Lỗi vào stderr. Không có preview, dry-run, force, backup, NDJSON, network, auth
hay entitlement.

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Tệp đã được xoá hoặc vốn đã vắng mặt. |
| `1` | Xoá thất bại hoặc sai số lượng argument theo vị trí. |
| `2` | Ref sai dạng hoặc không phân tích được cờ. |
