Xem xét một quyết định scenario, fix hoặc debug có giới hạn mà không thực thi nó.

Chế độ shadow chỉ gọi provider bên ngoài khi bạn đã bật `semantic_decision` ở user scope, cấp quyền tường minh cho consumer này bằng `semantic_decision.consumers.workflow-controller` đặt là `true`, và cung cấp `TYPESAFE_API_KEY` trong môi trường. Quyền cấp này là bắt buộc kể cả khi bạn không có map `consumers`. Xem [ak eval decision](./decision) để biết các key opt in.

Dùng `ak eval workflow` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Inspect a bounded scenario, fix or debug decision without executing it

### Synopsis

Off mode validates local facts without reading provider configuration or credentials. Shadow mode requires explicit user-scope workflow-controller consent. Effective legacy actions and scenario dispositions remain unchanged; recommendations never grant authority.

Effects:
  Optional shadow evaluation sends bounded sanitized facts to the configured provider and may incur charges. Prints a receipt; never executes actions or saves input.

Exit status:
  0   receipt available, including safe provider fallback
  1   invalid input or configuration
  2   invalid arguments

```
ak eval workflow <request.json|-> [flags]
```

### Examples

```
  ak eval workflow request.json --json
  ak eval workflow request.json --mode shadow --json
```

### Options

```
  -h, --help             help for workflow
      --json             Emit machine-readable JSON (implies --no-interactive)
      --mode string      off or explicitly authorized shadow evaluation (default "off")
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
