## ak skills

Browse and install kit skills

### Synopsis

What it does:
  (For per-skill runtime env management - verify, repair, upgrade - see `ak skill`. This command browses and installs from kits.) List, install, remove, show, and search individual skills from any kit. Skills are the primary unit of value users install / discover.

Who it's for:
  Both: power devs scripting installs (--json) and users browsing what's available.

When to use it:
  Use as the entry point for any per-skill catalog operation; subcommands handle the action.

Examples:
  ak skills list                            # show what's installed + available
  ak skills search browser                  # find skills matching a keyword
  ak skills install engineer/agent-browser  # install one skill
  ak skills show engineer/agent-browser     # inspect metadata
  ak skills remove engineer/agent-browser   # uninstall

What changes on disk:
  Read-only at this group level; subcommands document their own effects.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
