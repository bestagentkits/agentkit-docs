## ak skill repair

Rebuild a corrupted per-skill runtime env

### Synopsis

What it does:
  When `ak skill verify` reports `corrupt`, this command tears down the per-skill record and re-installs from the live runtime block. Other states (ok / missing / unknown) are no-ops so this is safe to drive from a reconciliation loop.

Who it's for:
  Power devs, drift-reconciliation jobs, CI cache hygiene.

When to use it:
  After `ak skill verify` reports corrupt.

Examples:
  ak skill repair marketing/youtube
  ak skill repair engineer/web-testing --kits-dir kits/

What changes on disk:
  Removes ~/.agentkit/skills/&lt;kit>/&lt;skill>/, then re-runs install. Holds an exclusive advisory lock at ~/.agentkit/skills/&lt;kit>/&lt;skill>.lock for the duration; concurrent repairs of the same skill conflict.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  4  skill has no runtime block
  5  kit or skill not found

```
ak skill repair <kit>/<skill> [flags]
```

### Options

```
  -h, --help              help for repair
      --json              Emit machine-readable JSON (implies --no-interactive)
      --kits-dir string   Kits directory (default: ./kits or $AGENTKIT_KITS_DIR)
      --no-interactive    Disable interactive prompts (CI-safe)
  -q, --quiet             Suppress non-error output on stderr
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes               Assume yes for all prompts
```
