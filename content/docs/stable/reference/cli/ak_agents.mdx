## ak agents

Per-agent management commands

### Synopsis

What it does:
  List, install, remove, show, and search individual agents from any kit. Agents are the per-role markdown personas users install into the underlying agent runtime.

Who it's for:
  Both: power devs scripting installs (--json) and users browsing what's available.

When to use it:
  Use as the entry point for any per-agent operation; subcommands handle the action.

Examples:
  ak agents list                         # show what's installed + available
  ak agents search code                  # find agents matching a keyword
  ak agents install engineer/researcher  # install one agent
  ak agents show engineer/researcher     # inspect metadata
  ak agents remove engineer/researcher   # uninstall

What changes on disk:
  Read-only at this group level; subcommands document their own effects.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

### Options

```
  -h, --help             help for agents
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)

  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
```
