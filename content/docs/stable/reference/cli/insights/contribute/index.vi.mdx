Chuẩn bị và gửi phần bằng chứng được chọn để đóng góp.

Dùng `ak insights contribute` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Preview and voluntarily share aggregate measurements

### Synopsis

Preview and voluntarily share aggregate measurements. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  No upload occurs without the explicit send subcommand.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights contribute [flags]
```

### Examples

```
  ak insights contribute --json
  ak insights contribute --help
```

### Options

```
  -h, --help             help for contribute
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
