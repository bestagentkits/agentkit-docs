Gửi payload đã chọn với sự cho phép chia sẻ.

Lệnh chỉ gửi aggregate đã freeze có đúng digest preview và chỉ khi sharing consent
đang bật. Hãy kiểm tra tháng, digest và endpoint HTTPS trước khi chạy.

Dùng `ak insights contribute send` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Send a previously previewed aggregate

### Synopsis

Send a previously previewed aggregate. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Transmits only the frozen aggregate to the configured approved HTTPS endpoint when sharing consent is enabled.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights contribute send [flags]
```

### Examples

```
  ak insights contribute send --month 2026-08 --digest preview-sha256 --json
  ak insights contribute send --help
```

### Options

```
      --digest string     SHA-256 from the exact preview
      --endpoint string   Approved HTTPS endpoint; defaults to AGENTKIT_CONTRIBUTION_ENDPOINT
  -h, --help              help for send
      --json              Emit machine-readable JSON (implies --no-interactive)
      --month string      Previously previewed UTC month
      --no-interactive    Disable interactive prompts (CI-safe)
  -q, --quiet             Suppress non-error output on stderr
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes               Assume yes for all prompts
```
