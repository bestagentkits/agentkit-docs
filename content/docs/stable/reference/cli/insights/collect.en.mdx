Use `ak insights collect` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Collect native runtime observations

### Synopsis

Collect native runtime observations. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Reads local transcript metadata only after collection consent; writes local observations.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights collect [flags]
```

### Examples

```
  ak insights collect --runtime codex --json
  ak insights collect --help
```

### Options

```
      --execution-id string   Managed execution owning this entire selected source; use on first import
      --file string           Optional selected JSONL source
  -h, --help                  help for collect
      --json                  Emit machine-readable JSON (implies --no-interactive)
      --no-interactive        Disable interactive prompts (CI-safe)
  -q, --quiet                 Suppress non-error output on stderr
      --runtime string        claude-code or codex
      --session-id string     Opaque source session ID for stable correlation
  -V, --verbose               Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                   Assume yes for all prompts
```
