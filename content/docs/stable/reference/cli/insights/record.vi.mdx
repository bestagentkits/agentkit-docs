Ghi bằng chứng thực thi vào kho cục bộ.

Dùng `ak insights record` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Import versioned execution observations

### Synopsis

Import versioned execution observations. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Writes validated local measurements when collection is enabled.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights record [flags]
```

### Examples

```
  ak insights record --file observations.json --json
  ak insights record --help
```

### Options

```
      --file string      JSON batch file
  -h, --help             help for record
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
