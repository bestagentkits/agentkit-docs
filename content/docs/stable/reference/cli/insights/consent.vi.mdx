Đọc hoặc thay đổi sự cho phép thu thập và chia sẻ bằng chứng.

Chỉ cờ được truyền rõ mới đổi consent cục bộ. Bật `--sharing` không upload dữ
liệu; thao tác gửi là lệnh riêng.

Dùng `ak insights consent` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Inspect or change local measurement consent

### Synopsis

Inspect or change local measurement consent. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Writes consent only for explicitly supplied flags. Sharing does not transmit data.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights consent [flags]
```

### Examples

```
  ak insights consent --collection=true --json
  ak insights consent --help
```

### Options

```
      --collection       Enable or disable local collection
  -h, --help             help for consent
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --sharing          Consent to voluntary allowlisted aggregate sharing; no upload is performed
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
