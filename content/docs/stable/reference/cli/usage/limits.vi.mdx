Đọc tổng token trong cửa sổ trượt 5 giờ và 7 ngày từ dữ liệu cục bộ; phần trăm do provider báo chỉ có khi bạn bật advanced polling.

Dùng `ak usage limits` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Show trailing 5h and week token usage per provider

### Synopsis

Sums local session-token facts inside the trailing 5-hour and 7-day rolling windows per provider and reports both windows with a raw_only provenance. Every fact is counted under the window that contains the session's start (session-start attribution). When advanced polling is switched on in settings, rows the provider reported carry provider_reported provenance, the provider's used percent, and the source endpoint; a failed poll keeps the local counts and records a degrade_reason. Use it before starting a long session, when tuning agent runs, or when a downstream dashboard needs the same numbers the desktop popover shows.

Effects:
  Read-only. Opens the local analytics SQLite index under ~/.agentkit/analytics/ in read-only mode; AGENTKIT_HOME overrides the base dir. A cold or absent index yields zeroed windows, not an error. Never opens a network socket unless advanced polling is enabled in settings (AGENTKIT_ADVANCED_POLLING=1 plus an explicit acknowledgement); then it sends at most one GET per enabled provider to that provider's usage endpoint with the access token the official CLI already stored, rate-limited to a burst of three per minute, and never refreshes or writes a token.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak usage limits [flags]
```

### Examples

```
  ak usage limits
  ak usage limits --json
  ak usage limits --provider claude --window 5h
  ak usage limits --provider all --json
```

### Options

```
  -h, --help              help for limits
      --json              Emit machine-readable JSON (implies --no-interactive)
      --no-interactive    Disable interactive prompts (CI-safe)
      --provider string   Provider to query: claude, codex, or all (default "all")
  -q, --quiet             Suppress non-error output on stderr
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
      --window string     Rolling window: 5h, week, or all (default "all")
  -y, --yes               Assume yes for all prompts
```
