Use `ak usage` for the operation described below. The command help records its arguments, effects, and options.

## Command contract

Inspect per-provider usage limits from local analytics

### Synopsis

Reports rolling-window token usage per coding-agent provider from the local analytics fact store. The default local mode never opens a network socket. Advanced provider-reported polling is an explicit opt-in (a risk acknowledgement in the dashboard settings) that overlays the provider's own percentages on the same rows. Use limits to inspect trailing 5-hour and week token counts per provider (claude, codex); both windows are always returned in one call.

### Examples

```
  ak usage limits
  ak usage limits --provider claude --json
  ak usage limits --window week --provider codex
```

### Options

```
  -h, --help             help for usage
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
