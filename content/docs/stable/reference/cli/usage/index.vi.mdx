Xem dữ liệu sử dụng provider từ analytics cục bộ.

Dùng `ak usage` với đối số và tùy chọn dưới đây. Phần help nguyên bản giữ nguyên thuật ngữ, cú pháp, tác động và điều kiện thực thi của CLI để đối chiếu chính xác.

## Contract và help của lệnh

Inspect per-provider usage limits from local analytics

### Synopsis

Reports rolling-window token usage per coding-agent provider from the local analytics fact store. The default local mode never opens a network socket; advanced provider-reported polling arrives in later phases behind an explicit opt-in and a build tag. Use limits to inspect trailing 5-hour and week token counts per provider (claude, codex); both windows are always returned in one call.

### Examples

```
  ak usage limits
  ak usage limits --provider claude --json
  ak usage limits --window week --provider codex
```

### Options

```
  -h, --help             help for usage
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
