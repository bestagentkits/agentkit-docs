---
title: ak license
description: Manage the devices bound to your AgentKit App license key, and see which command lists or deactivates them.
---

Use `ak license` to find the commands that inspect and manage the devices
activated against your AgentKit App license. The group command itself only
prints help; it makes no network request and does not read or write the
session.

## Usage

```bash
ak license
```

The group has no command-specific flags and takes no positional arguments. Run
one of the subcommands below. Shared flags are described in
[CLI conventions](../cli-conventions).

## Choose a command

| Goal | Command | Effect |
| --- | --- | --- |
| See the devices on your license | `ak license devices` | Read-only. Queries the registry with your license-key session. |
| Remove one device from your license | `ak license devices deactivate <device-id>` | Revokes that device's session on the registry. Deactivating this device also clears its local license session. |

## Before you run

Both subcommands need an App license-key session created by
`ak login --license-key`; see [`ak login`](../login). An API-key or email
session does not work here. Without that session they fail with
`no active license-key session; run 'ak login --license-key <key>' first`.
The session must also belong to the registry you target (default or
`--registry-url`); a mismatch is reported as a registry mismatch error.

This group manages devices, not kit grants. To check which kits your account
can install, use [`ak licenses`](../licenses).

## Exit behavior

Bare `ak license` prints help. Exit codes belong to the subcommands; see
[`ak license devices`](./devices) and
[`ak license devices deactivate`](./devices/deactivate).
