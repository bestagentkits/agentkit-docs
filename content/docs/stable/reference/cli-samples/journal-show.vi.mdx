Dùng `ak journal show` sau `ak journal list` khi cần toàn bộ bản ghi lịch sử
thay vì chỉ summary.

## Cách dùng

```bash
ak journal show <id-or-slug>
```

Cung cấp đúng một trong các dạng sau:

- slug như `fix-install-race`;
- filename stem như `2026-07-27-fix-install-race`;
- filename `.md` như `2026-07-27-fix-install-race.md`.

Giá trị chỉ được resolve trong thư mục `plans/journals/` của project đã chọn.
Path separator và traversal bị từ chối khi lookup filename.

## Tuỳ chọn

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--project <name>` | Project đăng ký cho cwd | Chọn chính xác tên project đã đăng ký. |

Từ cwd chưa đăng ký, lookup dùng basename của thư mục như một tên registry. Vì
thế nó có thể chọn project đã đăng ký khác có cùng tên. Hãy đăng ký thư mục hoặc
truyền `--project` hợp lệ một cách tường minh.

## Ví dụ

```bash
ak journal show 2026-07-27-fix-install-race
ak journal show fix-install-race --project myproj
ak journal show fix-install-race --project myproj --json
```

Slug ngắn phải resolve đúng một file. Nếu các entry ở ngày khác nhau dùng cùng
slug, hãy dùng filename stem có prefix ngày để phân biệt.

## Đầu ra và quyền riêng tư

Pretty output thêm title và header `date - filename`, sau đó in Markdown đã
lưu. Plain output in chính xác body Markdown đã lưu. JSON thành công dùng
`kind=journal.show`; `data` chứa các field summary cùng `body` và `path` tuyệt
đối.

`--quiet` ẩn đầu ra thành công. Đầu ra có thể chứa toàn bộ journal, chi tiết
project nội bộ và đường dẫn cục bộ tuyệt đối. Hãy kiểm tra hoặc redact trước khi
ghi log, dán vào issue hay chia sẻ ra ngoài project.

Lệnh chỉ đọc và hoạt động cục bộ. Nó không dùng mạng, auth, process, prompt,
preview, cache hay thay đổi filesystem.

## Mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Resolve và in đúng một entry. |
| `1` | Không tìm thấy entry hoặc project đã đăng ký, hoặc đọc thất bại. |
| `2` | Project selection, resolve ID, ambiguity hoặc parse argument không hợp lệ. |

`--project` tường minh nhưng không tồn tại được phân loại là mã `2`, còn thiếu
entry trong project hợp lệ là mã `1`. Với `--json`, các lỗi này có thể không có
JSON error envelope; hãy dùng process exit code.
