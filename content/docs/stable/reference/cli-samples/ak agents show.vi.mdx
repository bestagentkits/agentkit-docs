---

Dùng `ak agents show` để xem một agent trước khi cài hoặc xác nhận metadata
trong bản installed.

## Cách dùng

```bash
ak agents show <kit>/<agent>
```

Phải có đúng một ref. Nên dùng ref chuẩn; `ak:<agent>`, `ake:<agent>` và
`akm:<agent>` là dạng rút gọn được chấp nhận cho Kit `core`, `engineer` và
`marketing`.

Không có cờ riêng cho lệnh. Lệnh chỉ đọc, không prompt và không thực hiện công
việc mạng hay authentication.

## Thứ tự lookup

Lệnh kiểm tra `~/.claude/plugins/<kit>/agents/<agent>.md` trước, rồi fallback
sang `./kits/<kit>/agents/<agent>.md`. `AGENTKIT_PLUGIN_DIR` và
`AGENTKIT_KITS_DIR` thay các root đó.

Nếu có cả hai tệp, bản installed thắng. `show` không so sánh hai tệp hoặc báo
drift. Khối YAML frontmatter hợp lệ ở đầu tệp có thể cung cấp `description`,
`model`, `memory`, `tools` phân tách bằng dấu phẩy và tag. `tags` tường minh ưu
tiên hơn `keywords`. Frontmatter thiếu, không đọc được hoặc sai dạng tạo
metadata rỗng thay vì làm lộ Markdown body.

## Đầu ra

Stdout cho người dùng báo các trường sau khi có:

```text
ref, name, kit, description
model, memory, tools, tags
state: installed | available
```

JSON thành công dùng:

```text
schema_version: 1
kind: assets.show
data.kit, data.name, data.description, data.installed
data.tools?, data.model?, data.memory?, data.tags?
```

Không in nội dung tệp, source path, secret hoặc Markdown body. Lỗi dùng stderr;
lỗi thực thi JSON dùng shared error envelope.

## Kết quả và mã thoát

| Mã thoát | Ý nghĩa |
| --- | --- |
| `0` | Tìm thấy record installed hoặc available. |
| `1` | Sai số lượng argument theo vị trí hoặc có lỗi runtime cục bộ. |
| `2` | Ref sai dạng hoặc không phân tích được cờ. |
| `5` | Không có cả tệp installed lẫn available tại path dự kiến. |
