Dùng `ak mcp list` trước khi chỉnh sửa, link hoặc verify MCP config. Lệnh chỉ
đọc config cục bộ và không khởi động server.

## Cách dùng

```bash
ak mcp list
```

Lệnh không nhận argument theo vị trí và không có cờ riêng. Các cờ discovery kế
thừa từ `ak mcp`:

| Cờ | Mặc định | Mô tả |
| --- | --- | --- |
| `--claude-home <dir>` | `AGENTKIT_CLAUDE_HOME` hoặc `~/.claude` | Chọn Claude user root. |
| `--cwd <dir>` | Thư mục làm việc hiện tại | Chọn thư mục project `.mcp.json`. |

`CODEX_HOME` chọn Codex config root. Cờ dùng chung nằm trong
[quy ước CLI](../cli-conventions).

## Merge và redaction

Trong các nguồn Claude, project `.mcp.json` thắng user `.mcp.json`, rồi user
`.mcp.json` thắng `settings.json` với server cùng tên. Entry Codex ở inventory
harness riêng, nên kết quả có thể có cả entry Claude và Codex cùng tên.

Giá trị môi trường bị loại khi parse. Output có tên environment key, tên server,
command, argument, enabled state, harness, mô tả nguồn và đường dẫn tuyệt đối.
Tệp thiếu được bỏ qua; tệp hiện có sai định dạng hoặc không đọc được làm toàn bộ
lệnh thất bại.

## Output

Human output trên stdout liệt kê tên server và nguồn. Inventory rỗng in
`No MCP servers found.` và thoát `0`.

JSON output là một envelope với `kind=mcp.list`, `data.servers` và
`data.total`. Không xem output là an toàn để công bố chỉ vì không có giá trị
môi trường: path, command, argument và key name vẫn có thể nhạy cảm.

## Hiệu ứng và mã thoát

Lệnh không prompt, đọc stdin, request network, chạy subprocess, ghi cache hay
thay config.

| Mã | Ý nghĩa |
| --- | --- |
| `0` | Discovery hoàn tất, kể cả inventory rỗng. |
| `1` | Không resolve được root hoặc không đọc/parse được tệp hiện có. |
| `2` | Argument hoặc cờ không hợp lệ. |
