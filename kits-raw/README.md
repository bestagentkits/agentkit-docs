# Kit facts (`kits-raw/`)

Mechanical projection of each kit's `kit.yaml` roster and `SKILL.md` frontmatter.
Regenerated by `node scripts/ingest-kits.mjs` from the local kit cache
(`~/.agentkit/cache/kits/<kit>/claude-code/<train>/<kit>/`).

No LLM in this layer. Committed to the repo; CI does not re-ingest.
