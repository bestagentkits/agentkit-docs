List Claude Code sessions for registered AgentKit projects—a finite snapshot of session JSONL files.

**When to use it:** Before sharing, redacting, or inspecting local Claude Code session transcripts.

Read-only. Reads `~/.agentkit/projects.json` and `~/.claude/projects/*/*.jsonl`; `AGENTKIT_HOME` and `AGENTKIT_CLAUDE_HOME` override those roots.
