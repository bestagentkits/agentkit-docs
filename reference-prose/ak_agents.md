Manage individual agents from any kit—list, install, remove, show, and search per-role markdown personas that install into the underlying agent runtime.

**When to use it:** Use as the entry point for any per-agent operation; subcommands handle the action. Run `ak agents list` to see what's installed and available, or `ak agents search` to find agents by keyword.

This group is read-only at the top level; each subcommand documents its own disk effects.
