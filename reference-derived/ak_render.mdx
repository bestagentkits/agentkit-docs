Runs the AK Render compiler pinned by this ak release (@bestagentkits/render@0.3.0) through npx, the same version the kits released with it invoke. If an installed skill names a different @bestagentkits/render version, run that skill's npx command instead. Requires Node.js &gt;= 20.11 with npx on PATH; the first run downloads the package into the npm cache.
