Mark a plan as archived in the local plan store. A VACUUM INTO recovery snapshot is taken before the state change. Archived plans are excluded from `ak plan list` by default.

**Effects:** Writes the plans table and a recovery snapshot in the local plan store.

### Usage

```bash
ak plan archive <id> [flags]
```
