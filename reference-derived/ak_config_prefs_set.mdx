Write a per-hook toggle into config.yaml: `set hooks.<name> false` makes that hook exit early at its next run without unregistering it from the harness. Only keys under `hooks.` may be set; the whole document is schema-checked before writing.

**Who it's for:** Anyone disabling a hook for this machine or this project without editing YAML by hand.

**When to use it:** Use it to turn a hook off (or back on) as a soft preference; the harness registration is unchanged.

**What changes on disk:** Backs up then rewrites the selected scope's config.yaml (project scaffolds it when absent).

### Usage

```bash
ak config prefs set <key> <true|false> [flags]
```

### Examples

```bash
ak config prefs set hooks.simplify-gate false            # disable for the user
ak config prefs set hooks.simplify-gate true --scope project
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| `--scope string` | which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user") |
