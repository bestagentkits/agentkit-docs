Write a hook, journal, worktree, agent model, or semantic_decision preference. Semantic provider consent is user-scoped; project scope can only disable enabled or consumer flags. Provider credentials never belong in config.

**Effects:** Backs up then rewrites the selected scope's config.yaml file.

### Usage

```bash
ak config prefs set <key> <value> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--scope string` | which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user") |
