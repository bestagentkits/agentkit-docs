Read captured output without opening private invocation files. Capture is bounded and reports truncation. --limit is a raw-byte target, not a hard cap: a page ends early or runs past it by one released value plus its marker to keep the value whole; follow next_offset for the next page.

**Effects:** Read-only; does not launch or signal processes.

### Usage

```bash
ak orchestrate output <run-id> <job-id> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--limit int` | Target bytes in this page (1-65536); a page may end early or run over by one released value to keep it whole, so follow next_offset rather than assume this exact size (default 16384) |
| `--offset int` | Start at this byte offset |
