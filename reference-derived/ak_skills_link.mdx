Signs in to agentkit.best with OAuth (authorization code with PKCE) and stores a SkillX credential scoped to https://skillx.sh/api. While a link exists every SkillX request to skillx.sh uses it and refreshes it; SKILLX_TOKEN is used only when no link exists. A revoked link fails with a re-link message instead of falling back. SkillX must also be linked to the same agentkit.best account (skillx.sh: Link with AgentKit). AGENTKIT_OAUTH_ISSUER selects another agentkit.best deployment.

**Effects:** Opens the agentkit.best sign-in page in the default browser (the URL is also printed on stderr) and waits on a 127.0.0.1 loopback port for the approval. Stores the linked credential as SKILLX_LINK in the ak secrets store and the non-secret record AGENTKIT_HOME/state/skillx-link.json. Replaces an existing or revoked link and revokes the replaced one. SKILLX_TOKEN is kept and used again after `ak skills unlink`. Never prompts beyond the browser approval.

### Usage

```bash
ak skills link [--no-browser] [--timeout <duration>] [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--no-browser` | print the sign-in URL without opening a browser |
| `--timeout duration` | how long to wait for the approval (default 5m0s) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | linked |
| `1` | command failure: approval declined or timed out, agentkit.best unreachable or refused, or the secrets store unavailable |
| `2` | invalid flags or AGENTKIT_OAUTH_ISSUER |
