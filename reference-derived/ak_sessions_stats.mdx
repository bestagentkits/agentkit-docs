Aggregate privacy-bounded local session analytics for dashboard comparison charts—tokens, models, providers, projects, or date buckets.

**When to use it:** When comparing runtimes, models, providers, projects, or date buckets across a window. Use `--refresh` to bypass memoized analytics when available.

Read-only. Reads registered projects and local session JSONL summaries.

### Usage

```bash
ak sessions stats [flags]
```

### Examples

```bash
ak sessions stats --json
ak sessions stats --metric tokens --by model --window 168h --json
ak sessions stats --project myapp --runtime codex --by date --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--by string` | Dimension: runtime, model, provider, project, date, or duration (default "runtime") |
| `--metric string` | Metric to aggregate (default "tokens") |
| `--project stringArray` | Project name to include; repeatable |
| `--refresh` | Bypass analytics cache when available |
| `--runtime string` | Runtime filter, e.g. claude-code or codex |
| `--window string` | Lookback duration, e.g. 168h (default "720h0m0s") |
