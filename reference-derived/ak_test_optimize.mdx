Default is read-only planning. Supply a trusted manifest with group commands, ownership, full-suite groups and explicit policy mappings. Invalid optional evidence broadens; missing mandatory mappings block. --run executes repository code without a sandbox.

**Effects:** Planning reads Git and policy only. --run executes trusted commands in this repository; --output creates a local receipt. Semantic mode defaults off; an explicitly permitted mode may send compact facts and incur provider charges. Shadow never changes the effective plan.

### Usage

```bash
ak test optimize [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--base string` | Git comparison base (required) |
| `--evidence string` | Optional bounded external evidence JSON |
| `--head string` | Git comparison head; local changes also count (default "HEAD") |
| `--manifest string` | Repository-owned executable group manifest (default ".agentkit/test-impact.json") |
| `--output string` | Create a new local JSON result file; never overwrite |
| `--run` | Execute trusted manifest commands; this is not a sandbox |
| `--semantic string` | Optional semantic observations: off, shadow, or advisory; requires explicit user consent (default "off") |
| `--semantic-context string` | Reviewed compact semantic context JSON bound to this request |
