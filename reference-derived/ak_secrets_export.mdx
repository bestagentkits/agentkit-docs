Emit a schema-versioned inventory (schema_version 1) of every stored ref: name, creator, created/rotated timestamps, its rotation window in days, and how many grants name it. Values are excluded unless --include-values is passed, and that flag requires --out &lt;path&gt;.age: a value is never written to stdout or a terminal, in any mode including --json. --include-values asks for a y/N confirmation on stderr, then twice for a new passphrase, and seals the document to that passphrase with age before writing it; nothing on this host keeps that passphrase, so losing it loses the export, the same trade as any other age-encrypted backup you keep yourself. Without --include-values, --out (any extension) writes the bare plaintext document (mode 0600); omitted, it goes to stdout instead, wrapped in the usual envelope under --json or as a table otherwise. Use it to inventory a host before a migration, or to hand an auditor the list of refs without the secrets.

**Effects:** Reads the index and the grants file; reads the backend once per ref only with --include-values. Writes the --out path (mode 0600), replacing an existing file there and saying so; with --include-values the file is age-encrypted, sealed to a passphrase entered at the prompt and stored nowhere on this host.

### Usage

```bash
ak secrets export [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--backend string` | Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway) |
| `--include-values` | Include every value, age-encrypted to a passphrase you enter (requires --out &lt;path>.age) |
| `--out string` | Write the export to this path (mode 0600) instead of stdout; --include-values requires this and a .age extension |
| `--unlock-with-recovery` | Open the file backend's vault with a recovery private key and set a new passphrase |

### Exit codes

| Code | Meaning |
| --- | --- |
| `2` | invalid flags; for --include-values, --out is missing, does not end in .age, names stdout/a terminal/a symlink/a directory, or the confirmation/passphrase was declined, did not match, or was never entered (stdin closed or Ctrl-D at the prompt) |
| `3` | a listed ref has no stored value (only with --include-values) |
| `5` | backend, index, encryption, or --out write failure |
