Create, list, show, and validate chronological work journals. Journals are historical records, not durable authority.

**Who it's for:** Agents and developers recording session work.

**When to use it:** After meaningful implementation, reviews, or incident work.

**What changes on disk:** create writes one file under &lt;project&gt;/&lt;configured paths.plans&gt;/journals/. list/show/validate are read-only.

### Examples

```bash
ak journal create "Fix install race" --summary "Root cause and fix"
ak journal list --query install --json
ak journal show 2026-07-27-fix-install-race
ak journal validate 2026-07-27-fix-install-race
```
