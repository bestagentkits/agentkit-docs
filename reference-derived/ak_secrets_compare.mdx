Answer whether a candidate value equals &lt;ref&gt;'s stored value: match or differs. The candidate is read like `ak secrets set` reads a value — --value=- (stdin), --value-file=&lt;path&gt;, or an interactive, non-echoing prompt, never --value=&lt;literal&gt; — and compared byte for byte, so a trailing newline counts. The two SHA-256 digests are compared in constant time and neither value is printed, logged or put in --json output. Compare refuses (exit 2) when the candidate or the stored value is shorter than 16 characters, not counting a recognised public prefix (such as sk_live_) or one trailing line end, and counting bytes for a value that is not UTF-8. That is the rule the value hint uses; a short candidate is refused before the backend is read. When the audit ledger exists, each call adds one row with the ref and the result (match, differs or refused) and never a value or a hash of one; a ledger that cannot take the row is a warning on stderr, and the answer still stands. Use it to check a .env entry or a pasted token against the vault without --reveal; the value hint in list, get and search narrows the candidates first.

**Effects:** Reads the index and the stored value from the backend, which may prompt for keychain consent or the vault passphrase. Appends one row to the secrets audit ledger when it already exists; never creates it.

### Usage

```bash
ak secrets compare <ref> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--backend string` | Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway) |
| `--unlock-with-recovery` | Open the file backend's vault with a recovery private key and set a new passphrase |
| `--value string` | Candidate value source: '-' reads from stdin. A literal value is rejected — use --value=- or --value-file |
| `--value-file string` | Path to a file containing the candidate value |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | compared: the answer (match or differs) is in the output |
| `2` | invalid flags or arguments, an unreadable --value-file, or a candidate or stored value shorter than 16 characters |
| `3` | ref has no stored value |
| `5` | backend or index failure |
