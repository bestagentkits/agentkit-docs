Store a value under &lt;ref&gt; in the active secrets backend. The value is read from --value=- (stdin), --value-file=&lt;path&gt;, or an interactive, non-echoing prompt — never from --value=&lt;literal&gt; on the command line, which would leak the value into shell history and process listings (ps, /proc). The active backend sets no size limit per value. Use it before the first run that needs $&#123;REF&#125;, or with --force to overwrite an existing value. A new ref may not contain "/", a NUL byte, or a control, bidi, zero-width or line-separator character, since it would otherwise print as different text in `ak secrets list` and approval prompts.

**Effects:** Writes the value to the active backend and creates or updates the ref's metadata (never a value) in ~/.agentkit/secrets/index.json. --rotate-ttl records this ref's rotation window there; omitting it leaves a window already stored unchanged, so an ordinary rotation never resets one an operator shortened. The profile flags (--description, --project, --environment, --provider, --account, --tag) record searchable metadata in the same index; one left out keeps what is stored. Metadata text that contains the value is refused.

### Usage

```bash
ak secrets set <ref> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--account string` | Account or workspace at the provider (empty clears it) |
| `--backend string` | Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway) |
| `--description string` | What the secret is for (metadata, never a value; empty clears it) |
| `--environment string` | Environment, e.g. production or staging (empty clears it) |
| `--force` | Overwrite an existing value instead of failing |
| `--project strings` | Project the secret belongs to; repeat or comma-separate for several (replaces the list; empty clears it) |
| `--provider string` | Service the secret is for, e.g. stripe or openai (empty clears it) |
| `--rotate-ttl string` | How long this secret may go between rotations, in whole days, e.g. 30d, 2w, or 45 (default 90d) |
| `--tag strings` | Tag; repeat or comma-separate for several (replaces the tags; empty clears them) |
| `--unlock-with-recovery` | Open the file backend's vault with a recovery private key and set a new passphrase |
| `--value string` | Secret value source: '-' reads from stdin. A literal value is rejected — use --value=- or --value-file |
| `--value-file string` | Path to a file containing the secret value |

### Exit codes

| Code | Meaning |
| --- | --- |
| `2` | invalid flags or arguments, or profile text that would hold the value |
| `4` | ref already exists and --force was not passed |
| `5` | backend or index failure |
