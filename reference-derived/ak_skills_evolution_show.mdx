**Shows one candidate:** its skill and base, the diff per file, the findings, the blast radius and the evaluation and apply slots. The reference is the full ID, its hex part or a unique prefix of at least 8 hex characters.

**Effects:** Read-only: reads the candidate records under AGENTKIT_HOME/state/skill-evolve/candidates/ and verifies each against its candidate ID. Writes nothing, takes no lock, runs no script, model or network call, and skips the background update check.

### Usage

```bash
ak skills evolution show <candidateId> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, including an empty candidate store |
| `1` | the candidate store could not be read, or (show) the record failed verification (store.corrupt); list reports an unverified record and still exits 0 |
| `2` | invalid flags or arguments, or a candidate reference that is not an ID or a prefix of at least 8 hex characters |
| `5` | no recorded candidate matches the reference, or a prefix matches more than one (evolve.candidate_not_found) |
