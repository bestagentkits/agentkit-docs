Set the agent's model to inherit in the selected config scope and remove its pinned reasoning effort. Codex, OMP, and Pi omit the model line; the other runtimes write model: inherit.

**Effects:** Backs up then rewrites the selected scope's config.yaml when it exists, then rewrites the model fields of every installed file of the agent whose model AgentKit still owns. A file whose model was edited in the runtime is left alone and reported.

### Usage

```bash
ak agents model inherit <agent> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--project string` | project directory whose installs and .agentkit/config.yaml apply (default: the current directory) |
| `--runtime string` | runtime the agent is installed in ([claude-code codex cursor omp pi]) |
| `--scope string` | which config to write: user (the AgentKit home) or project (.agentkit/config.yaml in the project) (default "user") |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | command failure, including an installed agent file AgentKit cannot prove it still owns (nothing is written) |
| `2` | invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage |
| `4` | another AgentKit operation holds the kit lifecycle lock; retry when it finishes |
| `5` | adopt only: no readable installed file of the agent |
