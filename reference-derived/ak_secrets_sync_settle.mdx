Choose the value a conflicted secret keeps on every device: this device's (local), the current synced value (remote), or one conflict branch (branch:&lt;id&gt;, IDs from `ak secrets sync status`). Runs one sync cycle around the choice. Refused when an AI agent runs it.

**Effects:** Pushes signed records that close the conflict, and updates this device's store to the kept value.

### Usage

```bash
ak secrets sync settle <ref> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--backend string` | Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway) |
| `--keep string` | Which value to keep: local, remote, or branch:&lt;conflict_id> |
| `--unlock-with-recovery` | Open the file backend's vault with a recovery private key and set a new passphrase |
| `--wait-lock duration` | How long to wait for another sync cycle to finish (default 30s) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | conflict resolved |
| `2` | invalid --keep, or the store moved since enable |
| `3` | the ref, or the branch, has no open conflict |
| `6` | refused: an AI agent is running this command |
| `10` | sync is not enabled on this device |
| `11` | the vault server is unavailable or busy; retry |
| `12` | resolved, but something else needs attention |
| `13` | integrity alarm; sync halted |
| `14` | not logged in, or this device was removed |
