When an agent on one of your synced devices asks for a secret no grant covers, that device sends a sealed, signed request to your other devices. List them here and answer one with approve or deny; the requesting device checks the signed answer before it grants anything, and an answer given there first withdraws the request. Only a human owner or editor device can answer. Requests asked on this device are answered with `ak secrets approve`.

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Related commands

- [`ak secrets approvals approve`](./ak_secrets_approvals_approve) — Allow a pending request from another device
- [`ak secrets approvals deny`](./ak_secrets_approvals_deny) — Deny a pending request from another device
