Validate a job graph file, generate a fresh run ID, and spawn a detached worker. Always creates a new run.

**Effects:** Writes private state, bounded redacted logs, events, and a launch graph under AGENTKIT_HOME/orchestrate/runs/&lt;run-id&gt;/. The graph retains argv/env for recovery; keep credentials out of job specs and exclude invocation files from diagnostic exports.

### Usage

```bash
ak orchestrate start <job-graph.json> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | job graph invalid, or the worker failed to reach readiness |
| `6` | unsupported platform (v1 requires darwin) |
