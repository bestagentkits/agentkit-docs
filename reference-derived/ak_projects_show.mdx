Show registration metadata for a registered project. Lookup first by exact directory path, then by name.

**When to use it:** Inspecting registration details for a specific project.

Reads `~/.agentkit/projects.json`; read-only.

### Usage

```bash
ak projects show <name|path> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | project found |
| `2` | invalid arguments |
| `5` | project not found in registry |
