Joins the screened skills of ak skills self-improve status with the candidates ak skills improve recorded for them and their evaluation. list and inspect read; approve, reject and defer record a decision that also silences the session-start nudge. Approval is always explicit: approve previews without --yes. Only a skill of your own personal kit (@local/) is applied, through the same plan, --plan token and rollback record as ak skills evolution apply. An AgentKit skill is proposal-only: approve records the proposal and writes no kit file. An evaluation that is not_run or inconclusive is a normal outcome.

**Effects:** list and inspect are read-only; reject, defer and approve write review.json, and approve --yes of a personal kit skill applies the candidate.

### Usage

```bash
ak skills self-improve review [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, including a disabled feature or an empty store |
| `1` | the AgentKit home could not be resolved (self_improve.home_unresolved), the event store could not be read or written (self_improve.store_failed), the config could not be written (self_improve.config_write_failed), or a consent policy is invalid (self_improve.policy_invalid) |
| `2` | invalid flags, arguments or hook payload (self_improve.invalid_input) |
| `4` | another writer held the event store lock (self_improve.store_busy) |
| `5` | no screened skill or recorded candidate matches the reference (self_improve.not_found) |
