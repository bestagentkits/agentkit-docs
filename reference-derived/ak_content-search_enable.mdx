Creates one AKC1 FTS5 shard for a project after the owner accepts plaintext-at-rest disclosure.

**Who it's for:** Project owners enabling local search.

**When to use it:** Only after explicit opt-in; never created by startup or ingest alone.

**What changes on disk:** Creates AGENTKIT_HOME/operational/content/&lt;project-id&gt;.db and sidecars.

### Usage

```bash
ak content-search enable [flags]
```

### Examples

