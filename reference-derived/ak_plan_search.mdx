Ranked full-text search (SQLite FTS5 BM25) over plan task titles and phase titles/bodies/notes/evidence/acceptance. The positional argument is free text; --project/--branch/--issue/--status are structured filters, not search terms. Closed and archived plans are excluded unless included explicitly.

**Effects:** Read-only.

**Exit status:** 0 success 1 plan store I/O error 2 invalid --status value

### Usage

```bash
ak plan search <query> [flags]
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--branch string` | Filter to a git branch |
| `--include-archived` | Include archived plans |
| `--include-closed` | Include closed plans |
| `--issue int` | Filter to a linked issue number |
| `--limit int` | Maximum results (default 50) |
| `--project string` | Filter to a project slug |
| `--status string` | Filter to a plan status (pending\|in-progress\|completed\|cancelled\|unknown) |
