Create the age-encrypted vault, seal it under a passphrase you choose now, and generate one recovery keypair. The private half is shown once and stored nowhere: save it the way you would a password, somewhere the host itself cannot reach. If you lose both the passphrase and every recovery key, the vault cannot be opened by anyone, including AgentKit. Refuses to run when a vault already exists.

**Effects:** Prompts twice for a new passphrase, then writes vault.age and vault.key.age (both 0600) under AgentKit home. Prints the recovery private key to stderr and waits for you to acknowledge it, or writes it to --print-to with mode 0600.

### Usage

```bash
ak secrets recovery init [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--label string` | Label recorded for this recovery key (default "recovery-key-1") |
| `--print-to string` | Write the recovery private key to this path (created 0600) instead of showing it on the terminal |

### Exit codes

| Code | Meaning |
| --- | --- |
| `2` | no safe place to put the private key, or an empty label |
| `4` | a vault already exists at that path |
| `5` | the vault could not be written |
