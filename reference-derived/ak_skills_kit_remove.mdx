**Drops only the personal:** &lt;name&gt; references in the scope (all of the kit's runtimes, or --runtime). A file another owner still holds stays, a file you changed is preserved and reported, and an alias a legacy kit install also records keeps its files, with a hint to run `ak kit refresh <kit>`. The personal kit's own files and kit install records are never touched.

**Effects:** Applies without prompting unless the plan needs review; --dry-run prints the plan, its review findings and plan token, and writes nothing. In one journaled transaction under the kit lifecycle lock it writes the composed trees into the skill store under AGENTKIT_HOME, the projected files into each runtime's native skills root (mode 0644, never executable), and the scope's skill lock and receipts, owned by personal:&lt;name&gt;. Never rewrites the personal kit or the foundation kits, and never runs a script. Running sessions may see the new files as soon as the transaction commits. Needs the skill store on (after `ak update --ssot`, or AGENTKIT_SKILL_STORE=1).

### Usage

```bash
ak skills kit remove <name> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | Print the plan, its review findings and plan token; write nothing |
| `--runtime strings` | Runtimes: claude-code, codex (repeatable; the running revision's runtimes are always included) |
| `--scope string` | Lock and skills root scope: project (default) or global (default "project") |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, or nothing to change |
| `1` | command failure, such as a path too long or a recovery that is required |
| `2` | the skill store disabled, invalid flags or arguments, or a malformed manifest or proposal |
| `4` | another AgentKit operation holds the kit lifecycle lock |
| `5` | personal kit, foundation, version, skill or previous revision not found (removing a kit that is not applied changes nothing and exits 0) |
| `6` | review required, stale plan token, rebase conflict, alias collision (including a legacy kit alias), or an unowned or modified path |
| `7` | revoked foundation, a link in a target path, or a digest mismatch |
