Preview or apply AgentKit-owned project refreshes after a release. Bare `ak update` refreshes inferred project-owned `kits/<kit>/...` content; use `ak kit refresh` for installed plugins.

**When to use it:** After an AgentKit release to refresh AK-owned project files. Default is preview (dry-run); pass `--yes` or accept interactively to apply. User-modified files are skipped without `--force`.

When applied, takes a pre-update project snapshot before mutation. Does not refresh installed `~/.claude/plugins/<kit>/` plugin output.

### Usage

```bash
ak update [project-dir] [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--ack` | With --status: mark the last background result as seen |
| `--backup` | Snapshot the whole project, not only the files the refresh changes (off by default; set backups.enabled: true to make it the default) |
| `--beta` | Shorthand for --channel beta |
| `--channel string` | Remote registry channel for --remote (beta requires explicit opt-in) (default "stable") |
| `--dry-run` | Force preview (exit 0); update already previews by default unless --yes is given |
| `--force` | Overwrite user-modified files (a pre-update snapshot is taken first unless --no-backup) |
| `-g, --global` | Refresh AgentKit-owned kits at user/global scope instead of the current project |
| `--kits string` | Comma-separated list of kits to update |
| `--kits-dir string` | Explicit local kits source directory for development and CI |
| `--local` | Read kits from an explicit --kits-dir or AGENTKIT_KITS_DIR source (dev/CI) |
| `--no-backup` | Skip pre-update recovery snapshots, including the one --force takes (power users only — data loss risk) |
| `--no-project stringArray` | Remove a project from background updates, even if its directory is gone (repeatable) |
| `--project ak projects add` | Opt a registered project into background updates (repeatable; see ak projects add) |
| `--registry-url string` | AgentKit registry base URL (default: $AGENTKIT_REGISTRY_URL, then dev/staging https://staging.agentkit.best or release https://agentkit.best) |
| `--remote` | Download kits from the authenticated AgentKit registry (default) (default true) |
| `--runtime string` | Alias of --target. Agent runtime(s) to update, comma-separated. Project remote: claude-code, codex, cursor, dsh, grok, omp, pi; global remote: claude-code, codex, cursor, dsh, grok, omp; global local: claude-code, codex, cursor, dsh, grok, omp. Unset means all installed runtimes. (default "claude-code") |
| `--schedule string` | Background auto-update schedule: daily, weekly, or off (changes settings only; updates nothing now) |
| `--show-diff` | Show unified diff for each file that will be overwritten |
| `--status` | Show the background auto-update schedule and last result (read-only) |
| `--target string` | Agent runtime(s) to update, comma-separated. Project remote: claude-code, codex, cursor, dsh, grok, omp, pi; global remote: claude-code, codex, cursor, dsh, grok, omp; global local: claude-code, codex, cursor, dsh, grok, omp. Unset means all installed runtimes. Alias of --runtime; pass only one. |
| `--version string` | Remote kit version for --remote (default: channel latest) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | runtime error, CLI hard-gate, partial kit failure (including a failed project runtime refresh pass), or interrupt after mutation; for the auto-update settings and --status --ack, an I/O failure or a busy state file |
| `2` | invalid flags (including --target with --runtime set differently, or an unknown runtime); at project scope: no tracked kits and no runtime install, or a --target that matches no project runtime install; with --global: a project directory argument, an empty refreshable set, or a plugin-only result; for the auto-update settings: an invalid --schedule, an unregistered --project, or a settings flag combined with an update flag |
| `3` | preview only — neither --yes nor an interactive confirmation was given |
