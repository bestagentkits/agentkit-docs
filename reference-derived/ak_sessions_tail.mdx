Stream appended session messages by following one Claude Code session JSONL file and printing messages as they are written.

**When to use it:** While Claude Code is actively writing to a session file. Press Ctrl-C or cancel the process to stop.

Read-only. Tails the selected `~/.claude` session JSONL file.

### Usage

```bash
ak sessions tail <project> <session-id> [flags]
```
