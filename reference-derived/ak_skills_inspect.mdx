Shows the verified manifest of a SkillX release: identity, version, digest, publisher, trust, files, declared scripts, exposure, compatibility and license. It reads SKILL.md for its frontmatter and never requests an executable or declared-script file.

**Effects:** Read-only for skills, projects and configuration: never installs, executes, or requests an executable or declared-script file. Writes only the disposable, size-capped SkillX cache under AGENTKIT_HOME/cache/skillx. Needs SkillX on: after `ak update --ssot`, or with AGENTKIT_SKILLX=1.

### Usage

```bash
ak skills inspect <@publisher/slug[@version][@sha256:<hex>]> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--source string` | Skill source to read from; only skillx is supported (default "skillx") |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | command failure: offline without verified cached data, or credential refused |
| `2` | SkillX disabled, invalid flags or arguments, or a request the source does not support |
| `5` | release or file not found |
| `7` | release untrusted, revoked, yanked or quarantined, or a served manifest that fails an identity or tree check |
