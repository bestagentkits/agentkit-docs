Verify and accept one settled attempt's artifact receipt. CLI dispatch requires Darwin; internal dispatch belongs to the active harness.

**Effects:** Writes private jobs.yaml, state.json and metrics.jsonl in the run directory. Acceptance runs declared verification commands; advance may copy declared artifacts and spawn CLI jobs.

### Usage

```bash
ak orchestrate accept <run-dir> <job-id> --attempt <id> --result <receipt.json> [flags]
```
