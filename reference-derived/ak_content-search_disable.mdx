Stops indexing and search for one project while leaving shard files on disk.

**Who it's for:** Project owners pausing local search.

**When to use it:** When search should stop without deleting derived data yet.

**What changes on disk:** Updates the lifecycle marker; does not delete DB/WAL/SHM.

### Usage

```bash
ak content-search disable [flags]
```

### Examples

```bash
ak content-search disable --project <uuid> --json
```
