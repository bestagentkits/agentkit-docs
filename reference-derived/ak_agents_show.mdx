Print metadata for a single agent—name, version, description, and runtime requirements.

**When to use it:** After `ak agents list` or `ak agents search` finds a candidate; before running `ak agents install`.

This command is read-only.

### Usage

```bash
ak agents show <kit>/<agent> [flags]
```
