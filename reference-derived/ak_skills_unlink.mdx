Deletes the linked credential and record and revokes the grant at agentkit.best. Afterwards SkillX requests use SKILLX_TOKEN again when it is set. Running it with no link does nothing.

**Effects:** Removes SKILLX_LINK from the ak secrets store and AGENTKIT_HOME/state/skillx-link.json, then revokes the refresh token at agentkit.best best effort. Leaves SKILLX_TOKEN untouched. Never prompts.

### Usage

```bash
ak skills unlink [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | unlinked, or nothing was linked |
| `1` | the secrets store or the link record could not be changed |
