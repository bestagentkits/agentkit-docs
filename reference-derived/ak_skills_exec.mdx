Runs one entrypoint of an installed skill tree pinned by its sha256 digest; versions, tags and ranges are refused. The broker verifies the content-store entry into a read-only copy (nothing is fetched), checks the release state of every recorded origin (a yanked, quarantined or revoked SkillX release is refused, as is one whose state cannot be checked because SkillX is disabled or misconfigured; only when SkillX is unreachable does the last online check stand in, for 7 days), validates agentkit-exec.json against the signed declared scripts, binds the interpreter by path and sha256, and requires a matching grant from ak skills grants add and an isolation backend that enforces every needed capability. Every refusal happens before anything is spawned. Script output is bounded, secret-redacted and neutralized, and is untrusted data. --output needs an entrypoint that declares $OUTPUT writes ($OUTPUT is read-only otherwise) and copies its files only after a zero exit, once the sandbox is gone; links are never copied. Root and elevated administrator runs are refused. Arguments after -- reach the script argv without a shell. A declared secret also needs an ak secrets grant for the secret with --agent set to the tree digest and --purpose skill-exec:&lt;identity&gt;@&lt;digest&gt;#&lt;entrypoint&gt;; each run spends one use. The value reaches the script only as the read-only file secrets/&lt;name&gt; beside its $OUTPUT (or a variable the manifest maps), removed when the run ends, and is struck from output and errors; output files holding it are refused. With --json or --no-interactive a file vault passphrase is never prompted for, and the run fails closed.

**Effects:** Requires AGENTKIT_SKILL_EXEC_BROKER=1; with it off nothing is read or written. Never runs anything on the host shell: a script runs only inside an isolation backend that enforces every capability its manifest needs: bubblewrap on Linux, AppContainer on Windows 10 1607 (build 14393) or later, or a local Docker engine running Linux containers (Podman on Linux only). macOS has no native backend, so there only Docker can run a script; a host where no backend enforces every needed capability refuses the run. Makes and removes a verified read-only copy of the tree under AGENTKIT_HOME/tmp/exec-runs, writes one audit record under AGENTKIT_HOME/state/exec/runs and, after an online state check of a SkillX release, its record under AGENTKIT_HOME/state/exec/release-state. The audit record is written as started before the spawn and replaced by the outcome. --output, allowed only for an entrypoint that declares $OUTPUT writes, receives copies of the files the script wrote, staged beside it and moved in whole. --dry-run writes no run directory or record under AGENTKIT_HOME (its verified copy lives in the OS temp directory and is removed; stale copies older than a day are swept), though the SkillX state check may refresh the SkillX metadata cache under AGENTKIT_HOME/cache/skillx; it spawns nothing but the backend self-test. A run whose entrypoint declares secrets spends one use of each secrets grant, writes a secrets audit row and redaction manifest under AGENTKIT_HOME/secrets, and writes each value to a private file in its run directory that is removed when the run ends; a dry run spends nothing, though its secrets grant check may prune expired grants from the secrets grants file. Running as root, LocalSystem or an elevated administrator is refused.

### Usage

```bash
ak skills exec <@publisher/slug@sha256:<hex>> --entrypoint <name> [flags] [-- args...]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | Run every check and report whether the script would run, spawning nothing |
| `--entrypoint string` | Manifest entrypoint to run (required) |
| `--input stringArray` | Bind a declared input as name=path (repeatable) |
| `--output string` | Empty or new directory that receives the script's output files |
| `--project string` | Project root whose grant and lock apply before the global ones |
| `--timeout duration` | Shorter wall-time limit than the manifest's |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | the script exited 0, or a dry run finished (wouldRun reports the outcome) |
| `1` | command failure: a timeout, cancellation, output limit, or an audit write failure |
| `2` | exec broker disabled, invalid flags, a mutable reference, an invalid manifest, a denied request, or an unavailable interpreter |
| `5` | store entry or entrypoint not found |
| `7` | not granted (the exec grant or a secrets grant), capabilities changed, no enforcing isolation backend, a refused or stale release state, a failed verification, a secret that cannot be released, or output holding a secret |
| `255` | other non-zero codes are the script's own exit code |
