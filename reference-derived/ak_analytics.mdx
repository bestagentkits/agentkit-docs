Shows and explicitly manages AgentKit's disposable local SQLite analytics index. Session and activity sources remain authoritative; this command never sends analytics remotely.

**Who it's for:** Both: power users scripting local maintenance and desktop users who need a clear privacy boundary.

**When to use it:** Use status to inspect serving mode, refresh or rebuild only when desired, and delete to remove the local index.

**What changes on disk:** Status is read-only. Mutations preview first and require --yes or an interactive confirmation; delete retains only a disabled intent marker.

### Examples

```bash
ak analytics status --json
ak analytics enable --yes --no-interactive
ak analytics delete --yes --json --no-interactive
```
