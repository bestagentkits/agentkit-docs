Print full detail for one plan tracked in the local SQLite plan store: plan.md's full body, every recorded phase, and each phase file's full body. With no id, resolves the current-context plan the same way `ak plan use`/`ak plan resolve` would. Read-only on the repo; refreshes the index if stale.

**Who it's for:** Both: quick lookups and scripted --json inspection.

**When to use it:** (unspecified)

**What changes on disk:** Read-only on the repo; refreshes the index if stale.

### Usage

```bash
ak plan show [id] [flags]
```

### Examples

```bash
ak plan show
ak plan show my-project/260722-1200
ak plan show my-project/260722-1200 --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

| --- | --- |
