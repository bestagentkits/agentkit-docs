Send SIGTERM through the worker control socket, wait a grace period, then SIGKILL remaining verified jobs. Does not signal from persisted state alone.

**Effects:** Persists the stop request and its outcome to the run's state file.

### Usage

```bash
ak orchestrate stop <run-id> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | no live verified worker, or the stop failed |
| `6` | unsupported platform (v1 requires darwin) |
