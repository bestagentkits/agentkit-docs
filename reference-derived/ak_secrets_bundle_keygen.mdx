Generate an age X25519 key pair used for one CI trust boundary (for example production, separate from staging). The secret half is written to --key-out with mode 0600 and is never printed: load it into the protected CI environment's secret store, then delete the file. The public recipient (age1...) is printed and is what `bundle create --encrypt-for` takes. Never reuse the personal vault's passphrase, recovery key or any device key here.

**Effects:** Writes the 0600 key file; refuses to replace an existing one.

### Usage

```bash
ak secrets bundle keygen --key-out PATH [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--key-out string` | File to write the CI decryption key to (mode 0600, must not exist) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | the key file was written |
| `2` | no --key-out, or the path exists or is not a plain file path |
| `5` | the key could not be generated or written |
