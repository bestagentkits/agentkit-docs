Shows the qualifying fingerprints, the evidence event ids for /ak-dogfood --evidence, the decision, every recorded candidate with its owner and evaluation outcome, and the next commands. Use ak skills evolution show &lt;id&gt; for a candidate's diff.

**Effects:** Read-only: reads AGENTKIT_HOME/state/self-improve/events.jsonl and review.json and the candidate records under AGENTKIT_HOME/state/skill-evolve/candidates/. Writes nothing and runs no model, script or network call.

### Usage

```bash
ak skills self-improve review inspect <skill> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, including a disabled feature or an empty store |
| `1` | the AgentKit home could not be resolved (self_improve.home_unresolved), the event store could not be read or written (self_improve.store_failed), the config could not be written (self_improve.config_write_failed), or a consent policy is invalid (self_improve.policy_invalid) |
| `2` | invalid flags, arguments or hook payload (self_improve.invalid_input) |
| `4` | another writer held the event store lock (self_improve.store_busy) |
| `5` | no screened skill or recorded candidate matches the reference (self_improve.not_found) |
