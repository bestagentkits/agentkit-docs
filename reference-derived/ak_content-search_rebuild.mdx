Removes one corrupt or stale project shard and recreates an empty enabled shard.

**Who it's for:** Project owners recovering local search for a single project.

**When to use it:** When a shard is corrupt/incompatible; core operational.db is unaffected.

**What changes on disk:** Deletes and recreates only that project's shard files.

### Usage

```bash
ak content-search rebuild [flags]
```

### Examples

```bash
ak content-search rebuild --project <uuid> --yes --no-interactive
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
