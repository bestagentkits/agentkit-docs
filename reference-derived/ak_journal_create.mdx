Create a collision-safe markdown journal under &lt;project&gt;/&lt;configured paths.plans&gt;/journals/.

**Who it's for:** Agents and developers recording chronological work history.

**When to use it:** After meaningful implementation, reviews, or incident work.

**What changes on disk:** Writes one new .md file under the configured paths.plans journal directory. Never overwrites existing files.

### Usage

```bash
ak journal create <title> [flags]
```

### Examples

```bash
ak journal create "Fix install race" --summary "Root cause and fix"
printf 'body' | ak journal create "Notes" --stdin --date 2026-07-27
```
