Previews shard bytes/docs, then with --yes removes only that project's content DB/WAL/SHM.

**Who it's for:** Project owners removing derived search data.

**When to use it:** When opting out permanently; runtime sources stay untouched.

**What changes on disk:** Apply deletes only AgentKit-owned shard files under operational/content/.

### Usage

```bash
ak content-search delete [flags]
```

### Examples

```bash
ak content-search delete --project <uuid>
ak content-search delete --project <uuid> --yes --no-interactive
```
