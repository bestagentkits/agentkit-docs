List every stored ref with its metadata (creator, created/rotated timestamps). Never prints a value: this reads only the on-disk index, not the backend, so it works even when the backend cannot enumerate or would prompt for consent per item. Use it to check what is stored before a set/rotate, or to build a provisioning report.

**Effects:** Read-only: reads the on-disk index.

### Usage

```bash
ak secrets list [flags]
```
