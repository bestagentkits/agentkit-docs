Guided first-run configuration wizard for AgentKit. Existing Claude Code or Codex subscription login is reused; setup does not install kit content.

**When to use it:** Run once after installing AgentKit. Re-run any time to update a single field with `--step`. Use `--advanced` for direct API keys and provider or model overrides.

Creates or updates `~/.agentkit/config.yaml` atomically. Re-running is idempotent—only fields you change are updated.

### Usage

```bash
ak setup [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--adapter string` | Comma-separated list of adapters to enable. Replaces adapters.enabled: adapters not listed are disabled, and setup warns on stderr naming them and the command that restores the previous list. Registered choices: claude-code, codex, cursor, dsh, grok, omp, opencode, pi. Applies in non-interactive mode; with --step it is validated but applied only when the step is enabled_adapters. Without --adapter, --no-adapter, or an enabled_adapters --config answer, setup keeps the current adapters.enabled value (a first run picks a default). |
| `--advanced` | Configure direct provider API keys, provider/model preferences, Codex overrides, and optional telemetry consent |
| `--config string` | Path to a YAML file supplying answers for --no-interactive mode (keys match step IDs: anthropic_api_key, default_provider, etc.) |
| `--no-adapter string` | Comma-separated list of registered adapters to disable. With --adapter it filters that list; alone it removes them from the current adapters.enabled value (on a first run, from the detected runtimes) and keeps the rest. |
| `--step string` | Update a single field without re-running all steps (values: enabled_adapters, anthropic_api_key, openai_api_key, default_provider, default_model, image_provider, default_kit, telemetry, codex_api_key_env_var, codex_default_model, codex_provider) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | command failure; support report offered |
| `2` | missing required field in --no-interactive mode or unknown --step |
| `3` | user cancelled the TUI wizard |
