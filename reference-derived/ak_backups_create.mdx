Produces a database-aware snapshot of the durable operational core using SQLite VACUUM INTO. Live DB/WAL/SHM files are never raw-copied. Content shards are omitted unless --include-content.

**Who it's for:** Operators capturing recoverable operational state before maintenance.

**When to use it:** Before risky upgrades/recovery drills; not a substitute for runtime source backups.

**What changes on disk:** Writes a staged operational.db under a temp directory and reports checksum/schema metadata. Does not mutate runtime-owned sources.

### Usage

```bash
ak backups create [flags]
```

### Examples

```bash
ak backups create --json
ak backups create --include-content --json
```
