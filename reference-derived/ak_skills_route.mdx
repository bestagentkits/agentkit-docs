**Routes an intent over the local skills:** the Claude home skills directory, the project .claude/skills, the plugin root and the kits source, in that precedence (as in Claude Code). Answers NONE when no skill applies, one selected skill, or up to three candidates to clarify. Several words form one intent. --explicit resolves a name exactly (identity, alias, /ak-name, $ak-name, the legacy /ak:name or $ak:name spelling, or kit/alias, which names that kit's copy); names inside the intent text are never treated as explicit. An alias claimed by several skills fails closed. A higher-precedence copy whose exposure differs from a shadowed copy is reported as catalog.shadowed.

**Effects:** Read-only. Reads SKILL.md frontmatter from the local skill roots; writes nothing and follows no link below each root. Opens no network connection unless cloud discovery is enabled and the local answer leaves room for it; then one anonymous SkillX search is sent with the redacted query.

### Usage

```bash
ak skills route [intent...] [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--explicit string` | Resolve this skill name exactly instead of inferring from the intent |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | routed with no errors: NONE, selected, or clarify; unreadable roots or kits are warnings only |
| `1` | errors[] is non-empty and not a usage error: an alias collision, an unknown or internal --explicit name, a cancelled read, or no catalog at all (catalog.unavailable) |
| `2` | invalid arguments, such as no intent, a malformed --explicit name or an unknown flag |
