Opt-in. Values, names and metadata are encrypted on this device before upload; the server cannot read them. With sync off, ak secrets makes no network requests. resolve always reads this device's local store and never waits for the network. Changes sync when `ak secrets sync now` runs, or continuously under --watch.

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Related commands

- [`ak secrets`](./ak_secrets) — Manage named secret values (API keys, tokens)
- [`ak secrets sync disable`](./ak_secrets_sync_disable) — Stop syncing on this device; local secrets stay
- [`ak secrets sync enable`](./ak_secrets_sync_enable) — Create a synced vault from this device's secrets
- [`ak secrets sync now`](./ak_secrets_sync_now) — Run one sync cycle now, or keep syncing with --watch
- [`ak secrets sync recover`](./ak_secrets_sync_recover) — Restore the vault on this device with the vault password or recovery key
- [`ak secrets sync rotate-recovery`](./ak_secrets_sync_rotate-recovery) — Replace the recovery key, and optionally the vault password
- [`ak secrets sync settle`](./ak_secrets_sync_settle) — Resolve a sync conflict by choosing which value to keep
- [`ak secrets sync status`](./ak_secrets_sync_status) — Show this device's sync state without contacting the server
