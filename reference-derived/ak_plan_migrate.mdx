Discover AgentKit-shaped plan folders under the repo's configured paths.plans directory and import them into the plan store as local-backend plans. Runs as a dry run (detects and summarizes, mutates nothing) unless --apply is given. Symlinks and any path escaping the repo root are skipped and reported, never read or written; unrecognized folders are left untouched; nothing is ever deleted. Requires --from-project-files to select the migration source.

**Who it's for:** Both: one-off legacy migration and scripted --json runs.

**When to use it:** (unspecified)

**What changes on disk:** With --apply: writes plan-store rows and a .agentkit-migrated tombstone into each imported folder. Never deletes files.

### Usage

```bash
ak plan migrate [flags]
```

### Examples

```bash
ak plan migrate --from-project-files
ak plan migrate --from-project-files --path ./ --json
ak plan migrate --from-project-files --apply
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--apply` | Execute the import (default: dry run) |
| `--from-project-files` | Migrate legacy repo-local plan folders (required) |
| `--path string` | Repo root whose configured paths.plans directory is scanned (default: current project) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | plan store or filesystem error |
| `2` | missing --from-project-files |
