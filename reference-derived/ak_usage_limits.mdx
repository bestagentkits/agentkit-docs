Sums local session-token facts inside the trailing 5-hour and 7-day rolling windows per provider and reports both windows with a raw_only provenance. Every fact is counted under the window that contains the session's start (session-start attribution). When advanced polling is switched on in settings, rows the provider reported carry provider_reported provenance, the provider's used percent, and the source endpoint; a failed poll keeps the local counts and records a degrade_reason. Use it before starting a long session, when tuning agent runs, or when a downstream dashboard needs the same numbers the desktop popover shows.

**Effects:** Read-only. Opens the local analytics SQLite index under ~/.agentkit/analytics/ in read-only mode; AGENTKIT_HOME overrides the base dir. A cold or absent index yields zeroed windows, not an error. Never opens a network socket unless advanced polling is enabled in settings (AGENTKIT_ADVANCED_POLLING=1 plus an explicit acknowledgement); then it sends at most one GET per enabled provider to that provider's usage endpoint with the access token the official CLI already stored, rate-limited to a burst of three per minute, and never refreshes or writes a token.

### Usage

```bash
ak usage limits [flags]
```
