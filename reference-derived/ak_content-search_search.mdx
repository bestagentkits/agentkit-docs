Runs a parsed, budgeted FTS5 MATCH against one opted-in project shard.

**Who it's for:** Project owners searching local opted-in content.

**When to use it:** After enable and indexing have produced searchable documents.

**What changes on disk:** Read-only against the project shard; snippets are not logged.

### Usage

```bash
ak content-search search [flags]
```

### Examples

```bash
ak content-search search --project <uuid> --query 'token' --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--limit int` | max hits (default 20) |
| `--project string` | canonical project UUID |
| `--query string` | search tokens |
