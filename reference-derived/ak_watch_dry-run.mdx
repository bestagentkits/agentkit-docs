Preview what `ak watch start` would post without actually posting to GitHub. Simulates the full agent response pipeline including rate-limit accounting.

**When to use it:** Before running `ak watch start` for the first time on a repo, to verify label, author, and keyword filters match the right issues. Safe to run anytime—nothing is posted.

Read-only. No comments posted to GitHub; no state file updated.

### Usage

```bash
ak watch dry-run <owner/repo> [flags]
```
