Record a plan as the current plan for the enclosing git worktree, so `ak plan show` and `ak plan resolve` with no id surface it directly. The argument is either a plan directory (e.g. ./plans/260730-1000-slug) or a plan id from `ak plan list`; an id is resolved to its linked directory. The pointer is worktree-private and never committed.

**Effects:** Writes a worktree-private current-plan pointer under the worktree's git directory. Never modifies plan files.

**Exit status:** 0 success 1 not in a git repo, plan not found, or the target is outside the worktree 2 invalid flags or arguments

### Usage

```bash
ak plan use <plan-dir|plan-id> [flags]
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
