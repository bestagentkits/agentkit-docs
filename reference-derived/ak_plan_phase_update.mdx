Update the index-owned bookkeeping of phase &lt;n&gt; of plan &lt;plan-id&gt;: notes, evidence, acceptance, and the GitHub comment id. Title, status, and content are owned by the phase file — status via its checkboxes — so they are edited in the file (or via `ak plan check`/`uncheck`) and picked up by `ak plan reindex`, not set here.

**Effects:** Writes the index-owned phase columns (and FTS index) in the local plan store. Never writes phase files.

### Usage

```bash
ak plan phase update <plan-id> <n> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--acceptance string` | Acceptance criteria text |
| `--comment-id int` | GitHub tracking comment id for this phase |
| `--content ak plan reindex` | File-owned: edit the phase file body, then ak plan reindex (rejected here) |
| `--evidence string` | Evidence / links backing completion |
| `--notes string` | Free-form notes |
| `--status ak plan check` | File-owned: use ak plan check/`uncheck`, then `ak plan reindex` (rejected here) |
| `--title ak plan reindex` | File-owned: edit the phase file heading, then ak plan reindex (rejected here) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | plan not found or plan store I/O error |
| `2` | invalid arguments, or a file-owned flag (--title/--status/--content) |
