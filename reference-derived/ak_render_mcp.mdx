Runs `npx -y @bestagentkits/render@0.3.0 mcp`: catalog, search-catalog, describe, recipes, recipe, validate, render and themes as MCP tools over stdio. Register it with an MCP client as the command `ak render mcp`.

**Effects:** Long-running stdio server until the client closes stdin. Render tools write the files their callers name. npx may download the pinned package into the npm cache on first run.

**Output:** Output, --json envelopes and exit status are the AK Render compiler's own, passed through unchanged.

### Usage

```bash
ak render mcp [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | the server exited cleanly |
| `1` | the server or npx/npm failed (see stderr) |
| `2` | usage error |
| `127` | npx not found (install Node.js &gt;= 20.11), or on Windows an npx shim ak cannot run without cmd.exe |
