List the slash commands installed on this machine, optionally filtered by kit or tag.

**When to use it:** Run before `ak commands install` or `ak commands remove` to confirm what is and isn't already on disk.

This command is read-only.

### Usage

```bash
ak commands list [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--kit string` | Filter by kit name |
| `--tag strings` | Filter by tag (repeatable) |
