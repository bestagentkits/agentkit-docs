Print the preference values in effect here: the user config deep-merged with the project config, with the project winning. Keys are emitted in the legacy spelling kit hooks already read.

**Who it's for:** Kit hooks, which read the JSON form, and anyone checking which value actually applies.

**When to use it:** Use it when a setting seems to be ignored, to see whether the project config overrides it.

**What changes on disk:** Reads $AGENTKIT_HOME/config.yaml and &lt;project&gt;/.agentkit/config.yaml. Writes nothing.

### Usage

```bash
ak config prefs resolve [flags]
```

### Examples

```bash
ak config prefs resolve                 # human-readable listing
ak config prefs resolve --json          # the payload hooks parse
```
