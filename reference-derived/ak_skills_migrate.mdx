Records the kit skills a legacy install wrote into the skill store: for each alias a kit's legacy record of this runtime and scope lists, when every listed file is on disk with its recorded bytes, the files become a store entry and the receipt and lock record the kit's reference. No skill file is written, moved or removed. A modified file, a file the record lists but is missing, a link, a flat-file skill or an alias another record lists with other files keeps that alias a legacy install and is reported; kits whose records list the same files co-own it. A file no record lists is preserved and left out. A receipt reference whose kit no longer records the alias is dropped and its files kept. Running it again changes nothing.

**Effects:** Applies without prompting; --dry-run prints the plan and writes nothing. Snapshots the scope's skill lock, receipts and root registry through the backups subsystem, then writes the store entries, receipts and lock in one journaled transaction under the kit lifecycle lock; an interrupted run is rolled back by the next mutating skills command and legacy records are never changed. Needs the skill store on (after `ak update --ssot`, or AGENTKIT_SKILL_STORE=1).

### Usage

```bash
ak skills migrate [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | Print the plan and write nothing |
| `--runtime strings` | Runtimes to migrate: claude-code, codex (repeatable; default all) |
| `--scope string` | Scope to migrate: project (default) or global (default "project") |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, or nothing to change |
| `1` | command failure: offline without a verified copy, credential refused, path too long, or recovery required |
| `2` | SkillX or the skill store disabled, invalid flags or arguments, or a reserved alias |
| `4` | another AgentKit operation holds the kit lifecycle lock |
| `5` | release not found or not entitled |
| `6` | alias collision, unowned or modified path, untrusted project state, or the lock changed during the run |
| `7` | release revoked, yanked, quarantined or untrusted, a link in a target path, or a digest mismatch |
