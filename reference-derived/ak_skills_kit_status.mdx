Lists the personal kits under AGENTKIT_HOME/kits/personal, or one named kit, and whether each resolves against the exact foundation versions it pins. A kit that fails to resolve is listed with its contract error code.

**Effects:** Read-only: reads personal kits under AGENTKIT_HOME/kits/personal and the foundation kits directory, and never writes, installs, applies a plan, or calls a network or model. AgentKit user overrides are reported, never applied.

### Usage

```bash
ak skills kit status [name] [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--kits-dir string` | Foundation kits directory (default: $AGENTKIT_KITS_DIR or ./kits) |

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | success, including a rebase preview that needs review |
| `1` | command failure, or an overlay conflict, shared alias, alias collision or stale proposal (JSON error_code conflict) |
| `2` | invalid flags or arguments, or a malformed manifest, overlay or proposal |
| `5` | personal kit, foundation kit, version or skill not found |
| `7` | revoked foundation |
