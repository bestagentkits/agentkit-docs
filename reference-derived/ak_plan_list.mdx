List the current project's plans. Reads canonical files under the project's plans directory first, then best-effort-overlays index-owned fields (state, issue_number, linked_pr, current_phase) from the local SQLite plan store when it opens. Closed and archived plans are excluded by default. Use --all for every tracked project (requires the store, since files are single-project by design).

**Who it's for:** Both: quick project overview and scripted --json listings.

**When to use it:** (unspecified)

**What changes on disk:** Read-only.

### Usage

```bash
ak plan list [flags]
```

### Examples

```bash
ak plan list
ak plan list --all
ak plan list --all --include-closed --json
```

### Flags

| Flag | Description |
| --- | --- |
| `--all` | List plans across all projects, not just the current one |
| `--include-archived` | Include archived plans |
| `--include-closed` | Include closed plans |
