List plans recorded in the AgentKit-owned SQLite plan store. Defaults to the current project (matched by git remote or working directory); use --all for every tracked project. Closed and archived plans are excluded by default.

**Who it's for:** Both: quick project overview and scripted --json listings.

**When to use it:** (unspecified)

**What changes on disk:** Read-only.

### Usage

```bash
ak plan list [flags]
```

### Examples

```bash
ak plan list
ak plan list --all
ak plan list --all --include-closed --json
```
