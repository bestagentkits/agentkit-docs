Print the per-file manifest for one snapshot, including sha256 hashes, sizes, and the on-host source paths each file was captured from.

**When to use it:** Sanity-check before `ak backups restore`; debug discrepancies surfaced by `ak backups verify`.

This command is read-only.

### Usage

```bash
ak backups show <id> [flags]
```

### Examples

```bash
ak backups show 20260426T123005Z-deadbeef
ak backups show 20260426T123005Z-deadbeef --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
