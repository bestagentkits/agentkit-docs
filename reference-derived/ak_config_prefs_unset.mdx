Delete a per-hook toggle from config.yaml so the hook returns to its inherited or built-in default. Removing an absent key is a no-op. Only keys under `hooks.` may be unset.

**Who it's for:** Power users cleaning up an explicit toggle they no longer want pinned.

**When to use it:** Use it to stop overriding a hook at this scope and fall back to the other scope or the default.

**What changes on disk:** Backs up then rewrites the selected scope's config.yaml when the key was present.

### Usage

```bash
ak config prefs unset <key> [flags]
```

### Examples

```bash
ak config prefs unset hooks.simplify-gate
ak config prefs unset hooks.simplify-gate --scope project
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--scope string` | which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user") |

### Exit codes
