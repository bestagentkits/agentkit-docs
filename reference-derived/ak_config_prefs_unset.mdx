Delete a per-hook toggle, journal.auto, or worktree.root preference from config.yaml so it returns to default.

**Effects:** Backs up then rewrites the selected scope's config.yaml when the key was present.

**Exit status:** 0 success, 1 command failure, 2 invalid flags or arguments
