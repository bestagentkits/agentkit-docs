Install a single skill by resolving `<kit>/<skill>` and copying it into the user-level install location. If the asset declares a runtime block and skill runtime is not opted out, the per-asset env is created via the runtime manager.

**When to use it:** After confirming the skill exists with `ak skills show`. Use `--force` to overwrite an existing install.

Writes files under `~/.claude/plugins/<kit>/`. Unless `AGENTKIT_SKILL_RUNTIME=0`, runtime-bearing assets also write `~/.agentkit/skills/<kit>/<name>/` and `~/.agentkit/cache/<hash>/`.

### Usage

```bash
ak skills install <kit>/<skill> [flags]
```

### Examples

```bash
ak skills install engineer/agent-browser
ak skills install engineer/agent-browser --force
ak skills install engineer/agent-browser --yes --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--force` | Overwrite existing install |

### Exit codes

| Code | Meaning |
| --- | --- |
| `5` | skill not found |
| `6` | already installed (re-run with --force) |
