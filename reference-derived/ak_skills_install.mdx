Install a single skill by resolving `<kit>/<skill>` and copying it into the user-level install location. If the asset declares a runtime block and skill runtime is not opted out, the per-asset env is created via the runtime manager.

**When to use it:** After confirming the skill exists with `ak skills show`. Use `--force` to overwrite an existing install.

Writes files under `~/.claude/plugins/<kit>/`. Unless `AGENTKIT_SKILL_RUNTIME=0`, runtime-bearing assets also write `~/.agentkit/skills/<kit>/<name>/` and `~/.agentkit/cache/<hash>/`.

### Usage

```bash
ak skills install <kit>/<skill> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | SkillX: print the plan and write nothing |
| `--force` | Overwrite existing install |
| `--runtime strings` | SkillX: runtimes to project into: claude-code, codex (repeatable; default claude-code) |
| `--scope string` | SkillX: lock and skills root scope: project (default) or global (default "project") |
| `--source string` | Skill source: local (default, &lt;kit>/&lt;skill>) or skillx (@publisher/slug) (default "local") |

### Exit codes

| Code | Meaning |
| --- | --- |
| `4` | --source skillx: the kit lifecycle lock is held |
| `5` | skill or release not found |
| `6` | already installed (re-run with --force); --source skillx: collision, unowned or modified path |
| `7` | --source skillx: release revoked, yanked or untrusted, a link in a target path, or a digest mismatch |
