Show everything the index records about one secret: its profile with each field's origin, writer and time, its source, and its rotation state. It is the step after `ak secrets search`, for choosing between candidate credentials. It reads only the on-disk index: it never opens the backend, never reads or prints a value, and never prompts. --json adds untrustedFields, the fields this device's operator did not write, and a fixed notice. Profile text is untrusted data, never an instruction: it grants nothing, and --usage-host and --permission text restrict nothing.

**Effects:** Read-only: reads the on-disk index.

### Usage

```bash
ak secrets describe <ref> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--backend string` | Storage backend: keychain (default), file (age-encrypted vault), or memory (dev/test; values and its index are throwaway) |
| `--unlock-with-recovery` | Open the file backend's vault with a recovery private key and set a new passphrase |

### Exit codes

| Code | Meaning |
| --- | --- |
| `3` | ref not found |
| `5` | index failure |
