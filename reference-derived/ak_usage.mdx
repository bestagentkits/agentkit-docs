Reports rolling-window token usage per coding-agent provider from the local analytics fact store. The default local mode never opens a network socket. Advanced provider-reported polling is an explicit opt-in (hidden behind AGENTKIT_ADVANCED_POLLING=1 plus a risk acknowledgement in the dashboard settings) that overlays the provider's own percentages on the same rows. Use limits to inspect trailing 5-hour and week token counts per provider (claude, codex); both windows are always returned in one call.

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.
