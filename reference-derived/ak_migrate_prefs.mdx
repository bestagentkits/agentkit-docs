Read legacy ClaudeKit .ck.json preferences and merge values into user and project AgentKit config.yaml.

**Effects:** Read-only with --dry-run (default). Without --dry-run, merges settings into config.yaml after --yes.

### Usage

```bash
ak migrate prefs [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--dry-run` | Preview the preference migration without writing any files (default true) |
| `--from string` | Source to migrate from (currently supports "ck" for ClaudeKit) (default "ck") |
