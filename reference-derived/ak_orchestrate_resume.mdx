Reconnect to run-id using the same job graph file. Never relaunches jobs; if the worker crashed, reclassifies persisted state only.

**Effects:** Read-only against a live worker; persists a reclassification of orphaned jobs when the worker crashed.

### Usage

```bash
ak orchestrate resume <run-id> <job-graph.json> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | graph digest mismatch, run not found, or state is corrupt |
| `6` | unsupported platform (v1 requires darwin) |
