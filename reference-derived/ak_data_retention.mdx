Resolves most-protective retention for one derived class, builds a redacted preview, and optionally applies a bounded prune for Prunable && !Syncable tables.

**Who it's for:** Operators evaluating or applying fixed retention.

**When to use it:** When estimating or deleting eligible derived rows for a retain window.

**What changes on disk:** Preview is read-only; --apply deletes eligible derived rows only.

### Usage

```bash
ak data retention [flags]
```

### Examples

```bash
ak data retention --class session_metrics --json
ak data retention --class ingestion_runs --days 30 --json
ak data retention --class ingestion_runs --days 30 --apply --json
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--apply` | apply bounded prune after preview revalidation |
| `--class string` | derived data class (default "session_metrics") |
| `--days int` | optional fixed retain days to evaluate |
