Resolve, preview, or apply retention for one derived data class. Use --apply to delete eligible rows.

**Effects:** Preview is read-only; --apply deletes eligible derived rows from operational.db.

**Exit status:** 0 success, 1 command failure, 2 invalid flags or arguments

### Usage

```bash
ak data retention [flags]
```

### Flags
