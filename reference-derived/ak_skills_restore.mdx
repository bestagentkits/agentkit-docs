Restores a package deleted with ak skills unpublish, keeping its visibility and releases, until its restore deadline. Re-running is safe: a package that is not deleted succeeds with changed: false. A package deleted by a SkillX administrator can only be restored by one.

**Effects:** Clears the package's deletion on SkillX. Sends the request with the SkillX credential: the agentkit.best link (`ak skills link`) while one exists, otherwise SKILLX_TOKEN. Writes nothing locally and never prompts. Needs SkillX on (after `ak update --ssot`, or AGENTKIT_SKILLX=1 or features.skillx: true).

### Usage

```bash
ak skills restore <@publisher/slug> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | command failure: SkillX offline, the credential missing or refused, or an untrusted answer (a change may have been applied; check with ak skills visibility) |
| `2` | SkillX disabled, invalid flags or arguments, a skill directory that is not a valid skill tree, or a request SkillX refused as invalid |
| `5` | package or release not found, or release publishing not enabled on SkillX |
| `6` | conflict with the package's current state: visibility mismatch, version exists, publish to a deleted package, a release that is not published, a concurrent change that left another state, or the restore window passed |
| `7` | SkillX refused the change: approval needed on the dashboard, not the package owner, publisher suspended, or deleted by an administrator |
