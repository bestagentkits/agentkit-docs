Refresh an installed kit and remove stale generated files. Uses the same snapshot-backed path as `ak kit init --force`.

**When to use it:** After an AgentKit upgrade, bundled export changes, or when `ak audit` reports plugin drift. Paid kits require remote or explicit `--kits-dir`.

Snapshots AK-owned content, removes stale generated files, and writes current kit output.

### Usage

```bash
ak kit refresh <kit-name> [flags]
```

Global flags, output modes, and the standard exit codes (`0`–`3`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--channel string` | Remote registry channel (beta requires explicit opt-in) (default "stable") |
| `-g, --global` | Refresh the adapter user directory instead of the current project |
| `--kits-dir string` | Local kits directory override (default: $AGENTKIT_KITS_DIR or ./kits) |
| `--local` | Refresh from an explicit local kit source instead of the remote registry (dev/CI) |
| `--no-backup` | Skip the pre-refresh snapshot (power users only) |
| `--registry-url string` | AgentKit registry base URL (default: $AGENTKIT_REGISTRY_URL, then dev/staging https://staging.agentkit.best or release https://agentkit.best) |
| `--remote` | Refresh from the authenticated remote registry (default; use --local for an explicit dev/CI source) (default true) |
| `--switch-to-plugin` | Explicitly refresh Claude Code plugin delivery at the chosen project or user/global scope |
| `--target string` | Emitter target ID or comma-separated IDs; default detects the installed kit targets |
| `--version string` | Remote kit version (defaults to channel latest) |
