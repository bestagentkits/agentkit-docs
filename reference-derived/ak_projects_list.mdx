List all registered AgentKit projects from the global registry.

**When to use it:** Checking which projects AgentKit knows about. An empty registry still exits 0.

Reads `~/.agentkit/projects.json`; read-only.

### Usage

```bash
ak projects list [flags]
```

### Examples

```bash
ak projects list          # human-readable table
ak projects list --json   # JSON array for scripting
ak projects list --quiet  # suppress header (plain list)
```
