Apply a partial update to a plan tracked in the local SQLite plan store. Only flags explicitly passed are changed; every other field is left as-is. --status is file-owned, so it rewrites the plan.md front matter (the canonical source) and re-syncs the index; the remaining flags set index-only bookkeeping. --title is owned by the plan.md heading: edit the file and run `ak plan reindex`.

**Effects:** With --status: rewrites the plan.md front matter, then updates the plan store. Other flags write only the plan store.

### Usage

```bash
ak plan update <id> [flags]
```

Global flags, output modes, and the base exit codes (`0`–`2`) are shared by every command — see [CLI conventions](../cli-conventions). The sections below list only what is specific to this command.

### Flags

| Flag | Description |
| --- | --- |
| `--branch string` | New branch name |
| `--current-phase int` | New current phase number |
| `--issue int` | Linked GitHub issue number |
| `--linked-pr int` | Linked pull request number |
| `--root-comment-id int` | Root tracking comment id |
| `--status string` | New status (pending\|in-progress\|completed\|cancelled\|unknown); rewrites plan.md front matter |
| `--title ak plan reindex` | File-owned: edit the plan.md heading, then ak plan reindex (rejected here) |
| `--worktree string` | New worktree path |

### Exit codes

| Code | Meaning |
| --- | --- |
| `1` | plan not found or plan store / file I/O error |
| `2` | invalid flag value, or a file-owned flag (--title) that must be edited in the file |
