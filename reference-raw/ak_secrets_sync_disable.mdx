## ak secrets sync disable

Stop syncing on this device; local secrets stay

### Synopsis

Stop syncing on this device. Local secrets stay. --purge also deletes this device's sync keys and state; it is refused when an AI agent runs it. Neither form contacts the server: this device stays a vault member until `ak secrets devices remove` runs on another device. Re-enable a plain disable with `ak secrets sync enable --resume`.

Effects:
  Without --purge, marks sync disabled in local sync state. With --purge, deletes this device's sync keys from the keystore and the sync state under AgentKit home; only empty lock files stay.

Exit status:
  0   sync disabled
  2   --purge without a terminal or --yes, or declined
  5   local storage failure
  6   refused: an AI agent is running disable --purge
  10  sync is not set up on this device
  11  a sync cycle is running; retry

```
ak secrets sync disable [flags]
```

### Examples

```
  ak secrets sync disable
  ak secrets sync disable --purge --yes
```
