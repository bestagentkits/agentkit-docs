## ak sessions stats

Aggregate local session analytics

### Synopsis

Aggregates privacy-bounded local session metrics for dashboard comparison charts.

Effects:
  Read-only. Reads registered projects and local session JSONL summaries; when no project is registered, falls back to a bounded scan of ~/.claude/projects and reports source_scope "discovered" instead of a silent zero; --refresh bypasses memoized analytics when available.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak sessions stats [flags]
```

### Examples

```
  ak sessions stats --json
  ak sessions stats --metric tokens --by model --window 168h --json
  ak sessions stats --project myapp --runtime codex --by date --json
```

### Options

```
      --by string             Dimension: runtime, model, provider, project, date, or duration (default "runtime")
  -h, --help                  help for stats
      --json                  Emit machine-readable JSON (implies --no-interactive)
      --metric string         Metric to aggregate (default "tokens")
      --no-interactive        Disable interactive prompts (CI-safe)
      --project stringArray   Project name to include; repeatable
  -q, --quiet                 Suppress non-error output on stderr
      --refresh               Bypass analytics cache when available
      --runtime string        Runtime filter, e.g. claude-code or codex
  -V, --verbose               Extra diagnostic output on stderr (loses to --quiet)
      --window string         Lookback duration, e.g. 168h (default "720h0m0s")
  -y, --yes                   Assume yes for all prompts
```
