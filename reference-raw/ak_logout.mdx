## ak logout

Clear local AgentKit credentials

### Synopsis

Clear locally stored AgentKit session credentials. Idempotent: exits 0 if already signed out.

Effects:
  Removes CLI registry credentials from ~/.agentkit/auth/session.json.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak logout [flags]
```

### Examples

```
  ak logout
  ak logout --json
```
