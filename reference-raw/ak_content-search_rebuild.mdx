## ak content-search rebuild

Delete and recreate one project content shard

### Synopsis

What it does:
  Removes one corrupt or stale project shard and recreates an empty enabled shard.

Who it's for:
  Project owners recovering local search for a single project.

When to use it:
  When a shard is corrupt/incompatible; core operational.db is unaffected.

Examples:
  ak content-search rebuild --project &lt;uuid&gt; --yes --no-interactive

What changes on disk:
  Deletes and recreates only that project's shard files.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak content-search rebuild [flags]
```

### Options

```
  -h, --help             help for rebuild
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   canonical project UUID
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
