## ak content-search rebuild

Delete and recreate one project content shard

### Synopsis

Removes one project shard and recreates an empty enabled shard.

Effects:
  Deletes and recreates project shard database files.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content-search rebuild [flags]
```

### Examples

```
  ak content-search rebuild --project <uuid> --yes
  ak content-search rebuild --project <uuid> --yes --json
```
