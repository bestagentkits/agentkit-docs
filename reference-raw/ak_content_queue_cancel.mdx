## ak content queue cancel

Cancel (remove) a scheduled post by ID

### Synopsis

Cancel and remove a pending scheduled post from the queue by its ID.

Effects:
  Removes the specified entry from ~/.agentkit/content/queue.json.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content queue cancel <id> [flags]
```

### Examples

```
  ak content queue cancel abc123def456
  ak content queue cancel <id> --json
```
