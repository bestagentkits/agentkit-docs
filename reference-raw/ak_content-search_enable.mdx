## ak content-search enable

Opt a project into local plaintext content search

### Synopsis

Creates one FTS5 shard for a project after the owner accepts plaintext-at-rest disclosure.

Effects:
  Creates AGENTKIT_HOME/operational/content/&lt;project-id&gt;.db and sidecars.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content-search enable [flags]
```

### Examples

```
  ak content-search enable --project <uuid> --yes
  ak content-search enable --project <uuid> --yes --json
```
