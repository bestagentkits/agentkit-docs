## ak skills grants list

List exec grants

### Synopsis

Lists every recorded grant with its bound fields. A missing grant file is an empty list.

Effects:
  Read-only. Requires AGENTKIT_SKILL_EXEC_BROKER=1; creates nothing.

Exit status:
  0   success
  1   command failure, such as a busy grant store
  2   exec broker disabled, invalid flags or arguments, an invalid manifest, or an unavailable interpreter
  5   store entry, entrypoint or grant not found
  7   store entry fails verification, or the grant file is invalid

```
ak skills grants list [flags]
```

### Examples

```
  ak skills grants list
  ak skills grants list --json
```
