## ak sessions

Inspect and maintain local coding-agent sessions

### Synopsis

What it does:
  Inspect and maintain local session JSONL files used by supported coding agents.

Who it's for:
  Power devs and desktop users reviewing local session evidence.

When to use it:
  Use redaction before sharing local Claude Code session transcripts.

Examples:
  ak sessions list --json
  ak sessions show myapp session-abc --json
  ak sessions tail myapp session-abc --json
  ak sessions redact --json
  ak sessions redact --project myapp --json
  ak sessions redact --project myapp --apply --yes

What changes on disk:
  Parent command is read-only. Subcommands document their own disk effects.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
