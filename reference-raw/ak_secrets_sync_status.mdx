## ak secrets sync status

Show this device's sync state without contacting the server

### Synopsis

Report whether sync is enabled, the vault and device IDs, the last pull and push, pending work, open conflicts, quarantined items, any integrity alarm, and whether the current sign-in can sync (sync needs an email sign-in, or an API key with vault sync turned on, which enrolls this device on first use). Reads local state only: no network, no keystore, and no vault passphrase.

Effects:
  Read-only: reads the sync config, sync state and sign-in session under AgentKit home (briefly taking the session file lock other ak commands share).

Exit status:
  0   status reported, enabled or not
  2   invalid invocation
  5   local sync state could not be read

```
ak secrets sync status [flags]
```

### Examples

```
  ak secrets sync status
  ak secrets sync status --json
```

      --unlock-with-recovery   Open the file backend's vault with a recovery private key and set a new passphrase
