## ak config prefs unset

Remove a hook or journal.auto soft-preference so it returns to default

### Synopsis

What it does:
  Delete a per-hook toggle or the journal.auto leaf from config.yaml so the value returns to its inherited or built-in default (journal.auto defaults to true). Removing an absent key is a no-op. Only keys under `hooks.` and the exact key `journal.auto` may be unset.

Who it's for:
  Power users cleaning up an explicit toggle they no longer want pinned.

When to use it:
  Use it to stop overriding a preference at this scope and fall back to the other scope or the default.

Examples:
  ak config prefs unset hooks.simplify-gate
  ak config prefs unset hooks.simplify-gate --scope project
  ak config prefs unset journal.auto

What changes on disk:
  Backs up then rewrites the selected scope's config.yaml when the key was present.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  the key is not allowed or the config cannot be read/written

```
ak config prefs unset <key> [flags]
```

### Options

```
  -h, --help             help for unset
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
