## ak config prefs unset

Remove a hook, journal.auto, or worktree.root soft-preference so it returns to default

### Synopsis

Delete a per-hook toggle, journal.auto, or worktree.root preference from config.yaml so it returns to default.

Effects:
  Backs up then rewrites the selected scope's config.yaml when the key was present.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config prefs unset <key> [flags]
```

### Examples

```
  ak config prefs unset hooks.simplify-gate
  ak config prefs unset journal.auto
  ak config prefs unset worktree.root --scope project
```

### Options

```
  -h, --help             help for unset
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
