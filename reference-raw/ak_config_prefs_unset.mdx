## ak config prefs unset

Remove a supported preference so it returns to default

### Synopsis

Delete a supported preference from config.yaml. Removing user semantic_decision.enabled disables the provider; removing a project restriction restores user policy.

Effects:
  Backs up then rewrites the selected scope's config.yaml when the key was present.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config prefs unset <key> [flags]
```

### Examples

```
  ak config prefs unset hooks.simplify-gate
  ak config prefs unset semantic_decision.enabled --scope user
  ak config prefs unset worktree.root --scope project
  ak config prefs unset agent_models.cursor.sonnet
```

### Options

```
  -h, --help             help for unset
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
