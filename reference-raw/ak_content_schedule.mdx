## ak content schedule

Manage the content scheduler

### Synopsis

What it does:
  Run the content scheduler daemon. The daemon polls the queue every minute and publishes any posts whose scheduled time has arrived.

Who it's for:
  Power devs running persistent content pipelines.

When to use it:
  Use `ak content schedule daemon` to start a long-running scheduler process.

Examples:
  ak content schedule daemon
  ak content schedule daemon --poll-interval 30

What changes on disk:
  Reads and writes ~/.agentkit/content/queue.json atomically on each poll tick.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

### Options

  -y, --yes              Assume yes for all prompts
