## ak skills grants revoke

Revoke one exec grant, or all of them

### Synopsis

Removes a grant by id, or every grant with --all. A revoked entrypoint is denied with exec.not_granted until it is granted again.

Effects:
  Requires AGENTKIT_SKILL_EXEC_BROKER=1; with it off nothing is read or written. Never runs a script or an interpreter. add and revoke write only AGENTKIT_HOME/state/exec/grants.json, atomically and owner-only; add also makes and removes a verified read-only copy of the tree under AGENTKIT_HOME/tmp/exec-runs.

Exit status:
  0   success
  1   command failure, such as a busy grant store
  2   exec broker disabled, invalid flags or arguments, an invalid manifest, or an unavailable interpreter
  5   store entry, entrypoint or grant not found
  7   store entry fails verification, or the grant file is invalid

```
ak skills grants revoke <grant-id> | --all [flags]
```

### Examples

```
  ak skills grants revoke eg-0123456789abcdef
  ak skills grants revoke --all --json
```
