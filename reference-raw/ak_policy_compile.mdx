## ak policy compile

Propose policy rules from the project's instruction files

### Synopsis

Read the project's instruction files and propose rules for the sentences that match a known form. Proposals are written to .agentkit/policy-candidates.yaml, which the engine never evaluates; they take effect only once `ak policy adopt` promotes them. A sentence that reads like a rule but fits no form is reported rather than guessed at, and a proposed rule may only warn or rewrite — prose cannot ask for a block.

Effects:
  Writes .agentkit/policy-candidates.yaml, replacing any previous proposals. Never writes the active policy document and never changes what is enforced.

Exit status:
  0   success, including when no sentence matched a known form
  1   an instruction file or the candidates file could not be read or written
  2   invalid arguments

```
ak policy compile [flags]
```

### Examples

```
  ak policy compile
  ak policy compile --source CLAUDE.md --json
```

### Options

```
      --dir string           Project directory holding .agentkit/policy.yaml (default ".")
  -h, --help                 help for compile
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --no-interactive       Disable interactive prompts (CI-safe)
  -q, --quiet                Suppress non-error output on stderr
      --source stringArray   Instruction file to read, relative to the project directory (repeatable; defaults to the document's sources)
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
