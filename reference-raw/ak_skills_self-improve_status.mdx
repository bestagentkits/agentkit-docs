## ak skills self-improve status

Show consent and the skills worth an ak-dogfood review

### Synopsis

Shows the effective consent and, when enabled, the skills whose events in the last 7 days crossed the threshold: one strong signal, or the same weak fingerprint in at least 2 sessions. Events recorded for an older skill digest are ignored. Each candidate carries the exact /ak-dogfood --skill &lt;name&gt; --evidence &lt;ids&gt; command.

Effects:
  Read-only: reads the user config.yaml and the nearest project .agentkit/config.yaml for consent, and the event store AGENTKIT_HOME/state/self-improve/events.jsonl. Writes nothing, runs no model, script or network call, and skips the background update check.

Exit status:
  0   success, including a disabled feature or an empty store
  1   the AgentKit home could not be resolved (self_improve.home_unresolved), the event store could not be read or written (self_improve.store_failed), the config could not be written (self_improve.config_write_failed), or a consent policy is invalid (self_improve.policy_invalid)
  2   invalid flags, arguments or hook payload (self_improve.invalid_input)
  4   another writer held the event store lock (self_improve.store_busy)

```
ak skills self-improve status [flags]
```
