## ak commands

Per-slash-command management commands

### Synopsis

What it does:
  List, install, remove, show, and search individual slash commands (e.g. ckm:write/good) from any kit. Slash commands are markdown prompt templates Claude Code surfaces as /&lt;namespace>:&lt;name>.

Who it's for:
  Both: power devs scripting installs (--json) and users browsing what's available.

When to use it:
  Use as the entry point for any per-slash-command operation; subcommands handle the action.

Examples:
  ak commands list                              # show what's installed + available
  ak commands search email                      # find slash commands matching a keyword
  ak commands install marketing/ckm-email       # install one command
  ak commands show marketing/ckm-email          # inspect metadata
  ak commands remove marketing/ckm-email        # uninstall

What changes on disk:
  Read-only at this group level; subcommands document their own effects.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

### Options

```
  -h, --help             help for commands
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
