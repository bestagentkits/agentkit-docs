## ak insights evidence

Inspect an execution and its evaluation evidence

### Synopsis

Inspect an execution and its evaluation evidence. Unknown measurements remain unavailable; invocation success is not quality.

Effects:
  Read-only local evidence; no transcript content.

Exit status:
  0   success
  1   invalid input or unavailable local data
  2   invalid arguments

```
ak insights evidence <execution-id> [flags]
```
