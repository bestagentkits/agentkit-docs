## ak agents model apply

Write the configured model into installed agent files

### Synopsis

Write the model config resolves to into every pending agent file. A file whose model was edited in the runtime (drift) is replaced only with confirmation: --yes, or an answer on a terminal. Without confirmation nothing is written.

Effects:
  Rewrites the model fields of pending agent files; with confirmation, backs up and rewrites drifted ones.

Exit status:
  0   success
  1   command failure, including an installed agent file AgentKit cannot prove it still owns (nothing is written)
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage
  3   drifted files need confirmation and none was given; with --json the result names them under need_confirmation
  4   another AgentKit operation holds the kit lifecycle lock; retry when it finishes

```
ak agents model apply [agent] [flags]
```

### Examples

```
  ak agents model apply
  ak agents model apply kongming --runtime codex --yes
```

### Options

```
  -h, --help             help for apply
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime whose agents to read ([claude-code codex cursor omp pi]); empty reads all
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
