## ak plan add-phase

Append a new phase-NN-&lt;slug&gt;.md to an existing plan

### Synopsis

Create the next sequential phase-NN-&lt;slug&gt;.md file in the given plan directory, pre-populated with a template header and empty todo checkboxes.

Effects:
  Creates phase-NN-&lt;slug&gt;.md in the plan directory.

Exit status:
  0   success
  1   plan directory not found or I/O error
  2   invalid arguments

```
ak plan add-phase <plan-dir> <name> [flags]
```

### Examples

  ak plan add-phase ./plans/my-plan Deploy
  ak plan add-phase ./plans/my-plan Integration-Tests --json
