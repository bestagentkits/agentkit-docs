## ak journal list

List journal entries (newest first)

### Synopsis

What it does:
  List journal summaries newest-first with optional date/query filters.

Who it's for:
  Agents and developers discovering prior work records.

When to use it:
  Browsing project history before authoring a new entry.

Examples:
  ak journal list
  ak journal list --query install --json

What changes on disk:
  Read-only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak journal list [flags]
```

### Options

```
      --from string      Include entries on/after YYYY-MM-DD
  -h, --help             help for list
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   Limit to one registered project
      --query string     Filter title/summary/slug text
  -q, --quiet            Suppress non-error output on stderr
      --to string        Include entries on/before YYYY-MM-DD
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
