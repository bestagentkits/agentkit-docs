## ak journal list

List journal entries (newest first)

### Synopsis

List journal summaries newest-first with optional date and query filters.

Effects:
  Read-only. Reads journal files from plan storage.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak journal list [flags]
```

### Examples

```
  ak journal list
  ak journal list --query install --json
```
