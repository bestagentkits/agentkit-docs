## ak skills kit inspect

Show the resolved composition plan of a personal kit

### Synopsis

Resolves a personal kit offline and shows its lock-ready plan: foundations, every skill with its kind (foundation, overlay or fork), base, overlay and composition digests, exposure, trust and scripts. Runtime projections are not previewed.

Effects:
  Read-only: reads personal kits under AGENTKIT_HOME/kits/personal and the foundation kits directory, and never writes, installs, applies a plan, or calls a network or model. AgentKit user overrides are reported, never applied.

Exit status:
  0   success, including a rebase preview that needs review
  1   command failure, or an overlay conflict, shared alias, alias collision or stale proposal (JSON error_code conflict)
  2   invalid flags or arguments, or a malformed manifest, overlay or proposal
  5   personal kit, foundation kit, version or skill not found
  7   revoked foundation

```
ak skills kit inspect <name> [flags]
```

### Examples

```
  ak skills kit inspect mine
  ak skills kit inspect mine --runtime claude-code --json
```

### Options

```
  -h, --help              help for inspect
      --json              Emit machine-readable JSON (implies --no-interactive)
      --kits-dir string   Foundation kits directory (default: $AGENTKIT_KITS_DIR or ./kits)
      --no-interactive    Disable interactive prompts (CI-safe)
  -q, --quiet             Suppress non-error output on stderr
      --runtime string    Runtime to inspect the plan for
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes               Assume yes for all prompts
```
