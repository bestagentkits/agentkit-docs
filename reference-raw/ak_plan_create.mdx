## ak plan create

Bootstrap a new plan directory from template

### Synopsis

Scaffold a new AgentKit plan directory under --basedir (default: the project's configured paths.plans directory). Creates plan.md with YAML front matter and a starter phase-01-start.md.

Effects:
  Creates &lt;basedir&gt;/&lt;timestamp&gt;-&lt;slug&gt;/ with plan.md and phase-01-start.md.

Exit status:
  0   success
  1   I/O error or invalid name
  2   invalid flags or arguments

```
ak plan create <name> [flags]
```

### Examples

```
  ak plan create my-feature
  ak plan create deploy-pipeline --basedir ./work
  ak plan create auth --json
```

### Options

```
      --basedir string   Parent directory for the new plan (default: configured paths.plans under the project root)
  -h, --help             help for create
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
