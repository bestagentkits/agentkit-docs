## ak skills mcp

Serve the skill tools to MCP clients

### Synopsis

Runs the skill commands as tools of a local MCP server. To manage the MCP servers of a runtime, use ak mcp.

### Examples

```
  ak skills mcp serve
  AGENTKIT_SKILLX=1 ak skills mcp serve
```
