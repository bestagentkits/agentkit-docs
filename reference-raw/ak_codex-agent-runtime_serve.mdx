## ak codex-agent-runtime serve

Run the Codex agent MCP server over stdio

### Synopsis

Run the Codex agent MCP server over stdio, exposing discovered agents as MCP tools. Use --list-only to enumerate agents without starting the server.

Effects:
  Read-only. Runs long-running MCP stdio server.

Output:
  Serves MCP JSON-RPC protocol over stdio until interrupted.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak codex-agent-runtime serve [flags]
```

### Examples

```
  ak codex-agent-runtime serve
  ak codex-agent-runtime serve --list-only
  ak codex-agent-runtime serve --list-only --json
```
