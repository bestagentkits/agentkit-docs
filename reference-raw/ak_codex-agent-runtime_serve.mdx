## ak codex-agent-runtime serve

Run the Codex agent MCP server over stdio

### Synopsis

Run the Codex agent MCP server over stdio, exposing discovered agents as MCP tools. Agents come from three sources: the single nearest &lt;project&gt;/.codex/agents at or above the working directory, served only when Codex trusts that project or its repository root; the Codex home agents/ directory; and kit staging under the plugin root. A project agent replaces a user agent with the same name. Use --list-only to enumerate agents without starting the server.

Effects:
  Runs a long-running MCP stdio server. Each served tool launches a codex exec agent that may write the workspace according to that agent's sandbox policy.

Output:
  Serves MCP JSON-RPC protocol over stdio until interrupted. --list-only instead prints the discovered agents and exits.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak codex-agent-runtime serve [flags]
```

### Examples

```
  ak codex-agent-runtime serve
  ak codex-agent-runtime serve --list-only
  ak codex-agent-runtime serve --list-only --json
```

### Options

```
      --codex-home string    Override $CODEX_HOME (defaults to ~/.codex)
  -h, --help                 help for serve
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --list-only            Print discovered agents and exit without serving MCP
      --no-interactive       Disable interactive prompts (CI-safe)
      --plugin-root string   Override $AGENTKIT_PLUGIN_DIR (defaults to ~/.claude/plugins)
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
