## ak plan close

Close a plan in the local plan store

### Synopsis

Mark a plan as closed in the local plan store. A VACUUM INTO recovery snapshot is taken before the state change. Closed plans are excluded from `ak plan list` by default.

Effects:
  Writes the plans table and a recovery snapshot in the local plan store.

Exit status:
  0   success
  1   plan not found or plan store I/O error
  2   invalid flags or arguments

```
ak plan close <id> [flags]
```

### Examples

```
  ak plan close my-project/260722-1200
  ak plan close my-project/260722-1200 --json
```
