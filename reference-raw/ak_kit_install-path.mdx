## ak kit install-path

Print the resolved OS install path for a kit

### Synopsis

Print the resolved install path where `ak kit init` would place the kit plugin.

Effects:
  Read-only. Resolves target path.

Exit status:
  0   success
  1   empty or missing kit name argument
  2   invalid flags or arguments

```
ak kit install-path <kit-name> [flags]
```

### Examples

```
  ak kit install-path engineer
  ak kit install-path engineer --json
```
