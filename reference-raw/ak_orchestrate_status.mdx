## ak orchestrate status

Report a run's current lifecycle state

### Synopsis

Query the live worker through its verified control socket, or reconcile persisted state. A stale record is never reported as still running.

Effects:
  Read-only, except a fresh reclassification is persisted when the worker has crashed.

Exit status:
  0   success
  1   run ID not found, or run state is corrupt/unsupported
  2   invalid flags or arguments
  6   unsupported platform (v1 requires darwin)

```
ak orchestrate status <run-id> [flags]
```

### Examples

```
  ak orchestrate status 3f9a...
  ak orchestrate status 3f9a... --json
```
