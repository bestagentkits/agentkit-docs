## ak uninstall

Remove an AK-managed project

### Synopsis

Ownership-aware project removal. For each file in the manifest:
  clean (AK-owned, hash matches)  -&gt; deleted
  modified (user has edited)       -&gt; refused unless --force
  orphan (in dir, not in manifest) -&gt; reported only, never deleted
  missing (in manifest, gone)      -&gt; skipped

A snapshot is taken via `ak backups` BEFORE any deletion, even with --force.
Default behaviour is dry-run: pass --yes or confirm the prompt to execute.

Effects:
  Deletes AK-owned files from the project directory and removes .agentkit/ownership.json (and .agentkit/ if empty). Snapshots prior state via `ak backups` before any deletion.

Exit status:
  0   success
  1   project directory not found or not an AK project
  2   invalid flags or arguments
  3   user declined confirmation prompt or --dry-run
  6   user-modified files detected without --force

```
ak uninstall [path] [flags]
```

### Examples

```
  ak uninstall
  ak uninstall ./myproj
  ak uninstall --yes
  ak uninstall --force --yes
```

### Options

```
      --dry-run              Show classification plan without deleting anything (exit 3)
      --force                Delete user-modified files (requires confirmation; snapshot always taken)
  -h, --help                 help for uninstall
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --keep-registry        Skip deregistration from ~/.agentkit/projects.json after uninstall
      --no-interactive       Disable interactive prompts (CI-safe)
      --project-dir string   Explicit project root (default: cwd or first AK project found walking up)
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
