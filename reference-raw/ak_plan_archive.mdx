## ak plan archive

Archive a plan in the local plan store

### Synopsis

What it does:
  Mark a plan as archived in the local plan store. A VACUUM INTO recovery snapshot is taken before the state change. Archived plans are excluded from `ak plan list` by default.

Who it's for:
  Both: long-term retention of finished work and scripted automation.

When to use it:
  (unspecified)

Examples:
  ak plan archive my-project/260722-1200
  ak plan archive my-project/260722-1200 --json

What changes on disk:
  Writes the plans table and a recovery snapshot in the local plan store.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  plan not found or plan store I/O error

```
ak plan archive <id> [flags]
```
