## ak orchestrate

Run and supervise external CLI job graphs (Darwin only)

### Synopsis

Start, resume, check, and stop a graph of external CLI jobs under a dedicated local worker supervisor. Darwin only; other platforms return an unsupported error.

### Examples

```
  ak orchestrate start jobs.json
  ak orchestrate status <run-id>
  ak orchestrate resume <run-id> jobs.json
  ak orchestrate stop <run-id>
```
