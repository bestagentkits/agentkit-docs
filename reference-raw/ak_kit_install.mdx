## ak kit install

Install a kit into the current project or adapter user directory

### Synopsis

Install a kit into the current workspace or runtime adapter directory. Interactive TTY launches a wizard when kit name is omitted; bypass with positional kit name or --yes.

Effects:
  Writes kit assets into the target workspace or user adapter directory.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  6   drifted files detected without --force

```
ak kit install <kit-name> [flags]
```

### Examples

```
  ak kit install engineer
  ak kit install engineer --global
  ak kit install engineer --force
```
