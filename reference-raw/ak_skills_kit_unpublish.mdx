## ak skills kit unpublish

Unpublish (soft-delete) a personal kit from SkillX, restorable for 30 days

### Synopsis

Unpublishes the SkillX kit the personal kit's link records (or --kit): SkillX soft-deletes it, so nobody can read or sync it, and keeps it restorable for 30 days with ak skills kit restore. The local personal kit and its projections are untouched; ak skills kit remove drops those. SkillX accepts these calls only from the kit's owner with an unscoped SkillX API key (ak secrets SKILLX_TOKEN), which is used for them even while `ak skills link` links SkillX; the agentkit.best link alone is refused with a hint, and the SkillX creator dashboard does the same.

Effects:
  Soft-deletes the SkillX personal kit with one POST /api/v1/kits/@&lt;handle&gt;/&lt;name&gt;/delete: SkillX hides it and its revisions at once and keeps it restorable for 30 days; the name stays reserved. Nothing local changes: the personal kit, its projections and the link record AGENTKIT_HOME/state/personal-kits/&lt;name&gt;/skillx.json stay, so ak skills kit restore can bring it back. Asks for confirmation on a terminal; with --json, --no-interactive or no terminal it needs --yes. --dry-run sends nothing. Needs SkillX on (after `ak update --ssot`, or AGENTKIT_SKILLX=1).

Exit status:
  0   done, already done, or a dry run
  1   command failure: SkillX offline, or no unscoped SkillX API key (the agentkit.best link alone is refused)
  2   SkillX or the overlay flag disabled, invalid flags, or no linked kit and no --kit, or --yes missing without a terminal
  3   the user declined the confirmation; nothing was sent
  5   the SkillX kit was not found for this credential, or its 30-day restore window has passed
  7   refused by SkillX: the publisher is not owned, or an administrator deleted the kit
  10  personal kits are not enabled for your account yet (SkillX answered kit.api_disabled)

```
ak skills kit unpublish <name> [--kit @<handle>/<name>] [--yes] [flags]
```

### Examples

```
  ak skills kit unpublish mine
  ak skills kit unpublish mine --yes --json
  ak skills kit unpublish mine --kit @alice/mine --dry-run
```
