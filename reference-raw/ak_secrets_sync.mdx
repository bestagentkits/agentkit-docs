## ak secrets sync

Sync secrets across your machines with end-to-end encryption (preview)

### Synopsis

Opt-in. Values, names and metadata are encrypted on this device before upload; the server cannot read them. With sync off, ak secrets makes no network requests. resolve always reads this device's local store and never waits for the network. Changes sync when `ak secrets sync now` runs, or continuously under --watch.

### Examples

```
  ak secrets sync enable --recovery-kit-out ./vault-recovery-kit.txt
  ak secrets sync now
  ak secrets sync status --json
```
