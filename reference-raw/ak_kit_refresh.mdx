## ak kit refresh

Refresh an installed kit and remove stale generated files

### Synopsis

Re-emit an installed kit with force enabled. Refreshes active native or plugin output and unloads generated files that disappeared from kit source.

Effects:
  Snapshots AgentKit-owned content, removes stale generated files, and writes current kit output.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   kit not found in registry or source
  6   target directory cannot be refreshed safely

```
ak kit refresh <kit-name> [flags]
```

### Examples

```
  ak kit refresh engineer --yes
  ak kit refresh engineer --global --yes
  ak kit refresh engineer --target codex --yes
```
