## ak secrets bundle

Seal selected secrets into an encrypted CI bundle

### Synopsis

The CI bundle carries an explicit allowlist of secrets in a versioned file sealed with age to a dedicated key. A protected CI job decrypts it locally with that key and gives the values to one child process (`ak secrets run --bundle`). It needs no cloud access and no interactive step in CI. It is not cloud sync: whoever holds the bundle and its key reads every value in it, the CI provider holds the key, the runner sees plaintext while the job runs, and a copy of a bundle cannot be revoked remotely.

Effects:
  Subcommands write only the file they are given.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak secrets bundle [flags]
```

### Examples

```
  ak secrets bundle keygen --key-out ./ci-production.key
  ak secrets bundle create --profile ci-production --encrypt-for age1... --secret DEPLOY_TOKEN=${REF} --output ci-production.akv
```
