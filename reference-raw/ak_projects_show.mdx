## ak projects show

Show details for a registered project

### Synopsis

What it does:
  Display full detail for one project registered in ~/.agentkit/projects.json. Lookup is first by exact directory path, then by name.

Who it's for:
  Both: power devs (--json) and non-technical users.

When to use it:
  Inspecting registration metadata for a specific project.

Examples:
  ak projects show myproj              # lookup by name
  ak projects show $HOME/projects/myproj    # lookup by path
  ak projects show myproj --json       # machine-readable output

What changes on disk:
  Read-only: ~/.agentkit/projects.json.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  0  project found
  5  project not found in registry
  2  invalid arguments

```
ak projects show <name|path> [flags]
```

### Options

```
  -h, --help             help for show
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
