## ak projects show

Show details for a registered project

### Synopsis

Display full detail for one project registered in ~/.agentkit/projects.json. Lookup is first by exact directory path, then by name.

Effects:
  Read-only: ~/.agentkit/projects.json.

Exit status:
  0   project found
  2   invalid arguments
  5   project not found in registry

```
ak projects show <name|path> [flags]
```

### Examples

```
  ak projects show myproj
  ak projects show $HOME/projects/myproj
  ak projects show myproj --json
```
