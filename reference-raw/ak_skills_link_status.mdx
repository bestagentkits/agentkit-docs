## ak skills link status

Show whether SkillX is linked to an agentkit.best account

### Synopsis

Reports linked, not_linked or revoked, with the agentkit.best account, scope and times, and the command that moves a revoked or missing link on.

Effects:
  Read-only: reads AGENTKIT_HOME/state/skillx-link.json. Never opens the secrets store or the network and never prompts.

Exit status:
  0   reported
  1   the link record is unreadable
  2   invalid flags

```
ak skills link status [flags]
```

### Examples

```
  ak skills link status
  ak skills link status --json
```

  -y, --yes              Assume yes for all prompts
