## ak kit list-kits

List available content kits

### Synopsis

Walk the kits directory, load each kit.yaml, and print a summary table of name, version, extends, and per-category export counts.

Effects:
  Read-only. Reads kit definitions.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   kits directory not found

```
ak kit list-kits [flags]
```

### Examples

```
  ak kit list-kits
  ak kit list-kits --kits-dir /path
  ak kit list-kits --json
```
