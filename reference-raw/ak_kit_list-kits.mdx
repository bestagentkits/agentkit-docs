## ak kit list-kits

List available content kits

### Synopsis

List available kits. Explicit --kits-dir or $AGENTKIT_KITS_DIR is a local source view (dev/CI). With no override, list-kits uses the remote available catalog and does not treat ./kits as installed. Counts are measured only when source_metadata_known is true.

Effects:
  Read-only. Local source reads kit.yaml; default remote catalog is metadata-only.

Exit status:
  0   success
  1   command failure, including registry errors
  2   invalid flags or arguments
  5   explicit local kits directory not found

```
ak kit list-kits [flags]
```

### Examples

```
  ak kit list-kits
  ak kit list-kits --kits-dir /path
  ak kit list-kits --json
```
