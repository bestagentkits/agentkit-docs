## ak agents model reset

Remove an agent's override from one config scope

### Synopsis

Delete the agent's model and reasoning effort from the selected config scope so the next layer (the other scope, a tier mapping, or the adapter default) decides.

Effects:
  Backs up then rewrites the selected scope's config.yaml when it exists, then rewrites the model fields of every installed file of the agent whose model AgentKit still owns. A file whose model was edited in the runtime is left alone and reported.

Exit status:
  0   success
  1   command failure, including an installed agent file AgentKit cannot prove it still owns (nothing is written)
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage
  4   another AgentKit operation holds the kit lifecycle lock; retry when it finishes
  5   adopt only: no readable installed file of the agent

```
ak agents model reset <agent> [flags]
```

### Examples

```
  ak agents model reset kongming --runtime codex --scope project
  ak agents model reset reviewer --runtime cursor --json
```

### Options

```
  -h, --help             help for reset
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime the agent is installed in ([claude-code codex cursor omp pi])
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml in the project) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
