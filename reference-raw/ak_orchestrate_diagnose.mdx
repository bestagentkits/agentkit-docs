## ak orchestrate diagnose

Export a bounded observation bundle for diagnosis

### Synopsis

Emit redacted observations and artifact/tool events for offline review. This replays evidence, not model execution, and never includes graph argv or environment.

Effects:
  Read-only. Redirect output to save a diagnostic bundle.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate diagnose <run-id> [flags]
```

### Examples

```
  ak orchestrate diagnose <run-id> --json
  ak orchestrate diagnose <run-id> --json > diagnostic.json
```

### Options

```
  -h, --help             help for diagnose
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
