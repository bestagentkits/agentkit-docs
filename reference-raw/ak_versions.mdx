## ak versions

List installed destination versions for ak, kits, and skills

### Synopsis

Show the current ak binary version alongside every installed kit destination and installed skill. One row per destination (runtime, scope, delivery mode). Human output labels source version, recorded registry release, and available registry release separately, plus destination, health, check/version state, compatibility, and channel source. --local-only uses only local install evidence and never writes the registry cache. Latest kit versions come from authenticated ResolveRuntimeManifest (metadata-only). Cache/source trees are not installed kits. Data schema_version is 2; the envelope schema stays 1.

Effects:
  Read-only. --local-only makes zero network requests and writes no cache. Default mode may query signed binary check and authenticated registry metadata.

Exit status:
  0   success
  1   local enumeration failed (e.g. unreadable install root)
  2   invalid flags

```
ak versions [flags]
```

### Examples

```
  ak versions
  ak versions --local-only
  ak versions --json
  ak versions --cache-ttl 30m
```
