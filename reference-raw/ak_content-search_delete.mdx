## ak content-search delete

Preview and remove one project content shard

### Synopsis

What it does:
  Previews shard bytes/docs, then with --yes removes only that project's content DB/WAL/SHM.

Who it's for:
  Project owners removing derived search data.

When to use it:
  When opting out permanently; runtime sources stay untouched.

Examples:
  ak content-search delete --project &lt;uuid&gt;
  ak content-search delete --project &lt;uuid&gt; --yes --no-interactive

What changes on disk:
  Apply deletes only AgentKit-owned shard files under operational/content/.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak content-search delete [flags]
```

### Options

```
  -h, --help             help for delete
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   canonical project UUID
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
