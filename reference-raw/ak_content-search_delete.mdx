## ak content-search delete

Preview and remove one project content shard

### Synopsis

Previews shard bytes/docs, then with --yes removes that project's content DB/WAL/SHM files.

Effects:
  Deletes project content shard files under operational/content/.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content-search delete [flags]
```

### Examples

```
  ak content-search delete --project <uuid>
  ak content-search delete --project <uuid> --yes
```
