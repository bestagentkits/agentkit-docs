## ak gui

Launch the AgentKit desktop GUI

### Synopsis

Open the AgentKit desktop UI in a native window backed by the same binary as the CLI. When built without GUI assets, download the desktop app from https://agentkit.best/agentkit-app.

Effects:
  Read-only UI launch.

Exit status:
  0   success or GUI not packaged for platform
  1   GUI not linked and no desktop app found
  2   invalid flags or arguments

```
ak gui [flags]
```

### Examples

```
  ak gui
  ak gui --no-interactive
```
