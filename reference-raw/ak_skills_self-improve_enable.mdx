## ak skills self-improve enable

Turn skill self-improve event recording on

### Synopsis

Writes skill_self_improve.enabled: true to the user config. A project config can still turn it off for that project. Hooks start recording at the next Claude Code or Codex session end.

Effects:
  Backs up then rewrites AGENTKIT_HOME/config.yaml without a prompt (reversible with the opposite command). Touches no event, skill or project file.

Exit status:
  0   success, including a disabled feature or an empty store
  1   the AgentKit home could not be resolved (self_improve.home_unresolved), the event store could not be read or written (self_improve.store_failed), the config could not be written (self_improve.config_write_failed), or a consent policy is invalid (self_improve.policy_invalid)
  2   invalid flags, arguments or hook payload (self_improve.invalid_input)
  4   another writer held the event store lock (self_improve.store_busy)

```
ak skills self-improve enable [flags]
```

### Examples

```
  ak skills self-improve enable
  ak skills self-improve enable --json
```
