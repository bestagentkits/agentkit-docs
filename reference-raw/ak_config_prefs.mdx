## ak config prefs

Inspect resolved AgentKit preferences

### Synopsis

What it does:
  Read the preference sections of the AgentKit config: the user file under the AgentKit home, deep-merged with the project file at .agentkit/config.yaml.

Who it's for:
  Kit hooks resolving settings, and anyone checking which file supplies a value.

When to use it:
  Use `resolve` to see the effective values and where they came from, `validate` to check a file against the AgentKit config schema, and `set`/`unset` to toggle a hook soft-preference.

Examples:
  ak config prefs resolve            # human-readable summary
  ak config prefs resolve --json     # machine-readable payload (used by kit hooks)
  ak config prefs validate           # check both config files against the schema
  ak config prefs validate --file x  # check one file
  ak config prefs set hooks.simplify-gate false   # disable a hook (soft preference)
  ak config prefs unset hooks.simplify-gate       # return it to default

What changes on disk:
  `resolve`/`validate` are read-only; `set`/`unset` back up then rewrite one config.yaml.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
