## ak agents model explain

Explain which config layer decides an agent's model

### Synopsis

Walk the precedence chain (project agent, user agent, project tier, user tier, adapter default) for each installed file of one agent, mark the layer that decides it, and say what to do about a pending or drifted file. A global install never reads project config.

Effects:
  Read-only.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage
  5   the agent is not installed in the runtime

```
ak agents model explain <agent> [flags]
```

### Examples

```
  ak agents model explain kongming --runtime claude-code
  ak agents model explain reviewer --runtime cursor --json
```

### Options

```
  -h, --help             help for explain
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime the agent is installed in ([claude-code codex cursor omp pi])
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
