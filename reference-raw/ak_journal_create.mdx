## ak journal create

Create a journal in configured plan storage

### Synopsis

Create a collision-safe markdown journal under &lt;project&gt;/&lt;configured paths.plans&gt;/journals/.

Effects:
  Writes one new .md file under the configured paths.plans journal directory.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak journal create <title> [flags]
```

### Examples

```
  ak journal create "Fix install race" --summary "Root cause and fix"
  ak journal create "Notes" --stdin --date 2026-07-27
```
