## ak new

Bootstrap a new AgentKit project

### Synopsis

Create a new AgentKit project at ./&lt;project-name&gt;/. Records an ownership manifest so update and uninstall act precisely on AK-managed files.

Effects:
  Creates ./&lt;project-name&gt;/ directory and writes project ownership manifest and seed content.

Exit status:
  0   success
  1   command failure
  2   invalid flags or project name
  6   target directory already exists without --force

```
ak new <project-name> [flags]
```

### Examples

```
  ak new myproj
  ak new myproj --template engineer
  ak new myproj --force
```
