## ak api status

Show the running state of the API server

### Synopsis

Read the API server state file and report whether the server is running.

Effects:
  Read-only. Reads ~/.agentkit/api-state.json.

Output:
  Exits 0 whether running or not. Check the running field in JSON output.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak api status [flags]
```

### Examples

```
  ak api status
  ak api status --json
```

  -h, --help             help for status
