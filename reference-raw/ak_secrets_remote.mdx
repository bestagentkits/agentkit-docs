## ak secrets remote

Run commands with secrets through your online relay device (for cloud sandboxes)

### Synopsis

For a machine that must not hold secrets, such as a cloud coding-agent sandbox. `remote run` asks the vault's remote MCP endpoint to run a command on one of your online relay devices (`ak secrets sync now --watch --relay`), under that device's own exec grants, and prints the output with every released value redacted. The values never reach this machine. They do reach the relay device and the command it runs; the vault Worker sees the command, the variable and secret names and the redacted output in memory while it passes them on. Redaction removes exact values only: a command that prints a value encoded or split is not caught.

Effects:
  Writes the sign-in to AGENTKIT_HOME/state/vault-remote.json (0600). Reads no vault.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak secrets remote [flags]
```

### Examples

```
  ak secrets remote login
  ak secrets remote run --env STRIPE_API_KEY=STRIPE_API_KEY -- stripe customers list
```
