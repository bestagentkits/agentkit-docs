## ak content-search search

Run a bounded FTS query against one opted-in project

### Synopsis

What it does:
  Runs a parsed, budgeted FTS5 MATCH against one opted-in project shard.

Who it's for:
  Project owners searching local opted-in content.

When to use it:
  After enable and indexing have produced searchable documents.

Examples:
  ak content-search search --project &lt;uuid&gt; --query 'token' --json

What changes on disk:
  Read-only against the project shard; snippets are not logged.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak content-search search [flags]
```

### Options

```
  -h, --help             help for search
      --json             Emit machine-readable JSON (implies --no-interactive)
      --limit int        max hits (default 20)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   canonical project UUID
      --query string     search tokens
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
