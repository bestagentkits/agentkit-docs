## ak skills evolution

Review, evaluate, apply and roll back recorded skill evolution candidates

### Synopsis

Candidates are recorded by ak skills improve &lt;skill&gt; --session ... --candidate &lt;draft-dir&gt;. Each one pins its evidence, skill, base, prior overlay and overlay in its ID; recording never applies it. Review one with list and show, re-run its offline evaluation with evaluate, apply it into a personal kit with apply (a preview without --yes) and undo that with rollback. Publishing stays a separate, explicit ak skills kit publish &lt;name&gt; --private.

Effects:
  list, show and a preview are read-only; evaluate, apply --yes and rollback write under the kit lifecycle lock (see each command).

Exit status:
  0   success, including an empty candidate store
  1   the candidate store could not be read, or (show) the record failed verification (store.corrupt); list reports an unverified record and still exits 0
  2   invalid flags or arguments, or a candidate reference that is not an ID or a prefix of at least 8 hex characters
  5   no recorded candidate matches the reference, or a prefix matches more than one (evolve.candidate_not_found)

```
ak skills evolution [flags]
```

### Examples

```
  ak skills evolution list
  ak skills evolution show 3f2a91c0
  ak skills evolution apply 3f2a91c0
```
