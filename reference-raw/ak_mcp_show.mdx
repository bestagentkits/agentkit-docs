## ak mcp show

Show one discovered MCP server

### Synopsis

Shows one MCP server with args and env key names. Env values are never displayed.

Effects:
  Read-only. Reads MCP configuration files.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   MCP server not found

