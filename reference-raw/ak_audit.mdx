## ak audit

Check installed kits for drift

### Synopsis

Compares installed kit plugin trees against install-time fingerprints (per-file sha256) and reports drift. Audits every installed kit when no argument is given.

Effects:
  Read-only. Scans installed kit files.

Exit status:
  0   no drift detected
  1   drift detected or command failure
  2   invalid flags or arguments

```
ak audit [kit] [flags]
```

### Examples

```
  ak audit
  ak audit engineer
  ak audit engineer --strict
```

### Options

```
  -h, --help                 help for audit
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --no-interactive       Disable interactive prompts (CI-safe)
      --plugin-mode          Audit a Claude Code project plugin instead of a native project install
      --project-dir string   Audit a native project install; combine with --plugin-mode for a project plugin
  -q, --quiet                Suppress non-error output on stderr
      --strict               Exit non-zero when an installed AgentKit plugin lacks a readable install manifest
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
