## ak content-search disable

Stop indexing/search without deleting the shard

### Synopsis

Stops indexing and search for one project while leaving shard files on disk.

Effects:
  Updates the lifecycle marker in operational store.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content-search disable [flags]
```

### Examples

```
  ak content-search disable --project <uuid>
  ak content-search disable --project <uuid> --json
```
