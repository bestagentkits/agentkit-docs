## ak content-search disable

Stop indexing/search without deleting the shard

### Synopsis

What it does:
  Stops indexing and search for one project while leaving shard files on disk.

Who it's for:
  Project owners pausing local search.

When to use it:
  When search should stop without deleting derived data yet.

Examples:
  ak content-search disable --project &lt;uuid&gt; --json

What changes on disk:
  Updates the lifecycle marker; does not delete DB/WAL/SHM.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak content-search disable [flags]
```

### Options

```
  -h, --help             help for disable
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   canonical project UUID
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
