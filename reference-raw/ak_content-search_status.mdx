## ak content-search status

Show opt-in content-search status for one project

### Synopsis

Shows whether a project has an opted-in local content-search shard and its redacted health.

Effects:
  Read-only. Checks project shard status.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content-search status [flags]
```

### Examples

```
  ak content-search status --project <uuid>
  ak content-search status --project <uuid> --json
```

### Options

```
  -h, --help             help for status
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   canonical project UUID
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
