## ak plan validate

Check plan directory format; exits 0 (valid) or 3 (invalid)

### Synopsis

Validate that a plan directory follows the CK convention: plan.md with front-matter title, and at least one phase-NN-*.md file.

Effects:
  Read-only.

Exit status:
  0   plan is valid
  2   invalid flags or arguments
  3   plan failed validation

```
ak plan validate <path> [flags]
```

### Examples

```
  ak plan validate ./plans/my-plan
  ak plan validate ./plans/my-plan --json
```
