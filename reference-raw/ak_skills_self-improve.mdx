## ak skills self-improve

Record skill problems at session end and suggest an ak-dogfood review

### Synopsis

Off by default. When enabled in the user config, the Claude Code and Codex session-end hooks record a redacted local event for every skill a session invoked: opaque session and project refs, the skill id and digest, and a signal (denied tool call, user interrupt, task failure, explicit ak-dogfood, tool error, retry). No transcript text, tool output, secret or path is stored, and no model runs. status lists the skills whose events crossed the threshold with the exact /ak-dogfood command to review them; nothing is changed until you run it. While enabled, the next Claude Code or Codex session start shows one line naming new candidates, once per finding. review joins candidates with ak skills improve candidates and records approve, reject or defer decisions. A project config may only disable the feature. Contract: docs/specs/skill-self-improve-events.md.

Effects:
  status and history are read-only; enable and disable back up and rewrite the user config.yaml; review decisions write review.json.

Exit status:
  0   success, including a disabled feature or an empty store
  1   the AgentKit home could not be resolved (self_improve.home_unresolved), the event store could not be read or written (self_improve.store_failed), the config could not be written (self_improve.config_write_failed), or a consent policy is invalid (self_improve.policy_invalid)
  2   invalid flags, arguments or hook payload (self_improve.invalid_input)
  4   another writer held the event store lock (self_improve.store_busy)

```
ak skills self-improve [flags]
```
