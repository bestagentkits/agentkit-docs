## ak analytics

Control the private local analytics index

### Synopsis

What it does:
  Shows and explicitly manages AgentKit's disposable local SQLite analytics index. Session and activity sources remain authoritative; this command never sends analytics remotely.

Who it's for:
  Both: power users scripting local maintenance and desktop users who need a clear privacy boundary.

When to use it:
  Use status to inspect serving mode, refresh or rebuild only when desired, and delete to remove the local index.

Examples:
  ak analytics status --json
  ak analytics enable --yes --no-interactive
  ak analytics delete --yes --json --no-interactive

What changes on disk:
  Status is read-only. Mutations preview first and require --yes or an interactive confirmation; delete retains only a disabled intent marker.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

### Options

```
  -h, --help             help for analytics
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
