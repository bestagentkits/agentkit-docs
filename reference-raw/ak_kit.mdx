## ak kit

Kit management commands

### Synopsis

Commands for working with AgentKit content kits: list, validate, init, install, refresh, install-path, uninstall, and repair.

### Examples

```
  ak kit list-kits
  ak kit validate kits/
  ak kit install engineer
  ak kit uninstall engineer
```

  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
