## ak data retention

Resolve, preview, or apply retention for one data class

### Synopsis

Resolve, preview, or apply retention for one derived data class. Use --apply to delete eligible rows.

Effects:
  Preview is read-only; --apply deletes eligible derived rows from operational.db.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak data retention [flags]
```

### Examples

```
  ak data retention --class session_metrics
  ak data retention --class ingestion_runs --days 30
  ak data retention --class ingestion_runs --days 30 --apply
```

### Options

```
      --apply            apply bounded prune after preview revalidation
      --class string     derived data class (default "session_metrics")
      --days int         optional fixed retain days to evaluate
  -h, --help             help for retention

  -y, --yes              Assume yes for all prompts
```
