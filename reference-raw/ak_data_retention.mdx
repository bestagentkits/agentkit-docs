## ak data retention

Resolve, preview, or apply retention for one data class

### Synopsis

What it does:
  Resolves most-protective retention for one derived class, builds a redacted preview, and optionally applies a bounded prune for Prunable && !Syncable tables.

Who it's for:
  Operators evaluating or applying fixed retention.

When to use it:
  When estimating or deleting eligible derived rows for a retain window.

Examples:
  ak data retention --class session_metrics --json
  ak data retention --class ingestion_runs --days 30 --json
  ak data retention --class ingestion_runs --days 30 --apply --json

What changes on disk:
  Preview is read-only; --apply deletes eligible derived rows only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak data retention [flags]
```

### Options
