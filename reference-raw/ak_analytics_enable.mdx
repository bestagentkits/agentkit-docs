## ak analytics enable

Enable the local analytics index

### Synopsis

Enables the private local SQLite analytics index. Interactive terminals prompt before applying; pass --yes to bypass prompts.

Effects:
  Creates the local SQLite analytics index under ~/.agentkit/analytics/.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  3   preview complete (re-run with --yes to apply)

```
ak analytics enable [flags]
```

### Examples

```
  ak analytics enable
  ak analytics enable --yes
```

### Options

```
  -h, --help             help for enable
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
