## ak mcp verify

Verify MCP server stdio handshakes

### Synopsis

Starts one or more discovered MCP servers and requires an MCP initialize response within the timeout.

Effects:
  Read-only. Executes configured MCP server commands and sends MCP initialize only.

Exit status:
  0   success (all checked servers verified ok)
  1   one or more MCP servers failed verification or command failure
  2   invalid flags or arguments
  5   named MCP server not found

```
ak mcp verify [name] [flags]
```

### Examples

```
  ak mcp verify memory
  ak mcp verify dataforseo --timeout 30s --json
```
