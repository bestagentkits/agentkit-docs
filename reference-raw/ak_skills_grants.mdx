## ak skills grants

Manage digest-bound permissions for brokered skill scripts

### Synopsis

A grant permits one entrypoint of one verified skill tree to run under the exec broker. It never expires and is bound to the tree digest, the entrypoint, the capability set and the interpreter binary; any change needs a new grant. Requires AGENTKIT_SKILL_EXEC_BROKER=1.

### Examples

```
  ak skills grants add @publisher/report@sha256:<hex> --entrypoint render
  ak skills grants list --json
  ak skills grants revoke eg-0123456789abcdef
```
