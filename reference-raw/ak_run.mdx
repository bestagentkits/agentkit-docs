## ak run

Run a skill via the configured agent adapter

### Synopsis

Resolve &lt;kit&gt;/&lt;skill&gt; and dispatch it to the configured adapter (--target claude-code, --target codex, --target cursor, --target dsh, --target grok, --target omp). Streams stdout/stderr; honors SIGINT and --timeout.

Effects:
  Read-only on kit content; the adapter may write its own working directory.

Output:
  Pretty stream by default; --json emits NDJSON events.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  4   unmet dependency (missing skill env or backend binary)
  5   kit or skill not found

```
ak run <kit>/<skill> [args...] [flags]
```

### Examples

```
  ak run engineer/scout
  ak run engineer/scout --json
  ak run engineer/scout --timeout 30s
  ak run engineer/scout --target codex
```

### Options

```
  -h, --help               help for run
      --json               Emit machine-readable JSON (implies --no-interactive)
      --kits-dir string    Kits directory (default: ./kits or $AGENTKIT_KITS_DIR)
      --no-interactive     Disable interactive prompts (CI-safe)
  -q, --quiet              Suppress non-error output on stderr
      --target string      Adapter to dispatch to: claude-code | codex | cursor | dsh | grok | omp (default "claude-code")
      --timeout duration   Per-invocation timeout (e.g. 30s, 2m). Zero disables timeout.
  -V, --verbose            Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                Assume yes for all prompts
```
