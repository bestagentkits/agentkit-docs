## ak config prefs resolve

Print the resolved preference values

### Synopsis

What it does:
  Print the preference values in effect here: the user config deep-merged with the project config, with the project winning. Keys are emitted in the legacy spelling kit hooks already read.

Who it's for:
  Kit hooks, which read the JSON form, and anyone checking which value actually applies.

When to use it:
  Use it when a setting seems to be ignored, to see whether the project config overrides it.

Examples:
  ak config prefs resolve                 # human-readable listing
  ak config prefs resolve --json          # the payload hooks parse

What changes on disk:
  Reads $AGENTKIT_HOME/config.yaml and &lt;project&gt;/.agentkit/config.yaml. Writes nothing.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  a config file cannot be read or parsed

```
ak config prefs resolve [flags]
```

  -h, --help             help for resolve
