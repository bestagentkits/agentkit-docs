## ak plan phase close

Mark a phase as done

### Synopsis

Complete phase &lt;n&gt; of plan &lt;plan-id&gt; in its canonical phase file — the files-first path `ak plan check` takes: a phase with checkboxes has them all marked done, a checkbox-less phase gets its front-matter status set to done. The plan store is then re-synced from the file, so the change survives `ak plan reindex`.

Effects:
  Mutates the phase file in-place (atomic write), then re-syncs the local plan store from it.

Exit status:
  0   success
  1   plan/phase not found, no linked plan directory, or file / plan store I/O error
  2   invalid arguments

```
ak plan phase close <plan-id> <n> [flags]
```

### Examples

```
  ak plan phase close my-project/260722-1200 1
  ak plan phase close my-project/260722-1200 1 --json
```
