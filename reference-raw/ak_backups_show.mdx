## ak backups show

Print the manifest of a single snapshot

### Synopsis

Print the per-file manifest and metadata for a single snapshot.

Effects:
  Read-only. Reads snapshot manifest.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   snapshot not found

```
ak backups show <id> [flags]
```

### Examples

```
  ak backups show 20260426T123005Z-deadbeef
  ak backups show 20260426T123005Z-deadbeef --json
```

### Options

```
  -h, --help             help for show
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
