## ak agents model list

List installed agents with their model and status

### Synopsis

List every agent AgentKit installed globally or in the project, with the model its file carries, the model config resolves to, and their status: in-sync, pending (config changed; the next refresh or apply updates the file), drift (the runtime file was edited; refreshes keep it), or not-materialized.

Effects:
  Read-only. Reads AgentKit's agent model records, config, and the installed agent files.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage

```
ak agents model list [flags]
```

### Examples

```
  ak agents model list
  ak agents model list --runtime codex --json
```

### Options

```
  -h, --help             help for list
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime whose agents to read ([claude-code codex cursor omp pi]); empty reads all
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
