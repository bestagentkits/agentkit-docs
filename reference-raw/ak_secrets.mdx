## ak secrets

Manage named secret values (API keys, tokens)

### Synopsis

Store, read, list, delete, and rotate small named secret values behind the OS keychain, an age-encrypted vault (--backend=file, for a host with no usable keychain; see `ak secrets recovery`), or an in-memory --backend=memory dev backend. Values are written only to the active backend; ~/.agentkit/secrets/index.json holds metadata (ref, creator, timestamps, a short value hint, and an optional searchable profile) and never a value. Use it for an API key, token, or certificate AgentKit or an adapter needs at runtime, instead of an unmanaged .env file or shell export.

### Examples

```
  ak secrets set ${REF}                                  # interactive prompt
  ak secrets list --json                                 # machine-readable metadata
  ak secrets search stripe --environment production --json  # find a ref by metadata
  ak secrets describe ${REF} --json                      # one ref's full profile, never its value
```

### Options

```
  -h, --help             help for secrets
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
