## ak agents model set

Pin an agent's model or reasoning effort in config

### Synopsis

Write agent_models.&lt;runtime&gt;.agents.&lt;agent&gt;.model (and, for Codex and OMP, reasoning_effort) to the selected config scope, then apply it to the agent's installed files. A project value outranks a user value for project installs; global installs read user config only. OMP also takes an @role alias; a capability-gated runtime is rejected with the missing capability named.

Effects:
  Backs up then rewrites the selected scope's config.yaml when it exists, then rewrites the model fields of every installed file of the agent whose model AgentKit still owns. A file whose model was edited in the runtime is left alone and reported.

Exit status:
  0   success
  1   command failure, including an installed agent file AgentKit cannot prove it still owns (nothing is written)
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage
  4   another AgentKit operation holds the kit lifecycle lock; retry when it finishes
  5   adopt only: no readable installed file of the agent

```
ak agents model set <agent> [flags]
```

### Examples

```
  ak agents model set kongming --runtime claude-code --model opus
  ak agents model set kongming --runtime codex --model gpt-5.5 --effort high --scope project
  ak agents model set planner --runtime omp --model @plan
  ak agents model set debugger --runtime pi --model anthropic/claude-sonnet-4-5
```

### Options

```
      --effort string    reasoning effort (codex and omp), one lowercase word such as low, medium, or high
  -h, --help             help for set
      --json             Emit machine-readable JSON (implies --no-interactive)
      --model string     runtime model ID (an @role alias on omp), or inherit to use the parent session's model
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime the agent is installed in ([claude-code codex cursor omp pi])
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml in the project) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
