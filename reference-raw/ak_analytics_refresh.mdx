## ak analytics refresh

Refresh the local analytics index

### Synopsis

Incrementally refreshes the private local SQLite analytics index from new events. Interactive terminals prompt before applying; pass --yes to bypass prompts.

Effects:
  Updates ~/.agentkit/analytics/ SQLite tables with new event rows.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  3   preview complete (re-run with --yes to apply)

```
ak analytics refresh [flags]
```

### Examples

```
  ak analytics refresh
  ak analytics refresh --yes
```

### Options

```
  -h, --help             help for refresh
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
