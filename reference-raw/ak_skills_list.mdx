## ak skills list

List installed skills

### Synopsis

Enumerate skills installed on this machine, optionally filtered by kit or tag.

Effects:
  Read-only. Scans local installed skills.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak skills list [flags]
```

### Examples

```
  ak skills list
  ak skills list --kit engineer
  ak skills list --json
```

### Options
