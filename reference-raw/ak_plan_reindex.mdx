## ak plan reindex

Rebuild the plan store index from the plan files on disk

### Synopsis

What it does:
  Re-project every AgentKit plan folder under &lt;repo&gt;/plans/ into the plan store, so the index reflects hand-edits made directly to plan.md and phase files. File-owned fields (titles, statuses, bodies) are rebuilt; index-owned lifecycle and publish state (issue linkage, phase revisions and notes) is preserved. Unlike migrate, it re-syncs every recognized folder whether or not it was ever imported. Runs as a dry run unless --apply is given. Symlinks and any path escaping the repo root are skipped and reported, never read or written; nothing is ever deleted.

Who it's for:
  Both: interactive recovery after a hand-edit and scripted --json runs.

When to use it:
  (unspecified)

Examples:
  ak plan reindex
  ak plan reindex --json
  ak plan reindex --apply

What changes on disk:
  With --apply: updates plan-store rows to match the files. Never writes to or deletes plan files.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  plan store or filesystem error

```
ak plan reindex [flags]
```

### Options

```
      --apply            Execute the reindex (default: dry run)
  -h, --help             help for reindex
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --path string      Repo root whose plans/ directory is scanned (default: current directory)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
