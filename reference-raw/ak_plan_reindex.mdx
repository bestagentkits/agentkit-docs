## ak plan reindex

Rebuild the plan store index from the plan files on disk

### Synopsis

Re-project every AgentKit plan folder under the repo's configured paths.plans directory into the plan store, so the index reflects hand-edits made directly to plan.md and phase files. File-owned fields (titles, statuses, bodies) are rebuilt; index-owned lifecycle and publish state (issue linkage, phase revisions and notes) is preserved. Unlike migrate, it re-syncs every recognized folder whether or not it was ever imported. Runs as a dry run unless --apply is given. Symlinks and any path escaping the repo root are skipped and reported, never read or written; nothing is ever deleted.

Effects:
  With --apply: updates plan-store rows to match the files. Never writes to or deletes plan files.

Exit status:
  0   success
  1   plan store or filesystem error
  2   invalid flags or arguments

```
ak plan reindex [flags]
```

### Examples

```
  ak plan reindex
  ak plan reindex --json
  ak plan reindex --apply
```

### Options

```
      --apply            Execute the reindex (default: dry run)
  -h, --help             help for reindex
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --path string      Repo root whose configured paths.plans directory is scanned (default: current project)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
