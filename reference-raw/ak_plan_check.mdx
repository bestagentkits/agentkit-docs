## ak plan check

Mark all checkboxes in a phase file as done

### Synopsis

What it does:
  Toggle every '- [ ]' checkbox in the named phase-NN-*.md file to '- [x]'. Already-checked boxes are left unchanged (idempotent).

Who it's for:
  Both: interactive workflow and CI automation.

When to use it:
  (unspecified)

Examples:
  ak plan check ./plans/my-plan/phase-01-setup.md
  ak plan check ./plans/my-plan/phase-01-setup.md --json

What changes on disk:
  Mutates the phase file in-place (atomic write).

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  phase file not found or I/O error

```
ak plan check <phase-file> [flags]
```
