## ak content schedule daemon

Start the long-running scheduler daemon

### Synopsis

What it does:
  Poll the scheduled-post queue every --poll-interval seconds and publish any due posts via their channel adapter. Runs until SIGINT/SIGTERM. An advisory lockfile prevents two daemons from double-publishing the same post.

Who it's for:
  Power devs automating timed content delivery.

When to use it:
  Start once as a background service or systemd unit.

Examples:
  ak content schedule daemon
  ak content schedule daemon --poll-interval 30

What changes on disk:
  Reads/writes ~/.agentkit/content/queue.json on each tick. Holds a transient lock file during each publish window.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  unrecoverable I/O error

```
ak content schedule daemon [flags]
```

### Options

```
  -h, --help                help for daemon
      --json                Emit machine-readable JSON (implies --no-interactive)
      --no-interactive      Disable interactive prompts (CI-safe)
      --poll-interval int   Seconds between queue polls (default 60)
```
