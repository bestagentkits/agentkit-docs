## ak content schedule daemon

Start the long-running scheduler daemon

### Synopsis

Poll the scheduled-post queue every --poll-interval seconds and publish due posts. Runs until SIGINT/SIGTERM.

Effects:
  Reads and writes ~/.agentkit/content/queue.json; sends channel network requests.

Output:
  Runs continuously until interrupted.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak content schedule daemon [flags]
```

### Examples

```
  ak content schedule daemon
  ak content schedule daemon --poll-interval 30
```

### Options

```
  -h, --help                help for daemon
      --json                Emit machine-readable JSON (implies --no-interactive)
      --no-interactive      Disable interactive prompts (CI-safe)
      --poll-interval int   Seconds between queue polls (default 60)
  -q, --quiet               Suppress non-error output on stderr
  -V, --verbose             Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                 Assume yes for all prompts
```
