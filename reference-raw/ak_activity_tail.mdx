## ak activity tail

Stream new local activity events

### Synopsis

Follows the local activity log and prints new events as they are appended. Use Ctrl-C to stop.

Effects:
  Read-only. Streams local activity events.

Output:
  Streams events as they occur until interrupted.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak activity tail [flags]
```

### Examples

```
  ak activity tail
  ak activity tail --json
```

### Options

```
  -h, --help             help for tail
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
