## ak license devices deactivate

Deactivate a device bound to your AgentKit App license

### Synopsis

Deactivate one device on your AgentKit App license, identified by the id shown in `ak license devices`. Deactivating this device revokes it on the registry and clears its local license session; deactivating another device signs that machine out remotely. Idempotent. Asks for confirmation unless --yes is passed; with --json or --no-interactive, --yes is required.

Effects:
  Revokes the device's session on the registry so it can no longer validate or use Desktop.

Exit status:
  0   device deactivated
  1   command failure
  2   invalid device id, or --yes missing in non-interactive mode
  3   user cancelled

```
ak license devices deactivate <device-id> [flags]
```

### Examples

```
  ak license devices deactivate dev_abc123
  ak license devices deactivate dev_abc123 --yes
```

### Options

```
  -h, --help                  help for deactivate
      --json                  Emit machine-readable JSON (implies --no-interactive)
      --no-interactive        Disable interactive prompts (CI-safe)
  -q, --quiet                 Suppress non-error output on stderr
      --registry-url string   AgentKit registry base URL
  -V, --verbose               Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                   Assume yes for all prompts
```
