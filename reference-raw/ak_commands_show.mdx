## ak commands show

Show command details

### Synopsis

Print metadata, version, description, and requirements for a single command.

Effects:
  Read-only. Reads metadata for the specified command.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   command not found

```
ak commands show <kit>/<command> [flags]
```

### Examples

```
  ak commands show marketing/ckm-email
  ak commands show marketing/ckm-email --json
```

### Options

```
  -h, --help             help for show
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
