## ak migrate rollback

Roll back a failed migration to its pre-apply state

### Synopsis

Restore the migration target to its pre-apply state using the most recent rollback journal.

Effects:
  Restores legacy quarantined directories and files from rollback journal.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak migrate rollback [flags]
```

### Examples

```
  ak migrate rollback
  ak migrate rollback --json
```
