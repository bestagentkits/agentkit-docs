## ak commands install

Install a command

### Synopsis

Resolve a command by &lt;kit&gt;/&lt;command&gt; and install it into the local environment.

Effects:
  Writes command files to the local installation directory.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   command not found
  6   already installed (re-run with --force)

```
ak commands install <kit>/<command> [flags]
```

### Examples

```
  ak commands install marketing/ckm-email
  ak commands install marketing/ckm-email --force
```

### Options

