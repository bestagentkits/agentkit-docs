## ak plan update

Update fields of a plan in the local plan store

### Synopsis

Apply a partial update to a plan tracked in the local SQLite plan store. Only flags explicitly passed are changed; every other field is left as-is. --status is file-owned, so it rewrites the plan.md front matter (the canonical source) and re-syncs the index; the remaining flags set index-only bookkeeping. --title is owned by the plan.md heading: edit the file and run `ak plan reindex`.

Effects:
  With --status: rewrites the plan.md front matter, then updates the plan store. Other flags write only the plan store.

Exit status:
  0   success
  1   plan not found or plan store / file I/O error
  2   invalid flag value, or a file-owned flag (--title) that must be edited in the file

```
ak plan update <id> [flags]
```

### Examples

```
  ak plan update my-project/260722-1200 --status in-progress
  ak plan update my-project/260722-1200 --linked-pr 1120 --json
```
