## ak skill install

Install or refresh the per-skill runtime env

### Synopsis

Read the skill's runtime: block and create or refresh the per-skill env at ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/, with the package cache shared at ~/.agentkit/cache/&lt;runtime-hash&gt;/. Idempotent.

Effects:
  Writes to ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/.manifest.json and ~/.agentkit/cache/&lt;runtime-hash&gt;/ (venv or node_modules).

Exit status:
  0   success
  2   invalid flags or arguments
  4   missing tool (uv / pnpm) or skill has no runtime block
  5   kit or skill not found

```
ak skill install <kit>/<skill> [flags]
```

### Examples

```
  ak skill install marketing/youtube
  ak skill install engineer/web-testing --kits-dir kits/
```
