## ak skill install

Add a skill to an installed kit and refresh its runtime env

### Synopsis

When the kit has a native Claude Code install, add the skill into it: write only ~/.claude/skills/&lt;skill&gt;/, record it in the kit's native ownership indexes, and extend the saved skill selection so `ak kit refresh` keeps it. Then, when the skill declares a runtime: block, create or refresh the per-skill env at ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/, with the package cache shared at ~/.agentkit/cache/&lt;runtime-hash&gt;/. Plugin delivery, Codex and remote sources are not supported for the additive install yet. Idempotent.

Effects:
  Writes ~/.claude/skills/&lt;skill&gt;/ and the kit's lifecycle indexes under ~/.agentkit/adapters/claude-code/&lt;kit&gt;/.agentkit/ when the kit is installed natively; writes ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/.manifest.json and ~/.agentkit/cache/&lt;runtime-hash&gt;/ (venv or node_modules).

Exit status:
  0   success
  2   invalid flags or arguments
  4   missing tool (uv / pnpm), skill has no runtime block, or another install holds the kit lock
  5   kit or skill not found
  6   a skill file holds edits AgentKit did not write; nothing was changed

```
ak skill install <kit>/<skill> [flags]
```

### Examples

```
  ak skill install marketing/youtube
  ak skill install engineer/web-testing --kits-dir kits/
  ak skill install engineer/ak-advise --kits-dir kits/ --yes
```
