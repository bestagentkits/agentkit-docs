## ak license devices

List devices bound to your AgentKit App license

### Synopsis

List the devices activated against your AgentKit App license: name, platform, first seen, last seen, and which one is this device. Requires an active `ak login --license-key` session. When the license server does not offer the device list yet, prints a notice (JSON: "unsupported": true) and exits 0.

Effects:
  Read-only. Reads ~/.agentkit/auth/session.json and queries the registry.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak license devices [flags]
```

### Examples

```
  ak license devices
  ak license devices --json
```
