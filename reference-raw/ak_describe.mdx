## ak describe

Describe a command's contract for agents and scripts

### Synopsis

Print the structured contract of any ak command or namespace: summary, details, examples, effects, output behavior, declared exit codes, flags, subcommands, and the typed agent contract (mutation, risk tier, preview, confirmation, snapshot, network, auth, framing). Undeclared contract values read "unspecified". It reads the same help metadata as --help. With no arguments it describes the root command.

Effects:
  Read-only and offline. Reads only the command tree built into this binary.

Output:
  With --json, stdout carries one command.describe envelope whose data is the command description.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   no command matches the given path

```
ak describe [command...] [flags]
```

### Examples

```
  ak describe --json
  ak describe kit install --json
  ak describe migrate rollback
```

  -y, --yes              Assume yes for all prompts
