## ak secrets remote login

Sign in with a device code to run commands through the vault

### Synopsis

Runs the OAuth device authorization grant (RFC 8628): open the link on any device where you are signed in to agentkit.best and confirm the code. The grant allows only running commands (scope vault-mcp:use) and lasts 30 days. Its refresh token rotates on every use, and a used one sent again revokes the grant, so it is kept in one 0600 file and renewed under a lock. If a renewal's answer is lost in transit (a dropped connection or timeout), the next renewal can find the grant revoked; run this command again then. With --export the refresh token is printed once for a secret store (set it as AK_VAULT_MCP_REFRESH_TOKEN in a sandbox) and nothing is kept here; --export has no --json form. A seed is spent on its first use, so each sandbox that does not keep AGENTKIT_HOME needs its own sign-in.

Effects:
  Writes AGENTKIT_HOME/state/vault-remote.json (0600), unless --export.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak secrets remote login [flags]
```

### Examples

```
  ak secrets remote login
  ak secrets remote login --export
```
