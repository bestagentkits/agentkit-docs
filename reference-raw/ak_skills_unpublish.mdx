## ak skills unpublish

Delete a SkillX package (restorable for 30 days) or yank one version

### Synopsis

Without --version soft-deletes the package: every SkillX read path hides it and it takes no new version, and ak skills restore brings it back with its visibility and releases until the restore deadline 30 days later; after that the name is never reused. With --version yanks that published release: it no longer resolves by version, while lockfiles that pin its digest keep reading it. Both are reversible, so nothing is asked first. Re-running is safe: an already deleted package, or an already yanked release, succeeds with changed: false; a release in another state (such as quarantined) is a conflict (exit 6).

Effects:
  Soft-deletes the package, or yanks one release, on SkillX. Sends the request with the SkillX credential: the agentkit.best link (`ak skills link`) while one exists, otherwise SKILLX_TOKEN. Writes nothing locally and never prompts. Needs SkillX on (after `ak update --ssot`, or AGENTKIT_SKILLX=1 or features.skillx: true).

Exit status:
  0   success
  1   command failure: SkillX offline, the credential missing or refused, or an untrusted answer (a change may have been applied; check with ak skills visibility)
  2   SkillX disabled, invalid flags or arguments, a skill directory that is not a valid skill tree, or a request SkillX refused as invalid
  5   package or release not found, or release publishing not enabled on SkillX
  6   conflict with the package's current state: visibility mismatch, version exists, publish to a deleted package, a release that is not published, a concurrent change that left another state, or the restore window passed
  7   SkillX refused the change: approval needed on the dashboard, not the package owner, publisher suspended, or deleted by an administrator

```
ak skills unpublish <@publisher/slug> [--version <semver>] [flags]
```

### Examples

```
  ak skills unpublish @alice/my-skill
  ak skills unpublish @alice/my-skill --version 1.0.0
  ak skills unpublish @alice/my-skill --json
```
