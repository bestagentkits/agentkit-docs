## ak usage summary

Summarize local token usage for the current day, week, or month

### Synopsis

Sums the token lanes (input, output, cache creation, cache read) of every Claude Code and Codex session that started in the current UTC calendar period, from the period start up to now; a week starts on Monday. Totals are broken down by runtime, provider, and model. Token counts are exact. Reasoning output is counted inside output and reported as an unavailable separate lane. The cost is an estimate at the public API rates embedded in this build and becomes unavailable, never partial, when any model has no rate. Provider subscription windows are always unavailable here; use `ak usage limits` for rolling windows and opt-in provider-reported quotas. The analytics index answers first; when it is absent or not ready the command parses the session transcripts directly (source live) unless --no-live is set.

Effects:
  Read-only. Opens the local analytics SQLite index under ~/.agentkit/analytics/ in read-only mode (AGENTKIT_HOME overrides the base dir) and, as a fallback, reads Claude Code and Codex session transcripts. Never writes, refreshes, or creates the index and never opens a network socket.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak usage summary [flags]
```

### Examples

```
  ak usage summary
  ak usage summary --period week
  ak usage summary --period month --json
  ak usage summary --no-live
```

### Options

```
  -h, --help             help for summary
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --no-live          Do not parse session transcripts when the analytics index cannot serve
      --period string    Period: day, week, or month (current UTC calendar period) (default "day")
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
