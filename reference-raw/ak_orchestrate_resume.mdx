## ak orchestrate resume

Reconnect to an existing run after a client or coordinator crash

### Synopsis

Reconnect to run-id using the same job graph file. Never relaunches jobs; if the worker crashed, reclassifies persisted state only.

Effects:
  Read-only against a live worker; persists a reclassification of orphaned jobs when the worker crashed.

Exit status:
  0   success
  1   graph digest mismatch, run not found, or state is corrupt
  2   invalid flags or arguments
  6   unsupported platform (v1 requires darwin)

```
ak orchestrate resume <run-id> <job-graph.json> [flags]
```

### Examples

```
  ak orchestrate resume 3f9a... jobs.json
  ak orchestrate resume 3f9a... jobs.json --json
```
