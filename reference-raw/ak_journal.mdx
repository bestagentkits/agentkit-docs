## ak journal

Manage journals in configured plan storage

### Synopsis

Create, list, show, and validate chronological work journals in configured plan storage.

### Examples

```
  ak journal create "Fix install race" --summary "Root cause and fix"
  ak journal list
  ak journal show 2026-07-27-fix-install-race
```
