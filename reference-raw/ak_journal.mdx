## ak journal

Manage technical journal entries under plans/journals

### Synopsis

What it does:
  Create, list, show, and validate chronological work journals. Journals are historical records, not durable authority.

Who it's for:
  Agents and developers recording session work.

When to use it:
  After meaningful implementation, reviews, or incident work.

Examples:
  ak journal create "Fix install race" --summary "Root cause and fix"
  ak journal list --query install --json
  ak journal show 2026-07-27-fix-install-race
  ak journal validate 2026-07-27-fix-install-race

What changes on disk:
  create writes one file under &lt;project&gt;/plans/journals/. list/show/validate are read-only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  entry not found or I/O failure
  2  invalid flags or arguments
  3  validation failed
