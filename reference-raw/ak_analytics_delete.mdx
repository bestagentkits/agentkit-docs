## ak analytics delete

Delete the local analytics index

### Synopsis

Deletes the disposable local SQLite analytics index database and retains only a disabled intent marker. Interactive terminals prompt before applying; pass --yes to bypass prompts.

Effects:
  Deletes ~/.agentkit/analytics/ SQLite database files.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  3   preview complete (re-run with --yes to apply)

```
ak analytics delete [flags]
```

  ak analytics delete --yes
