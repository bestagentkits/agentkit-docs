## ak orchestrate stop

Terminate a run's live jobs (TERM, grace period, then KILL)

### Synopsis

Send SIGTERM through the worker control socket, wait a grace period, then SIGKILL remaining verified jobs. Does not signal from persisted state alone.

Effects:
  Persists the stop request and its outcome to the run's state file.

Exit status:
  0   success
  1   no live verified worker, or the stop failed
  2   invalid flags or arguments
  6   unsupported platform (v1 requires darwin)

```
ak orchestrate stop <run-id> [flags]
```

### Examples

```
  ak orchestrate stop 3f9a...
  ak orchestrate stop 3f9a... --json
```
