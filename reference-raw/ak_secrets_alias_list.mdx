## ak secrets alias list

List aliases and the refs they point at

### Synopsis

List every alias on this device, sorted by name. Names only, never a value.

Effects:
  Read-only: reads ~/.agentkit/secrets/aliases.json.

Exit status:
  0   success
  2   invalid flags or arguments, or an invalid row in the aliases file
  5   aliases file failure

```
ak secrets alias list [flags]
```

### Examples

```
  ak secrets alias list
  ak secrets alias list --json
```
