## ak secrets alias list

List aliases and the refs they point at

### Synopsis

List every alias on this device, sorted by name. Names only, never a value. An alias whose name is also a stored secret is marked shadowed (`shadowed: true` in --json): the stored secret wins, so a release of that name hands over that secret, not the alias target. A vault sync can bring such a secret in from another member, and `ak secrets sync` reports it as alias_shadowed when it does.

Effects:
  Read-only: reads ~/.agentkit/secrets/aliases.json and the secrets index, never a value.

Exit status:
  0   success
  2   invalid flags or arguments, or an invalid row in the aliases file
  5   aliases file failure

```
ak secrets alias list [flags]
```

### Examples

```
  ak secrets alias list
  ak secrets alias list --json
```
