## ak content-search

Opt-in local project content search (plaintext shards)

### Synopsis

What it does:
  Manages opt-in per-project FTS5 content shards under AGENTKIT_HOME/operational/content/. Searchable text is plaintext at the SQLite layer unless the OS disk is encrypted. Shards never sync and never enter operational.db.

Who it's for:
  Operators enabling local project search after accepting the plaintext disclosure.

When to use it:
  After a project exists in the operational store and an owner opts in explicitly.

Examples:
  ak content-search status --project &lt;uuid&gt; --json
  ak content-search enable --project &lt;uuid&gt; --yes --no-interactive
  ak content-search search --project &lt;uuid&gt; --query 'token' --json
  ak content-search delete --project &lt;uuid&gt; --yes --no-interactive

What changes on disk:
  Enable creates one project shard. Delete removes only that shard's DB/WAL/SHM files.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
