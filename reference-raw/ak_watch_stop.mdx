## ak watch stop

Stop a running watch daemon for the given repository

### Synopsis

Mark a repository watch as inactive by updating the state file. The next daemon poll cycle detects the inactive flag and stops automatically. Safe to call even when no daemon is running - exits 0 with an informational message.

Effects:
  Writes active=false to ~/.agentkit/watch/&lt;repo-slug&gt;/state.json.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak watch stop <owner/repo> [flags]
```

### Examples

```
  ak watch stop owner/repo
  ak watch stop owner/repo --json
```
