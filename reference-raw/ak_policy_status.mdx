## ak policy status

Show what the project policy currently enforces

### Synopsis

List every active rule with its action and its provenance: a hand-authored rule says so, and a rule compiled from prose names the file and line it came from, so any enforcement can be traced back to the instruction that asked for it.

Effects:
  Read-only. Reads the policy document and the instruction files it names.

Exit status:
  0   success
  1   the policy document is missing or unreadable
  2   invalid arguments

```
ak policy status [flags]
```

### Examples

```
  ak policy status
  ak policy status --json
```

### Options

```
      --dir string       Project directory holding .agentkit/policy.yaml (default ".")
  -h, --help             help for status
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
