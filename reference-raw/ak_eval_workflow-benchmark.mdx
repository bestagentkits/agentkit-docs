## ak eval workflow-benchmark

Replay labeled workflow decisions offline

### Synopsis

Replay up to100 independently labeled cases bound to exact sanitized requests, policy, thresholds and legacy decisions. Missing or invalid observations make complete=false. Synthetic data validates arithmetic only; actual avoided calls remain0 and unknown cost is null.

Effects:
  Reads a selected local corpus and prints a comparison. No provider, credential, configuration, subprocess or workflow execution.

Exit status:
  0   report available; inspect complete and coverage
  1   invalid corpus
  2   invalid arguments

```
ak eval workflow-benchmark <corpus.json|-> [flags]
```

### Examples

```
  ak eval workflow-benchmark corpus.json --json
  cat corpus.json | ak eval workflow-benchmark - --json
```
