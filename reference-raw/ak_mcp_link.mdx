## ak mcp link

Mirror MCP servers into another adapter config

### Synopsis

Plans or applies a conservative MCP mirror from discovered Claude-style MCP config into an adapter config.

Effects:
  Dry-run by default. With --apply, writes the target adapter config after creating a backup.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak mcp link --to <adapter> [flags]
```

### Examples

```
  ak mcp link --to codex --json
  ak mcp link --to codex --apply
  ak mcp link --to codex --source .mcp.json --target ~/.codex/config.toml
```
