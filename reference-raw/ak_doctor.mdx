## ak doctor

Run health checks on the AgentKit installation

### Synopsis

Run diagnostic health checks on the AgentKit installation. Actionable issues show suggested fixes; use --fix to apply automated repairs.

Effects:
  Read-only by default. With --fix, applies repair commands to local configuration and plugin paths.

Output:
  Exits 0 after completing checks regardless of health status, unless --exit-on-fail is set.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak doctor [flags]
```

### Examples

```
  ak doctor
  ak doctor --check api_keys
  ak doctor --fix --yes
  ak doctor --json
```

### Options

```
      --adapter string   Filter checks to an adapter with a dedicated doctor suite: claude-code, codex, cursor
      --check string     Run only the named check(s), comma-separated (e.g. binary_version,codex_binary_present)
      --exit-on-fail     Exit 1 when any check fails (default: exit 0, check healthy in --json output)
      --fix              Attempt automated fixes for failing checks (confirm each unless --yes)
  -h, --help             help for doctor
      --json             Emit machine-readable JSON (implies --no-interactive)
      --list             List the registered check names (valid --check values) and exit
      --no-interactive   Disable interactive prompts (CI-safe)
      --offline          Skip network-dependent checks (binary_version, network)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
