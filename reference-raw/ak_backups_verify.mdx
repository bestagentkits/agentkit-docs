## ak backups verify

Recompute manifest hashes and report ok | corrupt

### Synopsis

Recompute sha256 checksums of every file in a snapshot to verify integrity.

Effects:
  Read-only. Reads snapshot files and computes checksums.

Exit status:
  0   snapshot verified ok
  1   snapshot is corrupt or verification error
  2   invalid flags or arguments
  5   snapshot not found

```
ak backups verify <id> [flags]
```

### Examples

```
  ak backups verify 20260426T123005Z-deadbeef
  ak backups verify 20260426T123005Z-deadbeef --json
```
