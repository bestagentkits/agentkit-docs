## ak skills evolution list

List recorded skill evolution candidates

### Synopsis

Lists every verified candidate record by ID with its skill, classification, findings and slot states. A record that fails verification is reported, not listed.

Effects:
  Read-only: reads the candidate records under AGENTKIT_HOME/state/skill-evolve/candidates/ and verifies each against its candidate ID. Writes nothing, takes no lock, runs no script, model or network call, and skips the background update check.

Exit status:
  0   success, including an empty candidate store
  1   the candidate store could not be read, or (show) the record failed verification (store.corrupt); list reports an unverified record and still exits 0
  2   invalid flags or arguments, or a candidate reference that is not an ID or a prefix of at least 8 hex characters
  5   no recorded candidate matches the reference, or a prefix matches more than one (evolve.candidate_not_found)

```
ak skills evolution list [flags]
```

### Examples

```
  ak skills evolution list
  ak skills evolution list --json
```
