## ak skills sync

Install exactly the SkillX releases the skill lock pins

### Synopsis

Projects every SkillX package the scope's skill lock pins for you, at exactly the locked digest: it never upgrades and never writes the lock. A package already projected and intact needs no network. Offline, a package whose verified copy is in the local skill store still installs; one without fails with source.offline and nothing changes. A release served with a different digest for the locked version fails with store.digest_mismatch.

Effects:
  Applies without prompting; --dry-run prints the plan and writes nothing. Reads the scope's skill lock and never writes it: no locked digest changes. Writes the verified release into the skill store under AGENTKIT_HOME, the projected skill files into each runtime's native skills root (mode 0644, never executable), removing stale ones, the scope's receipts and, for a project, the project root registry under AGENTKIT_HOME/state and the project skill state .gitignore, all in one journaled transaction under the kit lifecycle lock. Never runs a declared script, npm, npx or any SkillX installer. Requires AGENTKIT_SKILLX=1 and AGENTKIT_SKILL_STORE=1.

Exit status:
  0   success, or nothing to change
  1   command failure: offline without a verified copy, credential refused, path too long, or recovery required
  2   SkillX or the skill store disabled, invalid flags or arguments, or a reserved alias
  4   another AgentKit operation holds the kit lifecycle lock
  5   release not found or not entitled
  6   alias collision, unowned or modified path, untrusted project state, or the lock changed during the run
  7   release revoked, yanked, quarantined or untrusted, a link in a target path, or a digest mismatch

```
ak skills sync --locked [flags]
```

### Examples

```
  ak skills sync --locked
  ak skills sync --locked --scope global --runtime claude-code,codex --dry-run --json
```

### Options

```
      --dry-run           SkillX: print the plan and write nothing
  -h, --help              help for sync
      --json              Emit machine-readable JSON (implies --no-interactive)
      --locked            Install exactly the lock's digests (required)
      --no-interactive    Disable interactive prompts (CI-safe)
  -q, --quiet             Suppress non-error output on stderr
      --runtime strings   SkillX: runtimes to change: claude-code, codex (repeatable; default all with a recorded projection)
      --scope string      SkillX: lock and skills root scope: project (default) or global (default "project")
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes               Assume yes for all prompts
```
