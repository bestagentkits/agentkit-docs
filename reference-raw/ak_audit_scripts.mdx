## ak audit scripts

Audit local kit hook and skill scripts

### Synopsis

Advisory audit for local hook scripts and skill scripts. Scans script text for language, dependencies, entrypoints, and heuristic risk findings.

Effects:
  Read-only. Scans local script files; never executes scripts.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak audit scripts [path...] [flags]
```

### Examples

```
  ak audit scripts
  ak audit scripts ./kits/engineer
  ak audit scripts --json
```

### Options

```
  -h, --help                 help for scripts
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --max-file-bytes int   Maximum bytes to read per script file
      --no-interactive       Disable interactive prompts (CI-safe)
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
