## ak agents model get

Show one agent's model layer by layer

### Synopsis

Show the kit default, adapter default, user and project overrides, AgentKit's recorded choice, and the model the runtime file carries for each installed file of one agent.

Effects:
  Read-only.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments, an unsupported runtime, or a field the runtime does not manage
  5   the agent is not installed in the runtime

```
ak agents model get <agent> [flags]
```

### Examples

```
  ak agents model get kongming --runtime codex
  ak agents model get reviewer --runtime cursor --json
```

### Options

```
  -h, --help             help for get
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --project string   project directory whose installs and .agentkit/config.yaml apply (default: the current directory)
  -q, --quiet            Suppress non-error output on stderr
      --runtime string   runtime the agent is installed in ([claude-code codex cursor omp pi])
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
