## ak plan phase

Manage phases of a plan tracked in the local plan store

### Synopsis

Namespace for phase-level mutations on a plan tracked in the local SQLite plan store: `phase update` upserts a phase's fields, `phase close` marks a phase done.

### Examples

```
  ak plan phase update my-project/260722-1200 1 --status in-progress
  ak plan phase close my-project/260722-1200 1
```
