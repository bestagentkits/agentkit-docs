## ak sessions show

Show paginated session messages

### Synopsis

Reads one Claude Code session JSONL file through the same runtime used by desktop and dashboard.

Effects:
  Read-only. Reads ~/.agentkit/projects.json and the selected ~/.claude session JSONL file.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak sessions show <project> <session-id> [flags]
```

### Examples

```
  ak sessions show myapp session-abc --json
  ak sessions show myapp session-abc --limit 50 --cursor 100 --json
```

### Options

```
      --cursor int       0-based line cursor
  -h, --help             help for show
      --json             Emit machine-readable JSON (implies --no-interactive)
      --limit int        Maximum messages to return (default 200)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
