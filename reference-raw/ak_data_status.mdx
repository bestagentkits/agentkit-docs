## ak data status

Show default retention posture for derived classes

### Synopsis

What it does:
  Lists known derived data classes and their default forever retention posture.

Who it's for:
  Operators auditing local data growth policy.

When to use it:
  During capacity planning or before changing retention.

Examples:
  ak data status --json

What changes on disk:
  Read-only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:

  1  runtime error
  2  invalid flags
