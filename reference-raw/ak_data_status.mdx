## ak data status

Show operational store health and default retention posture

### Synopsis

Reports the operational store's health, its on-disk schema next to the schema this build reads, and the safe remedy when it is not ready, then lists known derived data classes and their default forever retention posture.

Effects:
  Read-only. Inspects the operational store without creating, migrating, or repairing it, and reads derived data class metadata.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak data status [flags]
```

### Examples

```
  ak data status
  ak data status --json
```
