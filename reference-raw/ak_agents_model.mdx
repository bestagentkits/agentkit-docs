## ak agents model

Show and change the model each installed agent runs on

### Synopsis

Report each installed agent's model layer by layer (kit default, adapter default, user and project config, the runtime file) and change it through config. A model edited directly in a runtime agent file is kept across refreshes and reported as drift until it is adopted or replaced.

### Examples

```
  ak agents model list
  ak agents model set kongming --runtime codex --model gpt-5.5 --effort high
  ak agents model explain kongming --runtime claude-code
  ak agents model apply --runtime cursor --yes
```

### Options

```
  -h, --help             help for model
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
