## ak mcp add

Add or update an MCP server

### Synopsis

Writes one MCP server entry to a selected Claude-style MCP config file. Known catalog servers: dataforseo.

Effects:
  Writes the selected MCP JSON file (defaults to project .mcp.json).

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak mcp add <name> [flags]
```

### Examples

```
  ak mcp add memory --command npx --arg -y --arg @modelcontextprotocol/server-memory
  ak mcp add db --command node --arg server.js --env MCP_ENV_ONE=value --source .mcp.json
```
