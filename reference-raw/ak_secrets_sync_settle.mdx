## ak secrets sync settle

Resolve a sync conflict by choosing which value to keep

### Synopsis

Choose the value a conflicted secret keeps on every device: this device's (local), the current synced value (remote), or one conflict branch (branch:&lt;id&gt;, IDs from `ak secrets sync status`). Runs one sync cycle around the choice. Refused when an AI agent runs it.

Effects:
  Pushes signed records that close the conflict, and updates this device's store to the kept value.

Exit status:
  0   conflict resolved
  2   invalid --keep, or the store moved since enable
  3   the ref, or the branch, has no open conflict
  6   refused: an AI agent is running this command
  10  sync is not enabled on this device
  11  the vault server is unavailable or busy; retry
  12  resolved, but something else needs attention
  13  integrity alarm; sync halted
  14  not logged in, or this device was removed

```
ak secrets sync settle <ref> [flags]
```

### Examples

```
  ak secrets sync settle OPENAI_API_KEY --keep local
  ak secrets sync settle OPENAI_API_KEY --keep branch:0123456789abcdef0123456789abcdef
```

### Options

  -y, --yes                    Assume yes for all prompts
