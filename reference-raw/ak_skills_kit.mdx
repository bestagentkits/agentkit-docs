## ak skills kit

Preview, apply, rebase and roll back personal kits built on kit skills

### Synopsis

A personal kit (local/&lt;name&gt;) extends exact kit versions with overlays and forks. status, inspect and rebase --dry-run resolve and preview personal kits without writing anything. apply, rebase, rollback and remove project the composition into the native skills roots in one journaled transaction, owned by personal:&lt;name&gt;. init writes a new personal kit manifest; resolve records the user's resolution of a rebase finding, which the next rebase consumes. A plan that needs review is applied only with the plan token the user approved. publish uploads the kit's delta to SkillX as a private revision, only when asked; revisions lists its SkillX revisions; sync --locked projects one exact SkillX revision. status, inspect and the --dry-run of init, resolve and rebase work offline for every user, without the skill store or a SkillX account. apply, rollback, remove and sync (dry runs included) and init and resolve need the skill store; publish, revisions and sync need SkillX. Both turn on after `ak update --ssot`: init, resolve, publish and revisions only touch AGENTKIT_HOME and follow its global scope from any directory, while a projection follows the scope of --scope (or AGENTKIT_SKILL_STORE=1 and AGENTKIT_SKILLX=1). An upload needs an unscoped SkillX API key in ak secrets (SKILLX_TOKEN). AGENTKIT_SKILL_OVERLAYS set to anything but 1 hides this group.

### Examples

```
  ak skills kit status
  ak skills kit rebase mine --to engineer@0.3.0 --dry-run
  ak skills kit publish mine --handle alice --private
  ak skills kit sync mine --locked
```
