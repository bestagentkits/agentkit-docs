## ak plan cleanup

Archive old closed plans (retention sweep)

### Synopsis

What it does:
  Retention sweep: archive closed plans whose last update predates --older-than, moving them out of active listings while keeping them searchable. Runs as a dry run (reports what would change, mutates nothing) unless --apply is given. Operates only on plan-store rows; never deletes plan files or any content on disk.

Who it's for:
  Both: periodic housekeeping and scripted retention with --json.

When to use it:
  (unspecified)

Examples:
  ak plan cleanup --older-than 720h
  ak plan cleanup --older-than 2160h --json
  ak plan cleanup --older-than 720h --apply

What changes on disk:
  With --apply: updates plan-store rows (closed -&gt; archived) after a recovery snapshot. Never deletes files.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  plan store I/O error
  2  missing or invalid --older-than

```
ak plan cleanup [flags]
```

### Options

```
      --apply               Execute the archive sweep (default: dry run)
  -h, --help                help for cleanup
      --json                Emit machine-readable JSON (implies --no-interactive)
      --no-interactive      Disable interactive prompts (CI-safe)
      --older-than string   Minimum age of a closed plan's last update (Go duration, e.g. 720h)
  -q, --quiet               Suppress non-error output on stderr
  -V, --verbose             Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                 Assume yes for all prompts
```
