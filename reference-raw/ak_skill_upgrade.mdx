## ak skill upgrade

Re-resolve the per-skill env after editing skill.yaml

### Synopsis

After editing the runtime: block in skill.yaml, this command re-hashes the live block and reinstalls into a fresh cache dir if the hash drifted. No-op when the hash already matches the on-disk manifest.

Effects:
  May write to a new ~/.agentkit/cache/&lt;new-hash&gt;/ and refresh ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/.manifest.json. Old cache dir is preserved.

Exit status:
  0   success
  2   invalid flags or arguments
  4   missing tool (uv / pnpm) or skill has no runtime block
  5   kit or skill not found

```
ak skill upgrade <kit>/<skill> [flags]
```

### Examples

```
  ak skill upgrade marketing/youtube
  ak skill upgrade engineer/web-testing
```
