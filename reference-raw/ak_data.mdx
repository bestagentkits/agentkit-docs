## ak data

Inspect derived-data retention and run bounded ingest

### Synopsis

What it does:
  Shows retention policy resolution, runs one bounded operational ingest sweep, and applies fixed-retention prune for Prunable local tables. Runtime-owned source files are never auto-deleted.

Who it's for:
  Operators managing local derived operational data.

When to use it:
  Before/after enabling fixed retention, or to refresh the operational read model once.

Examples:
  ak data status --json
  ak data retention --class ingestion_runs --days 30 --json
  ak data retention --class ingestion_runs --days 30 --apply --json
  ak data ingest --json

What changes on disk:
  ingest writes operational.db; retention --apply deletes eligible derived rows only.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
