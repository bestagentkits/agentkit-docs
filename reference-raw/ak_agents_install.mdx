## ak agents install

Install an agent

### Synopsis

Resolve an agent by &lt;kit&gt;/&lt;agent&gt; and install it into the local environment.

Effects:
  Writes agent files to the local installation directory.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   agent not found
  6   already installed (re-run with --force)

```
ak agents install <kit>/<agent> [flags]
```

### Examples

```
  ak agents install engineer/researcher
  ak agents install engineer/researcher --force
```

### Options

