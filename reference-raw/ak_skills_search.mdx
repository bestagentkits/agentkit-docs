## ak skills search

Search skills

### Synopsis

Search available skills across configured kits by name, description, and tags. --source skillx is refused with source.unsupported: SkillX offers no search endpoint, so use ak skills resolve with a known @publisher/slug instead.

Effects:
  Read-only. Searches available skills catalogs; never connects to SkillX.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak skills search <query> [flags]
```

### Examples

```
  ak skills search browser
  ak skills search browser --json
```

### Options

```
  -h, --help             help for search
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --source string    Catalog to search: local (default) or skillx (unsupported) (default "local")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
