## ak kit uninstall

Remove an installed kit plugin

### Synopsis

Remove AgentKit-owned files for one installed kit while preserving user-modified and custom files. Pass --yes to execute; otherwise the command stays in dry-run.

Effects:
  Deletes matching AgentKit-generated files, unregisters plugin entries, and snapshots before writes.

Exit status:
  0   success
  1   invalid kit, unreadable install tree, or unsafe plugin ownership
  2   invalid flags or arguments
  3   dry-run or not confirmed

```
ak kit uninstall <kit-name> [flags]
```

### Examples

```
  ak kit uninstall engineer --dry-run
  ak kit uninstall engineer --yes
  ak kit uninstall engineer --global --yes
```

### Options

```
      --dry-run              Show uninstall plan without deleting files
  -g, --global               Select the user/global install scope
  -h, --help                 help for uninstall
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --kits-dir string      Local kits directory override (default: $AGENTKIT_KITS_DIR or ./kits)
      --no-interactive       Disable interactive prompts (CI-safe)
      --plugin-mode          Select Claude Code plugin delivery; combine with --global for the user plugin
      --project-dir string   Project directory for a native project install; combine with --plugin-mode for a project plugin
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
