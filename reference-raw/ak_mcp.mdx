## ak mcp

Inspect local MCP server configuration

### Synopsis

What it does:
  Reads Claude-style MCP server config from user settings, user .mcp.json, and project .mcp.json. Env values are redacted at parse time.

Who it's for:
  Power devs, AI agents, CI jobs, and desktop reviewers that need MCP inventory from CLI.

When to use it:
  Use before editing MCP config or validating cross-adapter MCP parity.

Examples:
  ak mcp list --json
  ak mcp show memory --json
  AGENTKIT_CLAUDE_HOME=/tmp/claude ak mcp list --cwd /tmp/project --json

What changes on disk:
  Read-only. Reads ~/.claude/settings.json, ~/.claude/.mcp.json, and ./.mcp.json.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

### Options

```
      --claude-home string   Claude home override; defaults to AGENTKIT_CLAUDE_HOME or ~/.claude
      --cwd string           Project directory override; defaults to current working directory
  -h, --help                 help for mcp
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --no-interactive       Disable interactive prompts (CI-safe)
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
