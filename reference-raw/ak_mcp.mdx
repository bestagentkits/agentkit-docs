## ak mcp

Inspect local MCP server configuration

### Synopsis

Reads Claude-style MCP server config from user settings, user .mcp.json, and project .mcp.json. Env values are redacted at parse time.

### Examples

```
  ak mcp list
  ak mcp show memory
  ak mcp add memory --command npx --arg -y --arg @modelcontextprotocol/server-memory
```

### Options

```
      --claude-home string   Claude home override; defaults to AGENTKIT_CLAUDE_HOME or ~/.claude
      --cwd string           Project directory override; defaults to current working directory
  -h, --help                 help for mcp
      --json                 Emit machine-readable JSON (implies --no-interactive)
      --no-interactive       Disable interactive prompts (CI-safe)
  -q, --quiet                Suppress non-error output on stderr
  -V, --verbose              Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                  Assume yes for all prompts
```
