## ak secrets alias unset

Remove an alias

### Synopsis

Remove NAME. The secret it pointed at is untouched.

Effects:
  Writes ~/.agentkit/secrets/aliases.json. Never touches a value.

Exit status:
  0   success
  2   invalid flags or arguments, or an invalid row in the aliases file
  3   no such alias
  5   aliases file failure

```
ak secrets alias unset <NAME> [flags]
```

### Examples

```
  ak secrets alias unset CLAUDE_API_KEY
  ak secrets alias unset CLAUDE_API_KEY --json
```
