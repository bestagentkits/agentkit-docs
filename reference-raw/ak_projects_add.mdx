## ak projects add

Register a project directory in the global registry

### Synopsis

Add &lt;path&gt; to ~/.agentkit/projects.json. If the directory is already registered, its entry is refreshed (UpdatedAt). This command is called automatically by `ak new` and `ak init`.

Effects:
  Writes ~/.agentkit/projects.json atomically.

Exit status:
  0   success (new or updated entry)
  1   path does not exist or is not a directory
  2   invalid arguments

```
ak projects add <path> [flags]
```

### Examples

```
  ak projects add ./myproj
  ak projects add $HOME/projects/myproj
  ak projects add . --json
```
