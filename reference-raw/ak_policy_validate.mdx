## ak policy validate

Check that the policy document is coherent

### Synopsis

Load the policy document and report every pair of rules that disagree about an input both describe, and every compiled rule whose source instruction has changed. A conflicting document enforces nothing, so this is the check that belongs in CI: it turns a typo into a red build instead of a silent enforcement gap in someone's session.

Effects:
  Read-only. Reads the policy document and the instruction files it names.

Exit status:
  0   success
  1   the policy document is missing or unreadable
  2   invalid arguments
  4   rules in the document disagree, so nothing in it is enforced

```
ak policy validate [flags]
```

### Examples

```
  ak policy validate
  ak policy validate --fail-on-stale --json
```
