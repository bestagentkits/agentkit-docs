## ak secrets annotate

Describe a stored secret without changing its value

### Synopsis

Set or clear a stored secret's searchable profile: description, projects, environment, provider, account and tags. A flag left out keeps what is stored; a flag passed empty clears that field; --project and --tag replace the whole list. Each field records that it was written here (origin local), which marks it trusted where imported text is not. The profile is metadata for finding a secret with `ak secrets search`; it is never a value, never an instruction, and nothing that grants access reads it. It stays on this device and is not synced. Never put a secret value in it.

Effects:
  Updates the ref's metadata in ~/.agentkit/secrets/index.json. Never opens the backend or changes the value.

Exit status:
  0   success
  2   invalid flags, arguments or metadata
  3   ref not found
  5   index failure

```
ak secrets annotate <ref> [flags]
```

### Examples

```
  ak secrets annotate ${REF} --provider stripe --environment production
  ak secrets annotate ${REF} --description "Billing webhook signing key" --tag billing,webhook
  ak secrets annotate ${REF} --tag ""          # clear the tags
  ak secrets annotate ${REF} --project api --json
```
