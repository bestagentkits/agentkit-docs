## ak activity

Inspect the local AgentKit activity feed

### Synopsis

Inspect the local activity event log used by the dashboard and CLI. Use list for a finite snapshot, tail for a live stream, and stats for skill usage aggregates.

### Examples

```
  ak activity list
  ak activity stats --window 7d
  ak activity tail
```
