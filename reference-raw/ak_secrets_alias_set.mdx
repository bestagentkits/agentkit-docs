## ak secrets alias set

Point NAME at a stored ref, replacing any earlier target

### Synopsis

Point NAME at REF. NAME must be an environment-variable name. REF need not be stored yet — a missing ref is a warning, not a refusal — so an alias can be set up before a sync brings the value in; until it is, a release through the alias is refused as a missing secret. Grants are checked against REF, never NAME.

Effects:
  Writes ~/.agentkit/secrets/aliases.json and reads the secrets index to warn about a target with no stored value. Never reads or writes a value.

Exit status:
  0   success
  2   invalid NAME or REF
  5   aliases file failure

```
ak secrets alias set <NAME> <REF> [flags]
```

### Examples

```
  ak secrets alias set CLAUDE_API_KEY CLAUDE_API_KEY_1   # pick account 1
  ak secrets alias set CLAUDE_API_KEY CLAUDE_API_KEY_2   # switch to account 2
```
