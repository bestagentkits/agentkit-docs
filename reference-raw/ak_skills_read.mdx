## ak skills read

Print one verified, non-executable file of a SkillX skill release

### Synopsis

Prints one file of a verified SkillX release as untrusted content; the path defaults to SKILL.md. Only files the signed manifest lists, and that are neither executable nor declared scripts, can be read; their sha256 is verified. Output is capped at 256 KiB with a truncation marker. Text mode writes a provenance banner to stderr and neutralizes terminal control sequences; --json wraps the content in an envelope marked untrusted with its provenance.

Effects:
  Read-only for skills, projects and configuration: never installs, executes, or requests an executable or declared-script file. Writes only the disposable, size-capped SkillX cache under AGENTKIT_HOME/cache/skillx. Requires AGENTKIT_SKILLX=1.

Exit status:
  0   success
  1   command failure: offline without verified cached data, or credential refused
  2   SkillX disabled, invalid flags or arguments, or a request the source does not support
  5   release or file not found
  7   release untrusted, revoked, yanked or quarantined, or a served manifest that fails an identity or tree check

```
ak skills read <@publisher/slug[@version][@sha256:<hex>]> [path] [flags]
```

### Examples

```
  ak skills read @publisher/review-guardrails@1.2.0
  ak skills read @publisher/review-guardrails@1.2.0 references/notes.md --json
```

### Options

```
  -h, --help             help for read
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --source string    Skill source to read from; only skillx is supported (default "skillx")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
