## ak projects

Manage the global AK project registry

### Synopsis

The project registry (~/.agentkit/projects.json) tracks every directory that `ak new` or `ak init` has bootstrapped. Use these subcommands to inspect and maintain the registry.

### Examples

```
  ak projects list
  ak projects list --json
  ak projects add ./myproj
  ak projects remove myproj
```

### Options

```
  -h, --help   help for projects
```
