## ak orchestrate output

Read bounded redacted job output by byte offset

### Synopsis

Read captured output without opening private invocation files. Capture is bounded and reports truncation.

Effects:
  Read-only; does not launch or signal processes.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate output <run-id> <job-id> [flags]
```

### Examples

```
  ak orchestrate output <run-id> <job-id> --json
  ak orchestrate output <run-id> <job-id> --offset 16384 --limit 4096
```

### Options

```
  -h, --help             help for output
      --json             Emit machine-readable JSON (implies --no-interactive)
      --limit int        Maximum bytes in this page (1-65536) (default 16384)
      --no-interactive   Disable interactive prompts (CI-safe)
      --offset int       Start at this byte offset
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
