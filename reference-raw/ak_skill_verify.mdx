## ak skill verify

Report the per-skill runtime env health (ok | missing | corrupt)

### Synopsis

Read the per-skill manifest at ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/.manifest.json and the live runtime block; report ok / missing / corrupt / unknown.

Effects:
  Read-only.

Output:
  With --json, stdout is one legacy unwrapped object &#123;"kit","skill","status"&#125; (no schema_version envelope); the dashboard consumes this shape. Exit 1 reports a missing or corrupt env after the object is written.

Exit status:
  0   success
  1   env is missing or corrupt, or verification failed
  2   invalid flags or arguments
  4   skill has no runtime block
  5   kit or skill not found

```
ak skill verify <kit>/<skill> [flags]
```

### Examples

```
  ak skill verify marketing/youtube
  ak skill verify engineer/web-testing --json
```
