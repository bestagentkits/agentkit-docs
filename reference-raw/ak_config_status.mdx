## ak config status

Show the running state of the dashboard server

### Synopsis

Read the dashboard server state file and report whether the server is running.

Effects:
  Read-only. Reads ~/.agentkit/dashboard-state.json.

Output:
  Exits 0 whether running or not. Check the running field in JSON output.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config status [flags]
```

### Examples

```
  ak config status
  ak config status --json
```
