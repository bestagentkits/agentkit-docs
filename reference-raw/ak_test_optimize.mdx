## ak test optimize

Explain impact-selected checks, optionally execute trusted commands

### Synopsis

Default is read-only planning. Supply a trusted manifest with group commands, ownership, full-suite groups and explicit policy mappings. Invalid optional evidence broadens; missing mandatory mappings block. --run executes repository code without a sandbox.

Effects:
  Planning reads Git and policy only. --run executes trusted commands in this repository; --output creates a local receipt. Semantic mode defaults off; an explicitly permitted mode may send compact facts and incur provider charges. Shadow never changes the effective plan.

Exit status:
  0   executable plan or all selected checks passed
  1   invalid inputs, blocked plan, failed or stale execution
  2   invalid arguments

```
ak test optimize [flags]
```

### Examples

```
  ak test optimize --base origin/dev --json
  ak test optimize --base origin/dev --run --json
```
