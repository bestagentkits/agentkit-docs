## ak commands remove

Remove an installed command

### Synopsis

Delete an installed command from the local environment. Idempotent: removing an absent command exits 0.

Effects:
  Removes command files from the local installation directory.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak commands remove <kit>/<command> [flags]
```

### Examples

```
  ak commands remove marketing/ckm-email
  ak commands remove marketing/ckm-email --json
```
