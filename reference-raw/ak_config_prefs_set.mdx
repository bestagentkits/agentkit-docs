## ak config prefs set

Set a supported preference in config.yaml

### Synopsis

Write a hook, journal, worktree, agent model, or semantic_decision preference. Semantic provider consent is user-scoped; project scope can only disable enabled or consumer flags. Provider credentials never belong in config.

Effects:
  Backs up then rewrites the selected scope's config.yaml file.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config prefs set <key> <value> [flags]
```

### Examples

```
  ak config prefs set hooks.simplify-gate false
  ak config prefs set semantic_decision.provider typesafe --scope user
  ak config prefs set semantic_decision.enabled true --scope user
  ak config prefs set worktree.root ../worktrees --scope project
```

### Options

```
  -h, --help             help for set
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
