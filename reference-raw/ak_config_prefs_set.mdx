## ak config prefs set

Set a supported preference in config.yaml

### Synopsis

Write a hook, journal, worktree, agent model, skill_routing, or semantic_decision preference. Semantic provider and skill cloud discovery consent are user-scoped; project scope can only disable them. Provider credentials never belong in config.

Effects:
  Backs up then rewrites the selected scope's config.yaml file.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config prefs set <key> <value> [flags]
```

### Examples

```
  ak config prefs set hooks.simplify-gate false
  ak config prefs set semantic_decision.provider cloudflare --scope user
  ak config prefs set skill_routing.cloud_discovery true
  ak config prefs set agent_models.codex.agents.kongming.reasoning_effort low --scope project
```

### Options

```
  -h, --help             help for set
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
