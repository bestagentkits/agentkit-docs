## ak config prefs set

Set a hook soft-preference in config.yaml

### Synopsis

What it does:
  Write a per-hook toggle into config.yaml: `set hooks.<name> false` makes that hook exit early at its next run without unregistering it from the harness. Only keys under `hooks.` may be set; the whole document is schema-checked before writing.

Who it's for:
  Anyone disabling a hook for this machine or this project without editing YAML by hand.

When to use it:
  Use it to turn a hook off (or back on) as a soft preference; the harness registration is unchanged.

Examples:
  ak config prefs set hooks.simplify-gate false            # disable for the user
  ak config prefs set hooks.simplify-gate true --scope project

What changes on disk:
  Backs up then rewrites the selected scope's config.yaml (project scaffolds it when absent).

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)
  1  the key is not allowed, the value is not a bool, or the result fails the schema

```
ak config prefs set <key> <true|false> [flags]
```

### Options

```
  -h, --help             help for set
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --scope string     which config to write: user (the AgentKit home) or project (.agentkit/config.yaml here) (default "user")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
