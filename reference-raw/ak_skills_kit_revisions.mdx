## ak skills kit revisions

List the SkillX revisions of a personal kit

### Synopsis

Lists every SkillX revision of the kit the personal kit's link records (or --kit), newest first, with its digest, state, origin and times, and marks the effective one. It also shows the kit's generation and visibility and the revision and generation this machine last saw, so a publish conflict can be checked before passing --expect-generation, or a revision chosen for sync --locked.

Effects:
  Read-only: reads the kit and its revision list from SkillX with the configured SkillX API key, and the link record AGENTKIT_HOME/state/personal-kits/&lt;name&gt;/skillx.json. Writes nothing, uploads nothing and never prompts. Needs SkillX on (after `ak update --ssot`, or AGENTKIT_SKILLX=1).

Exit status:
  0   listed
  1   command failure: SkillX offline, or the API key missing, scoped or expired
  2   SkillX or the overlay flag disabled, invalid flags, or no linked kit and no --kit
  5   the SkillX kit was not found

```
ak skills kit revisions <name> [--kit @<handle>/<name>] [flags]
```

### Examples

```
  ak skills kit revisions mine
  ak skills kit revisions mine --kit @alice/mine --json
```

### Options

```
  -h, --help             help for revisions
      --json             Emit machine-readable JSON (implies --no-interactive)
      --kit string       SkillX personal kit @<handle>/<name> (default: the linked one)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
