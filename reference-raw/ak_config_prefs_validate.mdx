## ak config prefs validate

Check config.yaml against the AgentKit schema

### Synopsis

Check user and project config files against the embedded AgentKit schema, reporting finding lines and severity.

Effects:
  Read-only. Reads and validates config files against schema.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config prefs validate [flags]
```

  ak config prefs validate --json
