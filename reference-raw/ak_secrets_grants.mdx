## ak secrets grants

List recorded agent grants

### Synopsis

Show every grant recorded under &#123;AGENTKIT_HOME&#125;/secrets/grants.json, which is ~/.agentkit unless AGENTKIT_HOME says otherwise. Grants whose expiry has passed are pruned as they are read, so what this prints is what would actually apply right now. A block outranks any allow on the same scope.

Effects:
  Reads the grants file. Rows that have already expired are compacted out of it as housekeeping, so a listing can rewrite the file even though it decides nothing. Stored secret values are not read.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak secrets grants [flags]
```

  ak secrets grants --json    # machine-readable
