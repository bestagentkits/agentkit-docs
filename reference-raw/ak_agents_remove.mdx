## ak agents remove

Remove an installed agent

### Synopsis

Delete an installed agent from the local environment. Idempotent: removing an absent agent exits 0.

Effects:
  Removes agent files from the local installation directory.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak agents remove <kit>/<agent> [flags]
```

### Examples

```
  ak agents remove engineer/researcher
  ak agents remove engineer/researcher --json
```
