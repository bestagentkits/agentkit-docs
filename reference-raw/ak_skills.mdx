## ak skills

Browse and install kit skills

### Synopsis

List, install, remove, show, search, and route individual skills from any kit. With AGENTKIT_SKILLX=1, resolve, inspect and read verified SkillX skill releases without installing them.

### Examples

```
  ak skills list
  ak skills install engineer/agent-browser
  ak skills show engineer/agent-browser
  ak skills inspect @publisher/review-guardrails
```

### Options

```
  -h, --help             help for skills
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
