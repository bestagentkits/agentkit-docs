## ak skill remove

Remove the per-skill runtime record (cache untouched)

### Synopsis

Delete ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/ -- the per-skill manifest record. Idempotent: a missing record is treated as success.

Effects:
  Removes ~/.agentkit/skills/&lt;kit&gt;/&lt;skill&gt;/. Shared package cache under ~/.agentkit/cache/&lt;hash&gt;/ is preserved.

Exit status:
  0   success
  2   invalid flags or arguments
  5   kit or skill not found

```
ak skill remove <kit>/<skill> [flags]
```

### Examples

```
  ak skill remove marketing/youtube
  ak skill remove engineer/web-testing
```

  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
