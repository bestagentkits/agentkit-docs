## ak policy

Inspect and apply project agent policies

### Synopsis

Read a project's executable agent policy: what it forbids, prefers and requires, where each rule came from, and what it answers for one operation. Rules compiled from instruction prose are proposals until adopted, and may only warn or rewrite — never block.

### Examples

```
  ak policy status
  ak policy check --path internal/gen/api.pb.go --json
  ak policy validate --fail-on-stale
```

### Options

```
  -h, --help             help for policy
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
