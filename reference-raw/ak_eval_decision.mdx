## ak eval decision

Compare an explicitly enabled semantic judgment with a legacy decision

### Synopsis

Run a shadow profile: domain-routing, fix-complexity, or orchestration-risk. Input contains consumer, compact state and legacy answers. User-scope semantic_decision consent and a credential are required for external evaluation. Invoking this command does not enable the provider.

Effects:
  When explicitly configured, sends bounded redacted facts to the provider and may incur charges. Prints local comparison only; never changes the legacy decision or persists input.

Exit status:
  0   completed or disabled; inspect status
  1   invalid input or enabled provider unavailable

```
ak eval decision <request.json|-> [flags]
```

### Examples

```
  ak eval decision request.json --json
  ak eval decision - --json
```
