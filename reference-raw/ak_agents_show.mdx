## ak agents show

Show agent details

### Synopsis

Print metadata, version, description, and requirements for a single agent.

Effects:
  Read-only. Reads metadata for the specified agent.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  5   agent not found

```
ak agents show <kit>/<agent> [flags]
```

### Examples

```
  ak agents show engineer/researcher
  ak agents show engineer/researcher --json
```
