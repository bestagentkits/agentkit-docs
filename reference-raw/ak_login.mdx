## ak login

Log in to AgentKit

### Synopsis

Authenticate with the AgentKit registry using a license key, email OTP, or API key.

Effects:
  Writes authentication session to ~/.agentkit/auth/session.json.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak login [flags]
```

### Examples

```
  ak login --email you@example.com
  ak login --license-key ak_license_...
  ak login --api-key ak_live_...
```
