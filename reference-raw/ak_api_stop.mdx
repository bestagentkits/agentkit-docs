## ak api stop

Stop the running API server daemon

### Synopsis

Send SIGTERM to the running AgentKit API server process. Succeeds (exit 0) if the server is not running.

Effects:
  Removes ~/.agentkit/api-state.json after a successful stop.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak api stop [flags]
```

### Examples

```
  ak api stop
  ak api stop --json
```
