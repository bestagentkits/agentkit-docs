## ak plan uncheck

Mark all checkboxes in a phase file as todo

### Synopsis

Toggle every '- [x]' checkbox in the named phase-NN-*.md file back to '- [ ]'. Already-unchecked boxes are left unchanged (idempotent).

Effects:
  Mutates the phase file in-place (atomic write).

Exit status:
  0   success
  1   phase file not found or I/O error
  2   invalid flags or arguments

```
ak plan uncheck <phase-file> [flags]
```

### Examples

```
  ak plan uncheck ./plans/my-plan/phase-01-setup.md
  ak plan uncheck ./plans/my-plan/phase-01-setup.md --json
```

### Options

```
  -h, --help             help for uncheck
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
