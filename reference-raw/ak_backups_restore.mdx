## ak backups restore

Restore AgentKit state from a snapshot

### Synopsis

Replay files from a rollback snapshot back to their original on-host paths. Top-level alias for `ak backups restore`. Prompts for confirmation on TTY unless --yes or --dry-run is passed.

Effects:
  Overwrites captured files, removes exact files recorded absent, and recursively removes only the AgentKit plugin directories explicitly listed in the confirmed plan. Accepts persisted bundle roots via --allow-root.

Exit status:
  0   success
  1   command failure
  2   invalid flags or arguments
  3   user cancelled
  4   lock held by another operation
  5   snapshot not found

```
ak backups restore [id] [flags]
```

### Examples

```
  ak backups restore <id>
  ak backups restore --latest
  ak backups restore --latest --yes
  ak backups restore <id> --allow-root /absolute/project --yes
```

### Options

```
      --allow-root stringArray   Explicitly authorize one absolute project bundle root (repeat for each printed recovery root)
      --dry-run                  Print the restore plan without modifying live files
  -h, --help                     help for restore
      --json                     Emit machine-readable JSON (implies --no-interactive)
      --latest                   Restore the most recently created snapshot (mutually exclusive with positional <id>)
      --no-interactive           Disable interactive prompts (CI-safe)
  -q, --quiet                    Suppress non-error output on stderr
  -V, --verbose                  Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                      Assume yes for all prompts
```
