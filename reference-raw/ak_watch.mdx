## ak watch

Watch a GitHub repository and auto-respond to issues

### Synopsis

Monitor a GitHub repository for new issues matching filter rules and automatically generate AI responses via `ak run`. State is persisted at ~/.agentkit/watch/&lt;repo&gt;/state.json so restarts never produce duplicate responses.

### Examples

```
  ak watch start owner/repo
  ak watch start owner/repo --daemon
  ak watch start owner/repo --label needs-response --max-per-hour 5
  ak watch dry-run owner/repo
```

### Options

```
  -h, --help             help for watch
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
```
