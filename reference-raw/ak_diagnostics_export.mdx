## ak diagnostics export

Export a redacted diagnostics bundle

### Synopsis

Runs local health checks, redacts secrets, emails, and local paths, and outputs a diagnostic support bundle.

Effects:
  Read-only. Emits redacted bundle to stdout.

Output:
  Emits redacted JSON diagnostics bundle to stdout.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak diagnostics export [flags]
```

### Examples

```
  ak diagnostics export
  ak diagnostics export --json
  ak diagnostics export --offline
```

### Options

```
  -h, --help             help for export
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
      --offline          Skip network-dependent doctor checks before export
  -q, --quiet            Suppress non-error output on stderr
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
