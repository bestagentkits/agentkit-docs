## ak licenses

Show licensed AgentKit kits

### Synopsis

List the kits the current account is licensed for. When the registry enforces update windows, each kit also shows its update window (state, updatesThrough, patch line, latest covered version, grant sources) and the renewal link. An ended window never stops installed versions.

Effects:
  Read-only. Reads ~/.agentkit/auth/session.json and queries registry.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak licenses [flags]
```

### Examples

```
  ak licenses
  ak licenses --json
```
