## ak agents list

List installed agents

### Synopsis

Enumerate agents installed on this machine, optionally filtered by kit or tag.

Effects:
  Read-only. Scans local installed agents.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak agents list [flags]
```

### Examples

```
  ak agents list
  ak agents list --kit engineer
  ak agents list --json
```
