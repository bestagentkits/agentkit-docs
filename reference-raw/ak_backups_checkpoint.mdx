## ak backups checkpoint

Capture a compressed, verifiable checkpoint of AgentKit and runtime state

### Synopsis

Stream the AgentKit home, every local runtime home and registered projects' agent configuration into one zstd-compressed tar under ~/.agentkit/backups/checkpoints/&lt;id&gt;/. The default lean scope leaves out runtime-owned session history, transcripts, telemetry and caches; --backup-sessions includes them. Secret files are sealed with an OS-protected key (DPAPI on Windows, an owner-only key file elsewhere), never stored in plaintext. SQLite databases are captured as consistent read-only snapshots. A disk estimate runs first and the capture is refused when space is short.

Effects:
  Writes one checkpoint directory and its key under ~/.agentkit/backups/checkpoints/ and applies checkpoint retention (the newest pre-upgrade checkpoint is always kept).

Output:
  With --json, prints one backups.checkpoint envelope (the checkpoint receipt).

Exit status:
  0   checkpoint created and verified
  1   capture failed or was refused (see remediation)
  2   invalid flags or arguments
  4   another checkpoint operation holds the lock

```
ak backups checkpoint [flags]
```

### Examples

```
  ak backups checkpoint
  ak backups checkpoint --backup-sessions --label before-experiment
  ak backups checkpoint --pre-upgrade --json
  ak backups checkpoint --pre-upgrade --state-version 2.9.1
```

### Options

```
      --backup-sessions        Also capture runtime session history, transcripts, telemetry and caches
  -h, --help                   help for checkpoint
      --json                   Emit machine-readable JSON (implies --no-interactive)
      --label string           Free-form label stored in the checkpoint manifest
      --no-interactive         Disable interactive prompts (CI-safe)
      --pre-upgrade            Mark the checkpoint as a pre-upgrade rollback source
      --project stringArray    Also capture this absolute project directory (repeatable)
  -q, --quiet                  Suppress non-error output on stderr
      --state-layout string    Captured state layout, legacy or ssot (default: detected from the AgentKit home); ak rollback --to v2 restores legacy checkpoints
      --state-version string   AgentKit CLI version that owns the captured state (default: the running version)
  -V, --verbose                Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                    Assume yes for all prompts
```
