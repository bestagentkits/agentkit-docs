## ak skills grants add

Grant one entrypoint of a verified skill tree, after printing its permissions

### Synopsis

Verifies the content-store entry, reads and validates its agentkit-exec.json from a read-only copy, binds the interpreter binary by path and sha256, and prints the full permission summary and an advisory script audit before recording the grant. With --container-image and --container-interpreter the grant instead binds the interpreter path inside a container image pinned by digest, for hosts whose only isolation backend is a container engine; ak never pulls that image. --dry-run prints the same and records nothing. Granting an identical key again is a no-op. Execution never prompts; this is the only way to grant.

Effects:
  Requires AGENTKIT_SKILL_EXEC_BROKER=1; with it off nothing is read or written. Never runs a script or an interpreter. add and revoke write only AGENTKIT_HOME/state/exec/grants.json, atomically and owner-only; add also makes and removes a verified read-only copy of the tree under AGENTKIT_HOME/tmp/exec-runs.

Exit status:
  0   success
  1   command failure, such as a busy grant store
  2   exec broker disabled, invalid flags or arguments, an invalid manifest, or an unavailable interpreter
  5   store entry, entrypoint or grant not found
  7   store entry fails verification, or the grant file is invalid

```
ak skills grants add <@publisher/slug@sha256:<hex>> [flags]
```

### Examples

```
  ak skills grants add @publisher/report@sha256:<hex> --entrypoint render --dry-run
  ak skills grants add @publisher/report@sha256:<hex> --entrypoint render --project . --json
  ak skills grants add @publisher/report@sha256:<hex> --entrypoint render --container-image docker.io/library/python@sha256:<hex> --container-interpreter /usr/local/bin/python3
```

### Options

```
      --container-image string         Bind the interpreter inside this image, pinned as name@sha256:<hex>
      --container-interpreter string   Absolute interpreter path inside --container-image
      --dry-run                        Print the permission summary without recording a grant
      --entrypoint string              Manifest entrypoint to grant (required)
  -h, --help                           help for add
      --json                           Emit machine-readable JSON (implies --no-interactive)
      --label string                   Short note stored with the grant
      --no-interactive                 Disable interactive prompts (CI-safe)
      --project string                 Scope the grant to this project root instead of everywhere
  -q, --quiet                          Suppress non-error output on stderr
  -V, --verbose                        Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                            Assume yes for all prompts
```
