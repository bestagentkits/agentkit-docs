## ak config stop

Stop the running dashboard daemon

### Synopsis

What it does:
  Send SIGTERM to the running AgentKit dashboard process. Reads the PID from ~/.agentkit/dashboard-state.json. Succeeds (exit 0) if the server is not running - idempotent and safe to call from scripts.

Who it's for:
  Both: power devs scripting lifecycle control and non-technical users via the dashboard.

When to use it:
  When you want to stop the dashboard server started with `ak config start`. Also useful in CI teardown or when switching ports.

Examples:
  ak config stop          # stop the running dashboard
  ak config stop --json   # emit stop confirmation as JSON

What changes on disk:
  Removes ~/.agentkit/dashboard-state.json after a successful stop.

Output modes:
  pretty   default on TTY (colors, ASCII markers)
  plain    auto when stdout piped or --no-interactive
  json     --json (single-object envelope, NDJSON-safe)

Exit codes:
  0  success
  1  runtime error
  2  invalid flags
  3  user-cancel (SIGINT, prompt-cancel)

```
ak config stop [flags]
```
