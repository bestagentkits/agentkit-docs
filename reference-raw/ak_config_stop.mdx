## ak config stop

Stop the running dashboard daemon

### Synopsis

Send SIGTERM to the running AgentKit dashboard process. Idempotent: exits 0 if already stopped.

Effects:
  Removes ~/.agentkit/dashboard-state.json after a successful stop.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak config stop [flags]
```

### Examples

```
  ak config stop
  ak config stop --json
```
