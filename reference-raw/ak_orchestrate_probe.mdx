## ak orchestrate probe

Discover installed coding runtimes without inference or authentication

### Synopsis

Inspect bounded version/help evidence and cache capability metadata. Installed binaries and recognized flags do not prove authentication, provider identity, model availability, or successful execution.

Effects:
  Executes version/help only and updates the owned metadata cache. Never installs runtimes or reads credential contents.

Exit status:
  0 success, 1 command failure, 2 invalid flags or arguments

```
ak orchestrate probe [flags]
```

### Examples

```
  ak orchestrate probe --json
  ak orchestrate probe --runtime pi,omp --refresh --json
```

### Options

```
  -h, --help               help for probe
      --json               Emit machine-readable JSON (implies --no-interactive)
      --no-interactive     Disable interactive prompts (CI-safe)
      --path stringArray   Explicit runtime=executable path (repeatable)
  -q, --quiet              Suppress non-error output on stderr
      --refresh            Refresh cached help metadata
      --runtime strings    Probe only these runtime identifiers
      --timeout duration   Maximum duration of each version/help probe (default 3s)
  -V, --verbose            Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes                Assume yes for all prompts
```
