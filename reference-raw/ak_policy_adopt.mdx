## ak policy adopt

Promote proposed rules into the active policy

### Synopsis

Copy named proposals from .agentkit/policy-candidates.yaml into .agentkit/policy.yaml, where the engine reads them. This is the explicit confirmation a generated rule needs, which is why naming nothing is an error rather than adopting everything. A proposal whose id already names an active rule is refused rather than overwriting a decision someone made by hand, and the adopted rule records the candidate and the instruction it came from.

Effects:
  Rewrites .agentkit/policy.yaml in canonical form: no existing rule is changed or removed, but the file is re-rendered from its rules, so ordering is normalised and comments are not kept.

Exit status:
  0   success
  1   no proposals, an unknown id, or a proposal that would overwrite an active rule
  2   invalid arguments
  4   the resulting document would conflict with itself, so nothing was written

```
ak policy adopt <candidate-id>... [flags]
```

### Examples

```
  ak policy adopt no-curl
  ak policy adopt --all --json
```
