## ak kit validate

Validate kit.yaml files in a kits directory

### Synopsis

Walk kits-dir, load each kit.yaml via the kit loader, and report any schema or inheritance violations.

Effects:
  Read-only. Validates kit definitions.

Exit status:
  0   all kits valid
  1   one or more violations found, or internal validator panic
  2   invalid flags or arguments

```
ak kit validate [kits-dir] [flags]
```

### Examples

```
  ak kit validate
  ak kit validate ./kits
  ak kit validate --json
```
