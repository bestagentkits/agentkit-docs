## ak orchestrate start

Launch a new orchestrated run from a job graph file

### Synopsis

Validate a job graph file, generate a fresh run ID, and spawn a detached worker. Always creates a new run.

Effects:
  Writes private state, bounded redacted logs, events, and a launch graph under AGENTKIT_HOME/orchestrate/runs/&lt;run-id&gt;/. The graph retains argv/env for recovery; keep credentials out of job specs and exclude invocation files from diagnostic exports.

Exit status:
  0   success
  1   job graph invalid, or the worker failed to reach readiness
  2   invalid flags or arguments
  6   unsupported platform (v1 requires darwin)

```
ak orchestrate start <job-graph.json> [flags]
```

### Examples

```
  ak orchestrate start jobs.json
  ak orchestrate start jobs.json --json
```
