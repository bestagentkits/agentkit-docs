## ak skills inspect

Inspect a verified SkillX skill release without fetching scripts

### Synopsis

Shows the verified manifest of a SkillX release: identity, version, digest, publisher, trust, files, declared scripts, exposure, compatibility and license. It reads SKILL.md for its frontmatter and never requests an executable or declared-script file.

Effects:
  Read-only for skills, projects and configuration: never installs, executes, or requests an executable or declared-script file. Writes only the disposable, size-capped SkillX cache under AGENTKIT_HOME/cache/skillx. Needs SkillX on: after `ak update --ssot`, or with AGENTKIT_SKILLX=1.

Exit status:
  0   success
  1   command failure: offline without verified cached data, or credential refused
  2   SkillX disabled, invalid flags or arguments, or a request the source does not support
  5   release or file not found
  7   release untrusted, revoked, yanked or quarantined, or a served manifest that fails an identity or tree check

```
ak skills inspect <@publisher/slug[@version][@sha256:<hex>]> [flags]
```

### Examples

```
  ak skills inspect @publisher/review-guardrails@1.2.0
  ak skills inspect @publisher/review-guardrails --json
```

### Options

```
  -h, --help             help for inspect
      --json             Emit machine-readable JSON (implies --no-interactive)
      --no-interactive   Disable interactive prompts (CI-safe)
  -q, --quiet            Suppress non-error output on stderr
      --source string    Skill source to read from; only skillx is supported (default "skillx")
  -V, --verbose          Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes              Assume yes for all prompts
```
