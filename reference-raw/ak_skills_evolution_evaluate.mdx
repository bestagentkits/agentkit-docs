## ak skills evolution evaluate

Re-run the offline evaluation of a recorded candidate

### Synopsis

Rebuilds the candidate on its base from --kits-dir (or the running personal kit composition it stacks on) and re-runs the offline, deterministic evaluation that ak skills improve --candidate ran when it recorded the candidate: the evidence tasks routed with no skill, the base and the candidate through the frozen lexical router, term coverage of the failures and corrections, the other skills of the kits directory as negative controls, and the functional and security checks. A base that moved since the candidate was recorded is evolve.base_changed. No model, network or script runs; a live model routing benchmark is a separate, optional check and never gates apply.

Effects:
  Reads the candidate record, the kits directory and the running personal kit records and skill store entries under the AgentKit home. Without --dry-run, replaces the evaluation slot of AGENTKIT_HOME/state/skill-evolve/candidates/&lt;id&gt;/candidate.json under the kit lifecycle lock. Never changes a skill, a kit or a personal kit; runs no script, model or network call.

Exit status:
  0   success, including a preview
  1   the candidate store, the personal kit or the skill store could not be read or written, or a record failed verification (store.corrupt)
  2   invalid flags or arguments, or an apply without the approval it needs (evolve.approval_required)
  4   another AgentKit operation holds the kit lifecycle lock (evolve.store_busy)
  5   no recorded candidate matches, or the skill's base cannot be resolved (evolve.base_unresolved)
  6   the base moved since the candidate was recorded (evolve.base_changed), the evaluation refuses the apply (evolve.apply_refused), or the personal kit does not hold what the apply or rollback expects (evolve.apply_conflict)
  7   redaction or the content gate could not be prepared (evolve.redaction_failed)

```
ak skills evolution evaluate <candidateId> [flags]
```

### Examples

```
  ak skills evolution evaluate 3f2a91c0
  ak skills evolution evaluate 3f2a91c0 --dry-run --json
```

### Options

```
      --dry-run           Print the evaluation; write nothing
  -h, --help              help for evaluate
      --json              Emit machine-readable JSON (implies --no-interactive)
      --kits-dir string   Foundation kits directory (default: $AGENTKIT_KITS_DIR or ./kits)
      --no-interactive    Disable interactive prompts (CI-safe)
  -q, --quiet             Suppress non-error output on stderr
  -V, --verbose           Extra diagnostic output on stderr (loses to --quiet)
  -y, --yes               Assume yes for all prompts
```
